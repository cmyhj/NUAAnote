### 四、简答题答案与解析

1. **答案**：
   Action通信机制的工作原理：
   - 客户端发送目标（Goal）到动作服务器
   - 动作服务器执行任务，定期发送反馈（Feedback）
   - 任务完成后，动作服务器发送结果（Result）
   - 客户端可以随时发送取消请求（Cancel）

   与Topic和Service的区别：
   - **Topic**：异步通信，无反馈，适用于连续数据流
   - **Service**：同步通信，有响应，适用于一次性请求
   - **Action**：异步通信，有反馈和结果，适用于长时间运行任务

   **解析**：Action是ROS中处理复杂任务的重要机制，理解其工作原理对于机器人控制至关重要。

2. **答案**：
   ROS功能包的结构：
   - **CMakeLists.txt**：CMake编译规则文件
   - **package.xml**：功能包元数据文件，声明依赖关系
   - **src/**：源代码目录（C++文件）
   - **scripts/**：脚本目录（Python文件）
   - **launch/**：launch文件目录
   - **msg/**：自定义消息类型定义
   - **srv/**：自定义服务类型定义
   - **action/**：自定义动作类型定义
   - **config/**：配置文件目录
   - **include/**：头文件目录（C++）

   **解析**：理解功能包结构是ROS开发的基础，考试中常出现填空题或选择题。

3. **答案**：
   QoS（Quality of Service）的作用：
   - 控制通信的可靠性、持久性、历史深度等
   - 适应不同的应用场景和网络条件

   不同QoS策略的应用场景：
   - **RELIABLE**：可靠传输，适用于关键数据（如控制指令）
   - **BEST_EFFORT**：尽力传输，适用于实时数据（如传感器数据）
   - **VOLATILE**：仅保存最新数据，适用于最新状态信息
   - **TRANSIENT_LOCAL**：保存历史数据，适用于后期加入的节点

   **解析**：QoS是ROS 2的重要特性，理解不同策略有助于设计高效的机器人系统。

4. **答案**：
   参数服务器的作用：
   - 存储全局配置参数
   - 允许节点在运行时读取和修改参数
   - 支持参数的动态调整

   在节点中使用参数：
   ```python
   # 获取参数
   rate = rospy.get_param('~rate', 10)  # 获取rate参数，默认值10
   
   # 设置参数
   rospy.set_param('~enabled', True)
   
   # 参数回调
   def parameter_callback(config):
       # 处理参数变化
       pass
   ```

   **解析**：参数服务器是ROS中管理配置的重要机制，考试中常出现编程题。

5. **答案**：
   Gazebo仿真器与ROS集成的基本步骤：
   1. 创建或下载机器人模型（URDF/SDF格式）
   2. 在launch文件中加载模型到Gazebo
   3. 启动Gazebo仿真器
   4. 连接ROS节点到仿真器
   5. 获取传感器数据（通过ROS话题）
   6. 发送控制指令（通过ROS话题）

   示例launch文件：
   ```xml
   <launch>
     <!-- 加载机器人模型 -->
     <param name="robot_description" textfile="$(find your_package)/urdf/robot.urdf" />
     
     <!-- 启动Gazebo -->
     <include file="$(find gazebo_ros)/launch/empty_world.launch">
       <arg name="world_name" value="$(find your_package)/worlds/robot.world"/>
     </include>
     
     <!-- 启动机器人状态发布 -->
     <node name="robot_state_publisher" pkg="robot_state_publisher" type="robot_state_publisher" />
   </launch>
   ```

   **解析**：Gazebo与ROS的集成是机器人仿真的重要内容，考试中常出现简答题或编程题。

**服务端节点：**
```python
#!/usr/bin/env python
"""
加法服务端节点
功能：接收两个整数请求，返回它们的和
"""
import rospy
from your_package.srv import AddTwoInts, AddTwoIntsResponse

def handle_add_two_ints(req):
    """
    服务回调函数
    参数：req - 请求对象，包含a和b两个整数
    返回：AddTwoIntsResponse对象，包含sum
    """
    rospy.loginfo(f"收到请求: {req.a} + {req.b}")
    
    # 计算结果
    result = req.a + req.b
    
    rospy.loginfo(f"返回结果: {result}")
    return AddTwoIntsResponse(result)

def add_two_ints_server():
    """加法服务端主函数"""
    # 初始化ROS节点
    rospy.init_node('add_two_ints_server')
    
    # 创建服务
    s = rospy.Service('add_two_ints', AddTwoInts, handle_add_two_ints)
    rospy.loginfo("准备接受加法请求...")
    
    # 保持节点运行
    rospy.spin()

if __name__ == '__main__':
    add_two_ints_server()
```

**客户端节点：**
```python
#!/usr/bin/env python
"""
加法客户端节点
功能：发送加法请求并打印结果
"""
import rospy
from your_package.srv import AddTwoInts

def add_two_ints_client(x, y):
    """
    客户端函数
    参数：x, y - 要相加的两个整数
    返回：相加的结果
    """
    # 等待服务可用
    rospy.wait_for_service('add_two_ints')
    
    try:
        # 创建服务代理
        add_two_ints = rospy.ServiceProxy('add_two_ints', AddTwoInts)
        
        # 发送请求
        resp = add_two_ints(x, y)
        return resp.sum
    except rospy.ServiceException as e:
        rospy.logerr(f"服务调用失败: {e}")
        return None

def main():
    """主函数"""
    # 初始化ROS节点
    rospy.init_node('add_two_ints_client')
    
    # 测试服务
    x = 5
    y = 3
    result = add_two_ints_client(x, y)
    
    if result is not None:
        rospy.loginfo(f"{x} + {y} = {result}")
    else:
        rospy.logerr("服务调用失败")

if __name__ == '__main__':
    main()
```

   **解析**：
   - 该程序实现了完整的ROS服务通信
   - 服务端接收请求并返回结果
   - 客户端发送请求并处理响应
   - 包含错误处理机制

2. **综合设计题参考答案：**

**节点关系图：**
```
[激光雷达] --(/scan)--> [避障节点] --(/cmd_vel)--> [机器人]
[机器人] --(/odom)--> [避障节点]
[避障节点] --(/visualization_marker)--> [rviz]
```

**节点代码框架：**
```python
#!/usr/bin/env python
"""
避障节点
功能：根据激光雷达数据控制机器人避障
"""
import rospy
from sensor_msgs.msg import LaserScan
from geometry_msgs.msg import Twist
from visualization_msgs.msg import Marker
import math

class ObstacleAvoidance:
    def __init__(self):
        """初始化避障节点"""
        # 初始化ROS节点
        rospy.init_node('obstacle_avoidance', anonymous=True)
        
        # 创建发布者，发布速度指令
        self.cmd_pub = rospy.Publisher('/cmd_vel', Twist, queue_size=10)
        
        # 创建发布者，发布可视化标记
        self.marker_pub = rospy.Publisher('/visualization_marker', Marker, queue_size=10)
        
        # 创建订阅者，订阅激光雷达数据
        self.scan_sub = rospy.Subscriber('/scan', LaserScan, self.scan_callback)
        
        # 避障参数
        self.safe_distance = 0.5  # 安全距离（米）
        self.linear_speed = 0.3   # 线速度（m/s）
        self.angular_speed = 0.5  # 角速度（rad/s）
        
        # 当前速度
        self.current_cmd = Twist()
        
    def scan_callback(self, msg):
        """
        激光雷达回调函数
        参数：msg - LaserScan消息，包含激光扫描数据
        """
        # 获取前方、左方、右方的距离
        front_distance = self.get_min_distance(msg, 0, 30)  # 前方±30度
        left_distance = self.get_min_distance(msg, 30, 90)  # 左方30-90度
        right_distance = self.get_min_distance(msg, -90, -30)  # 右方-90到-30度
        
        # 避障逻辑
        if front_distance < self.safe_distance:
            # 前方有障碍物，转向
            if left_distance > right_distance:
                # 左方空间更大，左转
                self.current_cmd.linear.x = 0.0
                self.current_cmd.angular.z = self.angular_speed
                rospy.loginfo("前方障碍物，左转")
            else:
                # 右方空间更大，右转
                self.current_cmd.linear.x = 0.0
                self.current_cmd.angular.z = -self.angular_speed
                rospy.loginfo("前方障碍物，右转")
        else:
            # 前方安全，直行
            self.current_cmd.linear.x = self.linear_speed
            self.current_cmd.angular.z = 0.0
        
        # 发布速度指令
        self.cmd_pub.publish(self.current_cmd)
        
        # 发布可视化标记
        self.publish_marker(front_distance)
    
    def get_min_distance(self, scan_msg, start_angle, end_angle):
        """
        获取指定角度范围内的最小距离
        参数：
            scan_msg - 激光扫描消息
            start_angle - 起始角度（度）
            end_angle - 结束角度（度）
        返回：最小距离（米）
        """
        # 将角度转换为索引
        angle_range = scan_msg.angle_max - scan_msg.angle_min
        start_index = int((start_angle * math.pi / 180 - scan_msg.angle_min) / angle_range * len(scan_msg.ranges))
        end_index = int((end_angle * math.pi / 180 - scan_msg.angle_min) / angle_range * len(scan_msg.ranges))
        
        # 确保索引有效
        start_index = max(0, start_index)
        end_index = min(len(scan_msg.ranges) - 1, end_index)
        
        # 获取最小距离
        distances = scan_msg.ranges[start_index:end_index+1]
        valid_distances = [d for d in distances if scan_msg.range_min <= d <= scan_msg.range_max]
        
        if valid_distances:
            return min(valid_distances)
        else:
            return scan_msg.range_max
    
    def publish_marker(self, distance):
        """
        发布可视化标记
        参数：distance - 前方障碍物距离
        """
        marker = Marker()
        marker.header.frame_id = "base_link"
        marker.header.stamp = rospy.Time.now()
        marker.ns = "obstacle"
        marker.id = 0
        marker.type = Marker.CYLINDER
        marker.action = Marker.ADD
        
        # 设置标记位置（前方）
        marker.pose.position.x = distance
        marker.pose.position.y = 0.0
        marker.pose.position.z = 0.5
        
        # 设置标记大小
        marker.scale.x = 0.1
        marker.scale.y = 0.1
        marker.scale.z = 1.0
        
        # 设置标记颜色
        marker.color.r = 1.0
        marker.color.g = 0.0
        marker.color.b = 0.0
        marker.color.a = 1.0
        
        # 设置标记生命周期
        marker.lifetime = rospy.Duration(0.5)
        
        self.marker_pub.publish(marker)
```
