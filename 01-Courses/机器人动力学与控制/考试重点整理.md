## 二、第二章：运动学基础

### 1. 自由度（高频填空题）
- 定义：独立坐标轴运动数目
- "反映机器人动作灵活的尺度是____"（答案：自由度）
- 老师原话："填空题说反映机器人动作灵活的尺度是"

### 2. 工作空间与奇异点
- **工作空间**：末端可达点的集合
- **奇异点**：雅可比矩阵不可逆，失去某些方向运动能力

### 3. 分辨率与精度
- **编程分辨率**：程序可设定的最小单位
- **控制分辨率**：传感器能检测的最小位移
- 编码器：$n$ 位 → $360°/2^n$

### 4. 速度递推公式
- **角速度递推**：${}^{i+1}\omega_{i+1} = {}^{i+1}_iR \cdot {}^{i}\omega_i + \dot{\theta}_{i+1}\hat{z}$
- **线速度递推**：${}^{i+1}v_{i+1} = {}^{i+1}_iR({}^{i}v_i + {}^{i}\omega_i \times {}^{i}P_{i+1})$

### 5. 雅可比矩阵
- 定义：$\dot{X} = J(\theta)\dot{\theta}$
- **力雅可比**：$\tau = J^T F$（与速度雅可比互为转置）
- **奇异位形**：$J$ 不可逆时的构型

### 6. 方向余弦矩阵
- **5个性质**：单位阵、3个独立参数、元素=代数余子式、逆=转置、行列式=1
- **列向量含义**：连体坐标系各轴在参考系中的投影

## 三、第三章：动力学

### 1. 牛顿-欧拉法
- **牛顿方程**：$\mathbf{F} = m\mathbf{a}_C$
- **欧拉方程**：$I_C\dot{\boldsymbol{\omega}} + \tilde{\boldsymbol{\omega}}I_C\boldsymbol{\omega} = \mathbf{M}_C$
- 递推方向：速度从内向外，力从外向内

### 2. 拉格朗日法
- **步骤**：选坐标→算动能势能→构造 $L=T-V$→代入方程
- **方程**：$\frac{d}{dt}\frac{\partial L}{\partial \dot{q}} - \frac{\partial L}{\partial q} = \tau$
- **好推难算 vs 难推好算**：拉格朗日=好推难算，牛顿欧拉=难推好算

### 3. 动力学方程
$$\tau = M(\theta)\ddot{\theta} + C(\theta,\dot{\theta})\dot{\theta} + g(\theta)$$
- $M(\theta)\ddot{\theta}$：惯性力项
- $C(\theta,\dot{\theta})\dot{\theta}$：离心力+科氏力
- $g(\theta)$：重力项

### 4. 惯量矩阵
- 主对角线：惯性矩（恒正）
- 非对角线：惯性积（可正可负可零）
- **平行轴定理**：$I_A = I_C + m[(P_c^TP_c)I_3 - P_cP_c^T]$

## 四、第四章：运动规划

### 1. 路径 vs 轨迹（填空题）
- **路径**：几何概念，不含时间
- **轨迹**：路径+速度+加速度+加加速度

### 2. 三次多项式（百分百必考）
$$\theta(t) = a_0 + a_1t + a_2t^2 + a_3t^3$$
- $a_0 = \theta_0$，$a_1 = 0$
- $a_2 = \frac{3(\theta_f-\theta_0)}{t_f^2}$
- $a_3 = -\frac{2(\theta_f-\theta_0)}{t_f^3}$
- 老师原话："记下来，必考的"、"再强调一遍，记下来这个公式背下来"
- 老师原话："该公式仅适用于初始角速度和终止角速度均为0的情况"
- 注意：期末考试会把时间改成0.5, 1, 1.5, 2, 2.5, 3这样的数值

### 3. 五次多项式
- 6个约束条件：位置、速度、加速度
- 末端加速度一般是负值（减速）
- 老师原话："你说让你背下来有点于心不忍，但是万一考到你要背不下来，但又有点太残酷了"
- 老师原话："5次多项式最重要的一个点，是在于把那个公式尽量能记住"

### 4. 抛物线拟合
- 先算加速度最小值：$a_{min} = 4(\theta_f-\theta_0)/t_f^2$
- 取整数后算 $t_b$
- 写出分段函数（三段）
- 老师原话："规划方法都有一个公式，记住它必考的，因为运动规划计算题总要要出一道题"

## 五、第五章：控制

### 1. 伺服驱动系统组成（必考填空）
- 驱动器、减速器、传动机构、传感器
- 老师原话："经常考填空题，驱动器的收费包括哪些部分？"

### 2. 交流伺服系统发展趋势（必考）
- **高效率、高性能、一体化、通用化、智能化**
- 老师原话："交流伺服系统发展趋势五个词必考"

### 3. 三个控制环
- 电流环（最快）→ 速度环 → 位置环（最慢）

### 4. 时不变/时变系统（每年必考）
- **时不变**：f不显含时间t
- **时变**：f显含时间t
- 老师原话："7.2的定义是每年必考的，就考你定义每年必考"

### 5. 李雅普诺夫稳定性（最后一道大题，10+分）
- **局部渐进稳定**：正定 + 负定
- **全局渐进稳定**：正定 + 正则 + 负定
- **拉萨尔原理**：半负定时，分析 $\dot{V}=0$ 的情况
- 老师原话："最后一道大题必考李雅普诺夫稳定性分析"

### 6. 必考例题（2012年起一直是A/B卷压轴）
非线性质量-弹簧-阻尼系统稳定性分析：
1. 构造李雅普诺夫函数（动能+势能）
2. 验证正定性和正则性
3. 求导得半负定
4. 分析 $\dot{V}=0$ 的情况
5. 应用拉萨尔原理
6. 结论：原点渐进稳定

- 老师原话："这道题背也得背下来"、"我再强调一下，这道题一定要会背也要背下来"
- 老师原话："这道题从2012年开始一直是A/B卷压轴题"
- 老师原话："给大家几分钟时间稍微记一下，所以整个的这一题背也得背下来好吧？"

### 7. 滑模控制
- **滑模面**：$s = \dot{e} + \lambda e$
- **可达性条件**：$s \cdot \dot{s} < 0$
- **颤振问题**：用饱和函数替代符号函数
