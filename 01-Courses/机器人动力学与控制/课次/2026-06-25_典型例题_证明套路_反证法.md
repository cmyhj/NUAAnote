## 关键概念
- **典型例题**: 非线性质量弹簧阻尼系统的稳定性分析，使用拉萨尔全局不变性原理。
- **证明套路**: 构造李亚普诺夫函数 → 求导 → 分析导数≤0 → 讨论等号成立条件 → 应用拉萨尔原理。
- **反证法**: 证明除原点外，不存在其他点能使系统稳定停留。
- **不变集分析**: 由V̇(x) = 0定义的集合中，最大不变集仅包含原点。
- **局部渐进稳定 vs 全局渐进稳定**: 取决于是否满足正则条件（当‖x‖→∞时，V(x)→∞）。
- **机器人位置控制**: 给定期望轨迹，设计控制器使实际轨迹渐进跟踪期望轨迹。
- **有限时间收敛**: 实际应用中需要快速收敛，而非等待时间趋向无穷。

## 要点详述
### 典型例题详解（100%会考）
**题目**: 质量弹簧阻尼系统 mẍ + b(ẋ)ẋ + k(x)x = 0，其中b(ẋ)和k(x)为非线性函数，满足：
- b(ẋ)·ẋ > 0（当ẋ ≠ 0）
- k(x)·x > 0（当x ≠ 0）
- 两者均位于第一、三象限的连续函数

**证明步骤**:
1. **构造李亚普诺夫函数**:
   - V(x, ẋ) = ½mẋ² + ∫₀ˣ k(s)ds
   - 第一项为动能，第二项为势能

2. **验证正定性和正则性**:
   - V(0, 0) = 0
   - 当(x, ẋ) ≠ (0, 0)时，V > 0（正定）
   - 当‖(x, ẋ)‖ → ∞时，V → ∞（正则）

3. **求导并分析**:
   - V̇ = mẋẍ + k(x)ẋ = ẋ[mẍ + k(x)x] = -b(ẋ)ẋ²
   - 由于b(ẋ)·ẋ > 0（当ẋ ≠ 0），所以V̇ ≤ 0（半负定）

4. **讨论等号成立条件**:
   - V̇ = 0 当且仅当 ẋ = 0
   - 当ẋ = 0时，代入系统方程得 mẍ = -k(x)x
   - 若x ≠ 0，则ẍ ≠ 0（因为k(x)·x > 0）
   - 这意味着系统不可能停留在x ≠ 0的任何一点（有加速度，会继续运动）

5. **应用拉萨尔全局不变性原理**:
   - 由V̇ = 0定义的集合Ω中，最大不变集M仅包含原点(0, 0)
   - 因此，系统原点是全局渐进稳定的

**关键点**:
- 必须证明"系统不可能停留在原点以外的任何一点"
- 使用反证法：假设存在x ≠ 0且ẋ = 0的点，推导出矛盾
- 每年考试都有同学写错符号或遗漏步骤，务必背熟

### 李亚普诺夫理论在论文中的应用
- 构造李亚普诺夫函数（通常包含误差项）
- 验证正定性、正则性
- 求导并分析导数符号
- 讨论等号成立条件
- 应用拉萨尔原理得出渐进稳定结论
- 最终可以定量计算出误差收敛的区域

### 机器人位置控制问题
- 目标：设计控制器使机器人实际轨迹渐进跟踪期望轨迹
- 动力学模型：M(q)q̈ + C(q, q̇)q̇ + G(q) = τ + d
  - M(q)：惯性矩阵
  - C(q, q̇)：科里奥利力和离心力
  - G(q)：重力项
  - d：外部干扰
- 控制器设计：PD控制 + 非线性补偿
- 稳定性分析：使用李亚普诺夫理论证明渐进稳定
- 实际应用：有限时间收敛（如终端滑模控制）
