## 关键概念
- **运动规划计算题**: 包括3次多项式、5次多项式、抛物线拟合三种题型，至少考一题。
- **非线性控制器设计**: 将控制力分解为两部分：一部分抵消非线性项，另一部分为线性反馈控制。
- **李亚普诺夫直接法**: 构造能量函数V(x)，若V(x) ≥ 0且V̇(x) ≤ 0，则系统稳定。
- **正定函数**: 连续标量函数V(x)，满足V(0) = 0，且对于x ≠ 0，V(x) > 0。
- **全局正定函数**: 正定函数的定义域从局部球域扩展到整个状态空间。
- **李亚普诺夫函数**: 一阶偏导连续的标量函数，正定且沿系统状态轨迹的导数半负定。
- **能量耗散**: 李亚普诺夫函数的物理含义是系统能量，其导数非正表示能量不增加。

### 非线性控制器设计复习
- 控制力f = α·f' + β，其中α = m，β = 非线性项。
- 目的：抵消非线性项，将系统简化为线性系统。
- 线性部分f'采用PD控制器：f' = Kp·e + Kv·ė。
- 开环控制：直接根据模型计算控制输入，无反馈修正，误差较大。
- 闭环控制：包含反馈环节，根据实际误差修正控制输入。

### 李亚普诺夫直接法
- 物理含义：构造类似能量的函数，若能量非负且变化率非正，则系统稳定。
- 质量弹簧阻尼系统示例：
  - 构造李亚普诺夫函数：V = ½mẋ² + ½kx⁴（动能 + 势能）。
  - 求导：V̇ = -bẋ² ≤ 0，说明系统能量耗散。
  - 分析：当ẋ = 0且x = 0时，系统静止在平衡点；否则能量持续耗散，最终趋向平衡点。
- 局限性：只能判断稳定性，无法给出误差的动态变化过程，最多能求出误差收敛的球域和到达时间。

### 正定函数与李亚普诺夫函数
- 正定函数定义：
  - 连续标量函数V(x)。
  - V(0) = 0。
  - 对于x ≠ 0，V(x) > 0（在某个球域内）。
- 全局正定函数：正定函数的定义域扩展到整个状态空间。
- 李亚普诺夫函数定义：
  - 一阶偏导连续的标量函数。
  - 正定（V(x) ≥ 0）。
  - 沿系统状态轨迹的导数半负定（V̇(x) ≤ 0）。
- 几何含义：李亚普诺夫函数总是向着更小方向运动。
