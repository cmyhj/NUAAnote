## 关键概念

- **五次多项式轨迹规划**: 在三次多项式基础上增加对加速度的约束，有6个约束条件（初始和终止的位置、速度、加速度），可获得更光滑的运动轨迹，对机械结构的冲击更小。

- **抛物线拟合轨迹规划**: 在直线插值的基础上，在起始段和终止段使用抛物线（恒定加速度）进行过渡，既保持了直线段的效率，又解决了加速度无穷大的问题。

- **拟合段(Blend Zone)**: 抛物线拟合中，起始加速段和终止减速段的抛物线区域。拟合段使用恒定加速度，使速度平滑变化。

- **直线段(Linear Segment)**: 抛物线拟合中，加速完成后进入的匀速运动阶段。

- **临界加速度**: 抛物线拟合中，当加速度取最小值时，直线段长度为零，加速段和减速段直接相连。此时抛物线拟合退化为单纯的加减速过程。

## 要点详述

### 一、五次多项式轨迹规划

**问题**：三次多项式的加速度是时间的线性函数，在起始和终止时刻存在突变（从0突然跳到某个值），产生柔性冲击。

**解决方案**：提高多项式阶数到五次，增加对加速度的约束。

**五次多项式方程**：
$$\theta(t) = a_0 + a_1 t + a_2 t^2 + a_3 t^3 + a_4 t^4 + a_5 t^5$$

**6个约束条件**：
1. θ(0) = θ₀（初始位置）
2. θ(t_f) = θ_f（终止位置）
3. θ̇(0) = 0（初始速度）
4. θ̇(t_f) = 0（终止速度）
5. θ̈(0) = θ̈₀（初始加速度约束）
6. θ̈(t_f) = θ̈_f（终止加速度约束）

**系数计算结果**：
- a₀ = θ₀
- a₁ = 0
- a₂ = θ̈₀/2
- a₃ = [20(θ_f - θ₀) - (8θ̇_f + 12θ̇₀)t_f - (3θ̈₀ - θ̈_f)t_f²] / (2t_f³)
- a₄ = [-30(θ_f - θ₀) + (14θ̇_f + 16θ̇₀)t_f + (3θ̈₀ - 2θ̈_f)t_f²] / (2t_f⁴)
- a₅ = [12(θ_f - θ₀) - 6(θ̇_f + θ̇₀)t_f + (θ̈_f - θ̈₀)t_f²] / (2t_f⁵)

**注意**：题目中说"加速度为5°/s²"，初始时刻加速度为+5°/s²，末端时刻加速度应为**-5°/s²**（减速），这是常见审题陷阱。

### 二、抛物线拟合轨迹规划

**线性插值的问题**：两点之间直线最短，效率最高，但起始和终止时刻加速度为无穷大，物理上无法实现。

**抛物线拟合的思路**：
- 中间大部分使用直线段（匀速运动，效率高）
- 起始段和终止段用抛物线过渡（恒定加速度，平滑改变速度）

**关键假设**：加速段和减速段完全对称（时间相同、加速度大小相同、方向相反）

**关键公式**：

中点速度公式：
$$\dot{\theta}_h = \frac{\theta_h - \theta_b}{t_h - t_b}$$

其中 θ_h 是中点对应的角度，θ_b 是拟合段终点的角度，t_h 是中点时间，t_b 是拟合段持续时间。

拟合段角度：
$$\theta_b = \theta_0 + \frac{1}{2} \ddot{\theta} t_b^2$$

加速度约束条件（以 t_b 为未知量的一元二次方程）：
$$t_b = \frac{t_f}{2} - \frac{1}{2}\sqrt{t_f^2 - \frac{4(\theta_f - \theta_0)}{\ddot{\theta}}}$$

**物理含义**：
- 加速度越大 → t_b 越小 → 直线段越长 → 效率越高
- 加速度取最小值时 → t_b = t_f/2 → 直线段消失
- 加速度无穷大时 → 回归简单的直线插值

**求解步骤**：
1. 先计算加速度最小值：a_min = 4(θ_f - θ₀)/t_f²
2. 选取一个大于 a_min 的整数加速度值
3. 代入公式计算 t_b
4. 写出分段函数（三段：加速段、匀速段、减速段）

**例题**：关节初始角15°，希望花3秒平滑运动到75°，用抛物线拟合规划。

解：
- θ₀ = 15°, θ_f = 75°, t_f = 3s
- a_min = 4×(75-15)/9 = 4×60/9 ≈ 26.67°/s²
- 取 a = 30°/s²（取整方便计算）
- t_b = 3/2 - ½√(9 - 4×60/30) = 1.5 - ½√(9-8) = 1.5 - 0.5 = 1s
- 分段函数：
  - 加速段 (0≤t≤1)：θ(t) = 15 + 15t²
  - 匀速段 (1≤t≤2)：θ(t) = 30 + 30(t-1)
  - 减速段 (2≤t≤3)：θ(t) = 75 - 15(3-t)²

### 三、第五章概述：关节驱动与线性控制

机器人系统的三个特性：
1. **多变量**：6轴机器人至少有6个关节角
2. **非线性**：运动学和动力学都是非线性的
3. **耦合**：运动学耦合和动力学耦合
