## 关键概念

- **非线性质量-弹簧-阻尼系统**: 弹簧力和阻尼力都是非线性函数的二阶系统。满足条件：x̃·B(x̃) > 0 且 x̃·K(x̃) > 0（x̃ ≠ 0），即弹簧力和阻尼力与位移/速度方向相同（位于一三象限）。

- **反证法在稳定性分析中的应用**: 假设系统能停留在原点外某点，通过代入系统方程发现矛盾（加速度≠0），从而证明只有原点是不变集。

- **最大不变集M**: 在V̇ = 0所确定的集合Ω中，最大的不变子集。如果M仅包含原点，则系统渐进稳定。

- **PD位置控制**: 对于机器人系统，设计控制律 τ = M(q)·(q̈_d + K_d·ė + K_p·e) + C(q,q̇)·q̇ + G(q)，使关节角q渐进跟踪期望轨迹q_d。

## 要点详述

### 一、必考例题详解（非线性弹簧系统稳定性分析）

**系统描述**：
$$m\ddot{x} + B(\dot{x})\dot{x} + K(x)x = 0$$

其中 B(ẋ) 和 K(x) 为非线性函数，满足：
- x̃·B(x̃) > 0（x̃ ≠ 0）
- x̃·K(x̃) > 0（x̃ ≠ 0）
- 两者均为一三象限的连续函数

**证明过程**（必背）：

**Step 1：构造李雅普诺夫函数**
$$V(x, \dot{x}) = \frac{1}{2}m\dot{x}^2 + \int_0^x K(\xi)\xi \, d\xi$$

物理含义：动能 + 势能

**Step 2：验证正定性**
- 第一项 ½mẋ² ≥ 0
- 第二项 ∫K(ξ)ξdξ ≥ 0（因为K(ξ)ξ > 0）
- 因此 V ≥ 0，且 V = 0 当且仅当 x = 0 且 ẋ = 0
- **正定性 ✓**

**Step 3：验证正则性**
- 当 ‖x, ẋ‖ → ∞ 时，V → ∞
- **正则性 ✓**

**Step 4：求导**
$$\dot{V} = m\dot{x}\ddot{x} + K(x)x\dot{x} = \dot{x}(m\ddot{x} + K(x)x)$$

将系统方程 mẍ = -B(ẋ)ẋ - K(x)x 代入：
$$\dot{V} = \dot{x}(-B(\dot{x})\dot{x}) = -B(\dot{x})\dot{x}^2$$

因为 B(ẋ) > 0（ẋ ≠ 0），所以 V̇ ≤ 0 → **半负定**

**Step 5：分析V̇ = 0的情况**

V̇ = 0 有两种可能：
1. ẋ = 0（速度为0）
2. B(ẋ) = 0（但这要求 ẋ = 0）

因此 V̇ = 0 当且仅当 ẋ = 0。

**Step 6：进一步分析（关键步骤）**

当 ẋ = 0 时，代入系统方程：
$$m\ddot{x} + K(x)x = 0$$

如果 x ≠ 0，则 K(x)x ≠ 0，因此 ẍ ≠ 0。

**物理含义**：当速度为0但位置不在原点时，加速度不为0，系统只是穿过速度为0的点，并不会停留。系统不可能稳定在原点外的任何一点。

**Step 7：应用拉萨尔不变性原理**

由 V̇ = 0 确定的集合 Ω = {(x, ẋ) | ẋ = 0}
Ω 内最大的不变集 M 只包含原点 (0, 0)

根据拉萨尔全局不变性原理，当 t → ∞ 时，所有解趋向于 M = {(0, 0)}

**结论**：系统原点是**局部渐进稳定**的。

**如果V(x)满足正则性**：则系统原点是**全局渐进稳定**的。

### 二、证明过程的关键细节

**为什么是小于等于（≤）而不是小于（<）？**
- 因为李雅普诺夫函数包含原点
- 在原点处 V̇ = 0（这是平衡点的正常状态）
- 条件中 x ≠ 0 或 ẋ ≠ 0 时 V̇ > 0

**为什么需要分析等号情况？**
- 半负定只能得出"稳定"的结论
- 要得到"渐进稳定"，必须排除系统停留在非平衡点的可能性
- 拉萨尔原理提供了从"半负定"到"渐进稳定"的桥梁

**反证法的核心逻辑**：
- 假设系统能停留在 x ≠ 0, ẋ = 0 的点
- 代入方程发现 ẍ ≠ 0
- 矛盾！因此系统不可能停留在该点

### 三、李雅普诺夫分析在实际研究中的应用

老师展示了自己发表的论文中的稳定性分析过程：
1. 构造李雅普诺夫函数（通常含有 ½ 因子）
2. 验证正定性、正则性
3. 沿系统轨迹求导
4. 分析导数的符号
5. 对等号情况进行单独分析
6. 引用拉萨尔原理得出结论

**要点**：即使在最新的控制领域顶刊论文中，稳定性分析的基本套路仍然是李雅普诺夫直接法 + 拉萨尔原理。

### 四、机器人PD位置控制简介

对于n自由度机器人：
$$M(q)\ddot{q} + C(q, \dot{q})\dot{q} + G(q) = \tau$$

PD控制律：
$$\tau = M(q)(\ddot{q}_d + K_d \dot{e} + K_p e) + C(q, \dot{q})\dot{q} + G(q)$$

其中 e = q_d - q 为跟踪误差。
