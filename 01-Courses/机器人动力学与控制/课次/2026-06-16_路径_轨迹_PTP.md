## 关键概念
- **路径(Path)**: 所有位置点的集合，只有几何属性，与时间无关（离散点）
- **轨迹(Trajectory)**: 每个自由度在运动过程中每时每刻的位置、速度、加速度（连续曲线，但仍无时间轴）
- **PTP (Point-to-Point)**: 点到点规划，只关心起始点和目标点，不关心中间路径
- **CP (Continuous Path)**: 连续轨迹规划，末端需要走一条连续曲线
- **关节空间**: 以各关节旋转角度为变量的空间
- **笛卡尔空间/任务空间**: 以末端执行器位置和姿态为变量的空间
- **重复定位精度**: 机器人多次到达同一点的精度，一般0.05mm以上
- **绝对定位精度**: 机器人到达空间中任意点的精度，一般0.5-1mm
- **奇异点**: 机器人关节转到某个角度时，加速度/速度趋于无穷大，难以继续运动
- **三次多项式**: θ(t) = a₀ + a₁t + a₂t² + a₃t³，最低满足二次可导要求

## 要点详述

### 1. 路径vs轨迹
- **路径**: 离散的位置点集合，只有几何属性，与时间无关
- **轨迹**: 连续的曲线，每时每刻都有位置信息，但仍无时间轴
- **轨迹规划**: 在轨迹基础上添加时间轴，得到位置、速度、加速度随时间的变化

### 2. PTP vs CP
- **PTP**: 只关心起点和终点，中间路径不重要（物料搬运、码垛、点焊）
- **CP**: 需要末端走连续曲线（焊接、喷涂、画线）
- 同一任务可能包含两种规划（如抓取是PTP，放入是CP）

### 3. 规划层级
- **高层规划**: 任务规划、动作规划（策略层面）、避障、避免奇异点
- **低层规划**: 末端轨迹规划（笛卡尔空间）+ 关节空间规划
- **底层控制**: 伺服控制，下发包含位置、速度、加速度信息的轨迹给电机

### 4. 运动规划与控制的关系
- 规划给出期望轨迹：qd（期望位置）、q̇d（期望速度）、q̈d（期望加速度）
- 控制算法（PID、滑模等）跟踪期望轨迹
- 误差 e = qd - q

### 5. 三次多项式轨迹规划
- **约束条件**（4个）：
  1. θ(0) = θ₀（初始位置）
  2. θ(tf) = θf（终止位置）
  3. θ̇(0) = 0（初始速度为0）
  4. θ̇(tf) = 0（终止速度为0）
- **求解结果**：
  - a₀ = θ₀
  - a₁ = 0
  - a₂ = 3(θf - θ₀)/tf²
  - a₃ = -2(θf - θ₀)/tf³
- **适用条件**: 初始和终止角速度均为0
- **必考**: 老师明确说100%会考，要求背下来

### 6. 课堂练习
- 题目：某关节5秒内从30°运动到15°，用三次多项式规划
- 答案：a₀=30, a₁=0, a₂=5.4, a₃=-0.72
- 加速度是时间的线性函数（一条直线）
