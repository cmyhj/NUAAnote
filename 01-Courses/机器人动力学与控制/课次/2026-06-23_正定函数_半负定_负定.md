## 关键概念

- **正定函数**: 连续标量函数 V(x) 满足 V(0) = 0 且在原点的某个邻域内，若 x ≠ 0 则 V(x) > 0。如果该条件在整个状态空间成立，则为全局正定。

- **半负定**: V̇(x) ≤ 0，即导数非正，允许等于0的情况。

- **负定**: V̇(x) < 0，即导数严格小于0（不包含等于0的情况）。

- **李雅普诺夫函数**: 满足以下条件的标量函数 V(x)：
  1. 一阶偏导连续
  2. 本身正定（V(x) > 0, x ≠ 0）
  3. 沿系统状态轨迹的导数半负定（V̇(x) ≤ 0）

### 二、非线性补偿控制复习

控制器设计的关键思路：
1. **前馈部分**：基于模型计算期望的力矩（M·ẍ_d）
2. **反馈部分**：PD控制器修正误差（K_p·e + K_d·ė）

完整的控制器：f = M·ẍ_d + K_d·(ẋ_d - ẋ) + K_p·(x_d - x)

### 三、李雅普诺夫直接法详解

**以非线性弹簧系统为例**（弹簧力 = kx³）：

系统方程：mẍ + bẋ + kx³ = 0

构造李雅普诺夫函数（动能+势能）：
$$V(x, \dot{x}) = \frac{1}{2}m\dot{x}^2 + \int_0^x k\xi^3 d\xi = \frac{1}{2}m\dot{x}^2 + \frac{k}{4}x^4$$

分析：
1. V(x, ẋ) ≥ 0（动能和势能都是非负的）→ **正定**
2. V̇ = mẋẍ + kx³ẋ = ẋ(mẍ + kx³) = ẋ(-bẋ) = -bẋ² ≤ 0 → **半负定**

等号成立时的分析（ẋ = 0 时）：
- 代入系统方程：mẍ + kx³ = 0
- 若 x ≠ 0，则 ẍ ≠ 0（加速度不为0），系统不会停留在该点
- 只有当 x = 0 且 ẋ = 0 时，系统才能稳定在平衡点

**结论**：系统在任何初始能量条件下，最终都将稳定在零点（平衡点）。

### 四、正定函数与李雅普诺夫函数

**正定函数定义**：
- 连续标量函数 V(x)
- V(0) = 0
- 在原点邻域内，x ≠ 0 时 V(x) > 0
- 如果在整个空间满足 → 全局正定

**李雅普诺夫函数定义**：
- 在某个球域 B_R 内
- 一阶偏导连续的标量函数
- 本身正定
- 沿系统状态轨迹的导数半负定（V̇ ≤ 0）

**几何理解**：李雅普诺夫函数像一个碗，系统状态像一个球，球总是向碗底（能量最低点）滚动。
