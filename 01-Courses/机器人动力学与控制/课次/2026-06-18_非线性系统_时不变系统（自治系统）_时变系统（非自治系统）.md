## 关键概念

- **非线性系统**: 可以用 ẋ = f(x, t) 描述的系统，其中f是非线性函数。机器人系统是典型的非线性系统。

- **时不变系统（自治系统）**: 描述方程中函数f不显含时间t的系统。系统的运动特性不随时间变化，与初始时刻无关。工业机械臂一般可视为时不变系统。

- **时变系统（非自治系统）**: 描述方程中函数f显含时间t的系统。系统的运动特性随时间变化，运动轨迹严重依赖于初始时刻。例：洒水车（质量随洒水减少）。

- **平衡点**: 系统状态x*满足 f(x*) = 0 的点。一旦系统到达平衡点，将永远保持在该点。

- **稳定（李雅普诺夫意义下）**: 对于任意 ε > 0，存在 δ > 0，当初始状态在 δ 球域内时，系统轨迹始终在 ε 球域内。

- **渐进稳定**: 在稳定的基础上，当时间趋向无穷时，系统轨迹趋向于平衡点。收敛速度一般为指数形式。

- **临界稳定**: 系统轨迹始终在某个有界球域内，但不趋向于平衡点。

- **不稳定**: 系统轨迹发散，不存在任何有界球域能包围所有轨迹。

- **李雅普诺夫直接法**: 通过构造一个类似能量函数的李雅普诺夫函数，判断系统稳定性的方法。若函数本身非负且其导数非正，则系统能量在耗散，系统稳定。

## 要点详述

### 一、时不变系统与时变系统

**定义7.2（必考）**：
- 若非线性系统 ẋ = f(x, t) 中的函数f**不显含时间t**，则该系统称为**时不变系统**（自治系统）
- 若f**显含时间t**，则称为**时变系统**（非自治系统）

**根本区别**：
- 时不变系统：独立于初始时刻，同样的输入产生同样的输出
- 时变系统：严重依赖初始时刻

**典型例子**：
- 洒水车：边洒水边运行，质量在减少 → 时变系统
- 燃油车：燃油消耗导致质量变化 → 严格来说是时变系统（但可忽略）
- 工业机械臂：参数基本不变 → 时不变系统

**重要说明**：严格来说任何系统都是时变的（如重力加速度、摩擦系数等都会微小变化），但工程中常做简化假设。

### 二、基于模型的非线性补偿控制

**思路**（控制器由两部分组成）：
1. **非线性补偿部分**：基于精确的非线性模型，将非线性项抵消
2. **线性PD控制部分**：对补偿后的线性系统使用PD控制器

**具体步骤**（以质量-弹簧-阻尼系统为例，弹簧力为非线性 kx³）：

1. 系统方程：mẍ + bẋ + kx³ = f

2. 设计控制器 f = α·f' + β，其中：
   - α = m（质量）
   - β = bẋ + kx³（非线性项打包）

3. 代入后得到：mẍ = m·f'，即 ẍ = f'（单位质量线性系统）

4. 引入PD控制器：f' = ẍ_d + K_d·(ẋ_d - ẋ) + K_p·(x_d - x)

5. 误差方程：ë + K_d·ė + K_p·e = 0

6. 选择合适的 K_p 和 K_d，可使误差收敛（临界阻尼、过阻尼或欠阻尼）

**开环控制 vs 闭环控制**：
- 开环：直接用模型计算力矩输入，无反馈，误差会累积
- 闭环：有误差反馈修正，可抑制扰动和模型误差

### 三、李雅普诺夫稳定性理论

**间接法**：求解线性系统的微分方程来判定稳定性。对非线性系统无法使用（非线性系统没有拉普拉斯变换）。

**直接法**：构造李雅普诺夫函数（类似能量函数），不需要求解微分方程。

**直接法的物理含义**：
- 一个系统的能量如果随时间在耗散（导数非正），那么系统终将回到能量最低点（平衡点）
- 不论初始状态如何，只要能量持续减少，系统必趋于稳定

**三种稳定性的直观理解**：
- **渐进稳定**：像减肥一样，体重持续下降（180→170→160...）
- **临界稳定**：体重维持在某个值不变（稳定的胖，190斤一直190斤）
- **不稳定**：体重持续增长，没有上限

**线性系统的稳定性特征**：
- 渐进稳定 → 总是指数收敛
- 不稳定 → 总是发散
