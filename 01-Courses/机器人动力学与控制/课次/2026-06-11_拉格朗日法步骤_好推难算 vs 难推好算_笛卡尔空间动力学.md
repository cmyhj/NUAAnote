## 关键概念
- **拉格朗日法步骤**: ①选取坐标系/广义坐标/广义力 → ②求动能T和势能V → ③构造L=T-V → ④代入拉格朗日方程
- **好推难算 vs 难推好算**: 拉格朗日法推导简单但计算繁琐；牛顿-欧拉法推导复杂但递推计算高效
- **笛卡尔空间动力学**: 通过雅可比矩阵将末端力转换到关节空间（τ = JᵀF），奇异点处某些量趋于无穷大
- **粘性摩擦**: f = v·θ̇（与速度成正比）
- **库伦摩擦**: f = c·sgn(θ̇)（符号函数，与速度方向有关）
- **Striebeck摩擦**: 更复杂的摩擦模型，考虑润滑等因素
- **位置相关摩擦**: f(θ,θ̇)，齿轮偏心导致摩擦随关节位置变化
- **欧拉法数值积分**: 最简单的数值积分方法，精度不高但易于编程
- **龙格-库塔法**: 4步法（k1→k2→k3→k4），精度比欧拉法高数倍

## 要点详述

### 1. 拉格朗日法完整步骤
1. 选取坐标系，定义广义坐标（关节角θ）和广义力（关节扭矩τ）
2. 求各连杆的动能T（平动+转动）和势能V（重力势能mgh）
3. 构造拉格朗日函数 L = T - V
4. 代入拉格朗日方程求解

### 2. 动能和势能计算要点
- 动能必须写成关于θ和θ̇的函数形式，才能求偏导
- 先将位置(x,y)表示为θ的函数，再求导得速度
- 动能 = Σ(1/2 mᵢvᵢ² + 1/2 ωᵢᵀIᵢωᵢ)
- 势能 = Σmᵢghᵢ，重力加速度和质心位置要在同一坐标系中表示

### 3. 笛卡尔空间动力学
- 关节空间：τ = M(θ)θ̈ + C(θ,θ̇)θ̇ + g(θ)
- 笛卡尔空间：F = Mₓẍ + Vₓ + Gₓ
- 力变换：τ = JᵀF（力雅可比矩阵是速度雅可比矩阵的转置）
- 加速度变换：需要对雅可比矩阵再求一次导
- 奇异点问题：雅可比矩阵不可逆时，某些量趋于无穷大

### 4. 摩擦力模型
- **粘性摩擦**: 最简单，f = v·θ̇
- **库伦摩擦**: f = c·sgn(θ̇)，静摩擦≠动摩擦
- **组合模型**: 粘性+库伦一起考虑
- **更复杂模型**: Striebeck摩擦、LuGre摩擦、位置相关摩擦等
- 摩擦力可达驱动力矩的1/4，不可忽略
- 摩擦模型会随时间变化（磨损、润滑状态改变）

### 5. 动力学方程扩充
- 基本方程：τ = Mθ̈ + Cθ̇ + g
- 加摩擦力：+ F(θ,θ̇)
- 加末端负载力：+ JᵀFₑₙd
- 关节弹性力、间隙等也可考虑

### 6. 欧拉法数值积分
- 时间步长Δt：通常取10⁻³秒（1毫秒）
- 初始条件：t₀时刻的θ和θ̇已知
- 迭代公式：θ̇(t+Δt) = θ̇(t) + θ̈(t)·Δt，θ(t+Δt) = θ(t) + θ̇(t)·Δt
- 精度不高，但思想简单

### 7. 龙格-库塔法
- 4步法：k1→k2→k3→k4，每步计算不同时间点的函数值
- 精度比欧拉法高数倍，同样步长下更接近真实值
- 是工程中最常用的数值积分方法之一
