## 关键概念
- **控制环路周期**: 电流环（微秒级）→ 速度环（2倍电流环周期）→ 位置环（2倍速度环周期）→ 轨迹规划（毫秒级）→ 人机交互（20~100毫秒）。
- **时不变系统**: 非线性系统ẋ = f(x, t)中的函数f不显含时间t，也称为自治系统。
- **时变系统**: 函数f显含时间t，也称为非自治系统。
- **线性化处理**: 在平衡点附近对非线性系统进行线性近似，但仅适用于小范围运动。
- **基于模型的非线性控制器**: 将控制力f分解为两部分：一部分抵消非线性项（基于精确模型），另一部分为线性反馈控制（如PD控制）。
- **PD控制器**: f = Kp·e + Kv·ė，其中e为误差，ė为误差导数。
- **开环控制**: 根据模型直接计算控制输入，无反馈修正。
- **闭环控制**: 包含反馈环节，根据实际误差修正控制输入。
- **李亚普诺夫稳定性**: 系统偏离平衡状态后自动恢复到原状态的能力。
- **平衡点**: 系统状态x*满足f(x*) = 0，一旦到达则保持不变。
- **渐进稳定**: 系统轨迹随时间趋向于平衡点，收敛速度一般为指数形式。
- **临界稳定**: 系统轨迹在某个有界区域内波动，但不趋向于平衡点。
- **不稳定**: 系统轨迹发散，不存在有界区域能包围所有轨迹。
- **全局渐进稳定**: 对于任意初始状态，系统轨迹都趋向于平衡点。
- **李亚普诺夫直接法**: 构造能量函数V(x)，若其导数V̇(x) ≤ 0，则系统稳定；若V̇(x) < 0，则系统渐进稳定。

## 要点详述
### 控制环路采样周期
- 电流环：控制周期最短，一般为微秒级（几十微秒）。
- 速度环：采样周期约为电流环的2倍。
- 位置环：采样周期约为速度环的2倍。
- 轨迹规划：周期约为毫秒级（1kHz左右）。
- 人机交互：周期约为20~100毫秒（10~50Hz）。

### 时不变系统与时变系统
- 时不变系统（自治系统）：非线性系统ẋ = f(x, t)中的函数f不显含时间t。系统特性不随时间变化，与初始时刻无关。
- 时变系统（非自治系统）：函数f显含时间t。系统特性随时间变化，运动轨迹依赖于初始时刻。
- 举例：洒水车（质量随时间减少）是时变系统；工业机械臂（忽略负载变化）通常可视为时不变系统。
- 注意：严格来说，任何系统都是时变的，但工程上常做简化假设。

### 非线性系统的线性化处理
- 线性控制方法仅在平衡点附近的小范围内有效，扩大应用范围会带来较大误差。
- 非线性控制方法不需要简化处理，控制性能更好。
- 基于模型的非线性控制器设计思路：
  1. 将控制力f分解为f = α·f' + β。
  2. 令α = m，β = 非线性项（如摩擦力、弹簧非线性力等），抵消系统非线性。
  3. 剩余线性部分f'采用PD控制器设计：f' = Kp·e + Kv·ė。
- 稳定性分析：将控制器代入动力学方程，得到误差动态方程，通过选择合适的Kp、Kv保证误差收敛。

### 李亚普诺夫稳定性理论
- 稳定性定义：对于任意ε > 0，存在δ > 0，当初始状态‖x(0)‖ < δ时，对于所有时间t，总有‖x(t)‖ < ε。
- 渐进稳定：系统轨迹随时间趋向于平衡点，收敛速度一般为指数形式。
- 临界稳定：系统轨迹在某个有界区域内波动，但不趋向于平衡点。
- 不稳定：系统轨迹发散，不存在有界区域能包围所有轨迹。
- 全局渐进稳定：对于任意初始状态，系统轨迹都趋向于平衡点。
- 李亚普诺夫两类方法：
  - 间接法：求解线性系统的微分方程来判定稳定性，但非线性系统难以求解。
  - 直接法：构造李亚普诺夫函数V(x)（类似能量函数），若V̇(x) ≤ 0，则系统稳定；若V̇(x) < 0，则系统渐进稳定。
- 应用示例：对于质量弹簧阻尼系统，构造能量函数V = ½mẋ² + ½kx⁴，求导得V̇ = -bẋ² ≤ 0，说明系统能量耗散，最终稳定在平衡点。
