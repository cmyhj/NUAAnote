## 关键概念
- **五次多项式**: θ(t) = a₀ + a₁t + a₂t² + a₃t³ + a₄t⁴ + a₅t⁵，6个未知数需6个约束
- **六约束条件**: 初始/终止位置、初始/终止速度、初始/终止加速度
- **抛物线拟合线性插值**: 加速段(抛物线) + 匀速段(直线) + 减速段(抛物线)
- **恒定加速度**: 加速段和减速段使用相同的加速度大小，方向相反
- **加速度约束**: a ≥ 4(θf-θ₀)/T²（否则无法完成规划）
- **分段函数**: 抛物线拟合的结果是分段函数（三段）
- **多变量**: 6轴机器人至少有6个关节角
- **非线性**: 运动学和动力学都是非线性的
- **耦合**: 运动学耦合和动力学耦合

## 要点详述

### 1. 五次多项式轨迹规划
- **优势**: 加速度也是光滑曲线，冲击更小，对机械结构更友好
- **6个约束条件**：
  1. θ(0) = θ₀（初始位置）
  2. θ(tf) = θf（终止位置）
  3. θ̇(0) = 0（初始速度）
  4. θ̇(tf) = 0（终止速度）
  5. θ̈(0) = θ̈₀（初始加速度）
  6. θ̈(tf) = θ̈f（终止加速度）
- **求解**: 6个方程6个未知数，可解出a₀到a₅
- **注意**: 终止加速度一般是负值（减速），题目可能不写正负号需要自己判断

### 2. 抛物线拟合线性插值
- **问题**: 线性插值（直接拉直线）在起点和终点加速度无穷大，物理上不可实现
- **解决方案**: 在起点和终点用抛物线（恒定加速度）过渡
- **三段结构**:
  - 第一段（0≤t≤tb）: 抛物线加速，θ = θ₀ + ½at²
  - 第二段（tb≤t≤tf-tb）: 匀速直线运动，θ = θb + v(t-tb)
  - 第三段（tf-tb≤t≤tf）: 抛物线减速，θ = θf - ½a(tf-t)²
- **对称性**: 加速段和减速段时间相等、加速度大小相等

### 3. 关键公式推导
- **中点速度**: v = (θh - θb)/(th - tb)
- **加速段终点**: θb = θ₀ + ½atb²
- **加速度约束**: a ≥ 4(θf - θ₀)/T²
  - 等号时：tb = T/2，直线段消失，只剩加速+减速
  - 加速度越大，直线段越长，但对机械和能量要求越高
- **求解步骤**:
  1. 计算最小加速度 amin = 4(θf-θ₀)/T²
  2. 选择加速度 a ≥ amin（取整数便于计算）
  3. 计算 tb = T/2 - √(T²a/4 - (θf-θ₀))/a
  4. 写出分段函数

### 4. 课堂练习详解
- **题目**: 关节从15°到75°，3秒，用抛物线拟合规划
- **计算过程**:
  1. amin = 4×(75-15)/3² = 4×60/9 ≈ 26.67°/s²
  2. 取 a = 30°/s²
  3. tb = 3/2 - √(9×30/4 - 60)/30 = 1.5 - √(67.5-60)/30 = 1.5 - √7.5/30 ≈ 1秒
  4. 分段函数:
     - 0≤t≤1: θ = 15 + 15t²
     - 1≤t≤2: θ = 30 + 30(t-1)
     - 2≤t≤3: θ = 75 - 15(3-t)²

### 5. 三种规划方法对比
| 方法 | 约束条件 | 优点 | 缺点 |
|------|----------|------|------|
| 三次多项式 | 4个（位置+速度） | 简单 | 加速度不光滑 |
| 五次多项式 | 6个（位置+速度+加速度） | 加速度光滑 | 公式复杂 |
| 抛物线拟合 | 加速度约束 | 物理意义明确 | 分段函数 |
