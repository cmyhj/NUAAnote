## 关键概念

- **方向余弦矩阵的正交性**: 方向余弦矩阵R是正交矩阵，满足 R^(-1) = R^T，即 R · R^T = I（单位矩阵）。因此行列式 |R| = ±1，对于旋转矩阵必为 +1。这是验证方向余弦矩阵是否正确的关键判据。

- **同一向量在不同坐标系中的投影**: 空间中任意向量r是客观存在的物理量，不依赖于坐标系。但在描述其大小和方向时必须投影到某个坐标系上。若r在a系中的坐标列为r_a，在b系中为r_b，则两者满足 r_a = R_ab · r_b。

- **方向余弦矩阵的链式法则**: 三个坐标系A、B、C之间，R_ac = R_ab · R_bc。下标顺序遵循"首尾相接"原则，中间坐标系B是过渡系。注意下标顺序不可搞混，研究生编程中常见错误就是搞反了R_ab和R_ba。

- **特征值为1的物理意义**: 任意方向余弦矩阵必有一个特征值λ=1，对应的特征向量即为旋转轴。这意味着任意两次坐标系之间的旋转都可以用绕某一固定轴的一次转动来等效描述，这就是"轴角法"的理论基础。

- **任意转动与简单转动**: 三次相继的绕坐标轴转动（任意转动）可以找到一个等效的转轴和转角，使得绕该轴一次转动就得到相同的姿态变化。转轴方向由特征向量确定，转角需要进一步计算。

- **基本旋转矩阵**: 绕单一坐标轴（x/y/z）旋转角度θ得到的3×3矩阵。Rx(θ)保持x轴不变，Ry(θ)保持y轴不变，Rz(θ)保持z轴不变。是构成任意旋转的基础构件。

- **齐次变换矩阵**: 4×4矩阵T，将姿态矩阵R（3×3）和位置向量p（3×1）组合在一起，统一描述两个坐标系之间的位置和姿态关系。左上3×3为方向余弦矩阵，右上3×1为位置向量，最后一行补[0 0 0 1]。

- **矢量三角形法则**: p^a_OA = p^a_OB + R_ab · p^b_BP，即某点在a系中的位置 = b系原点在a系中的位置 + 旋转后该点在b系中的位置。核心原则：同一个向量必须投影到同一个坐标系后才能相加。

## 要点详述

### 1. 方向余弦矩阵性质5——正交性与行列式

方向余弦矩阵R是正交矩阵，证明如下：
- 由定义，R^(-1) = R^T（逆等于转置）
- 因此 R · R^T = I（满足正交矩阵定义）
- 对两边取行列式：|R · R^T| = |I| = 1
- 由行列式乘法性质：|R| · |R^T| = |R|² = 1
- 所以 |R| = ±1，对于旋转矩阵取 +1

**考试提示**: 如果让你填写一个方向余弦矩阵，算出的行列式不为1则必然错误。

### 2. 方向余弦矩阵性质6——向量投影转换

**核心公式**: r_a = R_ab · r_b

**推导过程**:
- 设向量r在b系中投影为r_b = [r_x, r_y, r_z]^T（3×1列向量）
- 向量r可表示为：r = (CB)^T · r_b = r_x·e_1b + r_y·e_2b + r_z·e_3b
- 其中CB = [e_1b, e_2b, e_3b] 是b系的单位向量按列排成的矩阵
- 利用方向余弦矩阵定义：e_b = R_ab · e_a（b系单位向量用a系表示）
- 通过矩阵结合律和转置性质：(CB)^T · r_b = (R_ab · CA)^T · r_b = CA^T · R_ab^T · r_b
- 最终得到：r_a = R_ab · r_b

**物理理解**: 就像一个人站在公交车上，车内的人和地面的人观察同一个人，看到的结果不同，但两者之间有确定的转换关系。

### 3. 方向余弦矩阵性质7——三坐标系链式转换

**公式**: R_ac = R_ab · R_bc

- 三个坐标系A、B、C，从C系到A系的旋转可以通过B系作为过渡
- 先由C到B（R_bc），再由B到A（R_ab）
- **记忆方法**: 下标遵循"首尾相接"，即A→B→C的顺序，中间字母B消掉
- **常见错误**: 搞混R_ab和R_ba，研究生编程中因此出错的案例很多

### 4. 方向余弦矩阵性质8——特征值为1（重点/难点）

**定理**: 任意方向余弦矩阵R_ba必有一个特征值λ=1。

**证明思路**:
- 特征值定义：det(R - λI) = 0
- 令λ=1，需证明 det(R - I) = 0
- 展开行列式，利用代数余子式性质：
  - 对角元素 a_11, a_22, a_33 的代数余子式分别为 A_11, A_22, A_33
  - 方向余弦矩阵性质：任意元素等于其代数余子式（a_ij = A_ij）
  - 因此 (a_11 - 1)·A_11 + a_12·A_12 + a_13·A_13 = ... = 0
- 利用行列式为1的性质，最终 det(R - I) = 0 成立

**物理意义**:
- 存在一个实数特征向量r，满足 R·r = r
- 该向量r在旋转前后不变——它就是旋转轴
- **几何解释**: 绕某轴旋转时，该轴上的向量不会改变方向。就像绕大拇指旋转，大拇指所指的方向始终不变。
- **重要结论**: 任意两个坐标系之间的旋转都可以用绕某一固定轴的一次转动来等效描述

**轴角法概念引入**:
- 任意转动（三次绕坐标轴转动）→ 可等效为一次绕特殊轴的转动
- 只需确定：转轴方向（特征向量）+ 转角大小（需额外计算）
- 这就是后续课程要讲的"轴角法"描述姿态的基础

### 5. 基本旋转矩阵

绕单一坐标轴旋转角度θ的旋转矩阵：

**绕x轴旋转 Rx(θ)**:
```
[1    0      0   ]
[0  cosθ  -sinθ]
[0  sinθ   cosθ]
```

**绕y轴旋转 Ry(θ)**:
```
[ cosθ  0  sinθ]
[  0    1    0  ]
[-sinθ  0  cosθ]
```

**绕z轴旋转 Rz(θ)**:
```
[cosθ  -sinθ  0]
[sinθ   cosθ  0]
[ 0      0    1]
```

**记忆技巧**:
- 绕哪个轴旋转，该轴对应的行和列保持为 [0, 1, 0] 的单位矩阵结构
- 对角线元素为 cosθ
- 反对角线元素为 ±sinθ（注意正负号的位置）
- xyz 对应 123，哪个轴旋转则该轴编号对应的行列为单位向量
- **推荐方法**: 画坐标系图，标出旋转后的轴投影，自然得到矩阵元素

### 6. 坐标变换与齐次变换矩阵

**矢量三角形法则**:
- 两个坐标系原点不重合时，需要考虑位置偏移
- p^a_OA = p^a_OB + R_ab · p^b_BP
- 物理意义：点P在a系中的位置 = b系原点在a系中的位置 + P点在b系中的位置（经旋转转换到a系）

**齐次变换矩阵 T**:
```
T_ab = [R_ab  | p^a_OB]
       [0 0 0 |   1   ]
```
- 左上3×3：方向余弦矩阵R_ab（描述姿态）
- 右上3×1：b系原点在a系中的位置向量p^a_OB（描述位置）
- 最后一行：[0, 0, 0, 1]（齐次化）
- 统一描述两个坐标系之间的位置和姿态关系

**核心原则**:
- 向量必须在同一坐标系投影后才能相加
- 观察方便的量直接用，不方便的量用方向余弦矩阵转换

### 7. 逆变换

**已知**: T_ba（b系相对于a系的齐次变换矩阵）
**求**: T_ab（a系相对于b系的齐次变换矩阵）

**代数方法**:
- R_ab = R_ba^T（方向余弦矩阵的转置等于逆）
- p^b_OA = -R_ba^T · p^b_BO = -R_ab · p^b_BO

**几何方法（推荐）**:
- 利用矢量三角形法则：OA向量 = -OB向量
- 两边同时向b系投影
- p^b_OA = -R_ba · p^a_OB
- 两边左乘 R_ab = R_ba^T
- 得到 p^b_OA = -R_ab · p^a_OB

**考试建议**: 两种方法都可以，但推荐几何方法更简洁直观。
