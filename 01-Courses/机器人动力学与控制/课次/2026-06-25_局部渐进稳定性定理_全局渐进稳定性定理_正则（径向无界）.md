## 关键概念

- **局部渐进稳定性定理**: 若在某个球域B_r内，存在李雅普诺夫函数V(x)满足：①V(x)正定 ②V̇(x)负定，则平衡点是局部渐进稳定的。

- **全局渐进稳定性定理**: 若在整个状态空间内，存在V(x)满足：①V(x)正定 ②V(x)正则（径向无界）③V̇(x)负定，则平衡点是全局渐进稳定的。

- **正则（径向无界）**: 当 ‖x‖ → ∞ 时，V(x) → ∞。这是一个附加条件，用于保证全局稳定性。

- **不变集**: 一个子集G被称为系统的不变集，是指从G内某一点出发的系统状态轨迹始终保持在G内。平衡点是最典型的不变集。

- **拉萨尔全局不变性原理**: 若V(x)正则且V̇(x) ≤ 0，设Ω为所有满足V̇(x) = 0的点的集合，M为Ω内最大的不变集，则当t→∞时，所有解趋向于M。若M仅包含原点，则系统全局渐进稳定。

- **充分条件**: 李雅普诺夫稳定性定理只是系统稳定的充分条件，不是充要条件。即：能找到满足条件的V(x)→系统稳定，但系统稳定不一定能找到满足条件的V(x)。

## 要点详述

### 一、李雅普诺夫函数条件回顾

李雅普诺夫函数需满足：
1. **一阶偏导连续**：至少一阶可导，不能是分段函数
2. **标量函数**：只有大小，没有方向
3. **正定**：V(0) = 0，x ≠ 0 时 V(x) > 0
4. **导数半负定**：沿系统轨迹求导后 V̇(x) ≤ 0

### 二、局部稳定性定理

**条件**：
- 在球域 B_r 内
- V(x) 局部正定
- V̇(x) 局部半负定

**结论**：平衡点稳定（Lyapunov意义下）

**如果导数从半负定加强为负定**：
- 结论从"稳定"升级为"**渐进稳定**"
- 关键区别：稳定只保证轨迹不发散，渐进稳定保证轨迹趋向平衡点

**稳定vs渐进稳定的区别**：
- 稳定：体重维持在190斤不变（稳定的胖）
- 渐进稳定：体重持续下降180→170→160...（一直在减肥）

### 三、全局渐进稳定性定理

**三个条件**：
1. **正定**：V(x) > 0（x ≠ 0）
2. **正则**：‖x‖ → ∞ 时 V(x) → ∞
3. **负定**：V̇(x) < 0

**结论**：平衡点全局渐进稳定

**与局部定理的区别**：
- 局部：限制在某个球域内
- 全局：对任意初始状态都成立

### 四、拉萨尔全局不变性原理

**应用场景**：当只能证明 V̇(x) ≤ 0（半负定），而想得到渐进稳定的结论时使用。

**原理**：
- 设 Ω = {x | V̇(x) = 0}（导数等于0的所有点）
- 设 M 为 Ω 内最大的不变集
- 当 t → ∞ 时，所有解趋向于 M

**关键操作**：
1. 把 V̇(x) = 0 的情况单独拿出来分析
2. 证明除了平衡点外，没有任何其他点能使系统稳定停留
3. 因此 M 仅包含原点
4. 根据拉萨尔原理，系统渐进稳定

**证明技巧（反证法）**：
- 假设存在 x ≠ 0 使 V̇ = 0
- 代入系统方程，发现此时加速度 ≠ 0
- 说明系统只是穿过该点，不会停留
- 因此只有原点（x = 0, ẋ = 0）是不变集

### 五、例题：向量线性系统的稳定性判断

**系统**：ẋ = Ax，A为n×n矩阵

**步骤**：
1. 构造李雅普诺夫函数：V(x) = ½xᵀx（前加½是为了求导后消去系数）
2. 验证V(x)连续且正定
3. 求导：V̇ = xᵀẋ = xᵀAx
4. 若A正定 → V̇ 半负定
5. 分析等号情况：只有x = 0时V̇ = 0
6. 引用拉萨尔不变性原理 → 系统渐进稳定
