## 关键概念

- **变换方程**: 通过坐标系形成闭环，构造矩阵方程，利用已知的坐标系变换矩阵间接求解未知的变换矩阵。避免直接测量难以观测的变换关系。

- **方位角法**: 将刚体的任意转动用三个独立的相继转动来描述，三个转角称为方位角。包括RPY角（固定坐标系）和欧拉角（动坐标系）两种形式。

- **RPY角**: Roll-Pitch-Yaw角，绕固定坐标系的三次相继转动。分别对应偏航角（Yaw）、俯仰角（Pitch）、回转角（Roll），常用于描述飞机姿态。

- **欧拉角**: 绕动坐标系的三次相继转动。与RPY角的区别在于旋转坐标系的选择，但最终姿态相同（相反顺序绕运动坐标轴）。

- **24种表示方法**: 相邻两次旋转轴不重复的条件下，固定坐标系有12种组合，动坐标系也有12种，共24种姿态表示方法。

- **轴角法**: 基于方向余弦矩阵的性质，任意转动可用绕某一轴转动一个角度来描述。用单位向量λ和转角θ两个参数确定。

- **欧拉公式**: R(λ,θ) = I cosθ + λ̃ sinθ + λλᵀ(1-cosθ)，将轴角法与方向余弦矩阵联系起来的公式。

- **反对称矩阵λ̃**: 由向量λ扩展而成的3×3矩阵，满足λ̃ᵢⱼ = -λ̃ⱼᵢ。向量叉乘可表示为矩阵乘法：a×b = ã·b。

- **欧拉四元素法**: 用四个参数（三个投影分量+一个cos(θ/2)）描述姿态，避免方向余弦矩阵的奇异性问题。

- **超球**: 欧拉四元素满足约束ε₁²+ε₂²+ε₃²+ε₄²=1，形成四维超球面，反映了姿态空间的几何本质。

- **双变量反正切函数**: atan2(y,x)，在Matlab中直接调用，用于从方向余弦矩阵反求转角，能正确处理象限问题。

## 要点详述

### 1. 变换方程

变换方程是通过坐标系闭环构造的矩阵方程。假设有坐标系u、a、b、c、d形成闭环，d相对于u的变换矩阵可以沿两条路径计算：

- 路径1：T_ud = T_ua · T_ad
- 路径2：T_ud = T_ub · T_bc · T_cd

两条路径等价，可构造方程求解未知变换矩阵。实际应用中，可以架设激光跟踪仪等测量设备，通过已知的变换矩阵间接求解难以直接测量的变换关系。

### 2. RPY角（固定角法）

RPY角是绕固定坐标系的三次相继转动：
- 第一次绕x轴转γ角（回转角）
- 第二次绕y轴转β角（俯仰角）
- 第三次绕z轴转α角（偏航角）

方向余弦矩阵为：R = Rz(α)·Ry(β)·Rx(γ)，每个R都是基本旋转矩阵。反求转角时，通过观察法利用矩阵元素的代数关系消元求解。

### 3. 欧拉角（动坐标系法）

欧拉角是绕动坐标系的三次相继转动，每次都是绕当前动坐标系的轴旋转。与RPY角的关键区别：
- RPY角：绕固定坐标系旋转
- 欧拉角：绕动坐标系旋转

重要性质：三次绕固定轴旋转的姿态，可以相反顺序绕运动坐标轴得到相同结果。

### 4. 24种姿态表示

在相邻两次旋转轴不重复的约束下：
- 第一次旋转：3种选择（x、y、z）
- 第二次旋转：2种选择（不能与第一次相同）
- 第三次旋转：2种选择（不能与第二次相同）
- 共3×2×2 = 12种组合

固定坐标系12种 + 动坐标系12种 = 24种表示方法。虽然表示不同，但许多最终得到的姿态是相同的。

### 5. 轴角法与欧拉公式

轴角法基于方向余弦矩阵的特征值性质：λ=1对应的特征向量就是旋转轴。任意转动可分解为绕某一轴转动一个角度。

**欧拉公式**：
```
R(λ,θ) = I cosθ + λ̃ sinθ + λλᵀ(1-cosθ)
```

其中：
- I：单位矩阵
- λ̃：反对称矩阵
- λ：单位旋转轴向量
- θ：旋转角

**反对称矩阵的性质**：
- 由向量λ扩展而成
- 满足λ̃ᵢⱼ = -λ̃ⱼᵢ
- 向量叉乘：a×b = ã·b

### 6. 欧拉四元素法

**动机**：方向余弦矩阵在某些姿态下会出现奇异性（R奇异），导致计算崩溃。欧拉四元素法不存在此问题。

**定义**：
- 欧拉矢量：ε = λ sin(θ/2)
- 四个标量：ε₁, ε₂, ε₃, ε₄
- 其中ε₁, ε₂, ε₃是欧拉矢量在坐标轴上的投影
- ε₄ = cos(θ/2)

**约束方程**：ε₁² + ε₂² + ε₃² + ε₄² = 1

**几何意义**：
- x² + y² = 1 表示圆
- x² + y² + z² = 1 表示球
- ε₁² + ε₂² + ε₃² + ε₄² = 1 表示超球（四维球面）

这解释了为什么姿态难以描述——它存在于四维超球面上，超出人类直观的空间感知。

### 7. 坐标系标准命名

| 坐标系 | 符号 | 说明 |
|--------|------|------|
| 基坐标系 | G (Base) | 固定在机器人基座上，也称0系或连杆0系 |
| 腕部坐标系 | W (Wrist) | 法兰盘坐标系，也称坐标系n |
| 工具坐标系 | T (Tool) | 依据腕部坐标系定义，与具体工具相关 |
| 目标坐标系 | G (Goal) | 任务目标位置的坐标系 |
| 工作台坐标系 | S (Station) | 也称世界坐标系、任务坐标系、通用坐标系 |

**任务完成条件**：工具坐标系T与目标坐标系G重合，即T相对于S等于G相对于S。
