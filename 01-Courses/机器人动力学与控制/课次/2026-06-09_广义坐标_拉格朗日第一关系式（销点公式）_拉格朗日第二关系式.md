## 关键概念
- **广义坐标**: 可以完全确定系统位置的彼此独立的参数，通常等于系统自由度数
- **拉格朗日第一关系式（销点公式）**: ∂ṙ/∂q̇ = ∂r/∂q（速度对广义速度偏导 = 位移对广义坐标偏导）
- **拉格朗日第二关系式**: d/dt(∂r/∂q) = ∂ṙ/∂q（微分和变分次序可交换）
- **虚功原理**: 约束力与虚位移方向始终垂直，约束力做功为0
- **广义力 Qⱼ**: 外力与位移矢量对广义坐标偏导的点积之和
- **拉格朗日函数 L**: L = T - V（动能减势能）
- **第二类拉格朗日方程**: d/dt(∂L/∂q̇) - ∂L/∂q = τ
- **质量矩阵 M(θ)**: 正定对称矩阵，保证动力学方程有唯一稳定解
- **动力学方程**: τ = M(θ)θ̈ + C(θ,θ̇)θ̇ + g(θ)

## 要点详述

### 1. 牛顿-欧拉法例题结果
- 两连杆简化后（惯量矩阵为0）的动力学方程：τ₁和τ₂分别关于θ₁、θ₂、θ̇₁、θ̇₂的函数
- 如果给定τ₁(t)和τ₂(t)，需要通过编程数值积分求解θ随时间的变化
- 牛顿-欧拉法适合编程，拉格朗日法不依赖前面矢量力学知识

### 2. 广义坐标
- 定义：完全确定系统位置的最少独立参数
- 例子：质点被曲面φ(x,y,z)=0约束 → 广义坐标只需2个（如x和y）
- 机器人系统：广义坐标 = 关节角 θ₁ 到 θₙ（彼此独立）

### 3. 两个预备公式
- **第一关系式（销点公式）**: ∂ṙ/∂q̇ = ∂r/∂q，含义是"销掉点"（去掉求导符号）
- **第二关系式**: 微分和变分次序可交换，d/dt(∂r/∂q) = ∂ṙ/∂q

### 4. 第二类拉格朗日方程推导
- 基于虚功原理：对每个质点列 Fᵢ = mᵢaᵢ，两边乘以 ∂rᵢ/∂qⱼ
- 约束力做功为0（与虚位移垂直），只剩下主动力
- 经过数学变换得到：d/dt(∂T/∂q̇) - ∂T/∂q = Qⱼ
- 保守力时：Qⱼ = -∂V/∂q，构造 L = T - V

### 5. 机器人系统应用
- 广义坐标：关节角 θ₁ 到 θₙ
- 广义力：关节扭矩 τ₁ 到 τₙ
- 动能：T = Σ(1/2 mᵢ vᵢ² + 1/2 ωᵢᵀ Iᵢ ωᵢ)，可写成 1/2 θ̇ᵀ M(θ) θ̇
- 势能：V = Σ mᵢ g hᵢ（重力势能）
- 质量矩阵正定对称：动能 > 0 保证正定性，能量是标量保证对称性

### 6. 动力学方程各项含义
- **M(θ)θ̈**: 惯性力项（与加速度相关）
- **C(θ,θ̇)θ̇**: 包含离心力（θ̇²项）和科氏力（θᵢθⱼ交叉项）
- **g(θ)**: 重力矢量

### 7. 简化条件
- 连杆质量较轻 → 可忽略重力项
- 关节速度不大 → 可忽略离心力和科氏力
- 关节加速度不大 → 可忽略惯性力项
