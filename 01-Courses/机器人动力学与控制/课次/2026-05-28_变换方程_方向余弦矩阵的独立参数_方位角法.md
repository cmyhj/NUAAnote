## 关键概念

- **变换方程**: 通过多个坐标系形成闭环，利用变换矩阵链乘相等的关系，间接求出难以直接测量的坐标系间变换矩阵。实际应用中常借助激光跟踪仪等外部测量设备。

- **方向余弦矩阵的独立参数**: 3×3方向余弦矩阵有9个元素，但由于正交约束（模为1、两两正交），只有3个独立参数。凯莱公式从数学上证明了这一点。

- **方位角法**: 用三个独立的相继转角描述刚体任意转动。根据旋转轴是固定坐标系还是动坐标系，分为固定角法和欧拉角法。

- **RPY角（固定角）**: Roll-Pitch-Yaw，绕固定坐标系依次旋转。物理含义：偏航角（Yaw，绕Z）、俯仰角（Pitch，绕Y）、滚转角（Roll，绕X）。广泛用于飞控、机器人末端姿态描述。

- **欧拉角（proper Euler angles）**: 绕动坐标系依次旋转。与固定角的关键区别：固定轴旋转顺序与动轴旋转顺序相反时，得到相同姿态。

- **24种角表示法**: 相邻两次旋转轴不重复的前提下，固定轴有12种组合（如XYZ, XZY, XYX...），动轴也有12种，共24种。

- **轴角法**: 任意转动可等效为绕某一单位轴λ旋转角度θ。由方向余弦矩阵特征值λ=1对应的特征向量性质推导而来。

- **欧拉公式**: R(λ,θ) = I cosθ + λ̃ sinθ + λλᵀ(1-cosθ)，其中λ̃为反对称矩阵。这是万能公式，记住它可以推导出任意基本旋转矩阵。

- **反对称矩阵（波浪阵）**: 由向量λ = [λ₁, λ₂, λ₃]ᵀ扩展为3×3矩阵。叉乘可表示为矩阵乘法：a×b = ã·b。

- **欧拉四元素（Euler parameters）**: 由轴角法衍生，定义为ε₁₂₃ = λ sin(θ/2)（欧拉矢量投影），ε₄ = cos(θ/2)。满足约束ε₁²+ε₂²+ε₃²+ε₄²=1，独立变量仍为3个。

- **超球面（Hypersphere）**: 欧拉四元素的约束方程在四维空间中表示一个超球面，说明姿态空间的复杂性高于位置空间。

- **机器人标准坐标系**: G（基坐标系/Base）、W（腕坐标系/Wrist，法兰盘处）、T（工具坐标系/Tool）、O（目标坐标系/Object/Goal）、S（工作台坐标系/Station/Task/World）。

- **激光跟踪仪**: 高精度外部测量设备，用于标定各坐标系之间的位置关系，通过变换方程间接求解难以直接测量的变换矩阵。

## 要点详述

### 1. 变换方程的构造与应用

多个坐标系形成闭环时，沿不同路径求同一对坐标系间的变换矩阵，结果相等，由此构造方程。

例如坐标系U→A→D与U→B→C→D形成闭环，则：
$$T_U^D = T_U^A T_A^D = T_U^B T_B^C T_C^D$$

**实际应用**：当某个变换矩阵（如C相对于B）不便直接测量时，可架设激光跟踪仪等外部观测设备，测量其他易观测的变换矩阵，通过闭环方程间接求解。这在飞机部件对接、机器人标定等场景中广泛应用。

### 2. 方向余弦矩阵与凯莱公式

方向余弦矩阵R有9个元素，但正交约束（RRᵀ = I）使其只有3个独立参数。线性代数中的**凯莱公式**从数学上证明了这一点：

$$R = (I - S)(I + S)^{-1}$$

其中S为反对称矩阵，只有3个独立元素。这说明任意3×3方向余弦矩阵可由3个参数唯一确定，因此可以用3个转角来描述姿态。

### 3. RPY角（固定角）

绕**固定坐标系**（静止不动）依次绕X、Y、Z轴旋转γ、β、α角：

$$R_{XYZ}(\alpha, \beta, \gamma) = R_z(\alpha) R_y(\beta) R_x(\gamma)$$

每个基本旋转矩阵都是之前课上讲过的"基本旋转矩阵"。物理含义：
- **α（Yaw/偏航角）**: 绕Z轴旋转
- **β（Pitch/俯仰角）**: 绕Y轴旋转  
- **γ（Roll/滚转角）**: 绕X轴旋转

飞控领域惯用此描述飞机姿态。

### 4. RPY反求（已知R求α, β, γ）

采用**观察法**：从已知的方向余弦矩阵元素中，通过加减乘除消去不需要的未知量。

- 求α：利用n_y/n_x相除消去β，再取反正切
- 求γ：类似方法消去其他未知量
- 求β：需先算√(n_x² + n_y²)，再取反正切

使用**双变量反正切函数** `atan2(y, x)` 代替普通反正切，可正确处理象限。

**奇异性**：β = ±90°时发生退化（万向锁），此时规定α = 0，γ按公式单独求解。

### 5. 欧拉角（动坐标系角）

绕**动坐标系**依次旋转。关键区别与联系：

> **定理**：三次绕固定轴旋转的姿态，可以**相反顺序**绕运动坐标轴得到相同结果。

例如：固定轴按X→Y→Z旋转 = 动轴按Z→Y→X旋转，最终姿态相同。

左乘/右乘的顺序要注意：固定轴从左乘，动轴从右乘。

### 6. 24种角表示法

三次相继转动描述姿态时，**相邻两次旋转轴不能重复**：
- 可能的组合：3 × 2 × 2 = 12种（如XYZ, XZY, XYX, XZX, YXZ, YZX, YXY, YZY, ZXY, ZYX, ZXZ, ZYZ）
- 固定轴12种 + 动轴12种 = 共24种
- 最终姿态会有重复，但理论上有24种表示方式

### 7. 轴角法与欧拉公式

基于方向余弦矩阵的性质：特征值λ=1对应的特征向量即为旋转轴。任意转动可等效为绕单位轴λ旋转角度θ。

**欧拉公式**（核心公式，建议记住）：

$$R(\lambda, \theta) = I\cos\theta + \tilde{\lambda}\sin\theta + \lambda\lambda^T(1 - \cos\theta)$$

其中：
- I：3×3单位矩阵
- λ̃：反对称矩阵（波浪阵），由单位向量λ = [λ₁, λ₂, λ₃]ᵀ扩展而成
- λλᵀ：3×3矩阵（列向量乘行向量）

**反对称矩阵构造**：
$$\tilde{\lambda} = \begin{bmatrix} 0 & -\lambda_3 & \lambda_2 \\ \lambda_3 & 0 & -\lambda_1 \\ -\lambda_2 & \lambda_1 & 0 \end{bmatrix}$$

**叉乘的矩阵形式**：向量a叉乘向量b可表示为 ã·b（反对称矩阵乘列向量），避免了行列式计算。

**万能性**：记住了欧拉公式，任意基本旋转矩阵都可直接写出。例如绕x轴旋转θ：λ = [1,0,0]ᵀ，代入公式即可得到R_x(θ)。

### 8. 欧拉四元素法

**引入动机**：方向余弦矩阵在某些姿态下可能接近奇异（行列式趋近0），导致程序崩溃。欧拉四元素法不存在此问题。

**定义**：
- 欧拉矢量：e = λ·sin(θ/2)
- 四个标量（欧拉参数）：
  - ε₁, ε₂, ε₃ = 欧拉矢量在坐标系三轴上的投影
  - ε₄ = cos(θ/2)

**约束方程**：ε₁² + ε₂² + ε₃² + ε₄² = 1

这是因为λ₁² + λ₂² + λ₃² = 1（单位向量），而sin²(θ/2) + cos²(θ/2) = 1。

**独立变量**：虽然有4个参数，但有1个约束方程，所以独立变量仍为3个。

**几何意义**：
- 2个独立变量约束为1 → 圆（一维球面）
- 3个独立变量约束为1 → 球（二维球面）
- 4个独立变量约束为1 → **超球面**（三维球面，无法直观想象）

这解释了为什么姿态比位置更难描述——姿态空间是高维的超球面。

### 9. 各方法之间的转换

**欧拉四元素 → 方向余弦矩阵**：有固定公式，编程中常用，一劳永逸。

**方向余弦矩阵 → 欧拉四元素**（反求）：观察法
- 先求ε₄：对角线元素相加得4ε₄²，开方除以2
- 再求ε₁, ε₂, ε₃：利用矩阵非对角元素之差除以4ε₄

**欧拉四元素 → 转轴转角**：
- θ = 2·arccos(ε₄) 或 2·arctan(√(ε₁²+ε₂²+ε₃²) / ε₄)
- λ = [ε₁, ε₂, ε₃]ᵀ / sin(θ/2)

这些转换在机器人编程中需要来回进行，建议写成通用函数块。

### 10. 机器人坐标系标准命名

| 坐标系 | 符号 | 说明 |
|--------|------|------|
| 基坐标系 | G (Base) | 固定在机械臂基座上，也称0系/连杆0系，通常静止不动 |
| 腕坐标系 | W (Wrist) | 法兰盘处，取Wrist首字母 |
| 工具坐标系 | T (Tool) | 安装在末端执行器上 |
| 目标坐标系 | O (Object/Goal) | 加工目标所在位置的坐标系 |
| 工台/世界坐标系 | S (Station/Task/World) | 根据任务建立，机器人运动在此坐标系中执行 |

**注意**：
- G坐标系不一定是固定的（如机器人装在移动小车上）
- S坐标系根据任务而定，不同任务可建立不同的S坐标系
- S坐标系相对于G坐标系的关系需要标定（常用激光跟踪仪）

**标定方法**：架设激光跟踪仪，建立测量坐标系，形成闭环（激光仪-G-S），利用变换方程求解S相对于G的变换矩阵。
