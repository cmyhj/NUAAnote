## 关键概念
- **李亚普诺夫函数条件**: 连续一阶偏导、标量函数、正定、沿系统轨迹导数半负定。
- **局部稳定性定理**: 若存在李亚普诺夫函数，则平衡点局部稳定。
- **渐进稳定**: 系统轨迹随时间趋向于平衡点，误差持续减小。
- **全局渐进稳定**: 对于任意初始状态，系统轨迹都趋向于平衡点，需满足三个条件：正定、正则、负定。
- **不变集**: 从该集合内出发的系统轨迹始终保持在该集合内。
- **推论7.1**: 若李亚普诺夫函数正定、导数半负定，且导数等于0的集合仅包含原点，则原点渐进稳定。
- **拉萨尔全局不变性原理**: 若李亚普诺夫函数正定、正则、导数半负定，且导数等于0的集合中最大不变集仅为原点，则系统全局渐进稳定。

### 李亚普诺夫函数的定义与条件
- 李亚普诺夫函数V(x)需满足：
  1. 连续一阶偏导（至少一阶可导）。
  2. 标量函数（只有大小，没有方向）。
  3. 正定：V(0) = 0，对于x ≠ 0，V(x) > 0。
  4. 沿系统状态轨迹的导数半负定：V̇(x) ≤ 0。
- 几何含义：V(x)总是向着更小方向运动（碗底）。

### 李亚普诺夫稳定性定理
- **局部稳定性定理**：
  - 条件：在某个球域Br内，V(x)局部正定，V̇(x)局部半负定。
  - 结论：平衡点局部稳定。
- **渐进稳定性**：
  - 条件：V(x)局部正定，V̇(x)局部负定（去掉等号）。
  - 结论：平衡点渐进稳定，误差持续减小。
- **全局渐进稳定性定理**：
  - 三个条件：正定、正则（当‖x‖→∞时，V(x)→∞）、负定。
  - 结论：系统全局渐进稳定。

### 稳定与渐进稳定的区别
- 稳定：系统状态在某个有界区域内，不一定会减小（如体重稳定在180斤）。
- 渐进稳定：系统状态持续减小，趋向平衡点（如减肥后体重持续下降）。

### 不变集与推论7.1
- **不变集定义**：从该集合内出发的系统轨迹始终保持在该集合内（如寝室、平衡点、吸引力）。
- **推论7.1**：
  - 条件：V(x)局部正定，V̇(x)局部半负定，且V̇(x) = 0的集合仅包含原点。
  - 结论：原点渐进稳定，且由V(x)定义的区域为该平衡点的吸引力。
  - 应用：当只能证明V̇(x) ≤ 0时，通过分析等号成立的条件推导渐进稳定。

### 拉萨尔全局不变性原理
- 目的：当只能证明V̇(x) ≤ 0时，推导全局渐进稳定。
- 条件：
  1. V(x)正定。
  2. V(x)正则（当‖x‖→∞时，V(x)→∞）。
  3. V̇(x) ≤ 0。
  4. 设Ω为V̇(x) = 0的所有点，M为Ω内最大不变集。若M仅包含原点，则系统全局渐进稳定。
- 应用：通过反证法证明除原点外，不存在其他点能使V̇(x)持续等于0。

### 线性系统稳定性分析示例
- 系统：ẋ = Ax，A为Hurwitz矩阵。
- 构造李亚普诺夫函数：V(x) = ½xᵀPx，其中P满足AᵀP + PA = -Q（Q正定）。
- 步骤：
  1. 说明V(x)连续、正定。
  2. 求导：V̇(x) = -½xᵀQx，由于Q正定，V̇(x) ≤ 0。
  3. 分析等号成立条件：仅当x = 0时，V̇(x) = 0。
  4. 根据拉萨尔全局不变性原理，系统全局渐进稳定。
