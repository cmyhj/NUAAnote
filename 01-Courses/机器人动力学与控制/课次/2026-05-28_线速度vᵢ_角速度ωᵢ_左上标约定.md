## 关键概念

- **线速度vᵢ**: 连杆坐标系i原点的线速度，是点的属性。描述时必须指明是哪一点的线速度。

- **角速度ωᵢ**: 连杆坐标系i的角速度，是刚体/坐标系的属性。刚体上任意点的角速度相同，描述时可不指明具体点。

- **左上标约定**: 
  - 左上标表示在哪个坐标系中描述矢量大小（不能省略）
  - 双下标表示相对于哪个坐标系（静止坐标系可省略）
  - 例：ⁱωᵢ 表示i系的绝对角速度在i系中的描述

- **绝对角速度**: 相对于静止坐标系（0系）的角速度，省略相对坐标系下标。

- **相对角速度**: 相对于动坐标系的角速度，需标明相对哪个坐标系。

- **微小转动**: 转角θ的二阶及高阶量可忽略的转动。此时cosθ≈1，sinθ≈θ。

- **矢量性质**: 矢量具有可交换性和可叠加性。微小转动满足这些性质，有限转动不满足。

- **反对称矩阵波浪阵**: 由向量扩展而成的3×3矩阵，用于表示角速度与方向余弦矩阵的关系。

- **方向余弦矩阵导数**: Ṙ = ω̃·R 或 Ṙ = R·ω̃，取决于角速度在哪个坐标系中描述。

- **速度递推**: 从基坐标系（0系，静止）开始，逐级推导各连杆的速度。先推角速度，再推线速度。

## 要点详述

### 1. 速度概念与符号约定

**线速度与角速度的区别**：
- 线速度是点的属性，描述时必须指明是哪一点
- 角速度是刚体的属性，刚体上任意点角速度相同

**左上标约定**：
```
ⁱωⱼ 表示j系的绝对角速度在i系中的描述
```
- 左上标i：在i系中描述/投影（不能省略）
- 下标j：j系的角速度
- 省略相对坐标系表示绝对量

**示例**：
- ᵒωₙ⁰：n系的绝对角速度在0系中的描述
- ⁿωₙ⁰：n系的绝对角速度在n系中的描述
- 两者描述同一个物理量，只是在不同坐标系中衡量大小

### 2. 微小转动的矢量性质

**微小转动定义**：
当转角θ的二阶和高阶量可以忽略时，称为微小转动。
- cosθ ≈ 1
- sinθ ≈ θ

**证明微小转动具有可交换性**：

设有两次微小转动：
- 第一次：绕λ₁转θ₁，从I系转到J系
- 第二次：绕λ₂转θ₂，从J系系转到K系

合成转动：
```
R = (I + λ̃₁θ₁)(I + λ̃₂θ₂) ≈ I + λ̃₁θ₁ + λ̃₂θ₂
```

由于二阶项θ₁θ₂可忽略，结果与顺序无关，满足交换律。

**有限转动不具有可交换性**：

用手机演示：
- 先绕z轴转90°，再绕x轴转90° → 结果A
- 先绕x轴转90°，再绕z轴转90° → 结果B
- A ≠ B，说明有限转动不满足交换律

**结论**：
- 微小转动具有矢量性质（可交换、可叠加）
- 有限转动不具有矢量性质
- 角速度、角加速度始终是矢量

### 3. 角速度与方向余弦矩阵的关系

**推导过程**：

方向余弦矩阵用轴角法表示：
```
R(λ,θ) = I cosθ + λ̃ sinθ + λλᵀ(1-cosθ)
```

对θ求导：
```
∂R/∂θ = -λ̃ sinθ + λ̃ cosθ = λ̃(cosθ - 1) + λ̃
```

整理得：
```
Ṙ = λ̃·θ̇·R
```

其中：
- λ̃：旋转轴的反对称矩阵
- θ̇：角速度大小
- λ̃·θ̇ = ω̃：角速度的反对称矩阵

**两种形式**：
```
Ṙ = ω̃ⁿ⁰·R  （角速度在n系中描述）
Ṙ = R·ω̃⁰ⁿ  （角速度在0系中描述）
```

**记忆技巧**：
- n与n靠在一起（下标相同）
- 0与0靠在一起（下标相同）

### 4. 角速度递推公式

**物理意义**：
后一个连杆的绝对角速度 = 前一个连杆的绝对角速度 + 关节旋转引起的角速度

**矢量形式**：
```
ωᵢ₊₁ = ωᵢ + ωᵢ₊₁/ᵢ
```

**投影到i+1系**：
```
ⁱ⁺¹ωᵢ₊₁ = ᵢ₊₁ᵢR · ᵢωᵢ + ᵢ₊₁ωᵢ₊₁/ᵢ
```

其中：
- ᵢ₊₁ᵢR：i系到i+1系的方向余弦矩阵
- ᵢ₊₁ωᵢ₊₁/ᵢ = [0, 0, θ̇ᵢ₊₁]ᵀ：关节角速度在z轴方向

**递推过程**：
1. 令i=0：⁰ω₀ = 0（基座静止）
2. 令i=0：求¹ω₁
3. 令i=1：求²ω₂
4. 依次递推到i=n

### 5. 线速度递推公式

**物理意义**：
后一个连杆原点的绝对线速度 = 前一个连杆原点的绝对线速度 + 角速度引起的线速度分量

**矢量三角形法则**：
```
vᵢ₊₁ = vᵢ + ωᵢ × rᵢ,ᵢ₊₁
```

其中rᵢ,ᵢ₊₁是i系原点到i+1系原点的位置矢量。

**投影到0系**：
```
ᵒvᵢ₊₁ = ᵒvᵢ + ᵒω̃ᵢ · ᵒrᵢ,ᵢ₊₁
```

**投影到i+1系**：
```
ⁱ⁺¹vᵢ₊₁ = ᵢ₊₁₀R · ᵒvᵢ + ᵢ₊₁ᵢR · ᵢω̃ᵢ · ᵢrᵢ,ᵢ₊₁
```

**关键点**：
- Ṙᵢ = 0的物理意义：站在动坐标系上看固定于该坐标系的点，相对位置不变
- 角速度递推要先于线速度递推，因为角速度会影响线速度

### 6. 递推顺序

1. **先推角速度**：从i=0开始，逐级推导到i=n
2. **再推线速度**：利用已知的角速度，从i=0开始逐级推导到i=n
3. **结果在各自坐标系中描述**：每个连杆的速度在其自身坐标系中表示
