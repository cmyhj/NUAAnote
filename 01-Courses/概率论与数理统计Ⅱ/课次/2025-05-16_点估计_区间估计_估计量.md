## 关键概念
- **点估计**：用一个数值估计未知参数的真实值
- **区间估计**：给出未知参数真实值所在的区间
- **估计量**：用于估计未知参数的统计量（随机变量）
- **估计值**：将样本观测值代入估计量得到的数值
- **矩估计法**：利用样本k阶矩依概率收敛到总体k阶矩的性质，建立方程组求解未知参数
- **样本k阶矩**：$A_k = \frac{1}{n}\sum_{i=1}^n X_i^k$（随机变量）
- **总体k阶矩**：$\mu_k = E(X^k)$（数）

## 要点详述

### 第6章习题要点
**构造卡方分布**：
- 将非标准正态变量标准化：$\frac{X_i - \mu}{\sigma} \sim N(0,1)$
- 标准正态变量的平方和服从卡方分布
- 自由度等于独立标准正态变量的个数

**构造t分布**：
- 分子：标准正态分布
- 分母：卡方分布除以其自由度后开根号
- 形式：$T = \frac{X}{\sqrt{Y/n}}$

**确定样本容量**：
- 利用$E(\bar{X}) = \mu$，$D(\bar{X}) = \sigma^2/n$
- 或利用$\bar{X} \sim N(\mu, \sigma^2/n)$的性质

### 点估计的基本框架
统计学的终极目标是求总体$X$的分布$F(x)$，但这个问题太难。参数估计从简单问题入手：
- 假设分布形式已知（如正态分布、0-1分布）
- 但分布中有未知参数$\theta_1, \theta_2, \ldots, \theta_k$
- 目标：用样本估计这些未知参数

**点估计**：构造统计量$\hat{\theta} = g(X_1, X_2, \ldots, X_n)$，代入样本值得到$\hat{\theta}$作为$\theta$的估计值。

### 矩估计法
**理论依据**（大数定律）：
$$A_k = \frac{1}{n}\sum_{i=1}^n X_i^k \xrightarrow{P} \mu_k = E(X^k)$$

即样本k阶矩依概率收敛到总体k阶矩。

**估计步骤**：
1. 写出总体k阶矩$\mu_k$关于未知参数$\theta_1, \ldots, \theta_k$的表达式
2. 写出样本k阶矩$A_k$
3. 令$A_k = \mu_k(\theta_1, \ldots, \theta_k)$，$k = 1, 2, \ldots$
4. 解方程组，得到未知参数的矩估计量

**注意**：k个未知数需要k个方程，即需要利用到k个矩。

### 矩估计法的直观理解
当样本容量$n$充分大时：
- 样本k阶矩$A_k$是一个随机变量，但其观测值会密集地落在总体k阶矩$\mu_k$附近
- 远远看去，$A_k$就像一个常数$\mu_k$
- 因此可以近似认为$A_k = \mu_k$，从而建立方程求解未知参数
