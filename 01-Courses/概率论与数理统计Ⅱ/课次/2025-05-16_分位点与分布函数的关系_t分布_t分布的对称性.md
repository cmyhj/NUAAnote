## 关键概念
- **分位点与分布函数的关系**：$F(x) = 1 - \alpha$，其中$x = \chi_{1-\alpha}^2$（或$x = t_{1-\alpha}$）
- **t分布**：$T = \frac{X}{\sqrt{Y/n}} \sim t(n)$，密度关于y轴对称
- **t分布的对称性**：$t_{1-\alpha}(n) = -t_\alpha(n)$
- **F分布**：$F = \frac{U/n_1}{V/n_2} \sim F(n_1, n_2)$
- **样本均值的分布**（正态总体）：$\bar{X} \sim N(\mu, \sigma^2/n)$
- **一般总体下样本均值的数字特征**：$E(\bar{X}) = \mu$，$D(\bar{X}) = \sigma^2/n$
- **统计学三个重要结论**：正态总体下$\bar{X}$、$S^2$的分布及独立性

## 要点详述

### 分位点与分布函数值的转换
卡方分布表（t分布表）给出的是分位点值，但有时需要求分布函数值或区间概率。转换方法：
1. 设$P(\chi^2 < a) = \alpha$，则$P(\chi^2 \geq a) = 1-\alpha$
2. 根据分位点定义，$a = \chi_{1-\alpha}^2$
3. 反查卡方分布表，找到自由度$n$对应行中最接近$a$的值，即可求出$\alpha$

### t分布
**定义**：设$X \sim N(0,1)$，$Y \sim \chi^2(n)$，且$X$与$Y$独立，则：
$$T = \frac{X}{\sqrt{Y/n}} \sim t(n)$$

**重要性质**：
- 密度函数关于y轴对称（与标准正态分布类似）
- $n$越大越接近标准正态分布
- $t_{1-\alpha}(n) = -t_\alpha(n)$（对称性）

### F分布
**定义**：设$U \sim \chi^2(n_1)$，$V \sim \chi^2(n_2)$，且$U$与$V$独立，则：
$$F = \frac{U/n_1}{V/n_2} \sim F(n_1, n_2)$$

本课程只讲一个总体的情况，F分布在两个总体比较时才会用到，但定义需要掌握。

### 统计学三个重要结论（核心）
设$X_1, X_2, \ldots, X_n$是正态总体$X \sim N(\mu, \sigma^2)$的样本，$\bar{X}$为样本均值，$S^2$为样本方差，则：

**结论1**：$\frac{\bar{X}-\mu}{\sigma/\sqrt{n}} \sim N(0,1)$

**结论2**：$\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$

**结论3**：$\bar{X}$与$S^2$相互独立

**推论**：$\frac{\bar{X}-\mu}{S/\sqrt{n}} \sim t(n-1)$

**记忆要点**：
- 结论1将样本均值标准化
- 结论2的自由度是$n-1$（不是$n$）
- 结论3是正态分布的特殊性质（看似矛盾但数学上成立）
- 推论将结论1中的$\sigma$替换为$S$，分布从标准正态变为$t$分布

### 一般总体下样本均值的数字特征
即使总体不是正态分布，只要$E(X) = \mu$，$D(X) = \sigma^2$存在，则：
- $E(\bar{X}) = \mu$
- $D(\bar{X}) = \sigma^2/n$

推导利用了期望的线性性和样本的独立性。
