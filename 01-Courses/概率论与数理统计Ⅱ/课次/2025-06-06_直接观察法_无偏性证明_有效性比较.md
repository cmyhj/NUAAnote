## 关键概念
- **直接观察法**：当似然函数关于某参数单调时，用约束条件确定最大值点
- **无偏性证明**：计算E(θ̂)，验证是否等于θ
- **有效性比较**：计算两个无偏估计量的方差，方差小者更有效
- **方差计算技巧**：利用E(X²) = D(X) + [E(X)]²，避免硬算
- **样本方差凑形**：凑出S²的形式，利用重要结论3求方差
- **协方差计算**：Cov(X,Y) = E(XY) - E(X)E(Y)

## 要点详述

### 最大似然估计（7.8题）
**题目**：密度含μ和θ两个未知参数

**传统法失效**：关于μ的似然函数单调，无驻点

**直接观察法**：
1. L关于μ是增函数，μ越大L越大
2. 约束条件：所有样本值必须在非零段（xi ≥ μ）
3. 结论：μ̂ = x₍₁₎（样本最小值）

**θ的估计**：用传统求导法，令μ = x₍₁₎后对θ求导

### 无偏性证明（7.9题）
**技巧**：令Y = X₁ - μ ~ N(0, σ²)，则：
$$E|\hat{\sigma}| = \sqrt{\frac{2}{\pi}}E|Y| = \sqrt{\frac{2}{\pi}} \cdot \sqrt{\frac{2}{\pi}}\sigma = \sigma$$

**关键公式**：若Y ~ N(0, σ²)，则$E|Y| = \sigma\sqrt{2/\pi}$

### 有效性比较
**σ̄的方差**：$\frac{2}{\pi}\sigma^2 - \frac{2}{\pi}\sigma^2 = \frac{2}{\pi}\sigma^2(1 - \frac{2}{\pi})$（常数）

**σ̂的方差**：$\frac{\sigma^2}{n}(1 - \frac{2}{\pi})$（含1/n因子）

**结论**：当n很大时，σ̂的方差远小于σ̄的方差，σ̂更有效

### 方差计算技巧
**不要硬算**：
- 利用D(X) = E(X²) - [E(X)]²
- 正态分布二阶距用方差计算：E(X²) = D(X) + [E(X)]²
- 凑出已知分布的形式（如S²的χ²分布）

### 协方差计算（6.2题）
**展开技巧**：
$$Cov(Y_1, Y_n) = E(Y_1Y_n) - E(Y_1)E(Y_n)$$

**计算步骤**：
1. E(Y₁) = E(Yₙ) = 0（利用期望线性）
2. 展开E(Y₁Yₙ) = E[(X₁-X̄)(Xₙ-X̄)]
3. 利用期望线性和独立性分别计算各项
4. 合并同类项得到最终结果
