## 关键概念
- **最大似然函数**：$L(\theta) = \prod_{i=1}^n f(x_i; \theta)$（连续型）或$L(\theta) = \prod_{i=1}^n P(X_i = x_i)$（离散型）
- **传统求导法**：对$\ln L$求导，令导数为0，解出$\hat{\theta}$
- **直接观察法**：当似然函数无驻点时，直接分析函数性质确定最大值点
- **无偏性**：估计量的数学期望等于被估计参数的真实值
- **样本均值**：$\bar{X}$是$\mu$的无偏估计量（对任何分布成立）
- **样本方差**：$S^2$是$\sigma^2$的无偏估计量（分母为$n-1$的原因）

## 要点详述

### 最大似然估计法
**核心思想**：选择使样本出现概率最大的参数值作为估计值。

**一般步骤**：
1. 写出似然函数$L(\theta)$：将样本值代入分布率/密度函数后连乘
2. 取自然对数$\ln L$：将连乘变为连加，便于求导
3. 对$\theta$求导并令导数为0：$\frac{d}{d\theta}\ln L = 0$
4. 解方程得到$\hat{\theta}$

**注意**：似然函数是关于$\theta$的函数，样本值在求导时视为常数。

### 0-1分布的最大似然估计
**分布率**：$P(X=x) = p^x(1-p)^{1-x}$，$x = 0, 1$

**似然函数**：$L(p) = \prod_{i=1}^n p^{x_i}(1-p)^{1-x_i} = p^{\sum x_i}(1-p)^{n-\sum x_i}$

**取对数**：$\ln L = (\sum x_i)\ln p + (n-\sum x_i)\ln(1-p)$

**求导令为0**：$\frac{d\ln L}{dp} = \frac{\sum x_i}{p} - \frac{n-\sum x_i}{1-p} = 0$

**解得**：$\hat{p} = \frac{1}{n}\sum_{i=1}^n x_i = \bar{x}$

### 均匀分布的最大似然估计
**密度函数**：$f(x) = \frac{1}{b-a}$，$a \leq x \leq b$

**似然函数**：$L(a,b) = \frac{1}{(b-a)^n}$（假设所有样本值在$[a,b]$内）

**传统法失效**：$\frac{\partial L}{\partial a} = \frac{n}{(b-a)^{n+1}} \neq 0$

**直接观察法**：$L$随$b-a$减小而增大，但必须包含所有样本值
- $\hat{a} = x_{(1)}$（样本最小值）
- $\hat{b} = x_{(n)}$（样本最大值）

### 无偏性
**定义**：若$E(\hat{\theta}) = \theta$，则称$\hat{\theta}$是$\theta$的无偏估计量。

**直观理解**：
- 无偏估计量的多次观测值"平均"后等于真实值
- 有偏估计量的观测值系统性偏离真实值

**重要结论**（必须记住）：
1. 样本均值$\bar{X}$是总体均值$\mu$的无偏估计量
2. 样本方差$S^2$是总体方差$\sigma^2$的无偏估计量

**样本方差无偏性的验证**（计算繁琐）：
$$E(S^2) = E\left[\frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2\right] = \sigma^2$$

**为什么分母是$n-1$**：如果分母是$n$，则估计量有偏（偏小）。分母为$n-1$是为了保证无偏性。
