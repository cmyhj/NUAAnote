## 关键概念

- **最大似然估计 (MLE, Maximum Likelihood Estimation)**: 找到使样本出现概率最大的参数值
- **无偏估计 (Unbiased Estimator)**: 估计量的期望等于被估计参数的真实值，即 E(θ̂) = θ
- **似然函数 (Likelihood Function)**: 给定样本下参数 θ 的函数，表示样本出现的概率
- **计数器变量 (Count Statistic)**: Nᵢ = 样本中取值为 i 的个数，是充分统计量的一种形式

### 最大似然估计例题

**题目背景**:
- 离散随机变量 X 的分布律中有未知参数 θ
- 样本观测值：1, 1, 3, 3
- 第一问：用最大似然估计求 θ

**似然函数构造**:
- L(θ) = P(X₁=1) · P(X₂=1) · P(X₃=3) · P(X₄=3)
- = [P(X=1)]² · [P(X=3)]²
- = (θ²)² · (1-θ²)² = θ⁴ · (1-θ²)²

**求解步骤**:
1. 取对数 ln L(θ)
2. 对 θ 求导并令导数 = 0
3. 解出 θ 的 MLE

### 计数器变量的引入（第二问）

引入三个新的随机变量：
- N₁ = 样本中取值为 1 的个数
- N₂ = 样本中取值为 2 的个数
- N₃ = 样本中取值为 3 的个数

对于样本 (1, 1, 3, 3)：
- N₁ = 2, N₂ = 0, N₃ = 2

**问题**: 找到系数 a₂, a₃，使得 N = a₂·N₂ + a₃·N₃ 是 θ 的无偏估计

这需要满足 E(N) = θ，通过计算期望并解方程组得到 a₂ 和 a₃。
