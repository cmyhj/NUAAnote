## 关键概念
- **统计量**：样本$(X_1, X_2, \ldots, X_n)$的连续函数$g(X_1, X_2, \ldots, X_n)$，且函数中不含未知参数
- **抽样分布**：统计量的分布，本质上就是随机变量的分布
- **样本均值**：$\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$，是统计量，是随机变量
- **样本方差**：$S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$，分母为$n-1$
- **样本标准差**：$S = \sqrt{S^2}$
- **样本k阶原点矩**：$A_k = \frac{1}{n}\sum_{i=1}^n X_i^k$
- **样本k阶中心矩**：$B_k = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^k$
- **卡方分布**：$\chi^2 = X_1^2 + X_2^2 + \cdots + X_n^2$，记作$\chi^2(n)$
- **自由度**：卡方分布中独立标准正态变量的个数$n$
- **上α分位点**：满足$P(\chi^2 > \chi_\alpha^2) = \alpha$的值$\chi_\alpha^2$

## 要点详述

### 统计量的定义与判断
统计量是样本的连续函数，且**不含未知参数**。教师通过正态总体$X \sim N(\mu, \sigma^2)$的例子说明：
- 若$\mu$已知，则$g = \frac{1}{n}\sum(X_i - \mu)$是统计量
- 若$\mu$未知，则$g$不是统计量
- 样本容量$n$是已知的，不是未知参数

**核心要点**：统计量是随机变量，不是数值。样本均值$\bar{X}$是随机变量，$\bar{X}$的均值是$E(\bar{X})$，两者完全不同。

### 五个常用统计量
| 统计量 | 符号 | 表达式 | 备注 |
|--------|------|--------|------|
| 样本均值 | $\bar{X}$ | $\frac{1}{n}\sum_{i=1}^n X_i$ | 最常用 |
| 样本方差 | $S^2$ | $\frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$ | 分母为$n-1$ |
| 样本标准差 | $S$ | $\sqrt{S^2}$ | 样本方差开根号 |
| 样本k阶原点矩 | $A_k$ | $\frac{1}{n}\sum_{i=1}^n X_i^k$ | 后续会密集使用 |
| 样本k阶中心矩 | $B_k$ | $\frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^k$ | 选择填空可能用到 |

**重要提醒**：样本方差分母是$n-1$而非$n$，原因在第7章解释，必须记住。

### 卡方分布的定义
设$X_1, X_2, \ldots, X_n$是独立同分布的标准正态随机变量，则：
$$\chi^2 = X_1^2 + X_2^2 + \cdots + X_n^2 \sim \chi^2(n)$$

**关键性质**：
- $\chi^2$是统计量，其分布称为卡方分布
- 自由度$n$是分布参数，不能随意更改
- 密度函数含伽马函数，不要求记忆，但要会画草图（非对称，位于第一象限）

### 卡方分布的重要性质
**1. 可加性**：
若$\chi_1^2 \sim \chi^2(n_1)$，$\chi_2^2 \sim \chi^2(n_2)$，且独立，则：
$$\chi_1^2 + \chi_2^2 \sim \chi^2(n_1 + n_2)$$

**2. 期望与方差**：
- $E(\chi^2) = n$
- $D(\chi^2) = 2n$

**推导要点**：
- 期望计算：利用$E(X_i^2) = D(X_i) + [E(X_i)]^2 = 1 + 0 = 1$
- 方差计算：需要计算标准正态分布的4阶矩$E(X^4) = 3$，通过分部积分得到

### 上α分位点
**定义**：对于卡方分布随机变量$\chi^2$，满足$P(\chi^2 > \chi_\alpha^2) = \alpha$的值$\chi_\alpha^2$称为上α分位点。

**查表方法**：
1. 打开附录中的卡方分布表
2. 找到自由度$n$对应的行
3. 找到$\alpha$对应的列
4. 交叉处即为$\chi_\alpha^2$的值

**注意**：卡方分布表直接给出分位点值，而标准正态分布表给出的是分布函数值。
