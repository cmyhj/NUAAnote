## 关键概念

- **列空间 (Column Space)**：矩阵列向量的所有线性组合构成的子空间，y 是否在其中决定了 Ax=y 是否有解
- **零空间 (Null Space)**：满足 Ax=0 的所有向量构成的子空间，其维数决定了方程解的自由度（无穷多解的原因）
- **秩 (Rank)**：矩阵中最大线性无关列（或行）的个数，等于列空间的维数
- **行列式 (Determinant)**：方阵列向量构成的平行多面体的有向体积（2D 中为面积），为零 ⇔ 线性相关 ⇔ 降秩
- **内积 (Inner Product)**：向量间的一种双线性运算，几何意义为 `|a||b|cosθ`；满足交换律、分配律、齐次性、非负性即可定义为内积
- **范数 (Norm)**：向量长度的推广，满足非负性、齐次性、三角不等式；常见的 L1/L2/L∞/L0 范数
- **正交 (Orthogonality)**：垂直概念的推广——内积为零的两个向量互为正交
- **投影 (Projection)**：向量到子空间上的最佳逼近，误差与子空间正交；投影矩阵 P 满足 P² = P（幂等）
- **最小二乘 (Least Squares)**：当 Ax=y 无解时，最小化误差 ‖Ax−y‖ 的解，几何上等价于 y 在列空间上的投影

## 要点详述

### 1. 从空间角度理解 Ax=y

**满秩矩阵**：若 A 是满秩方阵，则 Ax=y 有唯一解 x = A⁻¹y。

**降秩矩阵（非满秩）**：以三维空间为例，三个列向量若线性相关，其列空间退化为一个平面或直线。
- 若 y 落入该列空间 → 有解，且因零空间非零 → **无穷多解**（任何一个特解加上零空间中的任意向量仍是解）
- 若 y 不在该列空间中 → 无解，即所谓的**矛盾方程组**

老师用"两个方程三个未知数"的例子直观说明：自由度多出一个，所以有无穷多特解。

### 2. 行列式的几何直观

2×2 矩阵的行列式 = 两个列向量张成的**平行四边形的面积**；3×3 矩阵的行列式 = 三个列向量张成的**平行六面体的体积**。行列式为 0 ⇔ 体积/面积退化（降维），对应向量线性相关。

### 3. 内积、范数与正交

**内积的几何意义**：⟨a,b⟩ = |a||b|cosθ，即 a 在 b 上的投影长度 × b 的长度。余弦值 cosθ 反映两个向量方向的一致性——完全同向时取最大值 1，正交时为 0。

**内积的推广**：不限于欧氏空间点积，只要满足交换律、分配律、齐次性、非负性四条公理，都可称为内积。例如随机变量的期望 E[XY] 也是一种内积，由此可推导出卡尔曼滤波与最小二乘的统一性。

**范数**：向量长度的推广，满足非负性、齐次性、三角不等式。常用类型：
- L2 范数（欧氏距离）：‖x‖₂ = √(x₁² + x₂² + ...)
- L1 范数：‖x‖₁ = |x₁| + |x₂| + ...
- L∞ 范数：‖x‖∞ = max|xᵢ|
- L0 范数：‖x‖₀ = 非零元素个数（注意 L0 不满足范数公理，需特殊定义）

### 4. ML 中的应用

- **图像作为高维向量**：320×200×3（RGB）的照片 ≈ 192000 维空间中的一个点
- **人脸识别**：在高维空间中找与目标最接近的向量，可用欧氏距离（绝对差异）或**余弦距离**（方向相似性，对光照等线性变换鲁棒）
- **超平面**：{x | wᵀx = b}，即所有在 w 方向上投影长度为定值的点——后续支持向量机（SVM）的核心概念

### 5. 正交性原理与最小二乘

**正交性原理**：一个向量到子空间的最优近似 = 它在子空间上的正交投影，此时误差向量与子空间正交。

**线性回归例子**：给定观测点 (tᵢ, sᵢ) 拟合匀速运动 s = vt，得到矛盾方程组。最小化误差平方和 ∑(sᵢ − vtᵢ)²，求导得解。从空间看：y 向量在列向量 t 上的正交投影即为最优 v。

**扩展到双参数**：y = ax + b 无非是投影到二维子空间（由 x 和常数列张成）。

### 6. 投影矩阵与正交补

投影算子 P 满足 P² = P（幂等性）。与 A 的列空间正交的补空间是 Aᵀ 的零空间，即 N(Aᵀ)。方程有无穷多解时，其任意解可写为特解 + 零空间向量；其中**范数最小的解**与零空间正交。

### 7. 凸集简介

老师简要扩展到凸优化概念：凸集 = 集合中任意两点连线仍在集合内的点集。凸集的一个重要性质是：对边界外任一点，存在一个支撑超平面将其与凸集分离。
