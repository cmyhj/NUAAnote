## 关键概念

- **万能逼近定理（Universal Approximation Theorem）**：足够宽或足够深的神经网络可以逼近任意连续函数。
- **[[神经网络|ReLU (Rectified Linear Unit)]]**：当前主流的激活函数，$f(x)=\max(0,x)$，使网络产生分段线性特性，缓解梯度消失问题。
- **梯度消失 / 梯度爆炸（Vanishing / Exploding Gradient）**：深层网络中，梯度连乘导致趋近于 0 或无穷大，使训练无法有效进行。
- **随机梯度下降（SGD）与小批量（Mini-batch）**：每次随机选取一小批数据计算梯度均值来更新参数，在计算效率和收敛稳定性之间权衡。
- **动量法（Momentum）**：对 SGD 梯度做指数加权移动平均（低通滤波），平滑梯度方向，加速收敛。
- **学习率（Learning Rate）**：控制参数更新步长的超参数，过大易震荡，过小收敛过慢。
- **超限学习机（ELM, Extreme Learning Machine）**：黄广斌提出的一种单隐层网络方法，隐层权重随机初始化后固定，仅训练输出层权重。

### 神经网络基础与万能逼近

- 神经元模型：输入加权求和 → 非线性激活 → 输出。多个神经元连接构成网络。
- 网络只要有足够的宽度或深度，理论上可以逼近任意函数（万能逼近定理）。
- **XOR 问题的历史教训**：单层感知机无法解决 XOR（异或）问题，因为它是线性不可分的。引入非线性激活函数后，双层网络可精确拟合 XOR。老师以 ReLU 为例，给出了一个 2 层、4 个参数的网络构造，可以精确等于异或函数——本质上是用分段线性来拟合。

### ReLU 与非线性激活的必要性

- 如果没有非线性激活层，多层线性变换等价于单层线性变换，网络表达能力不会随深度增加。
- ReLU（$\max(0, x)$）使网络成为**分片线性函数**（piecewise linear）：每个神经元要么关闭（输出 0）要么打开（线性传递），不同输入路径组合出不同的线性区域。
- 丘成桐（Shing-Tung Yau）等人从微分几何视角给出深度学习的几何解释，认为深层网络本质是分片线性逼近，并将其与 Grassmannian 流形上的变换联系起来。相关论文尚未正式发表，但预印本已引起震动。老师个人感慨刚把 Attention 机制弄明白，可能又面临大的理论变革。

### 超限学习机（ELM）

- 黄广斌（南洋理工 / 东南大学客座教授）提出的方法：把单隐层网络做得极宽，隐层权重随机初始化后固定不动，只训练输出层权重。该方法至今仍有人使用。

### 训练算法与主要挑战

- **监督学习**：给定带标签数据，定义损失函数衡量预测与真实值的差距，对参数求导并沿梯度反方向更新。
- **BP 算法（反向传播）**：利用链式法则逐层计算梯度。实现上的核心技巧在于用空间换时间——把中间计算结果缓存下来，避免重复求导。
- **梯度消失 / 爆炸**：深度网络中梯度逐层相乘，若各层导数均 <1 则趋近于 0（消失），均 >1 则指数增长（爆炸）。这是传统网络做不深的主要原因。
- **局部极小值**：损失函数非凸，梯度下降容易陷入局部极小。模拟退火等算法以一定概率跳出局部极小。
- **论文可重复性问题**：老师指出不少论文的优越结果依赖于随机种子或特定数据划分，换数据后效果大幅下降，"90% 的论文没有用"。建议选题避免跟踪已有 90% 精度的饱和任务。
- **SGD 与小批量**：全数据集计算梯度太慢且内存开销大，每次用一小批（mini-batch）数据计算平均梯度来更新，同时减少梯度噪声。Batch size 是超参数，越大梯度越平稳但计算成本越高。
- **病态条件（ill-conditioned）**：Hessian 矩阵条件数大时，梯度方向与最优方向偏离严重，导致收敛缓慢或震荡。老师以蝴蝶效应和气象预报做类比。
- **学习率**：步长超参数。太大会越过最优点来回震荡，太小收敛极慢。
- **动量法**：对梯度做指数加权移动平均 $v_t = \alpha v_{t-1} - (1-\alpha)g_t$，系数和为 1，等价于低通滤波，滤除高频震荡分量，使收敛路径更平滑。
