## 关键概念

- **约束优化（Constrained Optimization）**: 在等式或不等式约束下求目标函数的最小值/最大值。
- **代入法**: 利用等式约束消去部分变量，将约束优化转为无约束优化；局限性在于约束方程需可解出解析表达式。
- **拉格朗日乘子法（Lagrange Multiplier Method）**: 引入拉格朗日乘子将约束条件融合进目标函数，无需显式求解约束方程。**必要条件**，非充分条件。
- **松弛变量（Slack Variable）**: 将不等式约束 `g(x) ≤ 0` 改造为等式约束 `g(x) + s² = 0` 的辅助变量。
- **KKT 条件（Karush–Kuhn–Tucker Conditions）**: 不等式约束优化问题最优解的一阶必要条件，包含梯度为零、原始可行、对偶可行、互补松弛四条。
- **互补松弛（Complementary Slackness）**: 若 `λᵢ > 0` 则对应约束 `gᵢ(x) = 0`（紧约束）；若 `gᵢ(x) < 0` 则 `λᵢ = 0`（约束不起作用）。
- **拉格朗日对偶性（Lagrange Duality）**: 原问题（Primal）`min_x max_{λ,ν} L(x,λ,ν)` 与对偶问题（Dual）`max_{λ,ν} min_x L(x,λ,ν)` 在凸条件下等价，对偶问题有时更易求解。
- **支持向量机（SVM）**: 通过最大化分类间隔寻找最优分类超平面，支持向量是那些"刚好在边界上"的样本点。

### 约束优化 — 代入法（08:22-11:19）

问题形式：
```
min f(x)
s.t. hᵢ(x) = 0,  i = 1,...,m
     gⱼ(x) ≤ 0,  j = 1,...,t
```
- n 维变量加 m 个等式约束后，**自由度为 n-m**（约束数必须小于变量数，否则退化为点）。
- 代入法：从 m 个等式约束中解出 m 个变量，用剩余 n-m 个变量表示，代回目标函数转化为无约束优化。
- 局限性：大部分约束方程写不出解析解。

### 拉格朗日乘子法推导（11:19-17:11）

从代入法的思想出发：将后 m 个变量用前 n-m 个变量表示并代入，在最优解处梯度为零，整理可得：

```
∇f(x*) + Σ λᵢ ∇hᵢ(x*) = 0
```

其中 `λᵢ` 即拉格朗日乘子。定义拉格朗日函数：

```
L(x, λ) = f(x) + Σ λᵢ hᵢ(x)
```

该方法比代入法更通用——**不需要显式写出解析表达式**，只要梯度线性无关即可。

### 必要条件 vs 充分条件（17:11-19:53）

拉格朗日乘子法给出的是**必要条件**（梯度为零的点可能是极小、极大或鞍点）。老师留了一个思考题：结合非线性约束的例子，说明为什么它不充分。**不要求提交作业，但鼓励与 AI 讨论或私下交流。**

### 不等式约束与 KKT 条件（19:53-23:12）

对不等式约束 `g(x) ≤ 0`，引入松弛变量 `s²` 后化为等式约束，再按照拉格朗日框架可得到 **KKT 条件**：

1. **原始可行**: `hᵢ(x) = 0`, `gⱼ(x) ≤ 0`
2. **梯度为零**: `∇f(x) + Σ λᵢ ∇hᵢ(x) + Σ μⱼ ∇gⱼ(x) = 0`
3. **对偶可行**: `μⱼ ≥ 0`
4. **互补松弛**: `μⱼ gⱼ(x) = 0` → `gⱼ(x) < 0` 时 `μⱼ = 0`（约束不起作用），`μⱼ > 0` 时 `gⱼ(x) = 0`（紧约束）

老师提到 KKT 条件背后有个故事：一帮大数学家研究已久，后来发现数学系一个本科生的毕业论文早就给出了结果（Karush 的硕士论文）。

### KKT 条件的几何意义（27:00-29:44）

在最优解处，目标函数 f 的**减小方向**恰好是约束函数 g 和 h 的**增长方向**的线性组合。这意味着沿任何可行方向移动都会使目标增大或违反约束，因此无法再优化。

### 支持向量机（SVM）的直观引入（23:12-27:00 + 36:33-40:22）

将分类问题理解为：在两类数据间**插入一根尽可能粗的棍子**（最大化分类间隔）。决定这根棍子粗细的只有那些"刚好在边界上"的点——即**支持向量**。KKT 条件中的互补松弛正好刻画了这点：远离边界的点 `gⱼ(x) < 0 → μⱼ = 0`（不起作用），只有边界上的点 `gⱼ(x) = 0 → μⱼ > 0`（真正起约束作用）。

### 拉格朗日对偶性（31:08-33:41）

```
p* = min_x max_{λ,ν} L(x,λ,ν)    （原问题）
d* = max_{λ,ν} min_x L(x,λ,ν)    （对偶问题）
```
在凸条件下 `p* = d*`（强对偶）。当原问题难解时，可转为对偶问题求解。SVM 正是通过对偶形式引入核技巧的典型案例。
