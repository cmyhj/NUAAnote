## 关键概念

- **梯度消失/爆炸 (Vanishing/Exploding Gradients)**: 深度网络中梯度随层数指数级衰减或增长，导致网络无法有效学习。
- **回声状态网络 (Echo State Network, ESN)**: 固定循环/输入权重，仅训练输出权重，由人工设计状态表示。
- **Leaky Unit**: 带线性侧连接的单元，相当于低通滤波器，α 控制平滑程度。
- **[[LSTM（长短期记忆网络）|LSTM (Long Short-Term Memory)]]**: 引入遗忘门、输入门、输出门，通过门控机制实现长程记忆，所有门控权重可学习。
- **[[LSTM（长短期记忆网络）|GRU (Gated Recurrent Unit)]]**: 简化版 LSTM，合并遗忘门与输入门为更新门。
- **[[Attention 机制|Token]]**: 大语言模型处理的基本单元，可以是一个词、子词或字符，由分词器按频率切分。
- **BPE (Byte-Pair Encoding)**: 基于字节合并的子词分词算法，适用于多种语言。
- **词嵌入 (Word Embedding)**: 将 Token 映射到高维空间中的向量，语义相近的词在空间中距离近。
- **[[Attention 机制|注意力机制 (Attention)]]**: 借鉴数据库 QKV（查询-键-值）思想，通过计算相似度加权聚合信息。
- **QKV**: Query 与 Key 计算相似度，得到的权重对 Value 做加权和作为输出。
- **多头注意力 (Multi-Head Attention)**: 从多个维度计算相似性，捕捉不同层面的关联。

## 要点详述

### 深度学习的不可解释性与高维空间

神经网络的结果是在高维空间（如 100100 维的子空间）中做出决策，人类只能感知三维空间，因此难以直观理解模型行为的理由。不同层次上的梯度大小差异很大——有的区域梯度极小（消失），有的极大（爆炸），两者都会导致网络无法学习（`[00:00-02:17]`）。

### 梯度问题的数学本质与初始化解法

从矩阵运算角度，经过 t 次迭代，梯度传播依赖权重矩阵特征值的幂：特征值 < 1 时趋近于 0（消失），> 1 时发散（爆炸）。一种缓解措施是控制初始化时权重的方差范围，避免过大或过小（`[02:57-04:08]`）。

### 长程依赖——序列数据处理的根本困难

要完整理解一句话甚至一个段落，需要捕捉长跨度的关联。但关联跨度越大，基于梯度的优化越困难。这正是研究序列数据处理（以及后续注意力机制）的核心动机（`[05:03-06:00]`）。

### 处理长程依赖的传统方法

1. **回声状态网络 (ESN)**: 循环权重和输入权重固定，仅学习输出权重，本质是人为设计状态应包含哪些信息。
2. **稀疏关联/多时间尺度**: 不关联所有位置，只选取重要的关联。类比句子中只关注主谓宾（`[06:33-07:12]`）。

### 梯度控制与短路连接

梯度裁剪限制梯度的范数。另一种思路是设计多时间尺度的模型——引入带线性侧连接的单元（Leaky Unit），它相当于一个低通滤波器：α 接近 1 更平滑（但对输入不敏感，易丢失有用信号），α 接近 0 则输出反应更快（`[08:00-10:31]`）。

### LSTM 与 GRU

LSTM 和 GRU 通过可学习的门控机制实现长程传播，不是等同关注所有位置，而是通过学习决定关联谁、遗忘谁。LSTM 的遗忘门决定历史状态的影响，输入门控制当前输入的影响，输出门参与最终输出（`[10:32-13:25]`）。

教师强调：在计算资源受限的平台（无人机、机器人）上无法部署大模型，LSTM 对时间序列处理仍然很有价值（`[13:30-14:25]`）。

### Token 化与词嵌入

大语言模型首先将自然语言切分为 Token（子词单元），然后为每个 Token 做嵌入编码。BPE（字节对编码）根据出现频率合并常见子词序列，减少词表大小。嵌入的目标是让语义相关的词在向量空间中距离接近，例如"儿子"与"孙子"的关系可通过向量运算体现（`[22:55-24:16]`）。

嵌入要满足两个性质：1）距离反映语义关联度；2）支持向量加法运算。

### 注意力机制的基本思想

注意力机制借鉴数据库的 QKV 模型：
- **Query (Q)**: 当前关注的查询向量
- **Key (K)**: 每个 Token 的索引标识
- **Value (V)**: Token 携带的实质信息

通过计算 Q 与各 K 的相似度（点积或余弦相似度），经 Softmax 归一化后作为权重，对 V 做加权和得到输出。相似度高的 Token 获得更高的注意力权重（`[34:00-40:30]`）。

多头注意力从多个维度计算相似性，类似于从不同角度（身份、性格、兴趣等）评估两个人的相似度（`[43:07-43:40]`）。
