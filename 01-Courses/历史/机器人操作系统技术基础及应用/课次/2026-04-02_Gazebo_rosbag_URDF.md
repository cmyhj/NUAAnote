## 关键概念

| 概念 | 说明 |
|------|------|
| **Gazebo** | 基于 ODE 物理引擎的 3D 机器人仿真环境，与 ROS 深度集成，安装 ROS 时同步安装 |
| **rosbag** | ROS 数据录制/回放工具，可将运行时所有话题消息保存为 `.bag` 文件用于离线调试 |
| **URDF** (Unified Robot Description Format) | 机器人统一描述格式，下章重点 |
| **Building Editor** | Gazebo 内置工具，通过二维绘制墙/门窗快速生成三维场景，适用于导航建图 |
| **Service** | ROS 通信方式之一，用于 turtlesim 复位等一次性请求-响应操作 |

## 要点详述

### 一、Gazebo 仿真环境

1. **版本**：随 ROS 一起安装，需版本匹配。当前已全面过渡到 ROS2，对应更新版 Gazebo。若需旧版兼容需自行查找。
2. **界面**：
   - 3D 显示区（主区域）
   - 顶部工具栏（视图/显示设置）
   - 左侧面板：**World**（属性配置）/ **Insert**（插入模型）
3. **模型获取**：
   - Insert → 在线模型库（需联网，开源共享）
   - 手动下载后放入 `~/.gazebo/models/`
   - 演示模型：救护车（~100 MB）、轿车、公寓楼（~700 MB）、公交车等
4. **Building Editor**：菜单栏 `Edit → Building Editor`
   - 二维画墙 → 添加窗/门 → 设置材质（木楼梯、砖墙等）
   - 自动生成三维场景，适合做导航地图障碍物
5. **限制**：部分封闭模型（如公寓楼）门窗关闭只能外观，无法进入内部。

### 二、rosbag 数据记录与回放

**步骤**：
| # | 操作 | 命令 |
|---|------|------|
| 1 | 建目录 | `mkdir -p ~/bagfiles && cd ~/bagfiles` |
| 2 | 录制所有话题 | `rosbag record -a` |
| 3 | 停止录制 | `Ctrl+C` |
| 4 | 查看信息 | `rosbag info <file.bag>` |
| 5 | 回放 | `rosbag play <file.bag>` |

**turtlesim 演示**：
- 启动 `roscore` → `rosrun turtlesim turtlesim_node` → `rosrun turtlesim turtle_teleop_key`
- `rosbag record -a` 录制后，关闭键盘控制再回放，乌龟自动复现轨迹

**关键问题**：
- 回放轨迹偏移原因：**初始位置/姿态不同** → rosbag 记录的是相对运动，起始位姿变了整条轨迹就平移/旋转
- 解决方案：先调用服务复位乌龟
  ```bash
  rosservice list                    # 查看乌龟仿真器的服务
  rosservice call /reset             # 复位乌龟位置
  ```
  然后再 `rosbag play`，轨迹就与录制时一致。
