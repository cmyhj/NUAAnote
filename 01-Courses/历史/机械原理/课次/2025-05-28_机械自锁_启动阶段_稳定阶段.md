## 关键概念
- **机械自锁**：当效率η≤0时，机构无法反向运动，处于自锁状态
- **启动阶段**：输入功大于输出功，动能增加，速度从0增加到稳定值
- **稳定阶段**：输入功等于输出功，动能不变，速度在稳定值附近波动
- **制动阶段**：输入功小于输出功，动能减少，速度从稳定值降到0
- **驱动力**：使机械运动的力，可分为常力、位置函数、速度函数、时间函数
- **生产阻力**：阻碍机械运动的力，取决于机械结构和工艺过程
- **等效动力学模型**：将复杂系统简化为单自由度力学模型
- **等效转动惯量**：将系统所有构件的转动惯量等效到某一构件上
- **等效力矩**：将系统所有外力等效到某一构件上的力矩
- **速度波动**：机械运转速度偏离稳定值的现象
- **周期性波动**：速度波动具有周期性规律
- **非周期性波动**：速度波动无规律
- **速度不均匀系数**：δ = (ωmax - ωmin)/ωm，评价速度波动程度
- **飞轮**：利用惯性储能平衡速度波动的装置
- **飞轮调速原理**：能量多余时飞轮吸收，能量不足时飞轮释放

## 要点详述

### 机械自锁条件
**自锁定义**：当机构效率η≤0时，机构无法反向运动。

**自锁条件**：
- 螺旋副自锁：η = tanλ/tan(λ+φv) ≤ 0，λ为螺旋升角，φv为当量摩擦角
- 简化理解：推力小于静摩擦力时自锁
- 几何理解：当外力作用线落在摩擦角内时自锁

**物理意义**：输入功全部用于克服摩擦损耗，无法输出有用功。

### 机械运转三个阶段
**1. 启动阶段**：
- 输入功 > 输出功
- 动能增加，速度从0增加到稳定值
- 需要较大驱动力矩
- 例如：汽车启动、电机启动

**2. 稳定阶段**：
- 输入功 = 输出功（理论状态）
- 动能不变，速度在稳定值附近波动
- 实际存在周期性波动
- 例如：汽车匀速行驶、机床正常加工

**3. 制动阶段**：
- 输入功 < 输出功
- 动能减少，速度从稳定值降到0
- 需要制动力矩
- 例如：汽车刹车、电机制动

### 驱动力和生产阻力分类
**驱动力分类**：
- **常力**：重力（与位置无关）
- **位置函数**：弹簧力（F = kx）、内燃机力（随活塞位置变化）
- **速度函数**：电动机力（速度越快力越小）
- **时间函数**：揉面机阻力（随时间增大）

**生产阻力分类**：
- **常数**：机床切削力（取决于工艺）
- **位置函数**：活塞压缩力（随位移变化）
- **速度函数**：空气阻力（与速度平方成正比）
- **时间函数**：球磨机阻力（随时间增大）

### 等效动力学模型
**概念**：将复杂多自由度系统简化为单自由度力学模型。

**等效转动惯量**：
- 将系统所有构件的转动惯量等效到某一构件上
- Je = Σ(Ji·(ωi/ω)²)
- 考虑各构件角速度与等效构件角速度的关系

**等效力矩**：
- 将系统所有外力等效到某一构件上
- Me = Σ(Mi·(ωi/ω))
- 考虑各构件功率与等效构件功率的关系

**应用**：简化动力学分析，便于求解真实运动。

### 速度波动的原因和危害
**原因**：
- 驱动力和生产阻力的周期性变化
- 构件惯性的周期性变化
- 载荷的突变

**危害**：
- 引起附加动载荷，加剧磨损
- 产生振动和噪声，降低工作性能
- 影响加工精度，降低产品质量
- 严重时导致飞车或停车事故

### 速度波动的调节方法
**1. 自调节性**：
- 电动机具有自调节性
- 速度升高时力矩减小，速度降低时力矩增大
- 自动平衡速度波动

**2. 调速器**：
- 用于内燃机等无自调节性的原动机
- 离心式调速器：速度升高时离心力增大，减小供油量
- 速度降低时离心力减小，增大供油量

**3. 飞轮**：
- 利用飞轮惯性储能平衡速度波动
- 能量多余时飞轮吸收（速度升高）
- 能量不足时飞轮释放（速度降低）

### 飞轮调速原理
**基本原理**：
- 飞轮具有较大转动惯量
- 利用动能变化平衡速度波动
- 能量守恒：ΔE = 1/2·Je·(ωmax² - ωmin²)

**速度不均匀系数**：
- δ = (ωmax - ωmin)/ωm
- ωm = (ωmax + ωmin)/2
- δ越小，速度波动越小，机械越平稳

**飞轮设计**：
- 已知允许的δ，求飞轮转动惯量Je
- Je = ΔE/(0.5·δ·ωm²)
- 飞轮应安装在高速轴上（ω大，Je可减小）

### 飞轮安装位置
**高速轴优点**：
- 角速度ω大，相同能量变化所需转动惯量小
- 飞轮尺寸小，重量轻
- 调速效果更明显

**低速轴缺点**：
- 角速度ω小，需要更大转动惯量
- 飞轮尺寸大，重量重
- 增加系统惯性负担
