## 关键概念
- 法向模数 mn：法截面上相邻两牙顶之间的弧长与 π 的比值，是齿轮设计的基本参数
- 端面模数 mt：端截面上相邻两牙顶之间的弧长与 π 的比值，满足 mt = mn / cosβ
- 法向压力角 αn：法截面上法线与公法线之间的夹角，标准值为 20°
- 端面压力角 αt：端截面上对应的压力角，满足 tanαt = tanαn / cosβ
- 螺旋角 β：齿线与轴线之间的夹角，典型取值 8°~20°，决定了斜齿轮的重合度和轴向力
- 左旋/右旋齿轮：沿轴线方向看齿倾斜方向，逆时针为左旋（ZL），顺时针为右旋（ZR）
- 发生面：斜齿轮啮合过程中实际接触的曲面，比发生线具有更好的承载力和平稳性
- 端面重合度 εα：在端面上同时啮合的齿对数，计算方式与直齿轮相同
- 轴向重合度 εβ：由齿宽 B 和螺旋角 β 决定的额外重合度，εβ = B·tanβ / pt，总重合度 εε = εα + εβ
- 轴向力：斜齿轮啮合产生的沿轴线方向的力，大小为 Fx = Ft·tanβ，其中 Ft 为切向力
- 当量齿数 z'：用于强度计算的虚拟齿数，z' = z / cos³β，可将斜齿轮视为等效的直齿轮进行弯曲强度检验
- 蜗杆传动：由螺旋角大于某值的螺杆（蜗杆）与斜齿轮（蜗轮）啮合组成，传动比 i = z₂ / z₁，其中 z₁ 为蜗杆头数（通常 1~4），z₂ 为蜗轮齿数

## 要点详述

### 端面参数与法向参数的换算
教师开头提出要求：求书上184-185页公式中端面模数和端面压力角的关系。通过几何分析得知，法向模数 mn 与端面模数 mt 满足 mt = mn / cosβ，其中 β 为螺旋角。端面压力角 αt 与法向压力角 αn 的关系为 tanαt = tanαn / cosβ（或等价地 αt = arctan(tanαn / cosβ)）。教师反复强调，齿轮的**标准参数以法向为基准**，即在设计和强度计算时应使用 mn、αn 等法向量，而端面量主要用于几何尺寸（如端面分度圆直径 dt = mt·z）和制造检验。

### 左旋/右旋判定与齿轮画法
判定斜齿轮旋向的关键在于**找准旋转轴**。教师强调：无论齿轮在图中如何摆放（躺着、倾斜），必须沿其轴线方向观察齿的倾斜方向——如果齿从左到右呈逆时针倾斜则为左旋，顺时针倾斜则为右旋。常见错误是受齿轮在图中的摆放姿态误导，教师因此多次重申：“一定要找它的旋转轴”，并指出考试中若忽略这一点会导致判定错误。

### 斜齿轮啮合特性与重合度
直齿轮的啮合是点接触，而斜齿轮由于齿宽的存在，啮合过程从一端逐渐展开到另一端，形成一个**发生面**（而不是发生线）。这种面接触带来两 major 优势：
1. **承载能力提升**：载荷分布在更大的面积上，单位面积上的应力降低；
2. **传动更平稳**：啮合和脱啮合过程的延续使得瞬时力变化更为柔和，减少冲击和噪声。

重合度也因而提升。端面重合度 εα 与直齿轮计算方式相同（取决于模数、压力角、齿数等）；此外，齿宽 B 和螺旋角 β 额外贡献一个轴向重合度 εβ = B·tanβ / pt（pt 为法向节距），总重合度 εε = εα + εβ。教师指出，这就是为什么斜齿轮能够承受更大载荷且运行更安静的根本原因。

### 轴向力的产生及其影响
斜齿轮的螺旋齿形导致切向力 Ft 在啮合点处可分解为三个分量：沿切线方向的切向力（传递功率）、指向轮心方向的镜像力（径向力，保持啮合）以及**沿轴线方向的轴向力** Fx = Ft·tanβ。轴向力的存在意味着：
- 需要使用**止推轴承**来承受此轴向载荷，否则会导致轴窜；
- 轴向力方向与旋向和齿旋方向有关：左旋主动轮产生的轴向力方向可通过右手定则判定；
- 螺旋角 β 过大会导致轴向力过大，因此实际设计中 β 一般限制在 8°~20°，以平衡传动平稳性与轴向力的大小。

### 分度圆直径与当量齿数
教师讨论了分度圆直径的计算。标准公式 d = mn·z 仍然适用，但这里的 mn 必须是**法向模数**。端面分度圆直径则为 dt = mt·z = d / cosβ。为便于强度计算，引入了**当量齿数**的概念：z' = z / cos³β。其物理意义在于，斜齿轮在法截面上相当于一具有当量齿数 z'、法向模数 mn 的虚拟直齿轮，于是可直接使用直齿轮的弯曲强度公式进行检验。

### 蜗杆传动的简要介绍
在课程最后阶段，教师用蜗杆（worm）和蜗轮（worm gear）举例说明另一种利用螺旋原理实现运动和动力传递的机构。蜗杆实际上是一个具有较大螺旋角的螺杆，蜗轮则相当于斜齿轮。啮合时，蜗杆每转一圈相当于推动蜗轮前进一个牙距（若蜗杆为单头），因此传动比 i = z₂ / z₁，其中 z₁ 为蜗杆头数（即蜗杆在径向上的螺纹条数），z₂ 为蜗轮齿数。蜗杆传动具有以下特点：
- 结构紧凑，适用于两轴互相垂直（通常为 90°）且不在同一平面上的传动；
- 传动比可达到较大值（单级可达 80：1 甚至更高）；
- 具有自锁性（当螺旋角小于等相当摩擦角时，蜗轮不能反向驱动蜗杆）；
- 但由于滑动摩擦较大，效率通常较低，需注意散热和润滑。
