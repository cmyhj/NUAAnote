## 关键概念

| 概念 | 说明 |
|------|------|
| 信号流图 | 用节点和有向支路表示系统变量及传递关系的图形 |
| 节点 | 表示系统变量的点 |
| 支路 | 连接两个节点的有向线段，其上标注传递函数 |
| 输入节点（源节点） | 只有输出支路的节点 |
| 输出节点（阱节点） | 只有输入支路的节点 |
| 混合节点 | 既有输入支路又有输出支路的节点 |
| 前向通路 | 从输入节点到输出节点，每个节点只经过一次的通路 |
| 回路 | 起点和终点重合，且沿途节点只经过一次的闭合路径 |
| 互不接触回路 | 没有任何公共节点的回路 |
| 梅森增益公式 | 通过前向通路和回路直接求取系统传递函数的公式 |

## 要点详述

### 一、信号流图与结构图的关系

信号流图是结构图的简化形式，二者表示的数学关系完全等价。结构图可以转换为信号流图，转换时需注意：每个变量对应一个节点，传递函数对应支路增益。

### 二、梅森增益公式

梅森增益公式是信号流图法的核心工具：

**公式**：P = (1/Δ) × Σ(Pₖ·Δₖ)

其中：
- P：系统总传递函数
- Pₖ：第 k 条前向通路的增益
- Δ：流图特征式 = 1 - ΣLₐ + ΣLₐL_b - ΣLₐL_bL_c + ...（所有回路增益之和减去两两不接触回路增益乘积之和加上三三不接触回路增益乘积之和...）
- Δₖ：将第 k 条前向通路接触的回路从 Δ 中去除后的余子式

### 三、应用要点

使用梅森公式的关键是正确识别前向通路和回路：
1. 列出所有从输入到输出的前向通路及其增益
2. 列出所有独立回路及其增益
3. 找出所有互不接触回路组
4. 计算特征式 Δ 和余子式 Δₖ
5. 代入公式求解
