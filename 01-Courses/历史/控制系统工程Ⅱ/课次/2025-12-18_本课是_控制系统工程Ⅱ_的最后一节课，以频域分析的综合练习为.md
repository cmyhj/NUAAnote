## 关键概念

| 概念 | 说明 |
|------|------|
| 开环传递函数 | 系统前向通路与反馈通路传递函数的乘积 |
| 相角裕度 γ | γ = 180° + ∠G(jω_c)H(jω_c)，γ > 0 系统稳定 |
| 增益裕度 G_m | G_m = 1/|G(jω_g)H(jω_g)|，G_m > 1 系统稳定 |
| 穿越频率 ω_c | 幅值为 0dB 时的频率（增益穿越） |
| 相位穿越频率 ω_g | 相角为 -180° 时的频率 |

## 要点详述

### 一、综合例题详解

给定系统的开环传递函数，要求：
1. 绘制系统的开环伯德图（对数幅频和相频）
2. 从图中读出增益穿越频率 ω_c 和相位穿越频率 ω_g
3. 计算相角裕度 γ 和增益裕度 G_m
4. 判断系统的稳定性及其裕量

### 二、课程核心内容回顾

本学期"控制系统工程Ⅱ"覆盖的五大知识模块：
1. **控制系统基本概念**（第1章）：反馈原理、系统组成、分类
2. **数学模型**（第2章）：微分方程、传递函数、结构图、信号流图
3. **时域分析法**（第3章）：一/二阶系统响应、性能指标、稳定性、稳态误差
4. **根轨迹法**（第4章）：根轨迹绘制规则、稳定性与性能分析
5. **频域分析法**（第5章）：伯德图、频域指标、稳定性裕度

### 三、期末考试提示

教师对本学期所学内容进行了总结梳理，强调了核心考点，包括：
- 传递函数的求解与化简

- 稳定性分析与劳斯判据
- 稳态误差计算
- 根轨迹的绘制与分析
- 伯德图的绘制与稳定裕度计算
