## 本节主线

本节聚焦控制系统的稳态性能——稳态误差（Steady-State Error）。稳态误差是衡量控制系统精度的重要指标，反映了系统稳定后输出与期望值之间的残余偏差。教师介绍了稳态误差的定义、计算方法，以及系统型别（Type）对稳态误差的影响，最后讲解了静态误差系数法（位置、速度、加速度误差系数）。

## 关键概念

| 概念 | 说明 |
|------|------|
| 稳态误差 e_ss | 系统稳定后，期望输出与实际输出的差值 |
| 误差定义 | e(t) = r(t) - c(t)（单位反馈系统）或 e(t) = r(t) - b(t) |
| 系统型别 | 开环传递函数中积分环节的个数 ν（Type 0/Ⅰ/Ⅱ） |
| 静态位置误差系数 K_p | 衡量系统跟踪阶跃输入时的稳态精度 |
| 静态速度误差系数 K_v | 衡量系统跟踪斜坡输入时的稳态精度 |
| 静态加速度误差系数 K_a | 衡量系统跟踪抛物线输入时的稳态精度 |
| 终值定理 | e_ss = lim_{s→0} s·E(s)，用于由 E(s) 求稳态误差 |

## 要点详述

### 一、稳态误差的计算

计算稳态误差的前提条件是系统必须稳定。基本方法：
1. 终值定理法：e_ss = lim_{s→0} s·E(s)
2. 静态误差系数法：根据系统型别和输入信号类型查表

### 二、系统型别与静态误差系数

开环传递函数标准形式：G(s) = K·Π(τs+1) / [s^ν·Π(Ts+1)]

- **Type 0 系统**（ν=0）：K_p = K，对阶跃输入有稳态误差
- **Type Ⅰ 系统**（ν=1）：K_v = K，能无静差跟踪阶跃，对斜坡输入有常值误差
- **Type Ⅱ 系统**（ν=2）：K_a = K，能无静差跟踪阶跃和斜坡，对抛物线输入有常值误差

提高系统型别或增大开环增益 K 都可以减小稳态误差，但会影响系统的稳定性。

### 三、不同输入下的稳态误差

| 输入信号 | Type 0 | Type Ⅰ | Type Ⅱ |
|---------|--------|--------|--------|
| 阶跃 r(t)=1 | 1/(1+K_p) | 0 | 0 |
| 斜坡 r(t)=t | ∞ | 1/K_v | 0 |
| 抛物线 r(t)=t²/2 | ∞ | ∞ | 1/K_a |
