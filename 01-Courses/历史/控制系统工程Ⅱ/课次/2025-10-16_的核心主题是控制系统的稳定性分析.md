## 本节主线

本节课的核心主题是控制系统的稳定性分析。教师首先给出了稳定性的严格定义——系统在扰动消失后能否恢复原平衡状态，然后介绍了劳斯-赫尔维茨稳定判据（Routh-Hurwitz Criterion），这是一种无需求解特征方程根就能直接判断系统稳定性的代数方法。最后通过多个例题演示了该判据在不同阶次系统中的应用。

## 关键概念

| 概念 | 说明 |
|------|------|
| 稳定性 | 系统受扰动偏离平衡状态，扰动消失后能恢复到原平衡状态的能力 |
| 闭环极点 | 闭环传递函数分母多项式的根（特征根） |
| 左半平面 | 复平面实轴左侧区域（Re(s) < 0），极点位于此处系统稳定 |
| 劳斯判据 | 根据特征方程系数直接判断系统稳定性的代数方法 |
| 劳斯表 | 由特征方程系数按规则排列构造的判定表 |
| 临界稳定 | 极点位于虚轴上，系统输出等幅振荡 |
| 条件稳定 | 系统稳定性取决于某个参数取值的系统 |

## 要点详述

### 一、稳定性定义

系统稳定性是指：系统受到扰动偏离原平衡状态，当扰动消失后，如果系统能够逐渐恢复原平衡状态，则系统是稳定的；否则是不稳定的。线性系统的稳定性完全由系统结构和参数决定，与输入信号无关。

### 二、稳定性与极点位置

闭环极点（特征根）在复平面上的位置决定了系统的稳定性：
- 所有极点均位于左半平面 → 系统稳定
- 存在极点位于右半平面 → 系统不稳定
- 存在极点位于虚轴（其余在左半平面）→ 临界稳定

### 三、劳斯-赫尔维茨稳定判据

劳斯判据的步骤：
1. 写出系统特征方程：a₀sⁿ + a₁sⁿ⁻¹ + ... + aₙ = 0
2. 构造劳斯表（前两行为系数行，后续行按公式计算）
3. 若首列所有元素均大于0 → 系统稳定
4. 若首列符号变化次数 → 右半平面极点个数

**特殊情况处理**：
- **首列为零**：用一个小正数 ε 代替，继续计算
- **全零行**：存在对称于原点的根，用辅助多项式求导后替换
