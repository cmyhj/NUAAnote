## 关键概念

| 概念 | 说明 |
|------|------|
| 结构图 | 用图形方式表示控制系统各环节之间信号传递关系的工具 |
| 传递函数 | 零初始条件下，输出拉式变换与输入拉式变换之比 |
| 串联连接 | 前一环节的输出是后一环节的输入，总传递函数为各环节乘积 |
| 并联连接 | 各环节输入相同，输出相加，总传递函数为各环节之和 |
| 反馈连接 | 输出经反馈环节回到输入端的连接方式 |
| 比较点 | 对多个信号进行代数求和（通常做差）的点 |
| 引出点 | 从某处将信号分路引出的点 |

## 要点详述

### 一、结构图的基本组成

结构图由四种基本元素构成：信号线（带箭头的线段，表示信号传递方向）、比较点（求和点，对信号进行加减运算）、引出点（信号分路点）和功能框（传递函数方框）。

### 二、基本连接的等效变换

1. **串联**：G(s) = G₁(s)·G₂(s)·...·Gₙ(s)
2. **并联**：G(s) = G₁(s) + G₂(s) + ... + Gₙ(s)
3. **负反馈**：Φ(s) = G(s) / [1 + G(s)H(s)]
4. **正反馈**：Φ(s) = G(s) / [1 - G(s)H(s)]

### 三、比较点和引出点的移动

化简复杂结构图时，常常需要移动比较点或引出点的位置：
- 比较点前移/后移：需串入相应的传递函数环节
- 引出点前移/后移：同样需串入相应的传递函数环节

移动的基本原则：移动前后，被移动点之后的信号保持不变。
