## 要点详述

### 一、电位器式水位反馈控制系统工作流程（00:43–10:11）

接续上节课内容，对电位器式水位控制系统进行完整梳理：

- **平衡状态**：实际水位 = 期望水位，电位器滑壁居中，Ue = 0 → 放大器输出 Ua = 0 → 电动机不转 → 进水阀门开度不变
- **扰动（出水量增大）**：水位下降 → 浮子下沉 → 滑壁上移 → Ue > 0 → 放大器输出 Ua > 0 → 电动机正转 → 减速器带动进水阀门开大 → 进水量增加 → 水位回升
- **扰动（出水量减小）**：水位上升 → 浮子上浮 → 滑壁下移 → Ue < 0 → 电动机反转 → 阀门关小 → 水位下降

通过该实例引出控制系统的一般结构：任何自动控制系统均可划分为**控制器**（给定、比较、放大、执行、校正等元件）和**被控对象**两大部分。

### 二、飞机俯仰角自动控制系统（10:12–19:10）

以飞机俯仰角控制为例，介绍了多回路反馈系统的工作原理：

**系统组成**：
- **给定元件**：给定期望俯仰角 θ₀
- **测量元件**：垂直陀螺仪（将角度转换为电压信号）
- **放大元件**：放大器
- **执行元件**：舵机（驱动升降舵）
- **局部反馈**：反馈电位器（监测舵机实际偏转量）
- **被控对象**：飞机
- **被控量**：实际俯仰角 θ

**工作过程**：
1. 平衡时 θ₀ = θc（期望值），垂直陀螺仪无电压输出
2. 受气流干扰 → 实际俯仰角偏离期望值 → 陀螺仪输出与偏差成正比的电压信号
3. 信号经放大器输入舵机 → 推动升降舵向上偏转 → 产生抬头力矩 → 减小俯仰角偏差
4. 同时反馈电位器将舵偏角对应的电压信号反馈到输入端，防止舵机操作过量
5. 随偏差减小，陀螺仪输出减小，舵偏角随之减小，直至恢复平衡

**两层反馈的作用**：
- **主反馈**（陀螺仪→输入端）：控制飞机整体的俯仰角
- **局部反馈**（舵机→输入端）：精确控制舵机的操作量，防止超调

### 三、课堂练习：汽车定速巡航系统（19:10–31:23）

教师布置课堂练习：画出汽车定速巡航控制系统的反馈框图。学生板演后，教师点评指出常见错误：

**正确框图要点**：
- 给定速度信号 → 控制器 → 驱动装置（执行元件）→ 汽车（被控对象）→ 实际速度（输出）
- 反馈应从汽车的实际速度输出引出（而非从中间环节引出）
- 需包含比较元件（标注负号）和测量元件（速度传感器）

### 四、控制系统的三大性能要求（31:24–36:08）

1. **稳定性（稳）**：系统在扰动消失后能恢复平衡。线性系统的稳定性由系统结构和参数决定，与外界因素无关
2. **快速性（快）**：系统响应输入变化的迅速程度。由动态性能指标衡量，后续章节详细介绍
3. **准确性（准）**：系统稳态时输出与期望值的偏差大小。用稳态误差衡量，是控制系统精度的标志

### 五、典型外作用信号（36:08–48:10）

为了统一评价控制系统的性能，需要定义典型的输入测试信号：

**1. 阶跃函数**：
- 数学表达式：t < 0 时为零，t ≥ 0 时为常数 R
- 单位阶跃函数（R=1）记作 1(t)
- 物理意义：在 t=0 时刻将恒定外作用突然施加到系统上
- 重要性：阶跃响应是评价系统动态性能的标准依据

**2. 斜坡函数**：
- 数学表达式：t < 0 时为零，t ≥ 0 时以恒定速率 R 线性增长
- 应用场景：雷达跟踪系统（目标以恒定速率运动时）

**3. 脉冲函数**：
- 由两个阶跃函数合成，宽度 t₀ → 0 时得到理想脉冲
- 面积（强度）A = 1 时称为单位脉冲函数（δ 函数）
- 实际系统中不存在，但具有重要的数学分析意义
