## 关键概念
- **单位制一致性**: FEA 软件本身无单位，需要用户保持输入数据的单位封闭一致。常用组合：国际单位（m-N-kg-s）或 mm-N-ton-s，应力对应 Pa 或 MPa
- **一致质量 (Consistent Mass)**: 用形函数积分推导的质量矩阵，与刚度矩阵使用相同的形函数，矩阵非对角元素不为零
- **集中质量 (Lumped Mass)**: 将单元质量等分到各节点，形成对角矩阵，求逆速度快，工程中常用
- **固有频率 (Natural Frequency)**: 无阻尼自由振动的频率，由特征值问题 Kφ = ω²Mφ 求解
- **模态分析 (Modal Analysis)**: 求解系统矩阵 M⁻¹K 的特征值和特征向量，也称实特征值分析
- **刚体模态**: 无约束结构的前6个频率接近于零的模态（3平动+3转动），可用于验证建模质量

### 2. 单自由度振动基础
- 固有频率公式：ω = √(k/m)，单位 rad/s，除以 2π 得 Hz
- 阻尼比：钢材一般在 0.5%-1.5%
- 幅频特性图是隔振/减振设计的核心工具
- 频率比（激励频率/固有频率）决定隔振效果

### 3. 质量矩阵的两种形式
- **一致质量**：用形函数 N 在单元域上积分，M = ∫ρA·N^T·N·dx，结果为对称非对角阵
- **集中质量**：将质量等分到节点，形成对角阵，求逆快但精度略低
- 算例对比：一个杆单元，一致质量 ω₁ = √3/2 ≈ 1.7，集中质量 ω₁ = √2/2 ≈ 1.4，精确解为 1.57
- 两个单元时误差减小，说明网格细化可提高精度
- 高阶模态误差比低阶大
- 航空航天软件中还有耦合质量 (Coupled Mass)，精度更高

### 4. 多自由度模态分析
- 系统方程：Mü + Ku = 0，假设简谐振动 u = φ·sin(ωt)
- 转化为特征值问题：(K - ω²M)φ = 0
- 特征值 ω² 开方得固有频率，特征向量 φ 为模态振型
- 加权正交性：φᵢ^T M φⱼ = 0（i≠j），这是模态叠加法的基础
- 无约束结构前6个频率应接近于零（刚体模态），可用于验证建模
