## 关键概念

| 概念 | 说明 |
|------|------|
| **位移法** (displacement method) | 以节点位移为基本未知量，先求位移再求力的求解策略 |
| **单元刚度矩阵** (element stiffness matrix) | 描述单元节点力与节点位移之间关系的矩阵 `{f} = [k]{u}` |
| **总体刚度矩阵** (global stiffness matrix) | 将所有单元刚度矩阵按节点编号"对号入座"叠加得到 |
| **组集** (assembly) | 将单元刚度矩阵叠加到总体刚度矩阵的过程，本质是力的叠加 |
| **边界条件** (BC) | 已知位移（约束）或已知力（载荷），是求解定解的必要条件 |
| **自由度** (DOF) | 节点上能发生独立变形的方向数（弹簧:1, 平面三角形:6, 空间梁:6） |
| **NVH** | Noise, Vibration, Harshness — 汽车行业核心指标之一 |

## 要点详述

### 弹簧系统有限元回顾 [00:57-17:25]

- 单自由度弹簧的平衡方程 `f = k(u₁ − u₂)` 写成矩阵形式即得到 **2×2 单元刚度矩阵**。
- **组集方法**：每个单元刚度矩阵的元素按照节点编号"对号入座"放入总体矩阵，共享节点上的刚度值叠加（例如中间节点上的刚度是 `k₁ + k₂`）。
- **边界条件处理**（位移法）：
  1. 找出位移已知（通常为 0）的节点
  2. 从总体刚度矩阵中删除对应的行和列
  3. 求解缩减后的线性方程组得到未知位移
  4. 将位移代回原方程求未知支反力
- 示例：两弹簧三节点（2 springs, 3 nodes）→ 3×3 总体刚度矩阵；三弹簧四节点（3 springs, 4 nodes）→ 4×4 总体刚度矩阵。

### 有限元分析通用三步流程 [19:10-27:14]

1. **前处理 / 网格离散化** (meshing) — 将连续体划分为单元和节点，是最耗时的步骤之一。
2. **单元分析** (element analysis) — 推导单元刚度矩阵，建立单元平衡方程。
3. **整体求解与后处理** — 组集总体方程 → 引入BC → 求解位移 → 计算应力/应变（后处理）。

### 单元类型分类 [27:14-34:33]

- **0D 单元**：Ground（接地弹簧）、集中质量（mass），仅一个节点。
- **1D 单元**：弹簧(spring)、杆(rod, 仅轴向)、梁(beam, 含弯曲)、管(pipe)。梁单元每个节点 6 个自由度（3 平动 + 3 转动），2 节点梁单元刚度矩阵为 12×12。
- **2D 单元**：
  - **膜单元** (membrane) — 仅承受面内拉压，无弯曲刚度（适用于薄蒙皮等）
  - **板单元** (plate) / **壳单元** (shell) — 可承受弯曲（厚度超过 2–3 mm 时需使用）
- **3D 单元**：四面体（4 节点）、六面体（8 节点，等参数单元，收敛性好）。实体单元节点只有平动自由度，无转动自由度。

### 有限元法的工程应用 [34:33-43:54]

- **强度问题** (strength) — 最常见，以应力为衡量指标
- **稳定性问题** (buckling) — 薄壁结构屈曲，大变形非线性
- **振动与瞬态问题** — 颤振(flutter)：气动力与结构耦合，速度超过临界值振动发散
- **传热** (heat transfer) — 新能源车热管理、航空发动机热防护
- **电磁场** (electromagnetic field) — 磁悬浮、电子设备
- **流体力学** (CFD) — 有限体积法与有限元法本质相通

### 主流 FEA 软件 [47:56-51:04]

| 软件 | 特点 |
|------|------|
| **ANSYS / ANSYS Workbench** | 机械领域统治地位；高校版仅 1 元；模块最全（结构/流体/电磁/耦合） |
| **MSC Nastran** | NASA 开发，航空航天统治地位；求解效率高，无傻瓜式 GUI |
| **Abaqus** | 强非线性动力学；比 ANSYS/Nastran 便宜；欧洲高校广泛使用 |
| **HyperMesh** | 前/后处理工具，与前三者无缝衔接 |
| **COMSOL** | 多物理场耦合，当前很热门 |
