## 要点详述

### 一、滚动轴承代号解读（00:00–09:20）

**基本代号结构**（从右向左读）：

```
[类型] [宽度系列] [直径系列] [内径代号]
```

- **内径代号**：00=10mm, 01=12mm, 02=15mm, 03=17mm, 04~96=代号×5
- **直径系列**：表示外径大小（如 0(窄)、1(特轻)、2(轻)、3(中)、4(重)）
- **宽度系列**：表示宽度大小（可省略，省略为 0）
- **类型代号**：6—深沟球、7—角接触球、N—圆柱滚子、3—圆锥滚子、5—推力球

**示例解读**：
- `7205AC/P5`：7（角接触球）→ 宽度省略（0）→ 2（轻系列）→ 05（内径 25mm）→ AC（α=25°）→ P5（公差 5 级）
- `N205/P5`：N（圆柱滚子）→ 宽度省略 → 2（轻系列）→ 05（内径 25mm）→ P5
- `30205`：3（圆锥滚子）→ 0（宽度系列）→ 2（轻系列）→ 05（内径 25mm）

> **考试提醒**：这是**送分题**（约 5 分），务必掌握从右到左的解读顺序。

### 二、滚动轴承选型步骤（09:20–17:00）

| 步骤 | 内容 | 说明 |
|------|------|------|
| 1 | 确定载荷类型和方向 | 纯径向→深沟球/圆柱滚子；复合载荷→角接触/圆锥滚子；纯轴向→推力轴承 |
| 2 | 按轴径确定内径 | 轴径圆整到标准内径（如 24→25mm） |
| 3 | 先调外径 | 承载不够优先增大外径（直径系列），只需修改箱体孔 |
| 4 | 再调宽度 | 若外径调大仍不够，增加宽度系列 |
| 5 | 最后换类型 | 球→滚子（承载提高 1.5~3 倍），或换其他类型 |
| 6 | 校验极限转速 | 高速场合需考虑极限转速限制 |

**工程经验**：
- 轴径小于 20mm 时，球与滚子承载能力差别不大
- 课程设计中轴承不满足寿命要求时，**先调外径再调宽度**，不要贸然改轴

### 三、滚动轴承的应力特性（17:00–25:00）

| 部件 | 应力循环特性 | r 值 |
|------|-------------|------|
| **固定圈**（通常外圈） | 只有滚动体滚过时受载 → **脉动循环** | r = 0 |
| **旋转圈**（通常内圈） | 随轴旋转，载荷周期性变化 → **不对称循环** | 0 < r < 1 |
| **滚动体** | 在承载区/非承载区间交替 → 复杂循环 | 变化 |

> 应力特性联系前面第三章疲劳强度内容，是理解轴承疲劳失效的基础。

### 四、寿命计算基础（25:00–55:00）

#### 基本概念链

| 步骤 | 概念 | 说明 |
|------|------|------|
| ① | 基本额定寿命 L₁₀ | 同一批轴承，90% 不出现疲劳点蚀时的总转数（或小时数） |
| ② | 基本额定动载荷 C | 轴承在 L₁₀=10⁶ 转时能承受的最大载荷（查手册） |
| ③ | 寿命方程 | L₁₀ = (C/P)^ε × 10⁶（转） |
| ④ | 当量动载荷 P | P = X·Fr + Y·Fa（将复合载荷等效为单一直向载荷） |
| ⑤ | 派生轴向力 S | 角接触轴承由径向力 Fr 产生的附加轴向力 |

#### 寿命方程（考试必考）

**转数形式**：
```
L₁₀ = (C/P)^ε × 10⁶  (转)
```

**小时形式**（最常用）：
```
Lₕ = 10⁶/(60n) · (C/P)^ε  (小时)
```

其中：
- ε = 3（球轴承）
- ε = 10/3（滚子轴承）

**温度修正**（当工作温度 > 120°C）：
```
Cₜ = fₜ · C    (fₜ < 1)
```
然后将 Cₜ 代入寿命方程。

#### 当量动载荷 P 的确定流程

```
给定 Fa, Fr, C₀r
    ↓
计算 Fa/C₀r → 查表得 e
    ↓
比较 Fa/Fr 与 e：
    ├── Fa/Fr ≤ e → P = X·Fr + Y·Fa  (通常 Y=0, X=1)
    └── Fa/Fr > e → P = X·Fr + Y·Fa  (X<1, Y>0)
    ↓
考虑载荷系数 fₚ（有冲击时）：
    P' = fₚ · P
```

#### 派生轴向力 S 的处理

对于角接触球轴承和圆锥滚子轴承，需先计算 S 再确定各轴承的实际轴向力 Fa：

| 轴承类型 | 派生轴向力 S |
|---------|-------------|
| 圆锥滚子轴承（3 类） | S = Fr/(2Y) |
| 角接触球 25°（7 类 AC） | S = 0.68·Fr |
| 角接触球 40°（7 类 B） | S = 1.14·Fr |

**安装方式**：
- **正装（面对面）**：开口向内 → S 指向内侧
- **反装（背对背）**：开口向外 → S 指向外侧

由轴上所有轴向力（外部轴向力 FA + 派生力 S₁、S₂）的平衡关系，判断轴承的"压紧端"与"放松端"，从而确定每个轴承的实际 Fa。
