## 要点详述

### 一、螺纹连接类型与紧固件复习（00:55–07:40）

| 类型 | 特点 | 适用场景 |
|------|------|---------|
| **普通螺栓** | 螺杆与孔有间隙，靠预紧力产生的摩擦力承载 | 一般连接 |
| **铰制孔螺栓**（加强版螺栓） | 螺杆与孔无间隙（过盈/过渡配合），靠杆身受剪/挤压承载 | 承受横向载荷 |
| **双头螺柱** | 两端都有螺纹，坐端旋入、螺母端拧螺母 | 经常拆卸的场合 |
| **螺钉** | 直接旋入被连接件内螺纹 | 不常拆卸 |
| **紧定螺钉** | 端面抵住另一零件 | 固定位置 |

**垫圈的作用**：
- 增大支撑面积，减小压强
- **弹簧垫圈**：防松（尖端抵住 + 回弹增预紧力）

### 二、螺栓组受力分析核心方法（12:50–21:10）

分析步骤：**找到受力最大的螺栓** → 判断连接类型 → 调用相应公式。

#### 横向载荷

| 螺栓类型 | 承载机理 | 公式 |
|---------|---------|------|
| **普通螺栓** | 预紧力产生的摩擦力 | F₀ ≥ K_s·F_total / (f·i·z) |
| **铰制孔螺栓** | 杆身直接受剪/挤压 | F_i = F_total / z |

#### 轴向载荷（压力容器螺栓）（21:10–35:00）

**易错点**：螺栓总拉力 F₂ ≠ F₀ + F

**正确关系**：
```
F₂ = F₁ + F = F₀ + C_b/(C_b+C_m) × F
```

其中：
- F₀ = 初始预紧力
- F = 工作载荷（单个螺栓）
- F₁ = 残余预紧力（施加工作载荷后剩余的部分）
- C_b = 螺栓刚度系数
- C_m = 被连接件刚度系数
- C_b/(C_b+C_m) = **相对刚度系数**

**物理过程**：
1. 初始预紧 F₀ → 螺栓伸长 Δb，被连接件压缩 Δm
2. 施加工作载荷 F → 螺栓继续伸长 Δ，被连接件回弹 Δ
3. 螺栓总伸长 = Δb + Δ → 总拉力 F₂
4. 被连接件压缩量 = Δm - Δ → 残余预紧力 F₁

### 三、防松方法（11:16–12:50）

| 类别 | 原理 | 示例 |
|------|------|------|
| **摩擦防松** | 附加摩擦力阻止相对转动 | 弹簧垫圈、对顶螺母、尼龙圈锁紧螺母 |
| **机械防松** | 用机械元件直接锁住 | 开口销+六角开槽螺母、止动垫圈、串联钢丝 |
| **破坏螺纹副** | 使螺纹副变成不可拆卸 | 铆冲、焊接、涂胶 |

### 四、强度计算公式（41:30–50:00）

#### 松螺栓连接

```
σ = F / (πd₁²/4) ≤ [σ]
```

无预紧力，仅受轴向拉力。

#### 紧螺栓连接

螺栓拧紧后受：
- 轴向拉力 F₀ → 拉应力 σ
- 螺纹副摩擦力矩 → 扭转切应力 τ

按**第四强度理论**（最大变形能理论）合成：

```
σ_ca = √(σ² + 3τ²) ≈ 1.3σ
```

强度条件：
```
σ_ca = 1.3 × F₀ / (πd₁²/4) ≤ [σ]
```

> **1.3 倍系数**的来源：将扭转切应力（τ ≈ 0.5σ）按第四强度理论折算为等效拉应力。
