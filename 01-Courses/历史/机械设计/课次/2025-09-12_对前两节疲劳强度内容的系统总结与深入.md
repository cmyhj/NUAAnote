## 要点详述

### 一、核心知识回顾（02:12–17:24）

教师在正式开始新内容前，用约 15 分钟系统回顾了前两节课的核心内容：

**1. 基本参数与 S-N 曲线**

| 参数 | 定义 |
|------|------|
| σ_m = (σ_max + σ_min)/2 | 平均应力 |
| σ_a = (σ_max - σ_min)/2 | 应力幅 |
| r = σ_min / σ_max | 应力比（-1:对称, 0:脉动, 1:静应力） |

**S-N 曲线核心公式**（高周疲劳区 CD 段）：
```
σ_i^m · N_i = σ_0^m · N_0 = C（常数）
```

> "你只要记住这一个公式就够了，其他公式都是从这个基础上推导出来的。"

**2. 等寿命疲劳曲线（σ_m-σ_a 图）的四个关键点**

| 点 | 含义 | 坐标（σ_m, σ_a） |
|----|------|-----------------|
| A | r=-1（对称循环） | (0, σ_{-1}) |
| B | 静强度屈服 | (σ_s, 0) |
| D | r=0（脉动循环） | (σ_0/2, σ_0/2) |
| G | 45° 线与 AD 延长线交点 | σ_m + σ_a = σ_s |

**材料常数 ψ_σ**：
```
ψ_σ = (2σ_{-1} - σ_0) / σ_0
```
- 碳素钢：ψ_σ ≈ 0.1~0.2
- 合金钢：ψ_σ ≈ 0.2~0.3（考试若未给出，可取 0.2）
- ψ_σ 决定了 A-D 段直线的斜率 σ_a = σ_{-1} - ψ_σ · σ_m

> "考试没给你 ψ_σ？你就取 0.2，肯定不会给你改错。"

**3. 从材料到零件的修正**

三大影响因素，**仅影响应力幅 σ_a（纵坐标）**，不影响平均应力 σ_m（横坐标）：

| 因素 | 符号 | 影响 |
|------|------|------|
| 应力集中 | K_σ | 局部应力升高，疲劳极限下降 |
| 绝对尺寸 | ε | 尺寸越大，缺陷概率越高，疲劳极限下降 |
| 表面质量 | β | 表面越粗糙，疲劳极限越低；表面强化可提高 |

**零件疲劳极限**：
```
σ_{-1·零件} = σ_{-1·材料} × β × ε / K_σ
```

整个 ADGC 曲线沿纵坐标方向向下收缩，横坐标不变。

### 二、三种应力类型下的极限应力推算（22:00–41:15）

这是本节课的**核心内容**，也是考试重点。已知零件的等寿命疲劳曲线和一个工作点 M(σ_m, σ_a)，根据不同应力类型推算极限应力点 M'。

#### 类型一：r = 常数（应力比恒定）

**适用工况**：工作过程中 σ_min/σ_max 比值不变（最常见的简单应力循环）。

**推算方法**：
1. 连接原点 O 与工作点 M
2. 延长 OM 射线至与 ADGC 曲线相交于 M' 点
3. M' 即为极限应力点

**原因**：r 恒定意味着 σ_a/σ_m 为常数，即所有可能的应力状态位于从原点出发的同一条射线上。

**极限应力**：
```
σ_lim = σ_max' = σ_m' + σ_a'
```

**安全系数**：
```
S = σ_lim / σ_actual
```

#### 类型二：σ_m = 常数（平均应力恒定）

**适用工况**：平均应力保持不变，如弹簧的预压应力恒定。

**推算方法**：
1. 过 M 点做垂直线（平行于 σ_a 轴）
2. 向上延伸至与 ADGC 曲线相交于 M' 点

**特点**：这是最简单的类型——"你考到这个就笑醒了"。

#### 类型三：σ_min = 常数（最小应力恒定）

**适用工况**：最小应力保持不变（如车床主轴初始扭矩恒定）。

**推算方法**：
1. 过 M 点做斜率为 1 的 45° 线（因为 σ_min = σ_m - σ_a 为常数）
2. 延伸至与 ADGC 曲线相交于 M' 点

**注意**：需要区分 M' 落在 AD 段还是 GC 段，分别对应疲劳失效和塑性屈服。

#### 一般计算步骤（考试标准流程）

```
第一步：由外载荷求出 σ_max、σ_min → 计算 σ_m、σ_a
第二步：在 σ_m-σ_a 图上标出工作点 M
第三步：根据应力类型确定 M → M' 的延伸方向
   - r=C：连接 OM 做射线
   - σ_m=C：做垂线
   - σ_min=C：做 45° 线
第四步：求出 M' 的坐标 (σ_m', σ_a')
第五步：σ_lim = σ_max' = σ_m' + σ_a'
第六步：S = σ_lim / σ_actual（或按教材公式用安全系数法）
```

> "如果你能把 ADGC 的位置标好了，下面就是初中生都能干的事——解一次函数求交点。"

### 三、双向稳定变应力简介（41:15–44:00）

当零件同时受到两个方向的循环应力（如轴同时承受弯曲和扭转）时，需要采用**双向合成**的方法：

- 将弯曲正应力和扭转切应力分别写出其 σ_a、σ_m
- 按第三或第四强度理论合成为当量应力
- 在 σ_m-σ_a 图上用圆曲线（Gough 椭圆）进行校核

> "对于正常学习本课程，学到单向稳定变应力这一步就可以了。"

### 四、课后练习提示

教师给出了示例习题：
> "已知零件材料为合金钢，σ_{-1}=400MPa，σ_s=800MPa，试画出简化极限应力图（ADGC 曲线），并求 r=0.5 时的极限应力和安全系数。"

**提示**：
1. 合金钢取 ψ_σ=0.2
2. 由 ψ_σ 公式反求 σ_0
3. 确定 A、D、G、C 四点坐标
4. 连直线，标出工作点，按 r=C 方法求 M'
5. 该题通常 10 分，后续还可能有安全系数和损伤计算的小问
