## 要点详述

### 一、课程设计操作细节（00:00–27:00）

#### 1.1 设计耦合问题

**典型循环问题**：轴的最小直径 d<sub>min</sub> 根据扭矩法算出（例如 20mm）→ 选轴承时内径 20 → 但轴承承载能力可能不满足寿命要求 → 必须增大轴径（如到 25mm）→ 重新计算全部尺寸。

> 这不是设计错误，而是设计过程中必须进行的迭代。**第一次做有 50% 的人需要返工一部分。**

#### 1.2 图纸要求

| 项目 | 具体要求 |
|------|---------|
| **草图** | A3 或 A4，缩比绘制，只画主视图，标注核心尺寸（跨距、齿轮位置、中心距）；**下周五前签字** |
| **装配图** | A0，三视图 + 标题栏 + 技术特性表 + 技术要求 + 尺寸标注 |
| **零件图①** | A2，**低速轴**（含全部尺寸、公差、粗糙度、形位公差） |
| **零件图②** | A2，**低速级大齿轮**（含啮合参数表、齿形公差） |
| **设计说明书** | 手写（可用模板打印后手写填入），左边写过程右边写结果 |

**CAD 注意事项**：
- 建好图层（粗实线/细实线/点画线/剖面线），线型统一
- 比例按标准选取，**中心距必须与设计值一致**（老师会量）
- **禁止**用三维软件导出二维图（细节缺失严重，反而不省力）

#### 1.3 常见致命错误

| 错误类型 | 后果 | 避坑 |
|---------|------|------|
| 齿根圆与齿顶圆干涉 | 齿轮啮合错误→答辩扣大分 | 对照分度圆和模数验算齿顶高/齿根高 |
| 中心距与标注不符 | 老师一量就知道在抄图 | 保证图纸尺寸 = 计算值 |
| 齿轮啮合区不是 5 根线 | 约 30% 的人会错 | 齿顶圆×2 + 分度圆×2 + 齿根圆×1 |
| 轴承端盖/箱体画法错误 | 结构错误 | 参照 PPT 标准画法 |
| 油标/通气器/放油螺塞位置干涉 | 功能错误 | 注意打开空间（如油尺拔出时不碰其他件） |
| 剖面线未画 | 常规扣分项 | 所有剖切部分都画剖面线 |
| 标题栏信息错误（姓名/学号/老师） | 暴露抄袭 | 仔细填写 |

#### 1.4 题目解读

以 `t8-s5-1` 为例：
- **t8** = 减速器传动方案类型（对应一张方案简图）
- **s5** = 工况数据表编号（含功率、转速、工作条件等）
- **1** = 方案序号（对应表中第 1 行数据）

**特别注意**：
- 外面执行机构（链传动、锥齿轮等）的传动**只分配传动比、不算具体设计**
- t12 等带带传动的方案需要设计带传动（在设计说明书中写一页即可，不画在图上）

#### 1.5 答辩评分标准

| 等级 | 条件 |
|------|------|
| **优秀**（≥90） | 无结构/逻辑错误，≤5 处小错误（如剖面线缺失），回答流畅 |
| **良好**（80~89） | 错误 ≤10 处 |
| **中等**（70~79） | 错误 ≤15 处 |
| **及格**（60~69） | 错误较多但主要结构正确 |
| **不及格** | 严重错误（如没画键、轴断开了等）或抄袭 |

> **反抄袭**：教师会问"这个螺钉是干什么用的？"如果抄的图，这种细节问题一问就露馅。
> **延期答辩**：如果做不完可延期，但延期只有"及格"和"不及格"两档。

### 二、轴系结构改错终极练习（27:00–37:00）

教师用一张完整轴系结构图，带学生逐一找出 **14+ 个错误**：

| 编号 | 错误 | 正确做法 |
|------|------|---------|
| ① | **缺调整垫片**（左端盖） | 端盖与箱体间加垫片 |
| ② | **缺调整垫片**（右端盖） | 对称错误，与①算**同 1 个** |
| ③ | **缺键**（左端齿轮） | 传递扭矩必须加键 |
| ④ | **缺键**（右端联轴器） | 传递扭矩必须加键 |
| ⑤ | **轴段过长**（联轴器安装位） | 轴段应比轮毂短 2~3mm |
| ⑥ | **缺定位轴肩**（联轴器处） | 伸出端应有轴肩轴向定位 |
| ⑦ | **无间隙 + 缺毛毡圈** | 旋转件与端盖间留间隙并加密封 |
| ⑧ | **轴肩过高**（左轴承处） | 轴肩高度不能超过轴承内圈（拉马拆卸） |
| ⑨ | **轴肩过高**（右轴承处） | 对称错误，与⑧算**同 1 个** |
| ⑩ | **装配轴段过长**（轴承位） | 轴承位长度应等于轴承宽度，留台阶方便安装 |
| ⑪ | **轮毂 > 轴段**（齿轮处） | 轮毂长度 > 轴段 2~3mm |
| ⑫ | **端盖伸出段结构错误** | 轴伸出端盖处结构需配合密封 |
| ⑬ | **挡油环缺失** | 齿轮油润滑 + 轴承脂润滑 → 需加挡油环 |
| ⑭ | **箱体孔处缺线**（视图问题） | 局部剖视图线缺失 |
| ⑮ | **剖面线问题** | 剖切部分未画剖面线 |

> **考试提示**："考试给的图一般会有 10 个明确的错误，对称的算 1 个，你找 10 个就行。"

### 三、齿轮方向判定综合题回顾（37:00–45:00）

教师展示了包含直齿、斜齿、锥齿、蜗杆的综合传动系统图，核心要求：

1. **判断各轴转向**（从电机轴开始→逐轴推导）
2. **判断斜齿轮 / 蜗杆的旋向**（左旋/右旋）
3. **标注各齿轮的轴向力方向**
4. **标注各齿轮的圆周力方向**

**关键原则速查**：

| 齿轮类型 | 旋向 | 轴向力方向 |
|---------|------|-----------|
| 直齿圆柱齿轮 | — | 无轴向力 |
| 斜齿圆柱齿轮 | 主从动旋向**相反** | 主动轮用**左右手定则**（左旋左手、右旋右手，四指指转向，拇指指轴向力方向） |
| 锥齿轮 | — | 轴向力均**指向大端** |
| 蜗杆传动 | 蜗杆与蜗轮旋向**相同** | 蜗杆轴向力与蜗轮圆周力相反 |

> "这道题如果把齿轮/蜗杆/锥齿轮的受力方向都搞清楚了，整个机械设计最难的受力分析就掌握了。"
