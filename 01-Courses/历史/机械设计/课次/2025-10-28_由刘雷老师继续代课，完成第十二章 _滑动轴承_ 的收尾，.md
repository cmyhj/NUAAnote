## 要点详述

### 一、一维雷诺方程（00:00–12:00）

**最终形式**：
```
dp/dx = 6ηv(h - h₀) / h³
```

- **物理含义**：油膜压力沿 x 方向的变化率与动力粘度 η、相对速度 v、油膜厚度 h 及其最大压力处的厚度 h₀ 有关
- 当 h = h₀ 时，dp/dx = 0，该截面压力最大
- 当 h > h₀ 时，dp/dx > 0，压力上升（速度分布**凸**）
- 当 h < h₀ 时，dp/dx < 0，压力下降（速度分布**凹**）

> 教师强调：该方程**不要求记忆**，了解物理含义即可。

### 二、径向滑动轴承的动压形成过程（12:00–21:00）

| 阶段 | 状态 | 轴心位置 | 说明 |
|------|------|---------|------|
| ① 静止 | 未启动 | 轴瓦中心正下方 | 轴颈因重力接触轴瓦底部 |
| ② 爬升 | 刚启动 | 沿轴瓦内壁向右上方爬升 | 摩擦力方向与转动方向相反，推动轴颈上爬 |
| ③ 动压形成 | 转速升高 | 左上方 | 楔形间隙形成，油压产生，水平方向合力向左 |
| ④ 稳定运转 | 正常工作 | **左下方**（偏位角 φ） | 竖直方向油膜力 = 外载荷，水平方向合力 = 0 |

**考试要点**：给定轴颈转向（顺时针/逆时针），能判断最终稳定位置（左下方 vs 右下方）。

**关键参数关系**：
```
h_min = δ - e = r·ψ(1 - χ)
```
- δ：半径间隙
- e：偏心距（0 ≤ e < δ）
- χ：偏心率（越大→最小油膜厚度越小→承载能力越强）
- ψ：相对间隙，高速→取大值；重载→取小值

### 三、宽径比 B/d 的影响（25:00–26:50）

| B/d 小（窄轴承） | B/d 大（宽轴承） |
|-----------------|-----------------|
| 端泄量大，散热好 | 端泄量小，散热差 |
| 稳定性好 | 承载能力高 |
| 油膜压力沿轴向分布窄 | 油膜压力分布宽 |

**推荐范围**：0.3~1.5（与之前刘老师说的 0.5~1.5 略有差异，取较宽范围）

### 四、静压轴承与气体轴承（26:50–30:20）

#### 液体静压轴承
- **原理**：外部液压系统提供高压油，强制形成承载油膜
- **优点**：① 任何转速（包括零速）均有承载能力 ② 轴颈与轴承不直接接触，寿命长 ③ 油膜刚性好，运转平稳
- **缺点**：需要稳定的高压供油设备，成本高

#### 气体润滑轴承（气浮轴承）
- 介质：空气、氮气、氢气
- **优点**：极高转速（可达 10⁵ rpm）、低摩擦损失、无污染
- **缺点**：承载能力低（气体可压缩性大）
- 应用：高速离心机、原子反应堆、精密仪器

#### 滚动轴承的四大组成部分

| 部件 | 功能 | 材料 |
|------|------|------|
| **内圈** | 套在轴上，随轴转动 | 含铬合金钢（GCr15 等） |
| **外圈** | 固定在轴承座孔中，不转动 | 同上 |
| **滚动体** | 在内/外圈滚道间滚动（球/滚子/圆锥等） | 同上，HRC61~65 |
| **保持架** | 分隔滚动体，防止相互碰撞 | 低碳钢 |

#### 滚动轴承的优缺点

| 优点 | 缺点 |
|------|------|
| 摩擦阻力小，启动灵敏 | 抗冲击能力弱 |
| 效率高，润滑简便 | 高速时可能产生噪声 |
| 标准化→互换性好 | 承载能力一般低于滑动轴承（同等尺寸） |
