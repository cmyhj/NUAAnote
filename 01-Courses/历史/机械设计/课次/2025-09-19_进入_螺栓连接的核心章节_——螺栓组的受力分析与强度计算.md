## 要点详述

### 一、知识回顾（01:29–07:49）

快速回顾螺纹连接基础：
- **螺纹类型**：三角形(60°)、梯形(30°)、锯齿形、管螺纹
- **自锁条件**：λ ≤ ρ_v（螺纹升角 ≤ 当量摩擦角）
- **四种连接类型**：螺栓连接、螺钉连接、双头螺柱、紧定螺钉
- **两种螺栓连接**：普通螺栓（间隙配合）vs 铰制孔螺栓（无间隙配合）
- **防松方法**：摩擦防松（弹簧垫圈、双螺母、尼龙锁紧螺母）、机械防松（开口销、止动垫圈、串联钢丝）、永久防松（粘接、冲点）

### 二、螺栓组布局设计（07:49–17:40）

#### 基本原则

1. **对称均匀布置**：螺栓应按几何中心对称排列，受力均匀
2. **受力靠近边缘**：受扭矩或倾覆力矩时，螺栓尽量布置在边缘，利用大力臂减小单个螺栓受力
3. **避免过多铰制孔螺栓**：并排多个铰制孔螺栓时，因孔位加工误差难以同时对准，通常**只取两端两个做定位**，中间用普通螺栓
4. **留足扳手空间**：课程设计中的常见错误——螺栓紧贴凸缘导致扳手无法操作
5. **压力容器螺栓间距**：根据介质压力查标准表确定

#### 辅助承载措施

当横向载荷较大时，可在连接处加装：
- **套筒** —— 承受剪切，分担螺栓载荷
- **销轴** —— 定位兼承载
- **传感器螺栓** —— 监测载荷，超载时反馈信号

### 三、螺栓受力分析（17:40–52:00）

#### 3.1 横向载荷（普通螺栓）

**失效形式**：被连接件发生相对滑动（螺栓本身未断，但连接失效）

**设计条件**：
```
z · i · f · F₀ ≥ K_s · F
```
其中：
- z —— 螺栓个数
- i —— 连接面数（摩擦面数）
- f —— 接合面摩擦系数
- F₀ —— 单个螺栓预紧力
- K_s —— 工况系数（考虑震动、冲击）
- F —— 总横向外载荷

> "考试这道题为什么容易错？——螺栓个数不考虑、连接面数量不考虑、摩擦系数也不考虑，一步错步步错。"

#### 3.2 横向载荷（铰制孔螺栓）

**失效形式**：
1. 螺栓杆被**剪断**
2. 螺栓杆与孔壁接触面被**压溃**

**设计条件**（剪切强度）：
```
τ = F/(z · πd²/4) ≤ [τ]
```

**挤压强度**：
```
σ_p = F/(z · d · h) ≤ [σ_p]
```
其中 h 为螺栓杆与孔壁的接触高度。

#### 3.3 扭矩作用（普通螺栓）

仍以**摩擦力**抵抗扭矩，所有螺栓的预紧力 F₀ 相同。

**设计条件**：
```
K_s · T = f · F₀ · Σr_i
```
其中 r_i 为各螺栓到旋转中心的距离，Σr_i 为各距离之和。

由此可求出所需的预紧力 F₀。

#### 3.4 扭矩作用（铰制孔螺栓）

螺栓受力与**距旋转中心的距离成正比**（变形协调假设）。

**受力最大的螺栓**（距中心最远）：
```
F_max = T · r_max / Σr_i²
```

注意：此处分母为 r_i² 的累加，而不是 r_i 的累加——这是与普通螺栓的关键区别。

#### 3.5 轴向载荷——螺栓-被连接件变形协调 ★

这是**本章最难也是最核心**的内容。

**物理过程**（教师用动画演示）：

| 步骤 | 状态 | 螺栓 | 被连接件 |
|------|------|------|---------|
| 1. 预紧前 | 自由状态 | 无变形 | 无变形 |
| 2. 施加预紧力 F₀ | 拧紧后 | 被拉长 δ_b₀ | 被压缩 δ_m₀ |
| 3. 施加轴向工作载荷 F | 工作中 | 进一步拉长 Δδ_b | 回弹放松 Δδ_m |

**关键关系**：
- 工作载荷 F 被**两部分分担**：
  - 一部分使螺栓**进一步拉长**：ΔF_b = C_b × Δδ
  - 一部分使被连接件**回弹**：ΔF_m = C_m × Δδ
  - 且 ΔF_b + ΔF_m = F

**螺栓总拉力**：
```
F₂ = F₀ + ΔF_b = F₀ + C_b/(C_b+C_m) × F
```

**残余预紧力**：
```
F₁ = F₀ - ΔF_m = F₀ - C_m/(C_b+C_m) × F
```

其中：
- C_b —— 螺栓刚度（= F/δ_b）
- C_m —— 被连接件刚度（= F/δ_m）
- C_b/(C_b+C_m) —— **相对刚度系数**，典型值 0.2~0.3

**密封要求**（压力容器/气密连接）：
```
F₁ = (1.5 ~ 1.8) × F
```

> "这个变形协调图我闭着眼睛都能画出来——但你们要自己画一遍才能真正理解。"
