## 要点详述

### 一、派生轴向力 S 的产生机理（16:30–22:00）

角接触轴承的滚动体与滚道接触面是**倾斜**的（相对于轴线）。当径向力 Fr 作用在轴承上时，由于接触面倾斜，会产生一个**附加的轴向分力** S，方向由轴承的安装朝向决定。

**S 的计算公式**（不同轴承类型）：

| 轴承类型 | 派生轴向力 S | 说明 |
|---------|-------------|------|
| 圆锥滚子轴承（3 类） | S = Fr/(2Y) | Y 为轴向系数 |
| 角接触球 15°（7 类 C） | S ≈ 0.38·Fr | 约值 |
| 角接触球 25°（7 类 AC） | S = 0.68·Fr | **常用** |
| 角接触球 40°（7 类 B） | S = 1.14·Fr |  |

### 二、正装（面对面）下压紧/放松判断（22:00–35:00）

**结构特点**：两轴承开口相对，派生力 S 方向指向内侧。

```
     ← S₁          S₂ →
  ┌───┐            ┌───┐
  │ 1 │────轴──────│ 2 │
  └───┘            └───┘
```

**判断步骤**：

1. 标出每个轴承的 S₁、S₂ 方向
2. 计算 S₁ 和 S₂ 的大小（根据 Fr 计算）
3. 确定外部轴向力 FA 的方向和大小
4. 比较 FA + S₂ 与 S₁（注意方向相同相加，相反相减）：
   - **若 FA + S₂ > S₁** → 轴向合力向右 → 轴有右移趋势
     - 轴承 1（左侧）被**压紧**
     - 轴承 2（右侧）被**放松**
   - **若 FA + S₂ < S₁** → 轴向合力向左 → 轴有左移趋势
     - 轴承 2（右侧）被**压紧**
     - 轴承 1（左侧）被**放松**

**核心口诀**：
- **压紧端**的 Fa = 所有外部轴向力的**代数和**（不考虑自身的 S）
- **放松端**的 Fa = 其自身的 **S**（不考虑外部力）

> 戴老师比喻：你被压紧时（外部给压力），你的压力来自外部总和，跟你自己有多大本事（S）没关系；你被放松时，你的压力只来自你自己（S）。

### 三、反装（背对背）下压紧/放松判断（35:00–42:00）

**结构特点**：两轴承开口相背，派生力 S 方向指向外侧。

```
     S₁ →            ← S₂
  ┌───┐            ┌───┐
  │ 1 │────轴──────│ 2 │
  └───┘            └───┘
```

> 注意：反装时需有**挡圈**（卡圈）定位，防止轴承被挤出。

**判断方法**（与正装本质相同，仅因 S 方向反了导致结果不同）：

- **若 FA + S₂ > S₁** → 轴向合力向右
  - 正装时：轴承 1 被压紧
  - **反装时：轴承 1 被压紧**（相同！但压紧力的传递路径不同）
- **若 FA + S₂ < S₁** → 轴向合力向左
  - 正装时：轴承 2 被压紧
  - **反装时：轴承 2 被压紧**

**本质规律**：无论正装还是反装，**判断原则完全一致**——比较所有方向一致的力之和与反向的力，合力指向哪一侧，哪一侧的轴承被压紧。

### 四、完整例题演示（42:00–50:00+）

**已知条件**：
- 轴承类型：角接触球轴承（AC，α=25°）
- Fr₁ = 1050 N，Fr₂ = 700 N
- 外部轴向力 FA = 800 N（向右）
- S = 0.68·Fr

**计算步骤**：

| 步骤 | 内容 | 结果 |
|------|------|------|
| ① 计算 S | S₁ = 0.68 × 1050 = 714 N（←）<br>S₂ = 0.68 × 700 = 476 N（→） | |
| ② 比较 | FA(→) + S₂(→) = 800 + 476 = 1276 N > S₁(←) = 714 N | 合力向右 |
| ③ 判断 | 轴有右移趋势 → **轴承 1 被压紧**，轴承 2 被放松 | |
| ④ 求 Fa₁ | 压紧端 Fa₁ = FA + S₂ = 800 + 476 = **1276 N** | |
| ⑤ 求 Fa₂ | 放松端 Fa₂ = S₂ = **476 N** | |

得到 Fa₁、Fa₂ 后，代入当量动载荷公式 P = X·Fr + Y·Fa，再代入寿命方程求 L。

### 五、完整寿命计算流程总结

```
① 确定轴承类型 → 查 C（基本额定动载荷）
② 计算各轴承的 Fr（由齿轮等外部载荷计算）
③ 若为角接触轴承：
   ├ 计算派生力 S
   ├ 判断正装/反装
   ├ 判断压紧/放松
   └ 确定实际 Fa
④ 计算当量动载荷 P = X·Fr + Y·Fa
⑤ 代入寿命方程 Lₕ = 10⁶/(60n)·(C/P)^ε
⑥ 校核是否满足要求寿命
```
