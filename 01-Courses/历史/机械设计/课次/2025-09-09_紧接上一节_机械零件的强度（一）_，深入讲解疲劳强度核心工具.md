## 要点详述

### 一、S-N 曲线的深入理解（02:15–14:00）

教师将 S-N 曲线（也称 σ-N 曲线）分成四个区域逐一讲解：

| 区域 | 循环次数范围 | 名称 | 特征 |
|------|------------|------|------|
| A-B | 0 ~ 10^3 | 低周疲劳区 | 应力接近静强度，材料发生明显塑性变形后失效 |
| B-C | 10^3 ~ 10^4 | 过渡区/有限寿命区 | 介于低周与高周之间，强度随寿命快速下降 |
| C-D | 10^4 ~ 10^7 | 高周疲劳区 | **机械零件最常见的失效区间**，满足 σ_r^m · N = C |
| D 以后 | > 10^7 | 无限寿命区 | 应力低于疲劳极限 σ_r，理论上永不疲劳破坏 |

**核心公式**（CD 段）：

```
σ_r^m · N = C（常数）
```

其中：
- **σ_r**：应力比 r 对应的应力
- **m**：材料指数（钢取 9 左右，青铜等有色金属在拉弯剪工况下不同）
- **N**：循环次数
- **C**：常数，可由 D 点（σ_r, N_0=10^7）确定

由此可推导出有限寿命下的疲劳极限计算式：

```
σ_rN = σ_r · ⁿ√(N_0/N)，其中 n = m
```

教师强调："公式变化来变化去都是从它推导出来的，**记住这个基本公式就够了**。"

**损伤累积的直观理解**（11:40–13:00）：
- 在不同应力水平下（如 400MPa 下跑了 0.5×10^5 次，500MPa 下跑了少量次数），可将各应力水平造成的损伤线性累加（线性累积损伤理论初步概念）。
- 教师以直升机主轴为例说明实际工程的复杂性：一个轴成本几百万元，只做了一个样件，只能"靠公式靠理论去探索"寿命预测。

### 二、材料的 σ_m-σ_a 等寿命疲劳曲线（15:30–34:00）

S-N 曲线只能描述**单一应力比 r** 下的疲劳行为，但实际零件承受的应力循环形式多种多样。σ_m-σ_a 图的作用就是将**同一种材料在不同 r 下的疲劳极限统一到一个图上**。

#### 4 个关键点的确定：

**A 点（r=-1，对称循环）**：
- σ_m = 0，σ_a = σ_{-1}
- 通过对称循环疲劳实验得到（S-N 曲线的 D 点）

**D 点（r=0，脉动循环）**：
- σ_m = σ_a = σ_0/2
- 通过脉动循环疲劳实验得到

**B 点/F 点（静强度屈服点）**：
- σ_a = 0，σ_m = σ_s
- 即材料的屈服强度

**G 点**：
- 过原点做 45° 线（σ_m = σ_a），与 AD 延长线的交点
- 落在 σ_m + σ_a = σ_s 的屈服线上

绘图流程（考试重点）：
1. 做对称循环 S-N 曲线 → 获得 A 点
2. 做脉动循环 S-N 曲线 → 获得 D 点
3. 确定屈服极限 B 点
4. 过原点做 45° 线，与 AD 延长线交于 G 点
5. 连接 A-D-G-C 得到等寿命疲劳曲线
6. 区域 O-A-D-G-C 为**安全区**，之外为失效区

**材料常数 ψ_σ 的意义**：

```
ψ_σ = (2σ_{-1} - σ_0) / σ_0
```

- ψ_σ 决定了 A-D 段直线的斜率
- 直线方程：σ_a = σ_{-1} - ψ_σ · σ_m
- 常见参考值：碳钢 ψ_σ ≈ 0.1~0.2
- 靠前可查表获得，考试时通常直接给出

> "这个 ψ_σ 的公式要记住，考试去年就考了——先让你把等寿命疲劳图做出来，再给定一个工作点推算疲劳极限。"

### 三、从材料到零件——三大影响因素（34:00–46:00）

材料数据（如 45 钢的 σ_{-1}）来自标准试件实验，实际零件的疲劳极限受以下因素影响：

#### 1. 应力集中（K_σ）
- 截面突变（键槽、轴肩、圆角、倒角、孔等）引起局部应力远大于名义应力
- 修正系数 K_σ（>1），使疲劳极限降低

#### 2. 绝对尺寸（ε）
- 零件尺寸越大，内部缺陷概率越高，热处理和加工的一致性越差
- 类比：发面时一坨面与一张面发酵程度不同
- 修正系数 ε（<1），使疲劳极限降低

#### 3. 表面质量（β）
- 表面粗糙度（越粗糙越容易萌生裂纹）
- 表面强化处理（喷丸、渗碳、氮化、滚压等可提高表面硬度，提升疲劳极限）
- 修正系数 β（可大于或小于 1）

#### 综合修正公式：

```math
σ_{-1·零件} = σ_{-1·材料} × (β × ε) / K_σ
```

**关键理解**：三大因素**只影响应力幅 σ_a（纵坐标）**，不影响平均应力 σ_m（横坐标）。因此从材料曲线（A'D'G'C'）到零件曲线（ADGC），整个图形沿纵坐标方向向下收缩。

### 四、极限应力的推算方法概述（46:00–51:08）

已知零件的等寿命疲劳图和一个工作点 M(σ_m, σ_a)，如何推算该零件的极限应力（何时失效）？教师给出了三种常见应力类型，暂做概述，下节课详细展开：

1. **r = 常数**（应力比恒定）：连接 OM 并延长至与 ADGC 曲线相交
2. **σ_m = 常数**（平均应力恒定）：过 M 点做垂直线向上延伸至曲线
3. **σ_min = 常数**（最小应力恒定）：过 M 点做 45° 线延伸至曲线

> "有些同学问为什么是这么来的？——那就是我们下节课要继续学的内容。"
