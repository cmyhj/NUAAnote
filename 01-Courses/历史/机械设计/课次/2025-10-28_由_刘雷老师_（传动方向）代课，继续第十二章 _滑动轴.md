## 要点详述

### 一、润滑剂的选择（05:00–14:00）

#### 三种润滑剂对比

| 类型 | 状态 | 优点 | 缺点 | 适用场合 |
|------|------|------|------|---------|
| 润滑脂 | 半固体 | 密封简单、定期更换、不易流失 | 长期工作易变质 | 低速重载、摆动运动、不便供油处 |
| 润滑油 | 液体 | 散热好、可循环 | 需密封装置 | 通用场合，应用最广 |
| 固体润滑剂 | 固体 | 耐高温、无污染 | 寿命有限 | 太空/高温/清洁环境 |

#### 润滑油选择三原则

1. **重载低速** → 选**高粘度**润滑油（形成足够厚油膜）
2. **轻载高速** → 选**低粘度**润滑油（降低摩擦功耗）
3. **高温** → 选**高粘度**润滑油（补偿高温导致的粘度下降）

#### 润滑脂选用三原则

1. 压力高/速度低 → 锥入度**小**（更稠）
2. 工作温度 → 滴点至少高于轴承温度 20~30°C
3. 潮湿环境 → 选防水性能好的品种

### 二、非液体摩擦滑动轴承设计（14:00–27:50）

#### 失效形式与设计准则

| 失效形式 | 原因 | 设计准则 | 物理意义 |
|---------|------|---------|---------|
| 磨损 | 边界油膜破裂 → 直接接触 | p = Fr/(B·d) ≤ [p] | 限制接触面平均压力 |
| 胶合 | 摩擦发热 → 油膜破裂 → 局部焊接 → 撕裂 | pv ≤ [pv] | 限制摩擦功率（发热量） |
| 磨损加剧 | 滑动速度过高 | v ≤ [v] | 限制滑动线速度 |

#### 设计步骤

1. **确定轴承类型/结构/材料**（根据工作条件、载荷性质）
2. **选择宽径比 B/d**（推荐 0.5~1.5，B 为轴瓦宽度）
3. **三项校核**：
   - p = Fr/(B·d) ≤ [p]
   - pv = Fr/(B·d) · (πdn/60000) ≤ [pv]
   - v = πdn/60000 ≤ [v]
4. **选择配合**（孔轴配合公差）

### 三、流体动压润滑原理（27:50–50:00+）

#### 动压油膜形成三条件（考试重点）

1. **楔形间隙**：两相对滑动表面之间必须形成收敛间隙（大口进、小口出）
   - 平行板 → 无承载能力
   - 楔形板 → 有承载能力
2. **相对滑动速度**：运动方向须使润滑油从**大口流向小口**
   - 速度方向错误 → 无法形成动压
3. **润滑油有粘度且供油充分**
   - 粘度是传递剪切力的基础
   - 供油不足 → 油膜破裂

> 类比：冲浪板前端翘起（楔形）→ 在海面滑行（相对速度）→ 海水（流体）托起冲浪者

#### 微观机理

楔形间隙中，为满足**流量连续性**：
- 大口处：速度分布**凹**（中心速度低于线性分布）
- 小口处：速度分布**凸**（中心速度高于线性分布）
- 中间某截面：线性分布（速度梯度恒定）
- 由此产生的压力差 → 油膜具备承载能力

#### 雷诺方程简介

雷诺方程是**N-S 方程在润滑问题中的简化**，基于以下假设：

| 假设 | 内容 |
|------|------|
| ① 牛顿流体 | 剪切力 τ = η·du/dy（线性本构关系） |
| ② 层流 | 层与层之间无物质/能量交换 |
| ③ 忽略压力对粘度影响 | η 为常数（实际压力↑→粘度↑，但简化忽略） |
| ④ 忽略惯性力和重力 | 仅考虑表面力（压力+剪切力） |
| ⑤ 流体不可压缩 | 密度为常数 |
