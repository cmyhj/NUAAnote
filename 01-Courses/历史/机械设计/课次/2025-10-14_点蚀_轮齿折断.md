## 本节主线

本节课正式进入**齿轮传动**章节。教师首先简要回顾了带传动的设计流程，然后转入齿轮传动的系统介绍。前半部分复习了齿轮的基本类型、几何参数（模数 m、分度圆、压力角 α=20°、齿顶高/齿根高、顶隙系数）和精度等级（1~12 级），强调了齿轮传动相比带传动的优缺点（效率高、传动比恒定、寿命长，但成本高、不适合长距离）。后半部分重点讲解了齿轮的**失效形式**（轮齿折断、齿面点蚀、磨粒磨损、胶合、塑性变形）及对应的**设计准则**——开式齿轮按磨损设计（模数放大），闭式齿轮按齿面接触疲劳或齿根弯曲疲劳设计。最后提出齿轮材料的核心要求：**齿面硬、心部韧**。

## 要点详述

### 一、带传动设计流程回顾（01:45–06:01）

```
① 计算功率 P_ca = K_A · P  → ② 选带型 → ③ 确定基准直径 d_d₁、d_d₂
→ ④ 验算带速 v（5 ~ 25 m/s）→ ⑤ 初选中心距 a₀ → ⑥ 计算带长 → 取标准值
→ ⑦ 反推实际中心距 a → ⑧ 验算小轮包角 α₁（≥ 120°）→ ⑨ 确定 V 带根数 z
→ ⑩ 计算轴压力 F_Q
```

### 二、齿轮传动概述（06:22–15:17）

#### 齿轮传动的优缺点

| 优点 | 缺点 |
|------|------|
| ✅ 传动效率高（可达 0.99） | ❌ 加工精度要求高、成本高 |
| ✅ 传动比恒定（无弹性滑动） | ❌ 不适用于长距离传动 |
| ✅ 使用寿命长、可靠性高 | ❌ 无过载保护（不像带传动可打滑） |
| ✅ 结构紧凑、功率范围广 | ❌ 制造/安装误差易引起振动噪声 |

#### 齿轮类型复习

| 类型 | 轴线关系 | 特点 |
|------|---------|------|
| **直齿圆柱齿轮** | 平行 | 最常用，无轴向力 |
| **斜齿圆柱齿轮** | 平行 | 传动平稳，有轴向力，可通过调整螺旋角 β 适应交错轴 |
| **人字齿轮** | 平行 | 消除轴向力，用于大功率 |
| **锥齿轮** | 相交（多 90°） | 用于相交轴传动 |
| **蜗轮蜗杆** | 交错（多 90°） | 大传动比，自锁可能 |

### 三、齿轮几何参数与精度（15:17–35:55）

#### 基本参数

| 参数 | 公式 | 标准值 |
|------|------|--------|
| 分度圆直径 | d = m·z | — |
| 齿顶高 | h_a = h_a\*·m | h_a\* = **1** |
| 齿根高 | h_f = (h_a\* + c\*)·m | c\* = **0.25** |
| 齿全高 | h = (2h_a\* + c\*)·m | h = 2.25m |
| 齿顶圆直径 | d_a = d + 2h_a = m(z + 2) | — |
| 齿根圆直径 | d_f = d - 2h_f = m(z - 2.5) | — |
| 中心距 | a = (d₁ + d₂)/2 = m(z₁ + z₂)/2 | — |
| 传动比 | i = z₂/z₁ = d₂/d₁ | — |

#### 顶隙 c = c\*·m 的两个作用

1. **避免干涉**：防止一个齿轮的齿顶与另一个齿轮的齿根过渡曲线干涉
2. **储存润滑油**：为齿面啮合提供润滑

#### 精度等级

齿轮精度共 **1~12 级**（1 级最高，12 级最低）：

| 精度等级 | 使用场合 |
|---------|---------|
| 1~3 级 | 极高精度（极少用到） |
| 4~5 级 | **航空**齿轮（如航发传动） |
| 6~7 级 | 高精度通用机械、汽车变速箱 |
| **7~8 级** | **课程设计常用** |
| 9~12 级 | 低精度、低速机械 |

**三类误差**：
1. **运动准确性误差**——齿轮转一圈的最大转角误差
2. **运动平稳性误差**——啮合过程中的瞬时速度波动（通过振动/噪声反映）
3. **载荷分布均匀性误差**——齿宽方向载荷分布不均（齿向误差）

### 四、开式齿轮 vs 闭式齿轮（35:55–38:55）

| 对比项 | 开式齿轮 | 闭式齿轮 |
|--------|---------|---------|
| 工作环境 | 裸露在外，工况恶劣 | 封闭箱体，润滑良好 |
| 主要失效 | **齿面磨损** | **点蚀**（软齿面）或**弯曲疲劳**（硬齿面） |
| 设计准则 | 按齿根弯曲强度设计，**放大模数**以预留磨损量 | 软齿面→接触强度；硬齿面→弯曲强度 |
| 典型应用 | 风机大型齿轮、矿山机械 | 减速器、变速箱 |

### 五、齿轮的失效形式（40:55–50:27）

#### ① 轮齿折断（tooth breakage）

- **位置**：从**齿根**开始（应力集中最大处）
- **原因**：弯曲疲劳（交变应力）或意外过载
- **断口特征**：垂直于齿根（沿公法线方向）
- **对策**：
  - 正变位（增大齿根厚度）
  - 加大齿根过渡圆角半径
  - 消除加工刀痕（减少应力集中）
  - 喷丸强化（表面残余压应力）
  - 齿面硬、心部韧（表面抗磨、芯部抗弯）

#### ② 齿面点蚀（pitting）——接触疲劳

- **机理**：交变接触应力→表面微裂纹→润滑油渗入裂纹→在压力下裂纹扩展→材料剥落→形成凹坑
- **类比**：零食包装上的缺口——有了初始缺陷后很容易撕开
- **危害**：引起振动噪声，严重时导致轮齿折断
- **多发于**：闭式软齿面齿轮

#### ③ 磨粒磨损（abrasive wear）

- **原因**：外界硬颗粒（灰尘、金属屑）进入啮合区
- **与点蚀的本质区别**：磨损是物理刮削，不是疲劳

#### ④ 齿面胶合（scoring）

- **原因**：重载、低速、缺油条件下，齿面金属直接接触→局部高温→粘着→撕裂
- **特征**：齿面出现沿滑动方向的划痕

#### ⑤ 塑性变形（plastic flow）

- **原因**：重载下材料屈服，齿面发生塑性流动

### 六、齿轮材料的核心要求（46:05–47:45）

```
齿面硬（抗接触疲劳）+ 心部韧（抗弯曲断裂）
```

> "齿轮叫'色厉内荏'——这是个贬义词，但形容齿轮正好：齿面要硬（色厉），内部要有韧性（内荏）。"

**实现方法**：
- 表面硬化处理（渗碳、渗氮、感应淬火）
- 喷丸强化（shot peening）——高速弹丸冲击齿面，产生残余压应力，抑制裂纹扩展
