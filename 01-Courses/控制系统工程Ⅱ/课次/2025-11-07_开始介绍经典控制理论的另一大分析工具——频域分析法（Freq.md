## 本节主线

本节课开始介绍经典控制理论的另一大分析工具——频域分析法（Frequency Response Method），重点讲解了伯德图（Bode Plot）的绘制方法。频域分析法通过研究系统对正弦输入信号的稳态响应来分析系统特性，可以直观地展示系统在不同频率下的增益和相位变化规律。

## 关键概念

| 概念 | 说明 |
|------|------|
| 频率响应 | 系统对正弦输入信号的稳态输出，幅值和相位随频率变化 |
| 幅频特性 | 输出幅值与输入幅值之比随频率的变化关系 |
| 相频特性 | 输出相位与输入相位之差随频率的变化关系 |
| 伯德图 | 对数坐标下的频率特性图，包含对数幅频曲线和相频曲线 |
| 对数幅频 | 20lg|G(jω)|（单位 dB）随 lgω 的变化曲线 |
| 转折频率 | 典型环节伯德图斜率发生变化的特征频率 |
| 增益裕度 | 相角为 -180° 时对应的幅值倒数，衡量系统相对稳定性 |
| 相角裕度 | 幅值为 0dB 时对应的相角与 -180° 之差 |

## 要点详述

### 一、频率响应和伯德图

频率响应法的基本思想：给系统输入不同频率的正弦信号，观察输出信号的幅值和相位变化。伯德图用两张图（对数幅频曲线和相频曲线）来表示这种频率依赖关系，横坐标 ω 采用对数坐标。

### 二、典型环节的伯德图

1. **比例环节** K：幅频为 20lgK dB 的水平线，相频为 0°
2. **积分环节** 1/s：幅频斜率为 -20dB/dec，相频恒为 -90°
3. **微分环节** s：幅频斜率为 +20dB/dec，相频恒为 +90°
4. **惯性环节** 1/(Ts+1)：低频 0dB，高频 -20dB/dec，转折频率 ω=1/T
5. **振荡环节** 1/[(s/ω_n)² + 2ζ(s/ω_n) + 1]：低频 0dB，高频 -40dB/dec
6. **一阶微分环节** (Ts+1)：低频 0dB，高频 +20dB/dec

### 三、开环伯德图的合成

系统开环传递函数的伯德图等于各典型环节伯德图的叠加。绘制步骤：
1. 将传递函数分解为典型环节
2. 确定各转折频率，从小到大排列
3. 低频段由积分环节个数和 K 决定
4. 每经过一个转折频率，斜率相应变化
5. 叠加各环节的相频曲线
