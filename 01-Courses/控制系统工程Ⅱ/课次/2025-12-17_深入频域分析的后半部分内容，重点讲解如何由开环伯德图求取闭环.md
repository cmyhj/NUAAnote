## 关键概念

| 概念 | 说明 |
|------|------|
| 截止频率 ω_b | 闭环幅频特性下降至 -3dB 时对应的频率 |
| 带宽 | 0 ~ ω_b 的频率范围，反映系统对高频信号的衰减能力 |
| 谐振峰值 M_r | 闭环幅频特性的最大值 |
| 增益裕度 G_m | 系统距离临界稳定在增益上的裕量 |
| 相角裕度 γ | 系统距离临界稳定在相角上的裕量 |
| 带宽与响应速度 | 带宽越宽，系统响应越快 |

## 要点详述

### 一、闭环频率特性

由开环伯德图不能直接读出闭环频率特性。通常可利用尼柯尔斯图线（Nichols Chart）或等 M 圆/等 N 圆将开环频率特性转换为闭环频率特性。二阶系统的闭环频域指标可以解析计算。

### 二、频域指标与时域指标的关系

对于二阶系统，频域指标与时域指标之间存在明确的解析关系：
- 谐振峰值 M_r 与阻尼比 ζ 的关系：M_r = 1/(2ζ√(1-ζ²))
- 带宽 ω_b 与自然频率 ω_n 的关系：ω_b = ω_n√(1-2ζ²+√(2-4ζ²+4ζ⁴))
- 相角裕度 γ 与 ζ 的关系：γ ≈ 100ζ（适度阻尼范围内）

### 三、增益裕度和相角裕度

- **相角裕度 γ**：在增益穿越频率 ω_c 处（|G(jω_c)H(jω_c)| = 1），相角与 -180° 的差值
- **增益裕度 G_m**：在相位穿越频率 ω_g 处（∠G(jω_g)H(jω_g) = -180°），幅值的倒数

工程设计通常要求：γ = 30°~60°，G_m > 6dB。
