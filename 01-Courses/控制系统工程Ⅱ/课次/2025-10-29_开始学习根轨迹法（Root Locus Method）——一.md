## 本节主线

本节课开始学习根轨迹法（Root Locus Method）——一种通过图解方式分析系统参数变化对闭环极点影响的经典方法。根轨迹法是经典控制理论的重要组成部分，与频域法并称为两大分析方法。教师重点介绍了根轨迹法的基本概念、幅值条件和相角条件，以及绘制根轨迹的 6 条基本规则。

## 关键概念

| 概念 | 说明 |
|------|------|
| 根轨迹 | 开环系统某一参数（通常为 K）变化时，闭环特征根在复平面上的轨迹 |
| 幅值条件 | |G(s)H(s)| = 1，确定根轨迹上某点对应的 K 值 |
| 相角条件 | ∠G(s)H(s) = (2k+1)π，是判断某点是否在根轨迹上的充要条件 |
| 起点 | 开环极点（K=0 时闭环极点的位置） |
| 终点 | 开环零点（K=∞ 时闭环极点的位置） |
| 渐近线 | 根轨迹趋向无穷远时的渐近方向与交点 |
| 分离点/会合点 | 根轨迹在实轴上分离或汇合的点 |
| 出射角/入射角 | 根轨迹离开开环极点或进入开环零点的角度方向 |

## 要点详述

### 一、根轨迹的基本思想

根轨迹法不直接求解闭环特征方程，而是通过开环零极点的位置，随着某个参数（通常为开环增益 K）的变化，追踪闭环极点的运动轨迹。这样可以直观地看到 K 变化对系统稳定性和动态性能的影响。

### 二、幅值条件和相角条件

系统闭环特征方程为：1 + G(s)H(s) = 0，即 G(s)H(s) = -1

- **相角条件**（充分必要条件）：∠G(s)H(s) = 180° + k·360°
- **幅值条件**（用于求参数值）：|G(s)H(s)| = 1

相角条件用于判断复平面上的某点是否为根轨迹上的点，幅值条件用于求出该点对应的 K 值。

### 三、根轨迹绘制基本规则（6条）

1. **根轨迹分支数** = 开环极点数 n
2. **根轨迹对称于实轴**
3. **起点在开环极点**，终点在开环零点（或无穷远）
4. **实轴上的根轨迹**：实轴上某段右侧的零极点个数之和为奇数
5. **渐近线**：当 n > m 时，有 n-m 条渐近线，交点为 σₐ = (Σp - Σz)/(n-m)，角度为 φₐ = (2k+1)π/(n-m)
6. **分离点/会合点**：由 dK/ds = 0 或 Σ1/(s-pᵢ) = Σ1/(s-zⱼ) 确定
