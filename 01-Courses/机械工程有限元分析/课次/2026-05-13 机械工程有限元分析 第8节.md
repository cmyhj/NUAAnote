## 关键概念

- **节点应力平均**: 围绕同一节点的多个单元计算的应力值取算术平均
- **面积加权平均**: 按各单元面积比重对应力进行加权平均
- **矩形单元（四节点）**: 使用自然坐标 ξ, η ∈ [-1,1] 的二维平面单元
- **自然坐标 (Natural Coordinate)**: 在母单元上定义的归一化坐标（ξ, η），范围 -1 到 1
- **拉格朗日插值函数 (Lagrange Interpolation)**: 构造形函数的数学基础，用一维插值函数的乘积得到二维形函数
- **形函数 (Shape Function)**: 插值函数，在所属节点上值为 1，在其他节点上值为 0

## 要点详述

### 节点应力的处理方式

在有限元后处理中，围绕同一个节点的多个单元会算出不同的应力值，需要进行处理：

1. **取最大值（软件缺省常用）**: 输出各单元在该节点上的最大应力
   - 问题：网格划分不好时应力跨度大，可能虚高
   
2. **算术平均**: 将各单元算出的应力简单平均
   - 可缓解应力超标假象

3. **面积加权平均**: 按每个单元的面积比重加权
   - 单元面积越大，权重越高

**选择原则**: 取决于网格质量和工程判断，应力集中区域需特别关注。

### 四节点矩形单元

**单元定义**:
- 自然坐标系 ξ, η ∈ [-1, 1]
- 节点 1: (-1, -1), 节点 2: (1, -1), 节点 3: (1, 1), 节点 4: (-1, 1)
- 这种在母单元上定义的单元称为"母单元"，是有限元分析的基础

**形函数构造**（基于拉格朗日插值）:
- N₁(ξ, η) = ¼(1-ξ)(1-η)
- N₂(ξ, η) = ¼(1+ξ)(1-η)
- N₃(ξ, η) = ¼(1+ξ)(1+η)
- N₄(ξ, η) = ¼(1-ξ)(1+η)

**形函数性质**:
- 在所属节点上值为 1，在其他节点上值为 0
- 是线性插值函数
- 4 个节点对应 4 个形函数

**位移场表达**:
- u(ξ, η) = N₁·u₁ + N₂·u₂ + N₃·u₃ + N₄·u₄
- v(ξ, η) = N₁·v₁ + N₂·v₂ + N₃·v₃ + N₄·v₄
- 同一个形函数用于 X 和 Y 两个方向

**注意**: 这种正方形母单元本身在工程中不直接使用，但它是等参单元（Isoparametric Element）的理论基础，非常重要。
