## 关键概念

| 术语 | 含义 | 备注 |
|------|------|------|
| **应力** (Stress) | 内力集度，单位同压强 (Pa/MPa) | σ 正应力（垂直截面），τ 剪应力（沿截面） |
| **应变** (Strain) | 相对变形量，无量纲 | ε 线应变，γ 剪应变（弧度） |
| **微应变** (Microstrain, με) | 应变的 10⁶ 倍，1 με = 10⁻⁶ | 工程常测；钢 1 με ≈ 0.2 MPa |
| **平面应力问题** (Plane Stress) | 薄板、面内载荷，σz=τzx=τzy=0 | 未知量：σx, σy, τxy |
| **平面应变问题** (Plane Strain) | 长柱体、横截面载荷，εz=γzx=γzy=0 | 未知量：εx, εy, γxy；σz≠0 |
| **[[平衡方程|平衡方程]]** | 外力与应力（内力）的微分关系 | 三大方程之一 |
| **[[几何方程|几何方程]]** | 位移与应变的关系 | 三大方程之一 |
| **[[物理方程（本构方程）|物理方程 / 本构方程]]** (Constitutive Eq.) | 应力与应变的关系（广义胡克定律） | 三大方程之一 |
| **杨氏模量** (Young's Modulus) E | 材料抵抗拉伸/压缩的能力；钢 E=2.1×10¹¹ Pa | 必须用对！否则仿真全错 |
| **泊松比** (Poisson's Ratio) ν | 横向收缩与纵向伸长之比；钢 ν≈0.3 | 无量纲 |

## 要点详述

### 1. 弹性力学三大方程

```
┌─────────────────────────────────────────────────────┐
│  三大方程（静力学核心）                               │
│                                                      │
│   平衡方程  ── 外力 (F) 与 内力 (σ, τ) 的微分关系    │
│   几何方程  ── 位移 (u,v) 与 应变 (ε,γ) 的关系       │
│   物理方程  ── 应变 (ε,γ) 与 应力 (σ,τ) 的关系       │
│                 （广义胡克定律 / 本构方程）            │
└─────────────────────────────────────────────────────┘
```

### 2. 平面问题分类

| 比较项 | 平面应力 (Plane Stress) | 平面应变 (Plane Strain) |
|--------|------------------------|-------------------------|
| 几何特征 | 薄板 (厚度 << 长宽) | 长柱体/坝 (长度 >> 截面) |
| 载荷方向 | 仅面内 (xy)，z 向无载荷 | 沿横截面均匀，不随长度变化 |
| σz | **= 0** | ≠ 0 |
| εz | ≠ 0（可自由收缩/膨胀） | **= 0** |
| 独立未知量 | σx, σy, τxy | εx, εy, γxy |
| 典型单元 | Membrane (膜单元) | — |
| 工程案例 | 薄板拉伸 | 水坝、隧道、长墙 |

### 3. 平衡方程（平面应力，微分形式）

取微元体（厚度 = 1），分别在 x、y 方向投影列力平衡（剪应力互等 τxy=τyx 自动满足）：

- **x 方向**：∂σx/∂x + ∂τyx/∂y + Fx = 0
- **y 方向**：∂τxy/∂x + ∂σy/∂y + Fy = 0

> Fx, Fy 为单位体积力（体积力/体力）。推导要点：应力 × 面积 = 力，相邻面由于梯度产生增量项。

### 4. 几何方程（平面问题）

正应变：
- εx = ∂u/∂x
- εy = ∂v/∂y

剪应变：
- γxy = ∂u/∂y + ∂v/∂x

### 5. 物理方程（广义胡克定律，平面问题）

> **本构方程**描述材料固有的应力-应变关系。

**杨氏模量** E：反映轴向拉伸/压缩抵抗能力  
**泊松比** ν：纵向拉伸时横向收缩的比例（ν = −εy/εx）

- εx = (σx − νσy) / E
- εy = (σy − νσx) / E
- γxy = τxy / G （其中 G = E/[2(1+ν)]）

钢材：E = 2.1×10¹¹ Pa，ν ≈ 0.3

### 微应变实用估算

```
钢： 1 με × E = 10⁻⁶ × 2.1×10¹¹ = 2.1×10⁵ Pa ≈ 0.21 MPa
   ⇒ 粗略估算：1 με 对应约 0.2 MPa
```

若测试得 100 με → 应力约 20 MPa；2000 με → 400 MPa（已远超 Q235 屈服极限，检查数据）

### 6. 举例：常应力板（均匀拉伸薄板）

- 条件：薄板（平面应力），一端受均匀面力，y 方向自由无约束
- 应力：σx = F/A = 常数，σy = 0，τxy = 0（全场均匀）
- 应变：εx = σx/E，εy = −νσx/E，γxy = 0
- 位移：u = εx·x（线性），v = −ν·εx·y（线性）
- 特点：全场应力/应变为常数，位移线性；属于最简单的弹性力学解

### 7. 有限元求解路径

```
  ┌──────────┐     ┌──────────┐     ┌──────────┐
  │ 位移函数  │ ──→ │ 几何方程  │ ──→ │ 物理方程  │
  │ (u,v)    │     │ (应变)   │     │ (应力)   │
  └──────────┘     └──────────┘     └──────────┘
        ↑ 位移法求解（先设位移形式，
          代入边界条件 → 解出位移）
```

- **位移法**是最广泛使用的有限元静力求解方法
- **力法**（柔度法）用应力作为未知量，较少用于有限元软件

### 8. 虚功原理（虚位移原理）

> 弹性体在外力作用下平衡，给弹性体一个**虚位移**（满足约束条件的微小任意位移），则**外力在虚位移上所做的总虚功等于弹性体的虚应变能**（内力的虚功）。

- 外力虚功 = ∫(力 × 虚位移) dV
- 虚应变能 = ∫(应力 × 虚应变) dV，均含 1/2 因子（力-位移三角形面积关系）
- **意义**：从整体能量角度替代微分形式的平衡方程，是有限元单元平衡方程推导的基础

### 9. 其他推导方法（教材第三章，仅供参考）

| 方法 | 特点 |
|------|------|
| 加权余量法 (Weighted Residual) | 严格的数学方法 |
| Rayleigh-Ritz 法 | 基于能量变分原理 |
| Galerkin 法 | 俄罗斯力学学派，泛函推导 |
| 虚功原理 | **本课程采用**，最简洁 |
