## 关键概念

- **测量**: 给某物理量定下单位
- **实验**: 给对象进行特定单位的测量，描述其特性
- **测试系统组成**（考试重点）:  激励装置 →被测对象 → 传感器 → 中间变换装置（信号调理/放大/AD） → 显示记录装置 → 观察者 / 控制系统
- **传感器**: 将被测物理量检出并转换为电量的器件
- **简单传感器**: 仅含敏感元件（如热电偶）
- **复杂传感器**: 含敏感元件 + 弹性元件 + 交换电路 + 微处理器（如力传感器）
- **中间变换装置**: 对电信号进行硬件处理（放大、调制解调、滤波、AD转换）——对应"信息提取"
- **传感器**: 对应"信息转换"
- **时域信号**: 横轴为时间
- **频域信号**: 横轴为频率，通过傅里叶变换/拉氏变换相互转换
- **标定 (Calibration)**: 以最大激励输出为100%基准
- **模糊控制 (Fuzzy Control)**: 全自动洗衣机的关键技术
- **涡流检测**: 通过激励线圈产生涡流，遇裂纹时电流形态异常

## 要点详述

### 测试系统组成（考试重点）

老师明确划重点，并提到去年考生曲宇飞（徐宇飞）画出该图获得认可。组成链为：

1. **被测对象** — 待测物体及需测量的具体特性（质量、长度、硬度、固有频率等）
2. **激励装置** — 使被测特征显现（如涡流探头激励裂纹信号）
3. **传感器** — 将物理量转换为电量（信息转换）
4. **中间变换装置** — 对电信号放大、调制解调、滤波、AD转换（信息提取）[10:55-11:02]
5. **显示记录装置** — 输出给观察者或控制系统
6. **观察者 / 控制系统**

> 案例：肌电信号实验中，肌肉产生毫伏级信号 → 经小箱子放大 → 转换为数字信号 → 电脑显示 [06:48-07:45]

### 传感器分类

| 类型 | 描述 | 示例 |
|------|------|------|
| 简单传感器 | 仅含敏感元件 | 热电偶（温差→电压） |
| 复杂传感器 | 含敏感元件+弹性元件+交换电路±微处理器 | 力传感器（梁结构+桥路） |

### 测试系统分类

- **简单测试装置**：无需转换，直接读数（温度、质量、分贝）
- **信号变换系统**：需放大、调制解调、滤波（肌电传感器、力传感器）
- **功能较强系统**：含微型计算机，集成数据采集、非线性矫正、消除误差、数模/模数转换、滤波放大 [16:06-16:42]
- **远距离测量系统**：前述系统+超远距离通信（华为5G/6G远程手术）[16:50-17:38]

### 工程应用

- **航空航天**: 火箭燃料测量、姿态调整（空间交会对接）、空中加油 [22:59-24:10]
- **航海**: 定位导航 [24:00-24:11]
- **机器人**:

  - 传感器种类：关节角度、足底力、视觉、听觉、嗅觉（消防）[27:09-28:02]
- **AGV小车**: 二维码定位 + 集群控制与轨迹规划 [28:16-29:16]
- **特种加工**: 五轴车床精度（微米级），需要力传感器、噪声测量 [29:29-30:17]
- **流程工业**: 发电厂、污水处理、化工 [30:27-30:57]
- **产品质量检测**: 光刻机标定、公差测量（孟凯老师研究）[30:58-31:49]
- **楼宇控制**: 烟雾报警器、声控灯+光传感器、视觉传感器（闸机）、电表/水表/煤气 [31:49-34:34]
- **家电**: 全自动洗衣机模糊控制（测衣物材质/水温/液位/烘干）[35:43-36:56]
- **个人设备**: 指纹门禁（干燥季节识别困难）、鼠标光电位移传感器、摄像头、电容笔、麦克风（电容变化测声波）、声卡、光盘 [37:48-40:10]

### 前沿传感技术

- **电阻抗成像（EIT）**: 测量胸部电阻变化进行肺部成像，可替代CT（无辐射、可床边使用）[40:12-41:41]
- **碳纳米管可拉伸传感器**: 借鉴宏观梁结构设计，拉伸不易损坏，可用于关节角度/肌肉张紧度测量 [44:37-46:54]
- **软体机器人（火星爬虫）**: 按预定轨迹高精度运动 + 地形检测 + 磁控 [47:03-47:47]
- **微波布料传感器**: 缝在安全带上，通过微波测心率/疲劳度 [43:03-43:26]
- **电子鼻 / 激光灭蚊**: 光学传感新应用 [41:42-42:02]
- **光谱检测疾病**: 光照身体 → 光谱分析 → 判断疾病（无副作用）[49:28-50:07]

### 发展趋势 [47:57-48:52]

1. 精度越来越高（X光 → B超 → DR → 核磁共振）
2. 仪器小型化/微型化（家用血压计等）
3. 光学无创检测
