## 关键概念
- **傅里叶级数展开**: 将周期函数分解为不同频率的正弦/余弦函数之和，详见[[傅里叶变换]]
- **单边幅值谱**: 只画正频率部分的幅值-频率图，幅值为 aₙ 和 bₙ 的合成
- **奇函数/偶函数判断**: 奇函数 a₀=aₙ=0，偶函数 bₙ=0，可简化计算
- **欧拉公式**: e^(jωt) = cos(ωt) + j·sin(ωt)，连接三角函数与指数函数
- **拉普拉斯变换**: [[傅里叶变换]]的推广，引入 σ 项，可判断系统稳定性
- **Z 变换**: 离散信号的变换，用于计算机控制和数字信号处理

## 要点详述
### 1. 方波的傅里叶展开
- 方波是奇函数，所以 a₀ = 0，aₙ = 0
- 只需计算 bₙ，代入公式积分
- 结果：bₙ = 4/(nπ)，n 为奇数
- 频谱图：在 ω₀, 3ω₀, 5ω₀... 处有幅值，依次递减
- 考试技巧：至少画到 9 次谐波（奇函数画 1,3,5,7,9）

### 2. 三角波的傅里叶展开
- 三角波是偶函数，所以 bₙ = 0
- 只需计算 a₀ 和 aₙ
- 结果：aₙ = 8/(n²π²)，n 为奇数
- 频谱图：衰减比方波更快（平方反比）

### 3. 矩形波的傅里叶展开
- 与三角波类似但波形不同
- 利用三角函数变式进行化简
- n 为奇数时有值，n 为偶数时为 0
- 频谱图上标出具体数值（如 2/π, 1/π, 2/3π）

### 4. 欧拉公式与复指数展开
- 欧拉公式将三角函数统一为指数形式
- 几何理解：行星绕太阳公转 + 自转，比傅里叶变换多一个维度
- Cₙ = ½(aₙ - jbₙ)，同时包含幅值和相位信息
- 考试不会考复指数展开的计算，但可能考选择/判断题

### 5. 拉普拉斯变换
- 公式：F(s) = ∫f(t)·e^(-st)dt，其中 s = σ + jω
- 当 σ = 0 时，拉普拉斯变换退化为傅里叶变换
- σ < 0：函数收敛（系统稳定）
- σ > 0：函数发散（系统不稳定）
- 工程中用于系统稳定性分析，比傅里叶变换用得更多

### 6. Z 变换
- 用于离散信号（计算机控制）
- 描述第 n 时刻到第 n+1 时刻输出的关系
- 确定每一时刻的控制输入
