## 关键概念
- **传感器定义**: 将被测量转换为确定对应关系的、易测量和传输处理的另一种形式（通常是电压/电流/电阻等电信号）
- **敏感元件**: 直接感受被测量并输出相应信号的元件
- **辅助元件**: 供电、信号处理、放大等辅助敏感元件工作的部分
- **能量转换型传感器**: 直接从被测对象获取能量工作（如热电偶、压电）
- **能量控制型传感器**: 需外部激励源，被测量改变其参数（如电阻应变片需通电）
- **金属应变片**: 金属丝受力形变→长度和截面积变化→电阻变化，R = ρL/A
- **惠斯通电桥**: 将应变片微小电阻变化放大为可测电压的四臂电桥电路
- **差动电容**: 三极板结构，中间动极板同时改变上下两个电容，灵敏度提升2倍，非线性大幅减小

## 要点详述
### 电阻式传感器
1. **变阻式（滑动变阻器型）**
   - 最直观的位移传感器：杆伸缩改变电阻→分压测位移
   - 典型应用：液压缸/电缸行程测量、角位移测量
   - 线性度好（纯分压关系），但接入负载电阻后产生非线性
   - 参数：线性度、分辨率（斜率）、电阻温度系数、寿命
   - 单圈（绝对式，精度高，≤360°）vs 多圈（增量式，量程大，有累积误差）

2. **电阻应变式**
   - 金属丝贴在基底上，受力→形变→电阻变化
   - 公式推导：ΔR/R = (1+2μ)ε + Δρ/ρ（μ为泊松比，ε为应变）
## 金属应变片公式符号详解

公式来源：金属丝电阻 $R = \rho \frac{L}{A}$，对其取对数再微分推导得到。

---

### 公式：$\frac{\Delta R}{R} = (1+2\mu)\varepsilon + \frac{\Delta\rho}{\rho}$

| 符号 | 名称 | 含义 |
|:---|:---|:---|
| $\frac{\Delta R}{R}$ | **电阻相对变化率** | 应变片电阻的相对改变量，是最终要测量的量 |
| $\varepsilon$ | **应变**（纵向） | $\varepsilon = \frac{\Delta L}{L}$，即长度的相对变化量（无量纲） |
| $\mu$ | **泊松比** | 材料横向收缩与纵向伸长的比值，$\mu = -\frac{\Delta d/d}{\Delta L/L}$，金属通常在 0.25~0.35 之间 |
| $\rho$ | **电阻率** | 材料本身的电学特性参数 |
| $\frac{\Delta\rho}{\rho}$ | **电阻率相对变化** | 由**压阻效应**引起（受力后材料内部晶格变化导致电阻率改变） |

---

### 物理意义拆解

公式可分为两部分：

1. **几何效应** $(1+2\mu)\varepsilon$：
   - $+1\cdot\varepsilon$：轴向拉伸 → 长度 $L$ 增大 → 电阻增大
   - $+2\mu\cdot\varepsilon$：泊松效应 → 截面积 $A$ 减小 → 电阻增大（系数2是因为面积有长和宽两个方向）

2. **材料效应** $\frac{\Delta\rho}{\rho}$：
   - 受力后材料内部电阻率本身会改变（压阻效应）

---

### 工程简化

对于**金属材料**，$\frac{\Delta\rho}{\rho}$ 项非常小（通常可忽略），因此简化为：

$$\frac{\Delta R}{R} \approx (1+2\mu)\varepsilon = K\varepsilon$$

其中 $K = 1+2\mu$ 称为**应变灵敏系数**，金属的 $K$ 值约为 **2** 左右。
   - 半导体应变计：灵敏度远高于金属丝，但温度稳定性和可重复性较差
   - 测量电路：惠斯通电桥，当四臂相等时输出简化为 ΔU ≈ (1/4)·U·(ΔR/R)

3. **应用实例**
   - 力传感器（悬臂梁结构）、电子秤、桥梁固有频率测量
   - 振动传感器（质量块+悬臂梁）、机器人关节力传感器

### 电容式传感器
1. **基本公式**
   - C = ε₀·εᵣ·A / d（真空介电常数×相对介电常数×面积÷极距）

## 差动电容传感器完整推导

### 一、基本公式回顾

平行板电容器：
$$C = \frac{\varepsilon_0 \varepsilon_r A}{d}$$

其中 $d$ 在分母，所以 $\Delta C$ 与 $\Delta d$ 的关系**天然是非线性的**。

---

### 二、单极板（极距型）的非线性问题

初始状态：$C_0 = \frac{\varepsilon A}{d_0}$

动极板移动 $\Delta d$ 后：

$$C = \frac{\varepsilon A}{d_0 + \Delta d} = \frac{C_0}{1 + \frac{\Delta d}{d_0}}$$

令 $\delta = \frac{\Delta d}{d_0}$，则：

$$\frac{\Delta C}{C_0} = \frac{1}{1+\delta} - 1 = \frac{-\delta}{1+\delta}$$

**泰勒展开**（$|\delta| < 1$ 时）：

$$\boxed{\frac{\Delta C}{C_0} = -\delta + \delta^2 - \delta^3 + \delta^4 - \cdots}$$

> **问题**：第一项 $-\delta$ 是线性的，但第二项 $\delta^2$ 引入了**二次非线性误差**，其与线性项的比值为 $\delta^2/\delta = \delta$，不可忽略。

---

### 三、差动式结构

**三极板结构**：上固定极板、中间**动极板**、下固定极板

初始状态（两间隙均为 $d_0$）：
$$C_{10} = C_{20} = C_0 = \frac{\varepsilon A}{d_0}$$

动极板**向上移动** $\Delta d$：

| 电容 | 极距变化 | 新极距 |
|:---|:---|:---|
| $C_1$（上间隙） | 减小 | $d_0 - \Delta d$ |
| $C_2$（下间隙） | 增大 | $d_0 + \Delta d$ |

---

### 四、分别展开 $C_1$ 和 $C_2$

$$C_1 = \frac{\varepsilon A}{d_0 - \Delta d} = \frac{C_0}{1 - \delta}$$

$$C_2 = \frac{\varepsilon A}{d_0 + \Delta d} = \frac{C_0}{1 + \delta}$$

分别泰勒展开：

$$C_1 = C_0\left(1 + \delta + \delta^2 + \delta^3 + \delta^4 + \cdots\right)$$

$$C_2 = C_0\left(1 - \delta + \delta^2 - \delta^3 + \delta^4 - \cdots\right)$$

---

### 五、差动输出 $\Delta C = C_1 - C_2$

$$\Delta C = C_1 - C_2 = C_0 \Big[(1 + \delta + \delta^2 + \delta^3 + \cdots) - (1 - \delta + \delta^2 - \delta^3 + \cdots)\Big]$$

逐项相减：

| 项 | $C_1$ | $C_2$ | 相减结果 |
|:---|:---|:---|:---|
| 常数项 | $1$ | $1$ | **0** ✕ |
| $\delta^1$ | $+\delta$ | $-\delta$ | **$2\delta$** ✓ |
| $\delta^2$ | $+\delta^2$ | $+\delta^2$ | **0** ✕ （偶次项全部抵消！）|
| $\delta^3$ | $+\delta^3$ | $-\delta^3$ | **$2\delta^3$** |
| $\delta^4$ | $+\delta^4$ | $+\delta^4$ | **0** ✕ |

最终结果：

$$\boxed{\frac{\Delta C}{C_0} = 2\delta + 2\delta^3 + 2\delta^5 + \cdots = 2\left(\delta + \delta^3 + \delta^5 + \cdots\right)}$$

---

### 六、对比：灵敏度翻倍

| | 线性项 | 灵敏度 |
|:---|:---|:---|
| **单极板** | $-\delta$ | $K = 1$ |
| **差动式** | $2\delta$ | $K = 2$ |

> 差动式的灵敏度是单极板的 **2 倍**。

---

### 七、对比：非线性大幅减小

| | 第一个非线性项 | 非线性/线性比 |
|:---|:---|:---|
| **单极板** | $\delta^2$（**二次项**） | $\delta^2 / \delta = \delta$ |
| **差动式** | $2\delta^3$（**三次项**） | $2\delta^3 / 2\delta = \delta^2$ |

当 $\delta = 0.1$ 时：
- 单极板非线性误差比：$10\%$
- 差动式非线性误差比：$1\%$

> 偶次项（$\delta^2, \delta^4, \cdots$）**完全对消**，非线性误差从 $\delta$ 量级降到 $\delta^2$ 量级，减小了一个数量级。

---

### 八、一句话记忆

**差动结构 = 灵敏度 ×2 + 偶次非线性项全消**，这就是考试需要推导和理解的核心结论。---
