## 关键概念
- **采样保持 (Sample & Hold)**: 两次采样间隔间保持上一时刻的采样值，防止信号漂移导致失真
- **采集时间**: 采样保持器输出达到输入值所需时间（约10微秒）
- **孔径时间**: 保持电路转入保持状态所需时间（约100纳秒，即开关切换时间）
- **偏移电压**: 输入放大器偏移造成的差额电压（约5毫伏）
- **采样定理 (Shannon-Nyquist)**: 采样频率fs必须≥信号最高频率fc的2倍，才能无失真恢复原信号
- **频率混叠**: 当fs < 2fc时，高频成分"折叠"到低频区域，导致信号失真
- **量化单位 q**: q = FSR / 2^n（满量程除以2的n次方）
- **只舍不入**: 凡大于q的整数倍的部分一律舍去
- **有舍有入 (四舍五入)**: 超出q/2则入，不足q/2则舍

## 要点详述

### 1. 采样保持电路
- 组成：模拟开关 + 模拟信号存储电容 + 缓冲放大器
- 工作过程：
  - 开关接通（UC=高电平）→ 信号对电容充电 → **采样阶段**
  - 开关断开 → 电容保持电压 → 缓冲放大器输出 → **保持阶段**
- 三个关键参数：
  - 采集时间（充电时间）：~10μs
  - 孔径时间（开关切换时间）：~100ns
  - 偏移电压：~5mV（对应5V采集约0.05%误差）

### 2. 采样定理
- **条件1**：信号频率有上界fc（频率大于fc时频谱为0）
- **条件2**：采样频率 fs ≥ 2fc
- 满足两条件时，可由采样信号唯一确定原信号
- sinc函数在此处的作用：类似δ函数的采样重建功能

### 3. fs = 2fc的特殊情况
- 当采样频率恰好等于信号频率的2倍时：
  - 初始相位=0°：采样值恒为0（完全失真）
  - 初始相位在0°~90°之间：幅值均小于原信号（失真）
  - 初始相位=90°：才能采到真实值
- **结论**：实际工程中不会让fs恰好等于2fc，通常要高出很多倍（如调制解调中十几倍）
- 采样定理只是不失真的**基本条件**，不是全部条件

### 4. 频率混叠
- 当fs < 2fc时，高频成分会"折叠"到低频区域
- 例：8Hz信号用5Hz采样 → 4+5和4-5产生交汇 → 混叠
- 与第四章调制解调中的混叠概念一致

### 5. 采样练习题
- 信号含900Hz、400Hz、100Hz三个频率成分
- 用500Hz采样：
  - 900Hz成分：500 < 2×900=1800 → **失真**
  - 400Hz成分：500 < 2×400=800 → **失真**
  - 100Hz成分：500 > 2×100=200 → **正常采集**
- 最终采样结果接近100Hz信号
- 相当于采样过程起到了**低通滤波**的作用

### 6. 典型物理量采样值
| 物理量 | 定义 | 采样周期 |
|--------|------|----------|
| 流量 | 单位时间通过某截面的流体体积 | 1~2秒（注意流量脉动） |
| 压力 | 单位面积受力 | - |
| 液位 | 液体高度 | - |
| 温度 | - | - |
| 成分 | - | - |

- 工程实例：手表采样频率约200Hz以内，IMU约200Hz，压力传感器约100Hz以内
- 低频信号采集可有效过滤高频干扰

### 7. 量化
- 定义：将采样信号与最小数量单位的整数倍进行比较，取最接近的值
- 量化单位：q = FSR / 2^n
- 例：FSR=10V，n=8 → q=10/256≈0.039V
- n越大 → q越小 → 分辨率越高，但存储位数越多
- 编码器实例：2048位/4096位编码器，一圈=4096个数（非360°）
- 电机控制实例：0~20A对应编码1~2000（非实际电流值）

### 8. 量化方法
- **只舍不入**：计算简单，不需判断与q/2的大小关系
- **有舍有入**：需判断是否大于q/2，计算量稍大但精度更高
