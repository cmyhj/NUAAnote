## 关键概念
- **概率密度函数**: p(a) = lim[T→∞] (T_a/T) / Δa，描述幅值分布
- **概率分布函数**: F(r) = ∫₋∞ʳ p(a)da，从负无穷到r的累积概率
- **狄利克雷条件**: 信号能进行傅里叶展开的三个必要条件
- **傅里叶级数**: 任意周期信号 = 直流分量 + 各次谐波的正弦/余弦叠加
- **幅值Aₙ**: √(aₙ² + bₙ²)，第n次谐波的幅值
- **相位φₙ**: arctan(bₙ/aₙ)，第n次谐波的初始相位

## 要点详述

### 1. 不同信号的概率密度函数
| 信号类型 | 概率密度特征 | 物理解释 |
|----------|-------------|---------|
| 正弦波 | 两端高、中间低 | 峰值处导数为0，经过慢，概率高 |
| 方波 | 只在±a处有值 | 只有两个幅值，各占0.5 |
| 三角波 | 均匀分布 | 斜率恒定，每个幅值概率相同 |
| 白噪声 | 正态分布 | 符合高斯分布 |

### 2. 狄利克雷条件（傅里叶展开的前提）
1. **绝对可积**：∫|x(t)|dt < ∞（信号不能无穷大）
2. **有限不连续点**：一个周期内只有有限个间断点
3. **有限极值点**：一个周期内只有有限个极大/极小值

**物理理解**：正弦/余弦是有界函数，它们合成的函数也必须有界

### 3. 傅里叶级数公式
x(t) = a₀ + Σ[aₙcos(nω₀t) + bₙsin(nω₀t)]

其中：
- a₀ = (1/T)∫₋T/₂^T/₂ x(t)dt （直流分量）
- aₙ = (2/T)∫₋T/₂^T/₂ x(t)cos(nω₀t)dt
- bₙ = (2/T)∫₋T/₂^T/₂ x(t)sin(nω₀t)dt

### 4. 奇偶函数简化
- **奇函数**：a₀=0, aₙ=0，只有bₙ（正弦项）
- **偶函数**：bₙ=0，只有a₀和aₙ（余弦项）

### 5. 方波的傅里叶展开
- 方波是奇函数 → a₀=0, aₙ=0
- bₙ = 4A/(nπ)，n=1,3,5,7...
- x(t) = (4A/π)[sin(ω₀t) + (1/3)sin(3ω₀t) + (1/5)sin(5ω₀t) + ...]
- 只在奇数倍基频上有值
