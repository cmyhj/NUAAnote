## 关键概念

| 概念 | 说明 |
|------|------|
| **EMG（表面肌电信号）** | 人体肌肉活动产生毫伏级微弱电压信号，通过电极片采集后可解码肌肉运动意图 |
| **测量系统** | 将物理量（如肌电信号）检测、采集、转换的系统 |
| **执行系统** | 将测量结果转化为物理动作（如电刺激肌肉收缩）的系统 |
| **FES（功能性电刺激）** | 中风康复治疗手段，通过电刺激使僵直肌肉舒张/收缩 |
| **Open loop → Close loop** | 感知的核心作用：将开环系统变为闭环，使控制系统能根据外部反馈调整 |
| **BCI（脑机接口）** | 当前瓶颈：开颅植入 → 精度高但损伤大；非开颅脑电帽 → 信号不准 |
| **测量 vs 实验** | 测量 = 给物理量赋予单位（如"1米"）；实验 = 验证某对象特性/性能（如"楼高300米"） |

## 要点详述

### 机器人四大组成部分 [19:43-22:49]
1. **本体** — 机器人的基本结构与造型（机械设计）
2. **驱动** — 液压、气动、电机、记忆金属等
3. **感知** — 各类传感器感知外部环境 → 闭环控制
4. **控制** — 算法决策与运动控制

### 感知为何重要 [22:57-25:45]
- 使机器人从 **Open loop** 转变为 **Close loop**
- "感知最重要的就是把 open loop 变成 close loop" — 教师强调为面试/复试关键点

### EMG 人机接口原理 [14:25-19:43]
1. 女士侧（测量）：电极片采集前臂表面肌电信号（毫伏级）
2. 中间装置：信号放大、功率放大
3. 男士侧（执行）：高压电流输入皮肤电极 → 肌肉受电刺激收缩
4. 应用：强脑科技（BrainCo）的智能假肢

### 课程报告要求 [38:06-43:03]
- **形式**：每次课开始前安排 1-2 位同学做 PPT 汇报（从下次课开始）
- **题目**：自选一种智能传感器（如脑电、声音、气味传感器等）
- **提纲**：① 背景需求（为何重要）② 工作原理 + 原理图/视频 ③ 主要指标（精度等）④ 应用案例 ⑤ 个人心得
- **目标**："不是让我听懂，是让其他同学能听懂"
- **安排**：先自愿报名，无人自愿则按点名顺序
