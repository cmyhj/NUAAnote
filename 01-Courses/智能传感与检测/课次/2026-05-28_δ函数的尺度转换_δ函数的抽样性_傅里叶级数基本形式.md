## 关键概念
- **δ函数的尺度转换**: $δ(at) = \frac{1}{|a|}δ(t)$，因为总面积恒等于1，时间轴压缩则幅值增大，反之亦然
- **δ函数的抽样性**: $f(t)$与$δ(t-t_0)$相乘后积分，得到$f(t_0)$，即函数在某时刻的值；注意这与卷积不同
- **傅里叶级数基本形式**: 任何周期信号可展开为三角函数之和，需记忆$a_0$、$a_n$、$b_n$的计算公式，详见[[傅里叶变换]]
- **奇偶函数简化**: 奇函数→$a_0=a_n=0$，只需算$b_n$；偶函数→$b_n=0$，只需算$a_0$和$a_n$
- **周期信号频谱三特点**: ①周期→离散谱 ②谱线在基频整数倍上 ③高阶谐波能量衰减（工程上可忽略高阶）
- **卷积**: 两个函数互相扫描、交叠面积的积分；与采样的区别在于τ和t-τ的对应关系
- **系统辨识**: 已知输入x(t)和输出y(t)，反推传递函数H(t)
- **系统预测**: 已知x(t)和H(t)，预估输出y(t)
- **系统反求**: 已知y(t)和H(t)，求所需输入x(t)
- **线性时不变系统(LTI)**: 参数为常数、不随时间改变、具有单一确定的输入输出线性关系
- **灵敏度**: 输出量增量与输入量增量之比的极限值，即$dy/dx$；稳态时令$s=0$即可求得

## 要点详述

### 1. 傅里叶级数计算要点
考试必考计算题。基本形式为三角函数展开，$a_0$为直流分量，$a_n$为余弦系数，$b_n$为正弦系数。计算时先判断函数奇偶性可大幅简化：
- **方波**（奇函数）：只需算$b_n$，正负半周期分段积分，结果含$4a/(n\pi)$形式
- **三角波**（偶函数）：只需算$a_0$和$a_n$，结果含$1/n^2$形式
- **锯齿波**（基函数）：算$b_n$后转换为$a_n$和$\varphi_n$

频谱图绘制一般画到第9次谐波（奇函数画1,3,5,7,9；偶函数画2,4,6,8），需在图上标出幅值如$2/\pi$等。

### 复式级数与欧拉公式

#### 2.1 从实数形式到复数形式

实数傅里叶级数含有 $\sin$ 和 $\cos$ 两项，计算不方便。利用**欧拉公式**：

$$e^{j\omega t} = \cos(\omega t) + j\sin(\omega t)$$

可以将三角函数统一为复指数形式：

$$\cos(\omega t) = \frac{e^{j\omega t} + e^{-j\omega t}}{2}, \quad \sin(\omega t) = \frac{e^{j\omega t} - e^{-j\omega t}}{2j}$$

#### 2.2 复数傅里叶级数形式

周期信号 $f(t)$ 可展开为：

$$f(t) = \sum_{n=-\infty}^{\infty} C_n \, e^{jn\omega_0 t}$$

其中 $\omega_0 = \frac{2\pi}{T}$ 为基波角频率，系数 $C_n$ 为：

$$C_n = \frac{1}{T} \int_{-T/2}^{T/2} f(t) \, e^{-jn\omega_0 t} \, dt$$

> - $n > 0$：正频率分量
> - $n < 0$：负频率分量（复数表示中独有的概念）
> - $n = 0$：直流分量，$C_0 = \frac{1}{T}\int_{-T/2}^{T/2} f(t)\,dt$

#### 2.3 三维频谱理解

复式级数引入虚部后，频谱分析从**平面**扩展到**三维空间**：

| 维度 | 含义 |
| :--- | :--- |
| 横轴 | 频率 $n\omega_0$（或角频率） |
| 纵轴一 | 幅度 $\|C_n\|$（幅度谱） |
| 纵轴二 | 相位 $\varphi_n = \arg(C_n)$（相位谱） |

- $C_n$ 一般是**复数**，可写为 $C_n = \|C_n\| e^{j\varphi_n}$
- 幅度谱 $|C_n|$：关于 $n=0$ **偶对称**（$|C_{-n}| = |C_n|$）
- 相位谱 $\varphi_n$：关于 $n=0$ **奇对称**（$\varphi_{-n} = -\varphi_n$）

#### 2.4 与实数形式系数的对应关系

| 实数形式        | 复数形式                    |
| :---------- | :---------------------- |
| $a_0$（直流）   | $C_0 = a_0$             |
| $a_n$（余弦系数） | $C_n + C_{-n} = a_n$    |
| $b_n$（正弦系数） | $j(C_n - C_{-n}) = b_n$ |

对于**实信号**，满足 $C_{-n} = C_n^*$（共轭对称），这是复式变换**奇偶虚实性**的核心体现：

- $f(t)$ 为**实偶函数** $\Rightarrow$ $C_n$ 为实数（纯实偶）
- $f(t)$ 为**实奇函数** $\Rightarrow$ $C_n$ 为纯虚数（纯虚奇）

#### 2.5 复式表示的优势

- 运算统一：加减乘除只涉及一种函数 $e^{jn\omega_0 t}$，无需分别处理 $\sin$ 和 $\cos$
- 便于推导：卷积、调制等运算在复指数域更简洁
- 统一正负频率：物理上负频率无意义，但数学上与正频率共同合成实信号

### 3. 卷积的直观理解
卷积是两个函数互相扫描过程中交叠面积的积分。典型结果：
- 两个矩形窗卷积→三角形
- 两个不同大小矩形窗→梯形
- δ函数与常量互为傅里叶变换对（时域δ→频域常量，频域δ→时域常量）

### 4. 测试系统三大问题
这是第三章的核心框架：
- **系统辨识**：实验测出系统特性（如电机的电流-扭矩系数Kᵢ）
- **系统预测**：已知系统特性，预估输出（如设计时计算电机能否举起10kg）
- **系统反求**：仿真中提取完成动作所需的输入曲线（如人形机器人强化学习）

### 5. 人形机器人电流控制实例
位置控制在机器人与地面交互时不适用，需改用电流环控制。通过强化学习在仿真中训练机器人完成动作，反推出各关节电机的扭矩曲线，再通过电流系数Kᵢ转换为电流指令。这种方式允许一定的容错率，类似于人发力大一点小一点都能完成动作。

### 6. 一阶系统：RC电路
RC低通滤波器是最典型的一阶LTI系统：
- 微分方程：$RC \cdot \frac{dy}{dt} + y = x$
- 传递函数：$H(s) = \frac{Y(s)}{X(s)} = \frac{1}{RCs + 1}$
- 拉普拉斯变换规则：微分→乘s，常数不变

### 7. 二阶系统：弹簧-阻尼-质量块
标准形式：$m \cdot \ddot{y} + c \cdot \dot{y} + k \cdot y = x$
- 传递函数：$H(s) = \frac{1}{ms^2 + cs + k}$
- 二阶项(惯性力) + 一阶项(阻尼力) + 常数项(弹簧力)

### 8. n阶系统一般形式
$H(s) = \frac{b_m s^m + \ldots + b_1 s + b_0}{a_n s^n + \ldots + a_1 s + a_0}$
- 零点数量必须小于极点数量，系统才稳定
- 此公式在控制领域论文中极为常见

### 傅里叶级数基本形式与系数公式

对于一个周期为 $T$ 的信号 $f(t)$，其傅里叶级数展开（三角函数形式）为：
$$f(t) = a_0 + \sum_{n=1}^{\infty} [a_n \cos(n\omega_0 t) + b_n \sin(n\omega_0 t)]$$
其中，基波角频率 $\omega_0 = \frac{2\pi}{T}$。

各项系数的计算公式如下：

1.  **直流分量 $a_0$**（函数在一个周期内的平均值）：
    $$a_0 = \frac{1}{T} \int_{-T/2}^{T/2} f(t) \, dt$$

2.  **余弦项系数 $a_n$**：
    $$a_n = \frac{2}{T} \int_{-T/2}^{T/2} f(t) \cos(n\omega_0 t) \, dt, \quad n = 1, 2, 3, ...$$

3.  **正弦项系数 $b_n$**：
    $$b_n = \frac{2}{T} \int_{-T/2}^{T/2} f(t) \sin(n\omega_0 t) \, dt, \quad n = 1, 2, 3, ...$$

### 记忆与使用要点
*   **积分区间**：通常选取对称区间 $[-T/2, T/2]$ 计算最为方便。也可以选取任意一个完整的周期 $[t_0, t_0+T]$。
*   **系数关系**：$a_0$ 是**平均值**，公式前系数为 $\frac{1}{T}$；$a_n$ 和 $b_n$ 是**幅值**，公式前系数为 $\frac{2}{T}$。
*   **与奇偶性的结合**（简化计算的关键）：
    *   **奇函数**（如方波）：$a_0 = 0$，$a_n = 0$，只需计算 $b_n$。
    *   **偶函数**（如三角波）：$b_n = 0$，只需计算 $a_0$ 和 $a_n$。
*   **频谱图绘制**：计算出 $a_n$、$b_n$ 后，各次谐波的幅值为 $\sqrt{a_n^2 + b_n^2}$。考试作图时，务必在谱线上标出关键数值（如 $2/\pi$、$4/(\pi n)$ 等）。

δ函数的“抽样性”（或称筛选性质）与卷积确实有本质区别，尽管它们都涉及积分。我们可以从以下几个方面来理解它们的“不一样”：

---

### 1. **数学操作与定义**
- **抽样性**：
  - 操作：$\int_{-\infty}^{\infty} f(t) \delta(t - t_0) \, dt = f(t_0)$
  - 本质：这是一个**内积**或“点乘”过程，利用δ函数的筛选特性，直接提取函数 $f(t)$ 在 $t = t_0$ 处的值。
- **卷积**：
  - 操作：$(f * g)(t) = \int_{-\infty}^{\infty} f(\tau) g(t - \tau) \, d\tau$
  - 本质：这是一个**滤波**或**加权滑动平均**过程。对于每个输出时刻 $t$，你需要计算所有历史输入 $f(\tau)$ 与系统响应 $g(t-\tau)$ 的加权和。

---

### 2. **关键区别**
| 对比维度 | δ函数的抽样性 | 卷积（以δ函数为例） |
| :--- | :--- | :--- |
| **操作对象** | $f(t)$ 与 **固定位置** 的 δ函数 $\delta(t-t_0)$ | $f(t)$ 与 **一个函数** $g(t)$（如δ函数） |
| **积分变量** | 对 $t$ 积分 | 对 $\tau$ 积分（哑变量） |
| **结果** | 一个**标量**：函数在 $t_0$ 处的**值** $f(t_0)$ | 一个**函数**：随 $t$ 变化的 **$(f * g)(t)$** |
| **δ函数的角色** | 作为一个“探针”或“采样器”，在固定点 $t_0$ 进行“点查”。 | 作为一个系统的“冲激响应”。当 $g(t)=\delta(t)$ 时，卷积结果就是 $f(t)$ 本身（恒等系统）。 |
| **物理/几何意义** | 从连续信号中**提取离散样本**。 | 描述一个**线性时不变系统**如何变换输入信号。 |

---

### 3. **直观理解**
- **抽样性** 就像：
  你有一张完整的图片 $f(t)$。你用一个极细的、带有坐标标记的探针 $\delta(t-t_0)$，去“戳”图片上坐标为 $t_0$ 的那个点，然后读出那一点的颜色值（亮度）$f(t_0)$。**你只关心一个点**。

- **卷积**（以一个简单的移动平均系统为例）就像：
  你有一个函数 $f(t)$ 代表输入信号。系统的“记忆”或“响应模式”是 $g(t)$。要计算在某个时刻 $t$ 的输出，你需要回顾**所有历史**输入 $f(\tau)$，并用响应模式 $g(t-\tau)$ 对它们进行加权求和（比如，近期输入权重高，远期输入权重低）。**你关心的是整个历史输入的加权影响**。

---

### 4. **一个关键点澄清**
你笔记中提到的公式：
$$ \int f(t) \delta(t - t_0) dt = f(t_0) $$
**这与 $f(t) * \delta(t-t_0)$ 是不同的。**

- **抽样性公式**：积分变量是 $t$，$\delta$ 的参数是 $(t-t_0)$，积分后得到 $f(t_0)$。
- **与δ函数的卷积**：
  $$ f(t) * \delta(t - t_0) = \int f(\tau) \delta((t - \tau) - t_0) d\tau = \int f(\tau) \delta(\tau - (t - t_0)) d\tau = f(t - t_0) $$
  这个操作的结果是将原函数 $f(t)$ **向右平移**了 $t_0$ 个单位。它没有“提取”数值，而是**移动**了整个函数。

---

### 总结
**简单来说：**
- **抽样性**是 **“读取数值”** ，是一个**求值**过程，输出一个数。
- **卷积**是 **“变换信号”** ，是一个**系统映射**过程，输出一个函数。

所以，你笔记中的描述是正确的：抽样性得到的是 $f(t_0)$，即函数在某时刻的值；而卷积（即使是和δ函数卷积）得到的是一个新的函数 $f(t-t_0)$，这是信号的**平移**，不是“提取值”。这就是它们最核心的区别。
