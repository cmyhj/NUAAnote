## 关键概念
- **电涡流传感器**: 线圈通交变电流→金属表面产生涡流→涡流改变线圈等效阻抗→可测距离/电导率/裂纹
- **趋肤效应**: 涡流仅分布在金属表面，不深入内部
- **光栅**: 大量等宽等间距的平行狭缝或反射面（1cm内1000-10000条）
- **光栅常数 d = a + b**: a为透光部分宽度，b为不透光部分宽度
- **明纹公式**: d·sinθ = kλ（光程差等于波长整数倍时产生明条纹）
- **摩尔条纹**: 两片光栅相对移动时产生的条纹现象，具有**放大作用**
- **摩尔条纹间距**: B ≈ d/θ（d为光栅常数，θ为两光栅夹角，弧度制）
- **光纤传感器**: 利用光在纤芯内的全反射传播信号
- **SEA (Series Elastic Actuator)**: 串联弹性驱动器，在电机与负载之间加入弹簧

## 要点详述
### 电涡流传感器补充
1. **内部构造**: 线圈→探头壳体→调节螺纹→印刷电路板→加持螺母
2. **工作原理详细**:
   - 线圈通正弦交变电流→产生交变磁场
   - 金属导体感应到磁场→表面产生涡流
   - 涡流反抗原磁场→消耗能量→金属表面发热
   - 线圈等效阻抗发生变化→通过互感效应测量
3. **等效阻抗**: Z = f(ρ, μ, d, x)（电阻率、磁导率、尺寸、距离）
4. **等效电路**: 金属涡流等效为短路环，仅分布在环体之内
5. **考试要求**: 不考公式计算，但互感效应和等效阻抗的定性说法要会

### 光栅传感器
1. **光栅定义**: 大量等宽等间距的平行狭缝（透射式）或反射面（反射式）
2. **光栅常数**: d = a + b（透光+不透光），一厘米内至少1000-10000条
3. **光的衍射**:
   - 单缝衍射→产生衍射图样
   - 多缝干涉→条纹加强
   - 光栅=两者叠加→明暗相间的条纹
4. **明纹公式（要记）**: d·sinθ = kλ
   - d越小（精度越高）→衍射角越大→条纹越稀疏→越易分辨
   - 波长越大→衍射角越大
   - 白光入射→产生光谱

### 摩尔条纹（重点）
1. **产生条件**: 两片光栅相对移动，夹角θ
2. **放大原理**:
   - 两光栅常数相等（d₁ = d₂ = d）
   - 摩尔条纹间距 B ≈ d / (θ/2) ≈ 2d/θ（当θ很小时）
   - 实际 B ≈ d/θ（更常用的形式）
   - **例子**：d = 0.01mm，θ = 0.01 rad → B = 1mm（放大100倍）
3. **意义**: 相当于信号放大环节，将微小的光栅位移放大为可测量的条纹移动
4. **考试要点**: 摩尔条纹间距公式，注意θ用弧度制

### 光纤传感器
1. **光纤结构**: 纤芯（折射率高）+ 包层（折射率低）+ 保护套
2. **导光原理**: 全反射（纤芯折射率 > 包层折射率）
3. **三种类型**:
   - **功能型**: 光纤本身作为敏感元件，被测对象改变光的性质
   - **传光型**: 仅传输光信号，检测有光/无光
   - **拾光型**: 采集外部光源的光信号
4. **光纤位移传感器**: 发射光纤+接收光纤，反射面距离不同→接收光强不同→测距离
5. **应用**: 网络通信、结构健康监测、可穿戴设备（弯曲角度测量）

### 传感器选用原则
1. **灵敏度**: 输出变化量/输入变化量，有正负之分
   - 灵敏度越高→量程越小（矛盾关系）
2. **响应特性**: 一阶/二阶系统特性，频率范围内不失真
   - 二阶系统不失真条件：幅值衰减 < -3dB，相位滞后 < 180°
3. **线性范围**: 灵敏度保持不变的工作范围
   - 弹簧的非线性：起始段力偏大，中间段近似线性，有迟滞
4. **稳定性**: 长时间使用特性不变（时间漂移、温度漂移）
5. **精确度**: 测量值与真实值的接近程度
6. **分辨率**: 能测量的最小被测量（≠灵敏度）
7. **测量方式**: 接触/非接触、在线/离线、破坏/非破坏

### 串联弹性驱动器（SEA）
1. **概念**: MIT提出，在电机与负载之间串联弹簧
2. **三大优点**:
   - **被动柔顺**: 降低系统刚度，碰撞时有缓冲（类似自行车/汽车悬挂）
   - **力保真度高**: 用弹簧形变量（kx）代替力传感器，可选更大反馈增益
   - **成本低**: 力传感器几万元 vs 弹簧几十到几百元
3. **衍生优点**: 跟踪弹簧零位移→实现主动反驱（透明模式）
