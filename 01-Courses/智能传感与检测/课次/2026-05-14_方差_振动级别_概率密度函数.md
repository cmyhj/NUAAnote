## 关键概念
- **方差**: 信号波动程度的度量，σ² = (1/T)∫[x(t)-μ]²dt
- **振动级别**: 用均方值表示，描述振动的强度
- **概率密度函数**: 描述每个幅值在所有幅值中出现的概率比例
- **固有频率**: 系统自由振动的频率，刚度越高固有频率越高
- **PPT制作要点**: 少字、分点、图文配合、有结论

## 要点详述

### 1. PPT制作与学术报告技巧
- **第一眼原则**：让读者第一眼看到你想表达的结论
- **少字原则**：每个论点不超过一行
- **分点原则**：用1、2、3分点，条理清晰
- **图文配合**：每张图都有目的，与文字呼应
- **结论页**：报告结尾要有结论和展望
- **教鞭使用**：讲到重点时用教鞭指着，而非看着念
- **语速控制**：不要太快，显得紧张

### 2. 方差
- 定义：σ² = (1/T)∫₀ᵀ [x(t)-μ]²dt
- 物理意义：信号围绕均值的波动程度
- 直流分量小、方差大 → 信号波动剧烈
- 与均方值的关系：均方值 = 方差 + 均值²

### 3. 振动分析应用
- **汽轮发动机轴承**：主轴振幅不能超过0.05mm
- **振动级别的表示**：毫米/秒，用均方值（不是峰值、不是均值）
- **为什么用均方值**：
  - 均值可能为0（上下对称振动）
  - 峰值可能是偶然事件（压到石子）
  - 均方值反映信号的整体强度

### 4. 机器振动信号类型
1. **直流分量型**：持续的偏置（如阀门震动）
2. **递增型**：振幅随时间增大（轴偏了，有离心力叠加）
3. **脉冲型**：某时刻出现峰值（接近共振频率，过后恢复）
4. **随机型**：偶尔的冲击（如压过石子，通常不用管）

### 5. 固有频率
- 定义：刚度k = F/x，刚度越高固有频率越高
- **超声碎石原理**：石头（刚体）固有频率高，人体组织（软体）固有频率低
- 超声频率只与石头共振，不损伤组织

### 6. 概率密度函数
- 定义：p(a) = lim[T→∞] (T_a/T) / Δa
- 横轴是幅值，纵轴是概率（0~1）
- **正弦波的概率密度**：两端（峰值）概率高，中间（零点）概率低
  - 原因：正弦函数在峰值处导数为0，经过慢，概率密度大
  - 在零点处导数最大，经过快，概率密度小
- 判断方法：**看导数，导数越大，概率密度越小**
