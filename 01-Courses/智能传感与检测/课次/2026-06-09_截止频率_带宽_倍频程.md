## 关键概念
- **截止频率**: 信号被衰减至0.707倍（-3dB）时所对应的频率
- **带宽**: 滤波器-3dB截止点之间的频率范围
- **倍频程**: 衡量截止频率后信号衰减快慢的指标，倍频程越小衰减越快
- **滤波器因素**: -60dB带宽与-3dB带宽的比值，越小说明衰减越快
- **RC低通滤波器**: 一阶系统，H(s) = 1/(RCs+1)，低频通过、高频衰减
- **RC高通滤波器**: H(s) = RCs/(RCs+1)，高频通过、低频衰减
- **带通滤波器**: 低通与高通串联（取交集）
- **带阻滤波器**: 低通与高通并联（取并集）
- **有源RC滤波器**: RC网络+运算放大器，起隔离和放大作用
- **巴特沃斯滤波器**: 幅频特性平滑，不考虑相频，可用MATLAB实现
- **切比雪夫滤波器**: 幅频有纹波，N越大衰减越快但纹波越大，需平衡选择
- **贝塞尔滤波器**: 只考虑相频特性，相移与频率成正比，是相位滤波器

## 要点详述

### 1. 滤波器分类
- 低通和高通是两种最基本形式
- **串联**（取交集）：低通+高通 → 带通
- **并联**（取并集）：低通+高通 → 带阻

### 2. 滤波器参数
- **纹波幅度**：经过滤波器后信号残留的干扰波纹，越小越好
- **截止频率**：信号衰减至0.707倍（-3dB）的频率点
- **带宽**：-3dB截止点之间的频率范围
- **倍频程**：截止频率与二分之截止频率之间的衰减值，反映衰减快慢
- **滤波器因素**：-60dB带宽/-3dB带宽的比值，反映衰减快慢

### 3. RC低通滤波器推导
- 电路：R串联、C并联
- 基本公式：i = C × (dEy/dt)
- 回路方程：Ex = Ey + R×i → Ex = Ey + RC×(dEy/dt)
- 拉氏变换：X(s) = Y(s) + RCs×Y(s)
- 传递函数：**H(s) = Y(s)/X(s) = 1/(RCs+1)**
- 令τ=RC（时间常数），则H(s) = 1/(τs+1)
- 典型一阶系统：低频通过（f→0时H→1），高频衰减（f→∞时H→0）
- **τ越大，截止频率越小**（通带变窄）

### 4. RC高通滤波器推导
- 电路：C串联、R并联（与低通交换位置）
- 传递函数：**H(s) = RCs/(RCs+1)**
- 比低通多一个零点
- f→∞时H→1（通过），f→0时H→0（衰减）
- **τ增大，截止频率增大**（高通的带宽变小）

### 5. 带通与带阻
- 带通 = 低通 × 高通（传递函数相乘）
- 串联时高通在前、低通在后（考试重点！）
- 串联两级间需用输出器/运算放大器/光耦隔离，消除耦合效应

### 6. 三种改进型滤波器
| 滤波器 | 关注特性 | 特点 |
|--------|----------|------|
| 巴特沃斯 | 幅频特性 | 平滑无纹波，不需考虑相频 |
| 切比雪夫 | 幅频特性 | 有纹波，N越大衰减越快但品质越差 |
| 贝塞尔 | 相频特性 | 相移与频率成正比，是相位滤波器 |

### 7. MATLAB系统辨识工具箱
- 在MATLAB App中打开System Identification
- 导入扫频实验的输入/输出数据（time, input, output）
- 设置采样时间、起始时间
- 可选择滤波器、设置零极点数量（通常选0个零点、2个极点→二阶系统）
- Simulink中的Simscape也可用于动力学仿真

## 作业 / 考试 / 通知
- 课堂练习题（选择题+判断题）：
  1. 高频不衰减、低频衰减的滤波器是**高通滤波器**
  2. 使RC低通滤波器通带加宽，RC值应**减小**
  3. 频谱离散的信号不一定是周期信号（准周期信号也是离散频谱）→ **错**
  4. 随机信号是非确定性信号 → **对**
  5. 时域信号时移，频率信号也会移动（不是压缩）→ **错**
  6. 减小一阶系统时间常数可扩大工作频率范围 → **对**
  7. 两环节串联，总幅频特性=A₁(ω)×A₂(ω)
  8. 频率响应函数反映系统响应的**稳态**过程 → **对**
