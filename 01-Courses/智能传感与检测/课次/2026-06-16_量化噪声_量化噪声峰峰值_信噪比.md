## 关键概念
- **量化噪声**: 模拟信号经量化后产生的跳跃状误差信号
- **量化噪声峰峰值**: 等于量化单位q
- **信噪比 (SNR)**: 信号功率与噪声功率的比值，单位dB
- **SNR公式**: SNR = 6.02n + 1.76 + 10lg(3/2) ≈ **6.02n + 10.8 dB**（n为转换器位数）
- **单极性二进制码**: 信号只有正值（0~FSR），编码从最高位1/2开始逐位递减
- **双极性编码**: 增加一位符号位，0代表正数，1代表负数
- **偏移二进制码**: 加满量程直流分量将信号平移至正半平面，0000对应-FSR，1000对应0
- **补码**: 符号位与偏移二进制相反，数值部分相同；正数补码=二进制码，负数补码=取反+1

## 要点详述

### 1. 量化噪声与转换器位数
- 量化噪声是跳跃状的锯齿波形
- 噪声峰峰值 = q（量化单位）
- **转换器位数n越低** → q越大 → 量化误差越大 → 噪声峰值越高、频率越低 → 易与信号混叠
- **转换器位数n越高** → q越小 → 量化误差越小 → 噪声峰值越低、频率越高 → 可当高频噪声用滤波器滤除
- 对于相同量化单位：信号频率↑ → 量化噪声频率↑；信号频率↓ → 量化噪声频率↓

### 2. 信噪比 (SNR)
- 定义：信号功率与噪声功率的比值
- 功率比值（不是幅值比值），所以都取平方
- 公式推导：
  - 信号最大功率 ∝ (FSR)²
  - 噪声功率 ∝ (q²/12)（量化误差方差）
  - SNR = 10lg[(FSR)² / (q²/12)]
  - 代入 q = FSR/2^n
  - 最终：**SNR = 6.02n + 10.8 dB**
- **每增加1位转换器位数，信噪比增加约6dB**
- 实际应用：收音机杂音、降噪耳机原理

### 3. 编码方式

#### 单极性二进制码
- 适用于0~FSR的单向信号
- 量化电平 = A × Σ(aᵢ/2ⁱ) × FSR
- 第1位=1/2，第2位=1/4，第3位=1/8 ... 第n位=1/2ⁿ
- 例：110101 → 1/2+1/4+0+1/16+0+1/64 = 0.828
- **始终差一个1/2ⁿ的误差**（n不能无穷大）
- 最大值 = FSR × (1 - 1/2ⁿ)
- 例：12位、FSR=10V → 最大值 = 10×(1-1/4096) = 9.9976V

#### BCD码（选修，不考）
- 将二进制转换为十进制编码
- 8421码对应关系

#### 双极性编码（符号位法）
- 最高位为符号位：0=正数，1=负数
- 优点：信号在0附近变化时只有低位改变，无严重瞬态效应
- 缺点：0有两种表示（+0和-0），电路复杂造价高

#### 偏移二进制码
- 将信号加上满量程直流分量FSR，平移至正半平面
- 0000 → -FSR（真实值）
- 1000 → 0（模拟零点）
- 1111 → FSR - FSR/2^(n-1)（最大值）
- 优点：实现简单，可变换为补码
- 缺点：零点附近易发生码字跳变

#### 补码
- 符号位与偏移二进制**相反**，数值部分**相同**
- 正数补码 = 二进制码本身
- 负数补码 = 正数二进制码所有位取反 + 1
- 例：+3/8 → 0110；-3/8 → 1001+1=1010
- 补码的优势与偏移二进制相同

### 5. 课堂判断题
1. 随机信号是非确定信号 → **对**（不能用数学函数描述）
2. 周期信号的频谱都是离散的 → **对**
3. 瞬态信号是能量有限信号 → **对**（持续时间有限，面积可算）
4. 时域上信号的输出=输入×脉冲响应函数 → **错**（应为**卷积**）
5. 稳态响应法不能用于一阶系统动态测试 → **错**（一阶系统可以用）
6. 测试系统灵敏度越高测试性能越好 → **错**（灵敏度高也会引入更多噪声）
