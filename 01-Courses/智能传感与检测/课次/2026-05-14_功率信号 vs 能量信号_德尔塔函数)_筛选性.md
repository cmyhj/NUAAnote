## 关键概念

- **功率信号 vs 能量信号**: 能量信号有一定持续时间，能量为信号曲线积分面积；功率信号持续时间趋近于无穷小，只在某时刻有能量峰值
- **德尔塔函数 (Delta Function / δ(t))**: 理想化的脉冲函数，在 t=0 时无穷大，其他处为 0，但面积为 1
- **筛选性 (Sampling Property)**: δ(t) 与另一函数相乘后再积分，可提取该函数在特定时刻的值
- **辛格函数 (Sinc Function)**: Sinc(t) = sin(t)/t，一种由科学家构造的特殊函数

## 要点详述

### 信号分类复习

老师通过随机提问回顾了以下内容：

- **能量信号**: 有一定持续时间，能量为信号曲线从开始到结束的积分面积
- **功率信号**: 持续时间趋近于无穷小，只在某一时刻有能量峰值，由此引出德尔塔函数
- **复杂周期信号**: 由多个简单周期信号叠加而成，可以有无数个频率成分，但叠加后具有公周期
- **准周期信号**: 永远找不到一个时间点使其开始重复自身的信号变化
- **顺态信号**: 不是各种频率信号的叠加，而是单一事件（如敲击桌面）产生的衰减波形
- **噪声信号**: 非确定性信号，用一段时间内的持续强度（即积分或平均）来描述

### 物理不可能信号与前馈控制

- 物理不可能信号在 t < 0 时已有值
- 实际应用：前馈控制（Feedforward Control）
- 核心思想：将 n 时刻的信号提前用于 n+1 时刻的控制，补偿系统延迟
- 干扰观测器（Disturbance Observer）：观测干扰→滤波→提前减去，实现干扰消除

### 德尔塔函数（考试重点）

**定义**:
- 可看作脉冲函数在脉宽趋近于 0 时的极限
- 横坐标宽度 → 0，纵坐标高度 → ∞，但面积恒为 1

**三大特性**:
1. **对称性**: 只在 t=0 时有值，正负侧均为 0
2. **尺度变换**: δ(at) = (1/|a|)δ(t)
3. **筛选性**: ∫δ(t-t₀)·f(t) dt = f(t₀)，可提取任意函数在指定时刻的值

**考试提示**: 德尔塔函数的计算题是考试必考内容，包括与 cos 等函数结合的积分计算。

### 辛格函数（新内容）

- Sinc(t) = sin(t)/t，也可写作 sin(πt)/(πt)
- 由科学家构造的特殊函数，在信号处理中有重要应用
