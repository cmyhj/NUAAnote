## 关键概念

- **确定性信号**: 可用数学公式描述的信号，由多个周期信号叠加而成
- **周期信号**: 存在最小公倍周期（基频），信号可重复
- **准周期信号**: 由多个周期信号合成，但各频率不成公倍数（如 sin(t) + sin(√2 t)），整体上为非周期信号
- **瞬态信号**: 持续时间有限的非重复信号（如敲击振动、衰减信号）
- **非确定性信号（随机信号）**: 不能用数学公式表达，只能用统计量（均值、方差、能量）描述
- **白噪声**: 典型随机信号，用一段时间内的能量大小或均方差来描述
- **连续信号**: 任意时刻都有对应幅值
- **离散信号**: 仅在特定时间点有值
- **数字信号**: 时间和幅值均为离散
- **物理可实现信号**: 在正常时间线上发生的信号（t < 0 时为零）
- **物理不可实现信号**: t < 0 时已有值的理想化信号，用于前馈控制和延迟补偿

## 要点详述

### 确定性信号的分类

**周期信号**:
- 简单周期信号: 单一正弦/余弦函数
- 复杂周期信号: 多个周期信号叠加，但各频率存在公倍数（如 2^n 倍频），具有共同周期

**准周期信号**:
- 各部分为周期函数，但频率之比为无理数（如 sin(t) + sin(√2 t)）
- 找不到公共周期，因此整体非周期
- 仍可用不同频率函数分解表示

**瞬态信号（非周期信号）**:
- 持续时间有限的信号
- 如敲击桌子产生的衰减振动，由于阻尼逐渐衰减至零
- 完全非周期且不可重复

### 非确定性信号（随机信号）

- 不能用数学公式表达
- 用一段时间内的能量大小或均方差来描述
- 类比白噪声和下雨声，其"大小"用分贝或统计量衡量

### 连续与离散信号

- **连续信号**: 模拟信号，任意时刻可测到值，幅值连续处可求导
- **幅值不连续信号**: 在间断点不可求导
- **离散信号**: 时间轴不连续，仅在采样点有值
- **数字信号**: 时间和幅值均离散

关键认识：采样信号永远与实际信号有偏差，采样频率越高，近似越精确。

### 物理可实现与物理不可实现信号

- **物理可实现**: t < 0 时信号为 0，符合因果律
- **物理不可实现**: t < 0 时已有值的理想化信号
  - 应用例子：前馈控制 / 延迟函数 e^(-jωt)
  - 原理：提前一个控制周期假想信号作用，补偿系统延迟
