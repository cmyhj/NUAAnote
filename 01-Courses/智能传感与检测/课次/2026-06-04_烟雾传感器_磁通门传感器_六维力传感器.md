## 关键概念

- **烟雾传感器**: 将烟雾浓度信号转换为电信号的装置，分为离子式（镅241电离）和光电式（红外光折射）两种。离子式响应快但含放射性物质，光电式安全环保但响应较慢。

- **磁通门传感器**: 利用软磁铁芯的磁饱和效应测量静态磁场的传感器。核心结构包括高磁导率磁芯（坡莫合金）、激励线圈和感应线圈，采用差动结构消除偶次谐波。通过检测外磁场引起的二次谐波幅值来反推磁场强度。

- **六维力传感器**: 能同时测量空间中三个方向的力和三个方向的力矩的传感器。主要类型包括电阻应变式、光电式、电容式、压电式和电涡流式。应用于航空航天、机器人、手术机器人等领域。

- **乙醇气体传感器**: 检测乙醇气体浓度的传感器。MOS型通过金属氧化物与乙醇发生氧化还原反应引起电阻变化；燃料电池型通过电化学反应产生电流来检测。

- **滤波器 (Filter)**: 一种选频装置，可以使信号中的特定频率成分通过，而让其他成分衰减。用于噪声消除和频谱选择。

- **低通滤波器 (Low-Pass Filter)**: 允许低于截止频率的信号通过，高于截止频率的信号被衰减。RC电路是一阶低通滤波器的典型代表。

- **高通滤波器 (High-Pass Filter)**: 允许高于截止频率的信号通过，低于截止频率的信号被衰减。

- **带通滤波器 (Band-Pass Filter)**: 只允许两个截止频率之间的信号通过。可由低通和高通滤波器串联得到（取交集）。

- **带阻滤波器 (Band-Stop Filter)**: 阻止两个截止频率之间的信号通过，允许低频和高频信号通过。可由低通和高通滤波器并联得到（取并集）。

- **理想滤波器**: 截止频率前信号完全还原（幅值衰减为1），截止频率后信号瞬间衰减为0的滤波器。其脉冲响应为sinc函数，是物理不可实现的。

- **截止频率**: 信号幅值衰减到0.707（-3dB）时所对应的频率。这是工程上的妥协参数。

- **品质因数 (Quality Factor)**: 评价滤波器选择性的参数，等于中心频率与带宽的比值 $Q = f_0/B$。Q值越高，滤波器的选择性越好。

## 要点详述

### 1. 学生汇报要点

**烟雾传感器（徐浩天）**：
- 离子式：镅241放射α射线电离空气，烟尘吸附离子使电流减小，响应快但有放射性
- 光电式：红外光被烟雾折射后被接收端捕捉，安全环保但响应较慢
- 未来趋势：双波长光学探测+散射消光+智能算法融合，响应速度提升2倍，识别率99%

**磁通门传感器（吕志超）**：
- 历史：战国司南→1600年吉尔伯特《磁论》→法拉第/麦克斯韦电磁理论→磁通门传感器
- 原理：软磁铁芯在激励磁场作用下周期性达到磁饱和，外磁场打破对称性，产生二次谐波
- 差动结构：两个铁芯绕向相反，消除奇次谐波，只保留偶次谐波
- 与霍尔传感器对比：霍尔有气隙、量程宽、适合粗测；磁通门无气隙、量程窄、适合精测
- 应用：卫星姿态控制（嫦娥号）、地磁监测、工业无损检测

**六维力传感器（王汉卓）**：
- 1965年MIT和斯坦福诞生第一个六维力传感器
- 发展四阶段：实验室期→工业标准期→软件解耦期→智能化/国产化期
- 电阻应变式：惠斯通电桥，四梁并联结构，技术最成熟
- 全光学式（上海交大2025年）：尺寸仅1.7mm，AI自动标定
- 电涡流式（中科大2025年）：折纸结构，PCB一体成型，解决布线难题
- 性能指标：轻、快、准、纯、稳、小

**乙醇气体传感器（肖玉洁）**：
- 背景：乙醇易燃易爆（爆炸极限3%-19%）、致癌物、酒驾事故率是正常16倍
- MOS型：成本低，灵敏度一般，用于工业领域
- 燃料电池型：灵敏度高，用于交通执法
- 复合材料：锡酸锌（n型）+氧化镍（p型）形成p-n结，提升灵敏度
- 测试指标：最佳工作温度、气体选择性、响应/恢复速度、长期稳定性

### 2. 调频调制的数学原理

调频与调相本质上是相似的：

**调相 (PM)**：
$$x_{PM}(t) = A\cos[2\pi f_c t + k_p x(t)]$$

瞬时相位：$\theta(t) = 2\pi f_c t + k_p x(t)$

瞬时频率：$f(t) = \frac{1}{2\pi}\frac{d\theta}{dt} = f_c + \frac{k_p}{2\pi}\frac{dx(t)}{dt}$

**调频 (FM)**：
$$x_{FM}(t) = A\cos[2\pi f_c t + k_f \int x(t)dt]$$

瞬时频率：$f(t) = f_c + k_f x(t)$

通过微分可以将调频信号转换为包络检波的形式。

### 3. 滤波器的分类与关系

**四种基本类型**：

| 类型 | 通过频段 | 阻止频段 |
|------|----------|----------|
| 低通 | $f < f_c$ | $f > f_c$ |
| 高通 | $f > f_c$ | $f < f_c$ |
| 带通 | $f_{c1} < f < f_{c2}$ | $f < f_{c1}$ 或 $f > f_{c2}$ |
| 带阻 | $f < f_{c1}$ 或 $f > f_{c2}$ | $f_{c1} < f < f_{c2}$ |

**组合关系**：
- 低通 + 高通（串联）→ 带通（取交集）
- 低通 + 高通（并联）→ 带阻（取并集）

### 4. 理想滤波器 vs 实际滤波器

**理想滤波器**：
- 截止频率前：幅值完全还原（衰减 = 1），相位不失真
- 截止频率后：瞬间衰减为0
- 频率响应呈矩形
- 脉冲响应为sinc函数：$h(t) = \frac{\sin(2\pi f_c t)}{\pi t}$
- 物理不可实现（t<0时就有响应，违反因果性）

**实际滤波器**：
- 通带内存在纹波（波动）
- 截止频率处是渐变衰减，而非瞬间截止
- 需要更多参数描述其特性

### 5. 滤波器的关键参数

**纹波幅度 (Ripple)**：
- 通带内信号幅值相对于 $A_0$ 的波动范围
- 应远小于信号本身的幅值

**截止频率 (Cutoff Frequency)**：
- 信号幅值衰减到0.707（-3dB）时对应的频率
- 低通只有 $f_{c2}$，高通只有 $f_{c1}$，带通/带阻有两个

**带宽 (Bandwidth)**：
$$B = f_{c2} - f_{c1}$$

**品质因数 (Quality Factor)**：
$$Q = \frac{f_0}{B}$$

其中 $f_0$ 为中心频率，$B$ 为带宽。Q值越高，滤波器选择性越好，能更精准地选取所需频率成分。

### 6. RC电路作为低通滤波器

RC电路是最简单的一阶低通滤波器：
$$H(s) = \frac{1}{RCs + 1}$$

其频率响应特性：
- 低频信号完美通过
- 高频信号被衰减
- 截止频率：$f_c = \frac{1}{2\pi RC}$
