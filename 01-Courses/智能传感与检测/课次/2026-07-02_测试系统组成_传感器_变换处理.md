## 关键概念
- **测试系统组成**: 被测对象 → 激励装置 → 传感器 → 变换处理 → 输出显示，各环节作用需准确描述
- **传感器**: 将被测非电量转换为电量的装置，简单传感器（敏感元件），复杂传感器（力传感器+应变片）
- **变换处理**: 包括信号放大（毫伏级→伏级）、调制解调、滤波、模数转换等环节
- **确定性信号**: 能用数学公式表达的信号，如正弦波、方波
- **随机信号**: 不能用数学公式表达，每个点幅值随机产生，用统计特性（均值、均方值、方差）描述
- **能量信号**: 有一定持续时间，能量 = 功率 × 时间
- **功率信号**: 理想瞬态信号（如δ函数），时间持续趋近于0，实际不可能产生
- **周期信号**: 隔一段时间能重复自己，谐波分量周期存在公倍数，频率存在公约数
- **非周期信号**: 不能重复自己，包括准周期信号（无公倍数）和瞬态信号
- **物理可实现信号**: t<0时信号为0，系统开始前无信号
- **物理不可实现信号**: t<0时信号已存在，可用于前馈控制（降低反馈功率）、干扰观测器（高频控制抵消低频干扰）
- **δ函数**: 单位面积为1，仅在t=0时有意义，具有筛选性（提取特定时刻值）和尺度变换特性（时间压缩→幅值增大）
- **sinc函数**: 与矩形窗函数互为傅里叶变换，考试可能要求画图
- **傅里叶级数**: 将周期信号分解为直流分量+各次谐波，基本公式需记忆，计算必考
- **一阶系统**: 弹簧-阻尼系统（忽略质量），传递函数 $H(s) = \frac{1}{\tau s + 1}$，$\tau$为时间常数
- **二阶系统**: 弹簧-质量-阻尼系统，有阻尼比$\zeta$、固有频率$\omega_n$参数
- **灵敏度**: 自变量单位变化引起的因变量变化（斜率），$S = \frac{\Delta y}{\Delta x}$
- **线性度**: 曲线符合线性关系的程度，用最大偏差与满量程比值表示
- **回程误差**: 与磁滞相关，加载/卸载路径不一致，产生误差
- **灵敏阀**: 能检测到的最小输入变化
- **分辨率**: 能检测到的最小输入值（与灵敏度不同，灵敏度是变化率，分辨率是最小值）
- **调制**: 低频信号与高频载波信号相乘，包括调幅（AM）、调频（FM）、调相（PM）
- **解调**: 调制的逆过程，再乘一次高频信号，利用傅里叶卷积特性
- **混叠**: 载波频率过低时产生，原始信号+载波信号两倍频干扰，需用低通滤波器滤除
- **滤波器**: 允许部分频率信号通过，阻止其他频率信号
- **低通滤波器**: 允许低频通过，阻止高频，传递函数 $H(s) = \frac{1}{\tau s + 1}$，$\tau = RC$
- **高通滤波器**: 允许高频通过，阻止低频
- **带通滤波器**: 低通与高通串联（取交集）
- **带阻滤波器**: 低通与高通并联（取并集）
- **纹波幅度**: 滤波器通带内幅值波动范围
- **截止频率**: 幅值下降到0.707时的频率
- **带宽**: 截止频率之间的频率范围
- **品质因数**: 对信号过滤性好坏的度量
- **倍频程选择性**: 阻带内幅值衰减速度

## 要点详述

### 第一章：测试系统组成（重点考点，必考简答题）

测试系统由以下环节组成，需准确画出框图并说明各环节作用：

1. **被测对象**: 测试的目标。有些被测对象自身无法产生信号，需要激励装置使其产生可测信号。
2. **激励装置**: 使被测对象产生可测信号。例如，对结构施加激振力使其产生振动信号。
3. **传感器**: 将被测非电量转换为电量的装置（信息转换）。简单传感器（如温度传感器）仅需敏感元件；复杂传感器（如力传感器）需贴应变片，通过金属变形测力。
4. **变换处理**: 包括多个子环节：
   - **信号放大**: 将微弱信号放大（如表面肌电信号从毫伏级放大到伏级）
   - **调制解调**: 信号调制与解调处理
   - **滤波**: 去除噪声干扰，提取纯净信号
   - **模数转换**: 将模拟信号转换为数字信号（不是所有传感器都能直接输出数字信号）
   - **数据存储、采集、校正**: 数据预处理
5. **输出装置**: 显示器、万用表、示波器、计算机等，将处理后的信号显示或记录。

**考试要求**: 能准确画出系统框图，说明各环节作用。评分标准：意思对即可，不要求死记硬背，但每个环节作用要清楚。

### 第二章：信号分类与描述（重点章节，考点密集）

#### 2.1 信号分类
- **时域信号**: 横轴为时间，描述信号随时间变化
- **频域信号**: 横轴为频率，描述信号频率成分
- **确定性信号**: 能用数学公式表达的信号，如正弦波、方波
- **非确定性信号（随机信号）**: 不能用数学公式表达，每个点幅值随机产生，用统计特性描述
- **能量信号**: 有一定持续时间，能量 = 功率 × 时间
- **功率信号**: 理想瞬态信号（如δ函数），时间持续趋近于0，实际不可能产生
- **连续信号**: 每一刻都有值
- **离散信号**: 幅值离散
- **数字信号**: 幅值和时间都离散（考点：问数字信号特征）
- **模拟信号**: 处处可导，无跳变点（模拟信号与一般连续信号区别）
- **物理可实现信号**: t<0时信号为0，系统开始前无信号
- **物理不可实现信号**: t<0时信号已存在，应用场景：
  1. **前馈控制**: 用n时刻计算出的信号比例，反推n+1时刻基准信号，降低反馈回路动态功率
  2. **干扰观测器**: 用n时刻观测到的干扰，直接作为n+1时刻干扰量，条件是控制频率远高于干扰变化频率（如1000Hz控制频率 vs 10Hz干扰频率）

#### 2.2 周期信号与非周期信号
- **周期信号**: 隔一段时间能重复自己，谐波分量周期存在公倍数，频率存在公约数
- **非周期信号**: 不能重复自己，包括：
  - **准周期信号**: 不具有公倍数的信号合成
  - **瞬态信号**: 如爆炸信号
- **随机信号**: 不能用数学公式表示，用一段时间内的平均功率（强度）表示

#### 2.3 δ函数与sinc函数
- **δ函数**: 
  - 定义：单位面积为1，仅在t=0时有意义
  - 性质：筛选性（提取特定时刻值）、尺度变换特性（时间压缩→幅值增大，时间拉伸→幅值减小）
  - 计算：在t0时刻有意义，积分等于1，提取函数值
- **sinc函数**: 
  - 与矩形窗函数互为傅里叶变换
  - 考试可能要求画图
- **负指数函数**: 
  - 引入衰减/发散概念
  - 由于γ存在，正负都会影响增大/衰减
  - 幅值变换时有衰减包络线或发散包络线
  - **今年不考计算**（教师明确说明）

#### 2.4 时域信号统计概念
- **均值**: 信号在一段时间的平均数，代表直流分量
- **均方值**: 信号强度，代表信号功率
- **方差**: 信号发散程度
- **均方值诊断法**: 振动分析中使用均方值而非幅值大小
- **概率密度函数**: 某一极小幅值在整体中出现的频率（次数），关键词是"次数"
  - 判断大小：看该点周边导数大小，导数大→变化快→出现次数小
- **分布函数**: 概率密度函数积分，从0到1

#### 2.5 傅里叶级数（必考计算题）
- **基本公式**: 将周期信号分解为直流分量+各次谐波
  $$x(t) = a_0 + \sum_{n=1}^{\infty} [a_n \cos(n\omega_0 t) + b_n \sin(n\omega_0 t)]$$
- **计算步骤**:
  1. **判断奇偶性**:
     - 奇函数：$b_n = 0$，只算$a_0$和$a_n$
     - 偶函数：$a_n = 0$，只算$a_0$和$b_n$
  2. **计算系数**:
     - $a_0 = \frac{1}{T} \int_{0}^{T} x(t) dt$（直流分量）
     - $a_n = \frac{2}{T} \int_{0}^{T} x(t) \cos(n\omega_0 t) dt$
     - $b_n = \frac{2}{T} \int_{0}^{T} x(t) \sin(n\omega_0 t) dt$
  3. **计算幅值和相位**:
     - $A_n = \sqrt{a_n^2 + b_n^2}$（幅值）
     - $\phi_n = \arctan\left(\frac{b_n}{a_n}\right)$（相位）
- **必考图形**:
  1. **方波**: 傅里叶级数展开公式需记忆，画图时画到1、3、5、7次谐波
  2. **三角波**: 计算方法与方波类似，画图要求同方波
  3. **锯齿波**: 也是考点，需掌握计算
- **考试要求**: 
  - 带计算器，草稿纸两张
  - 计算正确可得大部分分数，画图额外2分
  - 奇偶性判断可得2分，即使不会计算

#### 2.6 傅里叶性质（可能考概念题）
- **线性**: 先加减后变换 = 先变换后加减，常数乘除可在变换前后进行
- **时频对偶**:
  - 时域周期 ↔ 频域离散
  - 时域离散 ↔ 频域周期
  - 口诀：周期↔离散，两个字互换
- **尺度变换**:
  - 时域压缩 ↔ 频域扩展
  - 时域扩展 ↔ 频域压缩
  - 例子：窗函数压缩→sinc函数扩展，窗函数扩展→sinc函数压缩
- **时移**: 时域平移 ↔ 频域平移（两个都会移动）
- **卷积**: 信号与自身衰减的重叠面积计算

### 第三章：系统传递函数（重点概念）

#### 3.1 一阶系统
- **典型系统**: 弹簧-阻尼系统（忽略质量）
- **传递函数**: $H(s) = \frac{1}{\tau s + 1}$，其中$\tau$为时间常数
- **推导**: 根据电压电流变化推导
- **特性**: 
  - 输入正弦信号 $x(t) = A_0 \sin(\omega t)$
  - 输出仍是同频率正弦信号，但幅值和相位变化
  - 输出 $y(t) = A \cdot A_0 \sin(\omega t - \phi)$
  - 其中 $A$ 为幅值比，$\phi$ 为相位滞后
- **幅频特性**: 高频衰减
- **相频特性**: 始终有相位滞后（一阶滤波缺陷）
- **伯德图**: 幅值曲线高频衰减，相位曲线始终滞后

#### 3.2 二阶系统
- **典型系统**: 弹簧-质量-阻尼系统
- **特性**: 在一定阻尼比范围内有良好跟踪特性
- **良好跟踪条件**:
  1. 幅值变化小于0.707（即$\sqrt{2}/2$）
  2. 相角在180度以上
- **伯德图**: 根据不同阻尼比描述图形特征
- **考试说明**: 二阶系统计算可能不考（教师说可能改为一阶）

#### 3.3 静态特性（名词解释考点）
- **灵敏度**: 自变量单位变化引起的因变量变化（斜率），$S = \frac{\Delta y}{\Delta x}$
- **线性度**: 曲线符合线性关系的程度，用最大偏差与满量程比值表示
- **回程误差**: 与磁滞相关，加载/卸载路径不一致，产生误差
- **稳定性**: 系统稳定性
- **精度**: 测量精度
- **灵敏阀**: 能检测到的最小输入变化
- **分辨率**: 能检测到的最小输入值（与灵敏度不同，灵敏度是变化率，分辨率是最小值）
- **量程**: 测试范围
- **可靠性**: 系统可靠性

**考试要求**: 这些名词要记住，可能考选择题或简答题。

### 第四章：调制解调与滤波器（必考计算题）

#### 4.1 调制
- **定义**: 低频信号与高频载波信号相乘
- **类型**:
  - **调幅 (AM)**: 载波幅值随信号变化
  - **调频 (FM)**: 载波频率随信号变化
  - **调相 (PM)**: 载波相位随信号变化
- **混叠现象**: 载波频率过低时产生，原始信号+载波信号两倍频干扰
  - 解决方法：用低通滤波器滤除高频干扰
- **考试重点**: 调制概念，混叠现象

#### 4.2 解调
- **定义**: 调制的逆过程，再乘一次高频信号
- **原理**: 利用傅里叶卷积特性
- **过程**: 解调后得到原始信号+两倍频信号，再通过低通滤波器还原

#### 4.3 滤波器（必考计算题）
- **定义**: 允许部分频率信号通过，阻止其他频率信号
- **类型**:
  - **低通滤波器**: 允许低频通过，阻止高频
  - **高通滤波器**: 允许高频通过，阻止低频
  - **带通滤波器**: 低通与高通串联（取交集）
  - **带阻滤波器**: 低通与高通并联（取并集）
- **理想滤波器**: 矩形窗函数
- **主要参数**:
  - **纹波幅度**: 通带内幅值波动范围
  - **截止频率**: 幅值下降到0.707时的频率
  - **带宽**: 截止频率之间的频率范围
  - **品质因数**: 对信号过滤性好坏的度量
  - **倍频程选择性**: 阻带内幅值衰减速度
- **一阶低通滤波器**:
  - **传递函数**: $H(s) = \frac{1}{\tau s + 1}$，其中 $\tau = RC$
  - **计算步骤**:
    1. 根据RC值计算时间常数$\tau = RC$
    2. 写出传递函数$H(s)$
    3. 给定输入信号，计算输出信号
    4. 计算幅频特性$A(f)$和相频特性$\phi(f)$
  - **公式**: $s = j2\pi f$，$\tau = RC$
  - **计算示例**: 
    - 已知RC值，求传递函数
    - 已知输入信号频率，求输出幅值和相位
- **考试要求**: 
  - 会写低通滤波器传递函数
  - 会计算给定输入信号的输出信号
  - 带计算器计算
