## 关键概念

### 量化误差 (Quantization Error)
模拟信号在数字化过程中，由于幅值需要用有限个离散电平近似表示，采样值与最近量化电平之间必然存在偏差，这个偏差称为量化误差。量化误差是原理性误差，来源于采样精度的固有限制，只能通过增加位数减小，无法从根本上消除。

### 量化单位 q (Quantization Step)
量化单位 q 是相邻两个量化电平之间的差值，等于满量程 FSR 除以量化级数 2^n，其中 n 为模数转换器的位数。q 越小，量化精度越高，对应的量化误差也越小。

### 信噪比 SNR (Signal-to-Noise Ratio)
信噪比定义为信号功率与噪声功率的比值，反映信号中有用成分相对于噪声成分的强弱程度。对于 n 位模数转换器，近似公式为 SNR = 6n + 10.8 dB。转换器每增加 1 位分辨率，信噪比提高约 6 dB。

### FSR (Full Scale Range)
FSR 即满量程，是模数转换器能够表示的最大信号范围。在单极性系统中为 0 到最大正电压，在双极性系统中为 -FSR 到 +FSR。量化电平的计算均以 FSR 为基准。

### 偏移二进制码 (Offset Binary)
双极性编码方式之一，通过在信号上叠加一个满量程的直流分量，将双极性信号平移到单极性范围。编码 0000 对应 -FSR，1000 对应 0，1111 对应接近 +FSR。偏移二进制码的符号位与补码恰好相反。

### 补码 (Two's Complement)
计算机中表示有符号整数的标准编码方式。正数的补码与其原码相同；负数的补码为该数绝对值的二进制码所有位取反后加 1。补码的符号位与偏移二进制码相反，数值部分相同。

### 串联弹性驱动器 SEA (Series Elastic Actuator)
一种将弹性元件串联在电机输出端与负载之间的驱动器结构，通过弹性变形来感知输出力矩，具有柔顺性和力控制能力，广泛应用于机器人关节和康复外骨骼等场景。本节课点明该概念，为后续传感器应用做铺垫。

## 要点详述

### 一、量化方法对比总结

量化是将连续幅值映射到离散电平的过程，两种基本方法对比如下：

**只舍不入法（截断法）：**
- 计算方式简单，直接截去多余低位
- 误差范围为 0 到 q（始终为正偏差），平均误差为 q/2
- 属于有偏量化方法（误差不围绕零对称）
- 误差方差为 q²/12
- 最大误差趋近于 q

**有舍有入法（四舍五入法）：**
- 需要判断采样值与 q/2 的大小关系来决定舍入方向
- 计算量增大，但整体误差减小
- 平均误差趋近 0，属于无偏估计方法
- 最大误差为 q/2（比截断法减小一半）
- 误差方差同为 q²/12

两种方法的方差相同，但有舍有入法的最大误差和平均误差均更小，是工程实践中更优的选择。量化误差是原理性误差，不可能通过任何算法完全消除，只能通过提高转换器位数来减小。

### 二、量化噪声与转换器位数的关系

量化误差在信号重建后表现为叠加在原始信号上的量化噪声，其特性与转换器位数密切相关：

**位数高的情况（量化误差小）：**
- 量化单位 q 小 → 量化噪声幅值小（峰值低）
- 量化噪声频率高（噪声变化周期短）
- 高频噪声可通过低通滤波器有效滤除
- 对信号质量影响较小

**位数低的情况（量化误差大）：**
- 量化单位 q 大 → 量化噪声幅值大（峰值高）
- 量化噪声频率低（噪声变化周期长）
- 低频大振幅噪声容易与有用信号发生频谱混叠
- 难以用滤波器分离，严重影响信号质量

**信号频率与噪声频率的关联：**
- 信号频率降低 → 量化噪声频率随之降低
- 信号频率增加 → 量化噪声频率随之增加
- 这是因为量化噪声本质上反映的是信号穿越量化电平时的误差变化速率

### 三、信噪比 SNR

信噪比是衡量信号质量的核心指标，定义为信号功率与噪声功率的比值（注意是功率之比，不是幅值之比）。

**计算公式：**

$$SNR = 6n + 10.8 \text{ dB}$$

其中 n 为模数转换器的位数。

**关键结论：**
- 转换器每增加 1 位，SNR 增加 6 dB
- 6 dB 意味着信号功率与噪声功率之比增加 4 倍（即幅值比增加 2 倍）
- 例如：8 位 ADC 的 SNR ≈ 58.8 dB，16 位 ADC 的 SNR ≈ 106.8 dB
- FSR（Full Scale Range）为最大量程，是 SNR 计算的参考基准

### 四、单极性编码

单极性编码适用于信号在 0 到某一正电平之间变化的场景（如 0~5V）。

**量化电平计算公式：**

$$\text{量化电平} = FSR \times \left(\frac{A_1}{2} + \frac{A_2}{4} + \cdots + \frac{A_n}{2^n}\right)$$

其中 A₁, A₂, ..., Aₙ 为二进制码的各位（0 或 1），A₁ 为最高位。

**编码特性：**
- 始终存在一个 1/2^n × FSR 的固有误差，无法精确表示任意模拟量
- 这是因为有限位二进制码只能表示有限个离散电平
- 位数 n 越大，该固有误差越小

### 五、双极性编码

当信号在正负之间变化时（如 -5V ~ +5V），需要双极性编码方式。主要有三种实现方式：

**符号位编码：**
- 最高位为符号位：0 代表正数，1 代表负数
- 缺点：0 附近的码值不确定（+0 和 -0 两种表示），电路实现复杂，工程中较少使用

**偏移二进制码：**
- 在信号上叠加满量程 FSR 的直流分量，将双极性信号平移到单极性范围
- 编码映射关系：
  - 0000 → -FSR（最负值）
  - 1000 → 0（零点）
  - 1111 → 接近 +FSR（最正值）
- 优点：可用单极性 ADC 直接处理双极性信号

**补码：**
- 符号位与偏移二进制码相反，数值部分相同
- 正数的补码 = 原码（二进制码）
- 负数的补码 = 该数绝对值的二进制码所有位取反后加 1
- 补码是计算机内部表示有符号整数的标准方式
- 优点：加法和减法运算可统一处理，无需区分符号

### 六、传感器分类（第六章引入）

第六章从人类五种感官出发，系统介绍各类传感器的工作原理与应用场景：

**视觉类传感器（对应人眼）：**
- 光电池：利用光伏效应将光信号直接转换为电信号
- 光敏电阻器：光照强度变化引起电阻值改变
- 光电晶体管：光信号控制晶体管导通程度

**听觉类传感器（对应人耳）：**
- 压电器件：利用压电效应，机械振动产生电荷
- 应变片：形变引起电阻变化
- 霍尔元件：磁场变化引起电压变化
- 可变电容：声压引起电容极板间距变化

**皮肤类传感器（对应触觉）：**
- 温度检测：热电偶（利用塞贝克效应）、热敏电阻（温度引起电阻变化）
- 压力检测：应变计、压电器件、电容式、电感式
- 湿度检测：电容式或电阻式湿度传感器
- 剪切力检测：多轴力传感器

**嗅觉类传感器（对应鼻子）：**
- 半导体气敏电阻：气体吸附引起电导率变化
- 电化学气体传感器：气体发生氧化还原反应产生电流

**味觉类传感器（对应舌头）：**
- 化学变换离子电极：离子浓度变化引起电位差
- 酶传感器：酶与特定物质的生化反应产生可测电信号
