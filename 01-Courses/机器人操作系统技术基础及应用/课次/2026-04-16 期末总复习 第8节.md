### 第1章 基本概念

- ROS **不是**传统操作系统，而是一个分布式通信框架
- 5 个特点：分布式网络、点对点、多语言支持、轻量级、开源免费
- 版本知识：长期支持版（LTS）vs 短期支持版，需了解支持周期
- 当前使用的 ROS 发行版及版本号必须清楚
- 常用 Linux 命令：`cd`, `ls`, `mv`, `cp`, `rm`, `sudo`
- 安装流程：配软件源 → 添加密钥 → 选择安装版本
- `rosdep init / install`：为功能包安装系统依赖
- **环境变量**（高频考点）：为什么要设、怎么设（选择题/判断题可能涉及）
- `roscore` 启动命令必须掌握
- **小乌龟历程**：启动乌龟仿真器节点 + 键盘控制节点的命令要会

### 第2章 核心概念（重点章节）

**架构三层**
```
应用层  ←—— ROS 横跨这两层
中间层
  └── ROS Master, TCP/UDP, Node API, Library
OS 层 —— Linux
```

**系统实现三层**
- **开源社区**——简单了解
- **文件系统**——重要，含功能包、消息类型、服务类型等
- **计算图**——重要，含节点、话题、服务、参数服务器

**节点（Node）**
- 基本计算单元
- 需要掌握节点关系图的阅读：椭圆形 = 节点，箭头 = 话题/服务，箭头上的字 = 名称

**消息与话题**
- Topic = 发布–订阅模型
- 允许多个节点发布或订阅同一话题

**服务**
- 客户端–服务器模型
- 只允许一个节点提供指定命名的服务
- 数据类型：`---` 上为请求域，下为应答域

**节点管理器**
- ROS Master / 节点管理器 / 主节点 —— 同一事物三种叫法
- 通过 RPC 帮助节点查找建立连接，管理参数服务器

**文件系统**
- 功能包 = ROS 软件基本单元
- package.xml：记录基本信息（编译依赖标签 vs 运行时依赖标签）
- 元功能包：组织多个同目的功能包；元功能包清单需额外加 `<export>`，且**不需要**编译依赖

**三种通信机制对比**

| 项目 | 话题（Topic） | 服务（Service） | 参数服务器 |
|------|---------------|-----------------|------------|
| 步骤数 | 7 步 | 5 步 | 3 步 |
| 通信方式 | 前 5 IPC + 后 2 TCP | 类似模式 | 最简单 |
| 模型 | 发布–订阅 | 客户端–服务器 | 键值存储 |
| 适用场景 | 连续数据流 | 一次性请求–应答 | 全局共享参数 |

### 第3章 工作空间与编程

- 工作空间 4 个目录：`src`、`build`、`devel`、`install`
- 环境变量作用：让 ROS 找到工作空间
- 创建功能包命令：`catkin_create_pkg`
- **工作空间覆盖**：不同工作空间有同名功能包时，ROS 按环境变量优先级查找
- **话题通信代码**：流程性，从上往下
- **服务通信代码**：回调函数中 `req` = 请求域指针，`res` = 应答域指针
  - 通过 `req->a`, `req->b` 获取参数，`res->sum` 返回结果
  - 命令行传参 `argv[1]`、`argv[2]`；判断参数个数
  - 服务调用：`client.call()`，需处理调用成功与否的返回值
- **编译**：`catkin_make`（注意不是 `cmake` 或 `make`）
- 运行顺序：`roscore` → 功能包节点
- **自定义消息**：`.msg`（话题）/ `.srv`（服务）
  - 基础数据类型（string、uint8 等）名称要记住
  - Standard Header 里面的字段要了解
  - 查看消息类型：`rosmsg show`；查看服务：`rosservice list` / `rosservice call`
- **命名空间（必考）**
  - 全局：以 `/` 开头
  - 相对：无 `/` 开头，基于默认命名空间解析
  - 私有：以 `~` 开头
  - **考查方式**：给定节点 + 名称，写出解析结果
- **重映射（必考）**
  - 命令行：`:=` 语法
  - launch 文件：`<remap>` 标签

### 第4章 常用组件

- **Launch 文件**
  - `<node>`：`pkg`（功能包）、`type`（可执行文件）、`name`（节点名）
  - `<param>` vs `<arg>`：参数 vs 参数（容易混淆）
  - `<remap>`：在 launch 文件中重设名称
  - 嵌套复用
- **TF 坐标变换**
  - `tf_monitor`：查看 TF 树状态
  - `tf_echo`：查看特定坐标变换
  - `static_transform_publisher`：发布静态变换
  - `view_frames`：可视化 TF 树
- **rqt_graph**：节点关系图
- **rviz**（可视化） vs **Gazebo**（仿真）——主要区别要理解
- **rosbag**：记录（record）与回放（play）

### 第6章 建模与仿真

- **URDF**
  - 重要标签：`<robot>`、`<link>`、`<joint>`
  - 6 种关节类型：revolute、continuous、prismatic、fixed、floating、planar
  - 完整的机器人 = link 标签 + joint 标签
- **XACRO**：URDF 的宏扩展，考试不要求写 XACRO，会写 URDF 即可
- **控制系统**
  - 传动配置与驱动配置
  - 控制插件的配置
  - 重点记住各配置对应的标签名称
  - 图 12345 中各部分的作用要掌握
