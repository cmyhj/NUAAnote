## 关键概念

| 概念 | 说明 |
|------|------|
| **catkin_make** | ROS 工作空间编译命令，需在工作空间根目录执行 |
| **roscore** | ROS 主节点管理器，所有节点通信前必须先启动 |
| **Publisher / Subscriber** | 话题通信模型：发布者按频率发送消息，订阅者接收并处理 |
| **`std_msgs/Header`** | 标准消息头，包含 seq（序号）、stamp（时间戳）、frame_id（坐标系ID）|
| **`.msg` 文件** | 语言无关的消息类型定义文件，位于功能包的 msg/ 目录下 |
| **`message_generation`** | 编译时依赖，用于从 .msg 生成代码（package.xml + CMakeLists.txt）|
| **`message_runtime`** | 运行时依赖，用于运行自定义消息 |
| **`rosmsg show`** | 查看自定义消息结构定义的命令 |

### 5. 自定义消息类型

- **官方类型**：`std_msgs`（标准）、`geometry_msgs`（几何/坐标）、`sensor_msgs`（传感器：激光雷达、摄像头等） [26:43-27:55]
- **`.msg` 文件定义**：位于功能包 msg/ 目录，语言无关 [29:32-29:56]
  - 语法：`<类型> <变量名>` 定义变量；`<类型> <常量名>=<值>` 定义常量 [32:28-33:10]
  - 示例：Person.msg 含 string name、uint8 age、uint8 sex 等 [30:12-31:16]
- **`std_msgs/Header` 标准头** [34:15-36:40]：
  - `seq` (int32)：消息序号，发布者自动累加
  - `stamp` (time)：时间戳
  - `frame_id` (string)：关联的参考坐标系 ID

### 6. 自定义消息编译配置

**`package.xml` 添加** [38:32-39:14]：
```xml
<build_depend>message_generation</build_depend>
<run_depend>message_runtime</run_depend>
```

**`CMakeLists.txt` 配置** [39:33-41:43]：
```cmake
find_package(catkin REQUIRED COMPONENTS ... message_generation)
add_message_files(FILES Person.msg)
generate_messages(DEPENDENCIES std_msgs)
catkin_package(CATKIN_DEPENDS message_runtime)
```

**编译验证**：`catkin_make` &rarr; `rosmsg show Person` 显示类型结构 [41:44-42:38]
