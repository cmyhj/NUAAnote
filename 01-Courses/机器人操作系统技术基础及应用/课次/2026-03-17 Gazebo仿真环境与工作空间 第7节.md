## 关键概念

- **[[Gazebo 仿真环境|Gazebo]]**：ROS物理仿真环境，可设置零部件的质量、转动惯量等物理参数，模拟真实机器人运动。
- **[[catkin 工作空间|工作空间（workspace）]]**：存放工程开发相关文件的根文件夹。名称可自定义，但内部子目录名建议保留默认。
- **四目录空间**：
  - `src`（代码空间 / source space）：存放功能包源代码（C++ 在 `src`，Python 在 `scripts` 等）。
  - `build`（编译空间 / build space）：存放编译过程中的缓存和中间文件。
  - `devel`（开发空间 / development space）：存放编译生成的可执行文件。
  - `install`（安装空间 / install space）：通过 `make install` 将可执行文件安装至此，便于终端直接运行。
- **Catkin**：ROS 的编译系统，取代了旧版 build 系统。
- **命名空间（namespace）**：第三章 3.8 节内容，容易混淆且考试重点。
- **三种通信方式**：话题通信（步骤最多、最常用）、服务通信（略少两步）、参数管理（相对简单）。

### 6. 小乌龟例程通信方式解析 [29:23-38:54]
- 小乌龟仿真器由多个节点通过三种通信方式协作：
  - **话题**：订阅 `/turtle1/cmd_vel`（速度指令），发布位姿信息（xy 坐标、线速度、角速度）。
  - **服务**：`clear`（清背景）、`reset`（复位）、`kill`（删除乌龟）、`spawn`（生成乌龟）、`set_pen`（画笔设置）、`teleport_absolute`（绝对移动）、`teleport_relative`（相对移动）。
  - **参数管理**：背景颜色等配置参数。
- 教师称该例程涵盖了 ROS 最底层的三种通信方式，非常适合初学者。

### 7. 第三章：工作空间四目录结构 [39:23-44:56]
- 工作空间名称可自定义（如 `catkin_ws`），但内部四子目录名建议保留默认。
  - `src`：存放功能包源码，最常用。
  - `build`：编译中间产物，对开发者不关键。
  - `devel`：存放编译后可执行文件（相当于 Windows 的 .exe）。
  - `install`：可选，`make install` 后将文件安装至此，方便终端调用。
- **考试重点**：工作空间覆盖（workspace overlay）——每年必考 [22:51-22:54]。
