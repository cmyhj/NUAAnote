## 要点详述

### 1. 虚拟机安装

- 从官网下载 Ubuntu 20.04 镜像（`.iso`），VMware/VirtualBox 新建虚拟机 → "从光盘映像文件安装"
- **硬盘大小**：默认 20 GB 动态分配 → 建议 30–40 GB（上限，非实际立即占用）
- **用户名/密码**：Linux 强制要求，没有则无法使用
- 镜像文件已拷给班级同学，建议大家用**相同版本**以便互相排查问题
- 安装过程基本傻瓜式，装完后进入图形桌面

### 2. 软件源配置

- Ubuntu Software & Updates 中勾选全部四项：
  1. 官方支持的开源软件
  2. 社区维护的开源软件
  3. 专有驱动(proprietary) — 不公开源码但可免费使用
  4. 有版权/合法性问题的软件
- 因服务器在国外，推荐配置国内镜像源（后续课程用命令行操作）

### 3. Linux 命令行 vs Windows GUI

- Linux 高度依赖命令行；Windows 从 Win10/8 起基本不再需要
- 命令行优势：灵活、可扩展、自动化脚本
- 本课只介绍 **不超过 10 个** 最常用的命令

### 4. 常用 Linux 命令

| 命令 | 全称 | 功能 | 本课使用频率 |
|------|------|------|-------------|
| `ls` | list | 列出当前目录内容 | ★★★★★ |
| `cd` | change directory | 切换工作目录 | ★★★★★ |
| `pwd` | print working directory | 显示当前绝对路径 | ★★★☆☆ |
| `mkdir` | make directory | 创建目录 / 文件夹 | ★★★★★ |
| `touch` | — | 改变文件时间戳（很少用到） | ★☆☆☆☆ |
| `mv` | move | 移动或重命名文件/目录 | ★★★☆☆ |

### 5. `mv` 课堂实操案例

任务：将 `test2/test3` 向上移一级到 `test/` 下

关键参数：
```
mv <源文件/目录> <目标路径>
```
- 源文件：`test3`（已在 `test2/` 中，无需完整路径）
- 目标路径：上级目录 → 使用 `..` 表示
- 正确命令：`mv test3 ..`
- 常见错误：源文件路径写错或目标路径未用 `..`，导致原地改名而非真正移动
