## 关键概念

| 概念                                                          | 说明                                        |
| ----------------------------------------------------------- | ----------------------------------------- |
| **`ros::init(argc, argv, "node_name")`**                    | 初始化 ROS 节点；第三个参数为节点名称（运行时必须唯一）            |
| **`ros::NodeHandle`**                                       | 节点句柄，用于管理节点资源与通信                          |
| **`advertise<std_msgs::String>("topic_name", queue_size)`** | 向 Master 注册发布者；指定话题名与消息队列大小（异步通信缓冲）       |
| **`ros::Rate(10)`**                                         | 设定循环频率 10Hz；调用 `rate.sleep()` 后按频率休眠以维持周期 |
| **`ros::ok()`**                                             | 判断节点是否正常运行；返回 false 时 `while` 跳出          |
| **话题队列**                                                    | 异步通信，发布者将消息存入队列；超出队列大小时自动丢弃最旧消息           |
| **`std_msgs/String.h`**                                     | 消息类型头文件，由 `.msg` 文件在编译时自动生成               |
| **`ros/ros.h`**                                             | 包含大部分 ROS 通用 API 的综合头文件                   |

### 3. 发布者 C++ 实现框架（三段式）
1. **初始化节点**：`ros::init(argc, argv, "node_name")` — 接收命令行参数，指定节点名
2. **注册发布者**：`NodeHandle.advertise<MsgType>("topic", queue_size)` — 向 Master 注册话题
3. **循环发布消息**：`while(ros::ok()){ publisher.publish(msg); rate.sleep(); }` — 按频率发布

### 4. `ros::ok()` 返回 false 的 4 种条件（[45:04–50:18]）
- 收到 **SIGINT 信号**（Ctrl+C 终止进程）
- **被同名节点踢出**（ROS 不允许同名节点同时存在）
- 节点主动调用 **`shutdown()`** 函数
- 节点句柄 **`NodeHandle` 被销毁**

### 5. 命令行参数 `argc / argv`
- `argc`：argument count，参数个数
- `argv`：argument vector，参数字符串数组
- 通过命令行或 launch 文件传入，在 `ros::init()` 中传递给 ROS 内部使用

### 6. 消息队列
- 话题为**异步通信**；`advertise()` 第二个参数指定队列大小（示例为 1000）
- 消息积压超出队列大小时，**自动丢弃最早入队的消息**（[39:38–39:45]）
