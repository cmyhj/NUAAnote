## 关键概念

| 概念 | 说明 |
|------|------|
| **[[Launch 文件|Launch 文件]]** | XML 格式的文本文件（`.launch`），用于一次性启动多个 ROS 节点，自动启动 rosmaster |
| **`<node>`** | 声明一个待启动节点，必含 `pkg`、`type`、`name` 三个属性 |
| **`<param>`** | 向 ROS 参数服务器写入参数（全局变量），节点内通过 `ros::param::get` 读取 |
| **`<rosparam>`** | 从 `.yaml` 文件批量加载参数到参数服务器 |
| **`<arg>`** | Launch 文件内部的局部变量（与 ROS 参数服务器无关），方便文件级重构 |
| **`<remap>`** | 话题/服务重映射，解决接口不兼容问题，避免修改第三方包源码 |
| **`<include>`** | 包含其他 Launch 文件，等价于复制粘贴其内容 |
| **`.yaml`** | 参数文件扩展名（考试常考） |

### 2. Launch 文件核心

**基本结构：**
```xml
<launch>
  <node pkg="turtlesim" type="turtlesim_node" name="sim"/>
  <node pkg="turtlesim" type="turtle_teleop_key" name="key" output="screen"/>
</launch>
```
- 根元素必须为 `<launch>`，所有内容包裹在 `<launch>...</launch>` 内
- 节点标签 `<node ... />` 自闭合，无需结束标签

**三类属性：**
- `pkg` — 功能包名称（对应命令行 `rosrun` 第一参）
- `type` — 可执行文件名称（对应命令行 `rosrun` 第二参）
- `name` — 节点运行名称（**可覆盖**节点代码中 `init` 赋予的名称；命令行原来没有此参数）

**节点可选属性：**
- `output="screen"` — 将标准输出打印到终端
- `respawn="true"` — 节点挂掉后自动重启（默认 false）
- `required="true"` — 必要节点，该节点终止时其他所有节点一并终止
- `ns="..."` — 设定命名空间
- `args="..."` — 传递命令行参数

### 3. `<param>` vs `<arg>` —— 中文都叫"参数"但本质不同

| | `<param>` | `<arg>` |
|------|-----------|---------|
| 英文 | param(eter) | arg(ument) |
| 作用域 | **ROS 参数服务器**，全局，节点代码可访问 | **Launch 文件内部**局部变量，节点代码不可访问 |
| 用途 | 节点运行所需的全局配置（传感器型号、尺寸、重量等） | 文件级变量，便于重构/循环（如 `$(arg id)` 拼接节点名） |
| 读写 | 写：`<param>` 标签；读：节点内 `ros::param::get` / 终端 `rosparam get` | 定义：`<arg name="id" default="0"/>`；使用：`$(arg id)` |

- 多人合作时易混淆这对概念；英文母语者因单词不同不容易混淆（教师原话）

### 4. `<rosparam>` 批量加载

- 使用 `<rosparam file="params.yaml" command="load" ns="..." />`
- 文件扩展名 **`.yaml`**（考点）
- 适用于大量参数的场景，避免逐行写 `<param>`

### 5. `<remap>` 重映射

- 避免修改第三方包源代码，只需在运行时改话题/服务名
- 语法：`<remap from="original_topic" to="new_topic"/>`
- 要求数据类型必须相同（[int → int, string → string]）

### 6. `<include>` 嵌套复用

- 将已有 Launch 文件内容包含进来，类似 C/C++ `#include`
- 语法：`<include file="$(find pkg_name)/launch/file.launch" />`

### 7. 课堂演示现象

- 双乌龟通过同一键盘节点控制，**同步运动**（与之前手动开两个乌龟各控各的不同）
- 原因是两个 `turtlesim_node` 订阅了同一 `/turtle1/cmd_vel` 话题
- 通过复制 `<node>` 标签即可增加乌龟数量，可循环至任意多个
