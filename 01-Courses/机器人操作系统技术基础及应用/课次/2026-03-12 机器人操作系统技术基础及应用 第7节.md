## 关键概念

| 概念 | 说明 |
|------|------|
| **功能包 (Package)** | ROS 软件基本单元，即一个独立文件夹，包含节点、库、配置文件等 |
| **package.xml** | 功能包清单，记录名称、版本、作者、许可、编译/运行时依赖 |
| **元功能包 (Metapackage)** | 组织多个同一目的的功能包的集合 (新版 ROS 替代旧版 `stack`) |
| **消息类型 (.msg)** | 话题通信的数据类型定义，存放在 `msg/` 目录 |
| **服务类型 (.srv)** | 服务通信的数据类型定义，存放在 `srv/` 目录 |
| **启动文件 (.launch)** | 批量启动多个节点的配置文件，存放在 `launch/` 目录 |
| **计算图 (Computation Graph)** | 节点、话题、服务、主节点管理器 (ROS Master) 构成的运行拓扑 |
| **TurtleBot3** | ROS 官方提供的差分驱动机器人仿真模型 (Burger / Waffle) |
| **build_depend / run_depend** | package.xml 中声明编译期/运行期依赖的 XML 标签 |

### 5. TurtleBot3 仿真环境 [20:03-33:53]

(本节为第九章内容提前引入)

- 官方教程网址见 PPT，推荐跟随**英文最新版**操作
- 步骤：
  1. 安装 `turtlebot3` 依赖包
  2. 创建工作空间 (`mkdir -p ~/catkin_ws/src`)

  4. 启动仿真模型：`turtlebot3_burger` / `turtlebot3_waffle`
- 提供三种地图：空地图、乌龟形状地图、室内环境 (厨房/客厅)

### 6. 第二章 — ROS 体系结构 [33:53-52:36]

**考试重点 (教师多次强调)：**

- **三个"三"**：
  - 架构三层次：OS 层、中间件层、应用层
  - 系统实现三层次 (每年必考)：每个层次的作用
  - 通信三种方式：Topic、Service、Action
- **计算图**：节点 (Node)、话题 (Topic)、消息 (Message)、服务 (Service)、节点管理器 (ROS Master)
- **文件系统**：
  - 功能包 (Package) — ROS 基本单元
  - `package.xml` — 功能包清单 (**考试常考文件名**)
  - 目录结构 (**重点**)：`src/` (C++)、`script/` (Python)、`launch/`、`msg/`、`srv/`、`action/`、`config/`、`include/`、`CMakeLists.txt`
- **ROS 专用命令**：`catkin_create_pkg`、`rospack` 等
