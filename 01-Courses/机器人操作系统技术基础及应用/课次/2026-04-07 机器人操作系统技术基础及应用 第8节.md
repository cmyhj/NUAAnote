## 关键概念

| 概念 | 说明 |
|------|------|
| **[[URDF（统一机器人描述格式）|URDF]]** | XML 格式的机器人描述文件（`.urdf`），支持 link/joint 层次结构 |
| **Rviz** | ROS 3D 可视化工具，可显示模型、轨迹、传感器数据、TF 坐标 |
| **Launch 参数** | `<param>`（ROS 参数）与 `<arg>`（launch 局部参数）的区别 |
| **joint_state_publisher** | 发布关节角度状态的节点，配合 GUI 可手动拖动控制 |
| **robot_state_publisher** | 发布 TF 坐标变换 |
| **material / color** | URDF 中通过 `<material>` 设置外观颜色，RGB + alpha |
| **collision / inertial** | 碰撞检测模型（简化几何包围盒） & 物理惯性属性 |
| **[[XACRO（宏语言）|XACRO]]** | URDF 的宏语言扩展（`.xacro`），支持常量、数学运算、宏定义、文件包含 |
| **property** | XACRO 常量定义，如 `<property name="PI" value="3.14159"/>` |
| **macro** | XACRO 宏定义，类似函数，可复用带参数的代码块 |
| **include** | XACRO 文件包含，实现模块化组合 |

## 要点详述

### 1. Launch 文件结构（`display_robot_chairs_urdf.launch`）

```xml
<!-- 设置机器人名称与 URDF 文件路径 -->
<param name="robot_name" textfile="$(find pkg)/urdf/robot.urdf" />

<!-- 关节控制 GUI 插件 -->
<param name="use_gui" value="true" />

<!-- 发布关节状态 -->
<node name="joint_state_publisher" pkg="joint_state_publisher" type="joint_state_publisher" />

<!-- 发布 TF 坐标 -->
<node name="robot_state_publisher" pkg="robot_state_publisher" type="robot_state_publisher" />

<!-- 启动 Rviz，加载预配置 -->
<node name="rviz" pkg="rviz" type="rviz" args="-d $(find pkg)/config/m_robot.rviz" />
```

**注意**: `use_gui` 参数缺失会导致关节控制滑块面板不出现（RA: 14:41 处补充后解决）。

### 2. Rviz 配置文件（`.rviz`）

保存在 `config/` 目录中，包含面板布局、视角、可视化管理器等预设，避免每次手动配置。

### 3. URDF 颜色设置规则

- `<material name="yellow">` + `<color rgba="..."/>` — 若 name 为 ROS 预设颜色名，则 **忽略** 下方 RGB 值
- 若 name 为 **非预设名称**，则按自定义 RGB 渲染

### 4. 碰撞模型简化原则

> 真实外观 → visual 标签；碰撞检测 → collision 标签，使用简化几何体（圆柱/长方体）以减少计算量。对不规则外形，选用最接近的规则形状做包围盒。

### 5. XACRO 核心特性

| 特性 | 语法 | 示例 |
|------|------|------|
| 常量 | `<property name="X" value="..." />` | `<property name="PI" value="3.14159" />` |
| 数学公式 | `${表达式}` | `${PI/2}` `${width*2}` |
| 宏定义 | `<xacro:macro name="..." params="...">` | 定义可复用的 link/joint 代码块 |
| 宏调用 | `<xacro:宏名 参数="..." />` | `<xacro:wheel parent="base" ... />` |
| 文件包含 | `<xacro:include filename="..." />` | 引入其他 `.xacro` 模块 |

**模块化思路**: 底盘、传感器、机械臂分别独立为 `.xacro` 文件，上层组装文件通过 `include` 组合，修改某一模块不影响其他模块。
