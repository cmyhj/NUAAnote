## 关键概念

| 概念 | 说明 |
|---|---|
| **SLAM** | Simultaneous Localization and Mapping，即时定位与地图构建 |
| **LaserScan** | ROS 激光雷达数据结构（`sensor_msgs/LaserScan`），包含角度范围、步长、时间步长、距离阈值及采样点数据 |
| **Odometry** | 里程计，通过编码器等传感器估计机器人相对位置变化，数据格式 `nav_msgs/Odometry` |
| **GMapping** | 基于粒子滤波的 2D SLAM 算法，已集成于 ROS 的 `gmapping` 功能包 |
| **占用网格地图** | GMapping 的输出形式，每个格子基于概率标记为"障碍物"或"空闲" |
| **`depthimage_to_laserscan`** | ROS 功能包，将深度图像/RGB-D 点云数据转换为 LaserScan 格式 |
| **差分驱动** | ROS 导航功能包推荐的机器人驱动方式 |
| **TF 坐标变换** | SLAM 中必需的坐标关系：激光雷达→基座、基座→里程计、地图→里程计 |

### 2. SLAM 传感器回顾 [05:46–11:50]

**三种常用传感器比较：**

| 传感器 | 精度 | 成本 | 特性 |
|---|---|---|---|
| 激光雷达 | 最高 | 最高 | 响应快，ROS 导航算法默认适配 |
| 摄像头（单目） | 中等 | 低 | 静止状态下无法测距，需运动才能估计深度 |
| 摄像头（双目） | 中等 | 中等 | 静止/动态均可测距，靠视差计算深度 |
| RGB-D / 结构光相机 | 较高 | 中等 | 直接提供每个像素的深度信息（深度图） |

**ROS 导航功能包对机器人的三大兼容要求：**
1. 差分驱动 + 轮式机器人
2. 安装指定传感器（推荐激光雷达——算法直接使用 `LaserScan`；若用摄像头/深度相机需转换格式）
3. 机器人外形最好为正方形或圆形（异形可能导致碰撞检测失效）

**LaserScan 消息结构（`sensor_msgs/LaserScan`）：**
- `Header`：序号、时间戳、坐标系
- `angle_min` / `angle_max`：激光检测的起始/终止角度
- `angle_increment`：相邻采样点之间的角度步长
- `time_increment` / `scan_time`：帧内采样时间间隔 / 整帧扫描时间
- `range_min` / `range_max`：最小/最大可检测深度
- `ranges[]`：实际的深度采样数据（核心数据）

### 3. 传感器转换与里程计 [11:50–14:10]

- 无激光雷达时，可使用其他传感器 + ROS 提供的 **`depthimage_to_laserscan`** 功能包：从深度摄像头获取的点云中抽取一行数据，重新封装为 LaserScan 格式
  - > "你想得到的事情大概率 99% 的情况下，都已经有人做过了，直接调用即可"
- **里程计（Odometry）**：通过编码器（轮子旋转圈数 × 轮子周长）估算机器人位移，结合速度对时间的积分
- Odometry 消息结构（`nav_msgs/Odometry`）：`pose`（位置 xyz + 姿态四元数）、`twist`（线速度 + 角速度）、协方差矩阵

### 4. GMapping 算法 [14:10–19:44]

- 基于 **粒子滤波** 的 2D SLAM 算法
- 📌 **考试重点**：GMapping 的输入与输出
  - **输入（3 个）**：深度信息（激光雷达/双目/深度相机）+ **IMU**（惯性测量单元）+ **里程计**
  - **输出**：基于概率的**二维占用网格地图**（occupancy grid map），每个格子标记为"障碍物"或"空闲区域"

### 5. GMapping 话题与坐标变换 [19:44–21:10]

- **订阅**：`/tf`（坐标变换）+ `/scan`（激光雷达数据）
- **发布**：`/map_metadata` + `/map`（占用网格地图）
- **关键参数**：机器人里程计坐标系、地图更新频率、激光最大探测范围等
- **必须的 TF 坐标变换**：
  - `laser` → `base_link`（激光雷达 → 机器人基座）
  - `base_link` → `odom`（基座 → 里程计）
  - `map` → `odom`（地图 → 里程计，用于估算机器人在全局地图中的位姿）

### 6. 仿真演示（turtlebot3 + Gazebo）[41:10–49:43]

- 使用 **burger 机器人**（多层小型机器人）—— 与后续实验课实物对应
- 步骤：
  1. 配置机器人模型
  2. 启动 Gazebo 仿真环境 + 机器人
  3. 新终端运行 GMAPPING launch 文件
  4. 打开 RViz 查看可视化
  5. 新终端运行键盘控制 launch 文件
- RViz 可视化颜色含义：
  - **绿色点**：激光碰到障碍物反射回来的点（障碍物所在位置）
  - **浅灰色**：已扫描过的空白区域（确认无障碍）
  - **深色背景（略带绿）**：尚未探测到的区域
- **键盘控制键位**：
  - `W` = 前进
  - `X` = 后退
  - `A` = 左转
  - `D` = 右转
  - `S` = 停止
  - 需**点击终端窗口激活**后才能响应键盘输入
- 机器人撞上柱子角卡住时，需用 `X` 后退脱困
