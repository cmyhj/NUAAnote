## 要点详述

### 1. 双机器人猫鼠追逐系统（第5组）[03:05–09:02]

- **架构：** 键盘控制小鼠移动 → 猫通过间歇性定位小鼠位置 → MoveBase + DWA 进行动态路径追踪，区别于完全跟随轨迹 [03:30–03:48]
- **建图：** 使用 Gazebo + `build` 工具绘制八卦阵地图，导出 URDF → `.world` 文件，再通过键盘控制的 SLAM 扫描生成 PGＭ 地图 [03:53–04:58]
- **路径规划：**
  - MoveBase 导航栈：整合全局 / 局部路径规划与地图管理 [05:10–05:26]
  - DWA：减少猫在窄道中的碰壁概率 [05:35–05:55]
  - TF：小鼠发布自身位置 → 猫订阅后导航追踪 [05:56–06:09]
- **多机通讯：** 两台电脑分别运行小鼠控制和猫摄像头画面显示 [06:44–06:58]
- **相机对准控制：** 猫机器人的摄像头实时对准小鼠（类似综艺跟拍摄影师 [11:40–11:45]）
- **存在问题 & 应对：**
  - 碰撞频繁 → 在 URDF 中添加障碍物碰撞属性 [07:11–07:19]
  - 静态路径规划局限 → 间歇性更新目标位置实现动态追踪 [07:29–07:44]
  - 窄道犹豫 → 未详细说明解决方案 [07:51–07:58]
- **教师意见：**
  - 需补充详细分工及贡献比例 [09:09, 14:01]
  - 摄像头未做图像识别，仅是物理对准 [11:23–11:28]

### 2. 多机器人迷宫自主探索协同系统 [15:18–24:32]

- **场景：** 5 台小车部署在迷宫不同位置，领航车自主探索 → 遇其他车即编队 → 共赴出口 [15:33–15:56]
- **分工：**
  - 多车跟随 & 编队协同
  - 激光避障 & 防撞
  - Gazebo 地图构建 & 5 车初始位置/朝向分配 [16:11–16:30]
- **工作模式：**
  - **探索模式：** 领航车通过激光雷达避障，沿迷宫一个方向前进 [17:24–17:29]
  - **导航模式：** 5 车集结完毕 → 共同向出口行进 [17:35–17:43]
- **跟随触发条件：** 从机器人与领航车距离 ≤ 2m 时自动激活跟随 [17:51–17:58]
- **避障策略：** 仅用三个方向（前方、左、右）的激光数据做决策：前+左同时有障则右转，否则默认右转至无障碍后直行 [23:34–23:57]
- **教师反馈：**
  - 未充分使用已建地图信息，仅依赖局部激光决策 [20:44–21:02]
  - 360° 激光雷达未充分利用 [24:07–24:15]

### 3. 实体小车综合项目 [24:59–31:07]

> ⚠ 该组说明本小车及部分代码来自另一门课"机器人综合实践"（王浩老师），与本课程有交叉 [37:56–38:10]

- **硬件：** ORD 主板 + 电机 + 激光雷达 + RGB-D 深度相机（Intel RealSense）[26:26–26:40]
- **系统：** 电脑虚拟机 Ubuntu 16.04 ↔ 小车 Ubuntu 18.04（Melodic）[26:08–26:19]
- **SLAM 建图：** 曾尝试 Cartographer 算法，但因动态扫描效果差，改回小车自带 Gmapping [26:57–27:14, 33:53–34:02]
- **导航：**
  - 单点导航 + 多点自主导航 [28:21–28:50]
- **紧急避让：** 基于 OpenCV 深度点云判断人腿距离：>2000 点 → 后退，100–2000 点 → 跟随，<100 点 → 默认状态（但参数不稳定，实际常直接后退）[29:08–29:58]
- **巡线：** RGB → HSV → 提取红色轨迹 → 转向控制；未识别到线时自动左转搜索 [30:30–31:07]
- **关键经验：** 因里程计未标定导致建图歪斜 → 实测转角与设定转角误差比例系数写入配置文件修正 [34:38–36:23]

### 4. 机械臂视觉引导抓取系统 [40:15–51:28]

- **架构：** OpenCV 颜色识别 + 定位 → MoveIt 机械臂轨迹规划 [40:18–40:38]
- **视觉流程：**
  1. 筛选 HSV 色相区间 → 提取目标颜色 [43:19–43:28]
  2. 计算像素点均值 → 获得质心坐标 [43:36–43:42]
  3. 质心坐标线性映射到低分率深度点云 → 获取三维世界坐标（经 TF 变换）[45:05–45:12, 47:32–48:01]
  4. RGB-D 相机未提供独立深度话题，以点云代替 [42:02–42:29]
- **演示：** 抓取橙色球 → 抓取绿色球；视频为 3 倍速 [40:52–40:59, 44:41–44:46]
- **问题：** 颜色范围重叠时质心落在两球中间 [45:48–46:24]；多节点同时启动时负载大，需延时启动 [49:29–49:36]
- **教师建议：** 确认深度话题是否存在 [44:08–44:28]
- **学生自评后续改进：** 引入深度学习实现动态抓取 + 实体部署 [49:54–50:20]
