## 关键概念

| 概念 | 说明 |
|------|------|
| `mv` | 移动（move），等价于"剪切+粘贴"，源文件不再保留 |
| `cp` / `cp -r` | 复制（copy），文件直接 cp，目录需加 `-r`（recursive） |
| `rm` | 删除（remove），可删文件或目录（`-r`） |
| `sudo` | 超级用户（superuser do），类似 Windows"以管理员身份运行"；密码不回显且 15 分钟内免密 |
| `sources.list` | Ubuntu 软件源地址配置文件，位于 `/etc/apt/`，可替换为国内镜像 |
| `ros-noetic-desktop-full` | ROS Noetic 桌面完整版（含工具、函数库、仿真器等），约 4 GB |
| `rosdep` | 初始化 ROS 系统依赖关系，国内可用 `rosdepc` 替代 |
| `.bashrc` | Bash 配置文件，写入环境变量后每次终端启动自动配置 |
| `roscore` | ROS Master（核心节点管理器） |
| `rosrun` | 运行 ROS 节点的命令行工具，格式：`rosrun <package> <node>` |

## 要点详述

### Linux 命令实操（[02:30-04:46] ~ [14:31-17:56]）

1. **目录导航**：`..` 代表上一级目录，`cd` 无参数回到 home（波浪线 `~`）；路径用斜杠 `/`，Windows 用户易混淆。
2. **mv**：即 move，把文件或目录从一个位置移到另一个位置。类比"剪切"。学生实操中常见问题是路径不完整或混淆相对 / 绝对路径。
3. **cp**：即 copy。普通文件用 `cp 源 目标`，目录要用 `cp -r 源 目标`。不加 `-r` 会报错。学生现场操作时未输文件全称导致报错，用键盘上下箭头翻历史命令可快速修正。
4. **rm**：即 remove。可直接在上级目录写完整路径删除，不必先 cd 进目标目录。有学生直接在上级目录 `rm test2/test4`，教师点评这种写法更"专业"。
5. **sudo**：切换到超级用户模式，输密码时**不显示任何字符**（连占位符都没有），比 Windows 圆点显示更安全——攻击者无法猜测密码长度。成功认证后有 **15 分钟缓存**，期间再敲 `sudo` 不需密码，过期后需重新输入。

### ROS 安装流程（[17:56-47:49]）

1. **软件源配置**：国内用户需将 `/etc/apt/sources.list` 中的官方地址（ubuntu.com）替换为中科大（ustc.edu.cn）或清华镜像，否则 apt update 会极慢（几 KB/s）。
2. **安装版本选择**：
   - **desktop-full**（推荐）：包含 ROS 核心、通信机制、通用函数库、2D/3D 感知、地图建图、导航、RViz 可视化、Gazebo 仿真等。约 4 GB。
   - **desktop**：去掉机器人功能包及部分工具，保留基础功能 + GUI 工具。
   - **ros-base**：最小系统，无 GUI，适合树莓派等嵌入式控制器。
3. **rosdep 国内问题**：`rosdep init && rosdep update` 需要连接 GitHub raw 内容，国内极易超时。**rosdepc** 是国内开发者制作的替代工具，先装 Python 包即可使用，命令格式与官方基本一致。
4. **环境变量**：将 `source /opt/ros/noetic/setup.bash` 写入 `~/.bashrc`，实现每次终端启动自动加载 ROS 路径。若不配，每次需手动 source 或输全路径。
5. **验证方式**：`roscore`（启动 Master）→ `rosrun turtlesim turtlesim_node`（启动乌龟仿真器）→ `rosrun turtlesim turtle_teleop_key`（键盘控制乌龟）。
