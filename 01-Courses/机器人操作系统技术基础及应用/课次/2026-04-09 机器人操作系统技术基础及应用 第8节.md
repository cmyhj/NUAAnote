## 关键概念

| 概念 | 说明 |
|------|------|
| **collision** | URDF link 下的碰撞属性标签，定义连杆的碰撞包围盒 |
| **inertial** | URDF link 下的惯性属性标签（质量、惯性矩阵），物理仿真必需 |
| **transmission** | 传动装置，将 joint 与 actuator（电机）绑定，指定减速比与控制类型 |
| **Gazebo plugin** | 动态链接库（`.so`），为 Gazebo 模型绑定 ROS 消息接口，使模型可被控制 |
| **`differential_drive_controller`** | 两轮差速驱动插件，订阅 `cmd_vel` 话题，将速度指令映射为左右轮关节运动 |
| **`cmd_vel`** | ROS 速度控制话题，消息类型 `geometry_msgs/Twist`，含线速度与角速度 |
| **`robot_namespace`** | 插件参数，设定机器人话题的命名空间，`/` 表示全局顶层 |
| **URDF → SDF** | Gazebo 内部将 URDF 自动转换为 SDF 格式后加载 |
| **xacro** | URDF 宏语言，用于参数化/模块化机器人模型描述 |
| **[[SLAM（即时定位与地图构建）|SLAM]]** | Simultaneous Localization and Mapping，同时定位与地图构建 |
| **gmapping** | 基于粒子滤波的 2D SLAM 算法，ROS 中常用功能包 |
| **LiDAR** | 激光雷达，通过发射-反射时间差测距，精度高、响应快 |
| **RGB-D camera** | 深度相机（如 Kinect、iPhone Face ID），同时提供彩色图像与深度信息 |

## 要点详述

### 1. 为模型添加物理属性

- **碰撞属性 `<collision>`**：为每个 link 添加碰撞几何体（通常与 visual 几何体一致或简化）。
- **惯性属性 `<inertial>`**：必须包含 `<mass>`（质量）与 `<inertia>`（惯性张量 6 个分量：ixx, ixy, ixz, iyy, izz, izz），否则无法进行物理仿真。
- **地面/地标材质 `<material>`**：可选，为模型添加颜色/纹理。

### 2. 传动装置 `<transmission>`

```xml
<transmission name="trans_left">
  <type>transmission_interface/SimpleTransmission</type>
  <joint name="left_wheel_joint">
    <hardwareInterface>VelocityJointInterface</hardwareInterface>
  </joint>
  <actuator name="left_wheel_motor">
    <mechanicalReduction>1</mechanicalReduction>
  </actuator>
</transmission>
```

- `mechanicalReduction`：减速比，`1` 表示无减速器
- 硬件接口使用速度控制模式

### 3. Gazebo 插件配置

**robot 层级插件**（`<gazebo>` 标签内）：

```xml
<gazebo>
  <plugin name="differential_drive_controller" filename="libgazebo_ros_diff_drive.so">
    <robotNamespace>/</robotNamespace>
    <leftJoint>left_wheel_joint</leftJoint>
    <rightJoint>right_wheel_joint</rightJoint>
    <wheelSeparation>0.4</wheelSeparation>
    <wheelDiameter>0.1</wheelDiameter>
    <wheelAcceleration>1.0</wheelAcceleration>
    <commandTopic>cmd_vel</commandTopic>
    <odometryFrame>odom</odometryFrame>
  </plugin>
</gazebo>
```

**关键参数**：

| 参数 | 说明 |
|------|------|
| `robotNamespace` | 话题命名空间，`/` 全局；如有多个机器人可分别设定 |
| `leftJoint` / `rightJoint` | 左右轮关节名称，须与模型 joint 名称一致 |
| `wheelSeparation` | 轮距（两轮中心距离），影响转向角速度计算 |
| `wheelDiameter` | 轮径，影响线速度映射 |
| `commandTopic` | 速度指令话题，默认 `cmd_vel`，须与上层发布节点一致 |
| `odometryFrame` | 里程计参考坐标系，通常设为 `odom` |

**Link/joint 层级插件**：在对应 link/joint 标签内嵌套 `<gazebo>` 配置。

### 5. 传感器类型（用于 SLAM）

| 类型 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| **激光雷达 (LiDAR)** | 激光发射-反射时间差测距 | 精度高、响应快、数据量小 | 成本（传统上）较高 |
| **单目摄像头** | 单镜头成像 | 成本低 | 静止状态无法测距 |
| **双目摄像头** | 双镜头视差计算深度 | 可测距（模仿人眼） | 计算量大 |
| **RGB-D 深度相机** | 红外结构光/ToF | 同时获取图像+深度，成本适中 | 受环境光影响 |

### 6. SLAM 核心概念

- **定义**：机器人从未知位置开始，在未知环境中运动，**边定位边建图**
- **历史**：1988 年首次提出，用于室内定位，早期军事用途
- **现代应用**：扫地机器人、自动驾驶、服务机器人
- **ROS 中常用算法**：`gmapping`（粒子滤波）、`cartographer`（图优化）
- **流程**：传感器数据 → 里程计估计 → 扫描匹配 → 地图更新 → 全局优化

### 7. 导航功能包的机器人硬件要求

1. **差分轮式 + 速度指令控制**：机器人须为差分驱动轮式底盘，直接接收 `Twist` 速度指令
2. **安装测距传感器**：至少配备激光雷达（或可转换为激光数据的深度传感器）
3. **方形/圆形外形**（推荐）：功能包以方形/圆形为模板开发，异形机器人避障效果可能不佳
