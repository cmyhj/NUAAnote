## 关键概念

| 概念 | 说明 |
|------|------|
| **[[TF（坐标变换）|TF (Transform)]]** | ROS 坐标变换框架，树形结构，带时间缓冲，支持多坐标系管理 |
| **TF monitor** | `rosrun tf tf_monitor` — 打印所有坐标系发布状态与频率 |
| **TF echo** | `rosrun tf tf_echo <源坐标系> <目标坐标系>` — 实时计算并输出坐标变换 |
| **static_transform_publisher** | 发布两坐标系间静态（不变）变换，支持 xyz+ypr 或 xyz+四元数两种格式 |
| **view_frames** | 生成 PDF 格式 TF 树图，但 Windows 下因 Python 字符串匹配问题报错不可用 |
| **rqt_tf_tree** | `rosrun rqt_tf_tree rqt_tf_tree` — 替代 view_frames，图形化实时显示 TF 树 |
| **[[RViz 可视化工具|RViz]]** | 三维可视化工具，可将坐标系、传感器数据等以图形方式呈现 |
| **RQT** | ROS Qt 工具箱，含节点图 (`rqt_graph`)、日志 (`rqt_console`)、数据绘图 (`rqt_plot`) 等 |

### 2. Launch 文件嵌套复用（07:35-09:16）
```xml
<include file="$(find package_name)/launch/file_name.launch" />
```
- `<include>` 可复用现有模块的 launch 配置
- 可直接组合驱动、摄像头等模块成完整机器人系统，无需编写 C++ 代码（理想情况）
- 常用标签之外的不考，官网可查阅全部细节

### 3. 坐标变换 TF（09:40-13:28）
- TF 使用 **树形数据结构**，根据时间缓冲维护多坐标系间变换关系
- 支持在**任意时间点**完成点、向量等坐标变换
- 示例场景：5 秒前头部坐标系相对全局坐标系、夹具物体相对机器人中心、机器人中心相对世界
- TF **分布式**：所有订阅 TF 消息的节点都会缓存一份完整的坐标变换关系

#### 两步操作
1. **监听（Listener）** — 接收并缓冲系统中所有坐标系变换数据，查询所需关系
2. **广播（Broadcaster）** — 向系统广播坐标系间变换关系，不需同步

### 4. TF 工具详解（13:28-23:29）
| 工具 | 命令 | 功能 | 备注 |
|------|------|------|------|
| TF monitor | `rosrun tf tf_monitor` | 打印所有坐标系发布状态与频率 | 不接参数显示全部 |
| TF echo | `rosrun tf tf_echo frame1 frame2` | 实时计算两坐标系变换 | 平移+旋转/四元数 |
| static_transform_publisher | `rosrun tf static_transform_publisher x y z yaw pitch roll frame_id child_frame_id` | 发布静态变换 | 两种格式（弧度/四元数），可在 launch 中使用 |
| view_frames | `rosrun tf view_frames` | 生成 PDF 格式 TF 树 | ⚠️ **Windows 不可用**（Python bytes/str 问题） |
| rqt_tf_tree | `rosrun rqt_tf_tree rqt_tf_tree` | 图形化 TF 树 | ✅ 替代方案，更方便 |

### 5. 乌龟 TF 跟随例程（23:30-44:55）
- 安装：`sudo apt install ros-noetic-turtle-tf`
- **Python 2/3 兼容问题**：旧例程用 Python 2，需安装 `python-is-python3` 使 `python` 指向 Python 3
- 运行后出现**两只乌龟**，第二只乌龟自动跟随第一只
- TF 工具实操验证：
  - `tf_monitor` 显示 `turtle1`、`turtle2` 坐标系及广播节点频率（~100Hz）
  - `tf_echo turtle1 turtle2` 显示两龟坐标变换（重叠时平移为 0，角度有偏差）
  - `rqt_tf_tree` 显示世界→turtle1→turtle2 的 TF 树

#### 代码要点
- **turtle_tf_broadcaster.cpp**：订阅乌龟位姿 → 构造 `transform` → `broadcaster.sendTransform()` 发布至 TF 树
- **turtle_tf_listener.cpp**：
  1. 通过 Service 生成第二只乌龟
  2. `TransformListener` 创建监听器（缓存 10 秒）
  3. `waitForTransform()` (超时 3 秒) + `lookupTransform()` (time=0 取最新)
  4. 计算偏差角 → 角速度 & 线速度（距离平方和开根号 × 系数）→ 发布速度命令
