## 关键概念

| 概念 | 说明 |
|------|------|
| **Xacro** | URDF的改进版，支持常量(`<xacro:property>`)、数学公式、宏定义(`<xacro:macro>`)，可大幅减少重复代码 |
| **[[ros_control 控制框架|ros_control]]** | ROS官方提供的机器人控制中间件，位于上层应用与底层硬件之间，提供通用控制接口 |
| **Controller Manager** | 控制器管理器，加载/卸载/启动/停止控制器，支持运行时重载插件 |
| **Controller** | 控制器本身，读取关节状态 → PID等算法计算 → 输出关节命令（位置/速度/力矩） |
| **Hardware Resource Layer** | 硬件资源层，在Controller与RobotHW之间做数据格式转换与隔离 |
| **RobotHW** | 机器人硬件抽象层，封装关节约束、力矩转换、减速比等，直接与硬件读写交互 |
| **Transmission** | URDF中的`<transmission>`标签，定义关节与执行器之间的传动关系（减速比） |
| **Joint Limits** | 关节限位，通过YAML文件定义位置/速度/加速度上下界 |

### 2. Xacro → URDF 转换实战排错
- **两种显示方式：**
  1. 转为URDF后在RViz显示
  2. 直接调用Xacro解析器（无需转换）
- **遭遇的三个坑：**
  - **Python脚本调用失败** — 去除 `.py` 后缀
  - **ROS环境变量未设置** — 需将工作空间路径加入 `ROS_PACKAGE_PATH`
  - **转换结果为空** — Xacro缺少命名空间声明 `xmlns:xacro="http://www.ros.org/wiki/xacro"`
- **宏定义的价值：** 8根立柱仅需定义一个macro，传入不同参数即可复用；修改macro即可一次更新全部立柱

### 3. ros_control 框架（五大层次，自顶向下）

```
应用层（导航、机械臂规划等）
        ↓
[Controller Manager]  — 加载/卸载/启停控制器
        ↓
[Controller]           — 核心控制算法（PID），读状态→算差值→发命令
        ↓
[Hardware Resource]    — 数据隔离：上行（状态） / 下行（指令）
        ↓
[RobotHW]              — 硬件抽象：关节约束、力矩→电流转换、减速比补偿
        ↓
[Real Robot]           — 嵌入式控制器 + 电机执行器
```

**各层详解：**

| 层次 | 输入 | 输出 | 职责 |
|------|------|------|------|
| Controller Manager | 上层应用/命令行指令 | 对Controller的调度指令 | 管理控制器的全生命周期 |
| Controller | 关节状态 + 目标设定值 | 关节命令（力矩） | PID控制算法，消除误差 |
| Hardware Resource Layer | 上下两层的原始数据 | 格式化后的状态/命令 | 数据格式转换与隔离 |
| RobotHW | 传感器信号 + 关节命令 | 电机命令（电流/速度） | 关节约束、力矩→电流换算、减速比处理 |
| Real Robot | 电机命令 | 传感器反馈 | 物理执行 |

### 4. 关键配置

#### Transmission（传动系统，URDF）
```xml
<transmission name="simple_trans">
  <type>transmission_interface/SimpleTransmission</type>
  <joint name="joint_name">
    <hardwareInterface>EffortJointInterface</hardwareInterface>
  </joint>
  <actuator name="motor">
    <mechanicalReduction>50</mechanicalReduction>
    <!-- 减速比50：无需在模型中画出减速器，通过此参数模拟 -->
  </actuator>
</transmission>
```

#### Joint Limits（关节限位，YAML）
```yaml
joint_limits:
  joint_name:
    has_position_limits: true
    min_position: 0.0
    max_position: 1.0
    has_velocity_limits: true
    max_velocity: 0.5
    has_acceleration_limits: true
    max_acceleration: 1.0
```

#### Controller Manager CLI
| 命令 | 功能 |
|------|------|
| `rosrun controller_manager controller_manager list` | 列出所有控制器及状态 |
| `list-types` | 列出所有控制器类型 |
| `reload-libraries` | 以插件形式重载控制器库（无需重启） |
| `spawn 控制器名` | 加载并启动控制器 |
| `stop 控制器名` | 停止控制器（不卸载） |
