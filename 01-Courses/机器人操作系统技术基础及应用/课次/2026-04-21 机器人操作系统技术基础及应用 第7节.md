## 要点详述

### 一、ROS2 演示（03:12–14:50）

教师因上次课上网络过慢导致 ROS2 未装完，直接将已装好的系统镜像复制到教室机器。

1. **环境变量设置** [03:46–03:52]
   - 一次性：`source /opt/ros/humble/setup.bash`（版本号需与实际匹配）
   - 永久：写入 `~/.bashrc`

2. **基础通信示例** [03:54–04:00]
   - talker 节点持续发布 `"hello world"` + 递增序号
   - listener 节点订阅接收，**仅接收启动后的消息**，之前发布的不补收

3. **Turtlesim 演示** [04:09–04:48]
   - 启动仿真器：`ros2 run turtlesim turtlesim_node`（窗口风格与 ROS1 有差异）
   - 启动键盘控制：`ros2 run turtlesim turtle_teleop_key`
   - 查看节点：`ros2 node list`
   - 查看话题：`ros2 topic list` / `ros2 topic info <topic>`
   - 发布话题消息：通过命令行让乌龟自动转圈
   - 调用服务：`ros2 service call /spawn ...` 生成第二只乌龟
   - 发送动作：控制乌龟旋转指定角度

4. **数据录制** [04:56–05:00]
   - 使用 `ros2 bag` 录制手动操作过程并回放

> **教师强调**：ROS1 中大部分操作在 ROS2 中都能对应完成，命令格式有所不同，建议后续参考官方教程深入学习。

### 二、小组1：小乌龟赛跑项目（15:42–22:55）

**项目概述**：在 turtlesim 中实现两只乌龟在圆形轨道上竞速，同时争夺随机刷新的"食物"。

**核心机制**：
- 圆形轨道半径 3，两只乌龟轨迹分别为红色/蓝色
- 每 6 秒在圆心附近随机生成食物（第三只乌龟）
- 乌龟两种状态：**竞速模式**（圆周运动）和**冲向食物模式**
- 胜利条件：跑完 5 圈 **或** 吃掉 5 个食物（满足其一即专注完成另一条件）

**节点设计**（共 4 个）：
| 节点 | 功能 |
|------|------|
| 倒计时节点 | 比赛开始前倒计时，同步多节点启动（通过参数服务器 `restart` 标志） |
| 裁判系统节点 | 判断圈数、食物计数、定时生成食物、碰撞时删除食物乌龟 |
| 进度控制节点 | 轮询 `restart` 标志，启动后控制乌龟竞速/转向食物 |
| 乌龟生成节点 | 将两只乌龟初始化到起点（圆心偏移至起点位置） |

**通信方式**：话题（速度订阅、位置发布）、服务（生成/删除乌龟、乌龟位移）、参数服务器

**分工与迭代**：
- 第一版 bug：乌龟吃完 5 个食物后仍会抢食物 → 第二版修复：吃完 5 个食物后不再争夺，专心跑圈
- 轨迹改进：为区分两只乌龟，轨迹分别设为红/蓝
- 圆周运动精度问题：引入前端点引导，乌龟追逐前端点实现标准圆周

### 三、小组2：自主巡逻 + 避障 + SLAM 建图（27:02–37:38）

**项目概述**：机器人在 Gazebo 仿真工厂环境中循环巡逻，遇障自主避让，同时进行激光 SLAM 建图。

**系统架构**：
- 仿真平台：Gazebo + ROS2
- 机器人模型：turtlebot
- 编程语言：C++
- 可视化：RViz

**核心算法**：
1. **自主巡逻** — 比例控制器 + 有限状态机
   - 欧式距离计算当前位置与目标点距离
   - 计算角度差 → 若 < 0.2 rad 则前进，否则原地旋转调整
   - 到达判定阈值 0.5 米（考虑控制误差，避免厘米级精度导致的震荡）
   - 三个目标点循环（`index = (index + 1) % 3`）

2. **实时避障** — 基于 LaserScan
   - 仅取前方 ±30° 激光数据减少计算量
   - 安全阈值 0.5 米 → 遇障停止前进，原地旋转直至障碍消失

3. **SLAM 建图** — gmapping 算法
   - 激光雷达 + 里程计，边走边建
   - 因机器人控制不稳导致墙体断裂 → 降低转弯速度后改善

**仿真环境**：10m × 10m 封闭场地，含球体/立方体/圆柱体障碍物，设置光源

**分工**：环境搭建与 SLAM、避障控制与参数调试（比例系数 1.2）、系统框架梳理、信息搜集与 PPT

### 四、小组3：同步跟随送餐机器人（38:11–44:30）

**项目概述**：高端餐厅场景，主机器人配送正餐，从机器人同步跟随配送自助用品。

**工作流程**：
1. **建图** — 使用 Building Editor 手动绘制咖啡厅环境，通过 SLAM 扫描生成地图
2. **双车跟随** — 两辆机器人独立启动，从车订阅主车位置，保持 0.5 米固定距离
3. **避障跟随** — 从车在避障优先级下跟随前车

**跟随算法**：
- 初版：固定比例角速度计算 + 四元数朝向 → **抖动、冲撞**
- 优化版：**双 PID 控制** — 角度 PID 平滑对准目标（避免来回晃头），距离 PID 控制跟车间距

**导航集成**：将空世界跟随迁移至已建地图中，实现地图内的自主导航跟随，调整双雷达互不干扰

**问题记录**：
- 初次建图墙体断裂 → 降低转速与速度后解决
- 跟随冲撞 → PID 优化后实现丝滑转弯与跟车
