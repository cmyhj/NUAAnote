## 关键概念

| 概念 | 说明 |
|------|------|
| **ROS2** | ROS 的第二代，去中心化架构，面向产品级机器人开发 |
| **DDS** (Data Distribution Service) | 取代 ROS1 的 TCP/UDP，去中心化、高可靠、可替换实现的通信中间件 |
| **Discovery 机制** | 节点自动发现，不再需要 Master |
| **ROS2 Jazzy** | 对应 Ubuntu 24.04 的 LTS 版本 |
| **rmw** (ROS Middleware) | 衔接 ROS 与 DDS 实现的抽象层 |
| **面向对象编程** | ROS2 节点开发更倾向 OOP，更像企业级软件 |
| **`ros2` 命令** | 统一命令入口，子命令包括 `run`、`topic`、`service`、`launch` 等 |

### 2. 为何推出 ROS2 [09:50-12:30]

三个主要原因：

1. **嵌入式性能不足** — ROS1 设计时面向高性能平台，未做性能优化，难以移植到廉价嵌入式板卡 [10:00-10:23]
2. **通信不可靠** — ROS1 通信不够稳定可靠 [12:06-12:14]
3. **商业化需求** — 需要更便宜、可用于真正产品级机器人 [12:25-12:36]

### 3. ROS2 核心特性 [12:43-13:55]

- 多机器人更好支持
- 跨平台（Linux / Windows / macOS / RTOS / 裸机 MCU）
- 实时性更好
- 网络更可靠
- 可直接用于商业产品 [13:33-13:43]
- 全流程项目管理（设计 → 开发 → 测试 → 部署）[13:47-13:55]

### 4. ROS1 vs ROS2 架构对比 [13:56-16:52]

| 方面 | ROS1 | ROS2 |
|------|------|------|
| 节点管理 | 需 Master 节点 | **去 Master**，Discovery 自发现 |
| 通信中间件 | TCP/UDP | **DDS**，可替换实现 |
| API | Nodelet API | Inter-process API |
| OS 支持 | 默认 Linux | 多平台完美兼容 |
| 编译系统 | 不同 | 重新设计 |

> DDS 允许多种实现（开源如 CycloneDDS、FastDDS，或商业高性能实现），通过 `rmw` 抽象层衔接 [17:09-17:24]

### 5. 核心概念的延续 [18:28-19:57]

ROS2 **保留**了 ROS1 的核心概念，方便迁移：

- 工作空间 (workspace)
- 功能包 (package)
- 节点 (node)
- 话题 (topic)
- 服务 (service)
- 参数 (parameter)
- 动作 (action)
- 分布式通信

### 6. 编程风格变化 [20:04-21:37]

- ROS2 更倾向 **面向对象编程**，代码可读性、可维护性更高 [20:24-20:35]
- 更接近真实企业软件开发流程 [20:41-20:44]
- 掌握 OOP 风格的 ROS2 对就业更有利 [20:56-21:02]

### 7. 命令行变化 [21:37-23:25]

| 功能 | ROS1 | ROS2 |
|------|------|------|
| 运行节点 | `rosrun` | `ros2 run` |
| 话题操作 | `rostopic` | `ros2 topic` |
| 服务操作 | `rosservice` | `ros2 service` |
| 启动文件 | `roslaunch` | `ros2 launch` |
| 录制/回放 | `rosbag` | `ros2 bag` |

所有命令统一为 **`ros2` + 子命令** 的形式 [22:28-22:37]

### 8. 安装流程 [24:01-31:47]

**推荐环境**：Ubuntu 24.04 + ROS2 Jazzy (LTS)

### 9. 复制粘贴修复 [26:41-27:16]

Ubuntu 24.04 在 VMware 中默认无法复制粘贴，需安装 VMware Tools：

```bash
sudo apt update
sudo apt install open-vm-tools open-vm-tools-desktop
```

### 10. ROS2 小乌龟演示 [36:51-40:27]

与 ROS1 功能一致，命令略有变化：

```bash
ros2 run turtlesim turtlesim_node        # 启动小乌龟
ros2 run turtlesim turtle_teleop_key     # 键盘控制
ros2 topic list                          # 查看话题列表
ros2 topic pub ...                       # 发布话题（自动转圈）
ros2 service call ...                    # 生成新乌龟
ros2 bag record ...                      # 录制消息
ros2 bag play ...                        # 回放消息
```
