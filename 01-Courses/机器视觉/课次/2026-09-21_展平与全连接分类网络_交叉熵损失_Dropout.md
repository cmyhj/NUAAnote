## 关键概念

- **展平与全连接分类网络**: 输入 $32\times32$ 的图像先打平成一维向量，接线性层输出 10 个类别，最后接 Softmax，是最简单的图像分类结构。
- **交叉熵损失 (CrossEntropyLoss)**: 分类任务的损失函数，替代回归场景常用的均方误差；类别数固定、输出为概率分布时用它。
- **Dropout**: 防过拟合手段。在网络中插入 `nn.Dropout`，按比例（课上用 0.5）随机丢弃部分神经元，配合非线性激活函数使用；加入后测试集准确率从 92% 提升到 97%。
- **正则化 / 权重衰减**: 另一种防过拟合手段。网络结构不变，在优化器里加入 weight_decay = 0.001，即损失函数中的 $\lambda\lVert w\rVert^2$ 惩罚项系数，让权重更均衡。
- **迁移学习 (Transfer Learning)**: 加载在大数据集（ImageNet 1000 类）上预训练好的网络（VGG16），只用它的卷积层做特征提取，把原分类层替换成自定任务的全连接层（猫狗两类），并冻结原有权重参数（`requires_grad=False`），只训练新加的全连接层。
- **模型模式切换 `model.eval()`**: 推理阶段使用，关闭训练相关行为；同时推理不再需要 GPU 并行计算，可以把数据和模型放回 CPU，并为单张图片补一个 batch 维度（batch size 改为 1）。
- **数字图像**: 用 0/1 编码记录信息，常见为 8 位图像，包含 $0\sim255$ 共 256 级灰度；$0$ 表示最暗、$255$ 表示最亮。
- **二值图像 / 灰度图像 / 彩色图像**: 二值图像非黑即白，像素值只有 0 和 1（条形码、二维码、文档扫描件）；灰度图每个像素只有一个采样颜色，黑白之间存在多个灰阶；彩色图由红、绿、蓝三个分量构成，每个分量取值 $0\sim255$。
- **OpenCV 的 BGR 通道顺序**: OpenCV 读取的图像通道顺序是 BGR，而 Matplotlib 等库按 RGB 显示，两者需要反转通道（如 `img[:, :, ::-1]`）才能正确显示颜色。
- **饱和运算与模运算**: OpenCV 的 `cv2.add` 是饱和加法，$250+10=260$ 会被截断为 255；NumPy 数组直接相加是模运算（uint8 下 $260 \bmod 256 = 4$），两幅图像叠加时应使用 `cv2.add`。
- **图像混合 `cv2.addWeighted`**: 按权重把两幅图像叠加，公式为 $g(x) = (1-\alpha)f_0(x) + \alpha f_1(x)$，两个系数之和为 1，修改 $\alpha$ 可以得到不同的透明混合效果。

## 要点详述

### 收尾 MNIST 全连接网络与三种提升手段

上节最后的网络结构是：输入 $32\times32$ 图像先展平，接线性层输出 10 个类别，最后接 Softmax，属于非常简单的结构。加载训练好的模型即可预测，例如某张图片预测为 7056（按课上数值，待核对），简单网络能给出结果，但预测效果比较有限。

三种改进：

1. **交叉熵损失**：把 `Train` 中原来的损失函数改为 `CrossEntropyLoss`，网络结构不变。
2. **Dropout 防过拟合**：在定义网络加线性层时插入 `nn.Dropout`，比例设为 0.5，再加非线性激活函数（例如从 784 变到 500 的线性层之后）。效果：加上这些改进后测试集准确率可达 97%，不加则只有 92%。
3. **正则化**：网络结构不变，在随机梯度下降优化器里加 weight_decay = 0.001，即加入 $\lambda\lVert w\rVert^2$ 惩罚项系数；课上也提到后面会给出防止过拟合的正则化对比实验。

课程还提到长短记忆网络（LSTM）这条线本次不展开。

### 用 PyTorch 搭卷积神经网络并训练

数据准备与全连接网络相同：下载训练集、测试集，每批 64 张图片，装载训练集与测试集，构建对应的张量与标签。

网络结构（用 `nn.Sequential` 顺序组织）：

- 第一层卷积 `nn.Conv2d`：输入通道 1（灰度图），输出通道 32，卷积核尺寸 $5\times5$，步长 1；随后接非线性激活函数，再接最大池化。
- 第二层卷积：输入通道必须等于上一层的输出通道 32，输出通道 64，卷积核仍为 $5\times5$，步长 1，池化步长 2；再接非线性激活与最大池化。
- 展平后接全连接：由于卷积输出最终为 $7\times7$、通道 64，展平成 $64\times7\times7$ 的向量，接全连接到 1000，再到 10；每个全连接层后都接非线性激活函数（同样用 ReLU）。

前向传播流程：输入 $28\times28$（MNIST 数据本身是 $28\times28$，上一节讲的 $32\times32$ 是口误）→ 第一个卷积层（内部已包含卷积、非线性、池化）→ 第二个卷积层（同样含三者）→ 展平 → 两个全连接层。

训练：定义学习率，损失函数用交叉熵，优化器不加前面几项改进，直接迭代训练数据，循环里做梯度清零、计算梯度、修改权重、测试。

结果：卷积神经网络在 MNIST 测试集上准确率可达 99%、训练集 99.7%，明显高于全连接网络（全连接最高约 95%）。

### 项目实战：猫狗分类与迁移学习

数据集放在本地 `image` 目录下，里面按类别分文件夹（狗、猫等，还有天气图片等示例数据）。构建数据集直接调用 `torchvision.datasets.ImageFolder`，把根目录下的训练集和测试集分别加载；`DataLoader` 每次取 8 张图片（batch size = 8）构建输入，测试集同样处理，`shuffle` 打乱。类别是**根据文件夹名自动定义的**，索引分别为 0 和 1（因为训练目录下就是 cat 和 dog 两个文件夹）。

模型直接加载预训练好的 VGG16：它最后输出 1000 个类别（在 ImageNet 1000 上训练），而我们只需要猫、狗两类，所以要改造网络。

迁移学习做法：

1. 遍历网络中的所有权重参数，把梯度属性设为 `False`（`requires_grad=False`），冻结原有卷积层；
2. 重新构建分类部分的分类器（`classifier`）：原来是 25088 → 100 的线性层，保留 25088 → 100（加非线性），但把最后的输出从 100 改成 2；
3. 通过 `model.classifier = ...` 直接替换分类层，打印模型可以看到结构已经变成 25088 → 100 → 2；
4. 学习率取 $3\times10^{-4}$，损失函数仍用交叉熵（分类问题），优化器改用 Adam（比随机梯度下降多了动量等机制，需课后自行了解）。

训练结果：损失逐渐降低，准确率可达 82%。如果是卷积神经网络版本的训练，数据加载、类别、模型结构流程完全一样，只需构建全新的全连接层再训练。

推理程序要点：训练完成后进入运行时阶段，不再需要 GPU 并行运算，要把数据从 GPU 上解放出来；读取图片后需要增加一个维度（因为模型输入带 batch 维度，训练时 batch size 为 8，推理时置为 1）；输出通过 argmax 取到对应类别。课上用一张小狗图片测试输出类别正确，但继续换图测试时效果较差——原因是当时只用全连接网络训练过，卷积版本没有训练。教师说明这段代码会放到学习资料里，同学可以自己训练（训练耗时较长）。

课程还留了天气分类的练习（晴天、下雨天、黄昏、日落等类别图片），可以自己构建数据集试着搭网络训练。在 PyTorch 中搭网络的通用流程总结为：构建数据集 → 创建数据加载器 DataLoader → 迭代数据并观察数据长什么样 → 写一个展示函数 → 创建模型（有多种创建方法）→ 写训练过程。

### 转入数字图像处理技术

在神经网络出现之前，目标检测、边缘检测、特征点检测，以及相机标定时黑白棋盘格角点的检测，靠的都是传统的数字图像处理技术，其中的模型多为机器学习模型。本部分以 OpenCV 为基础展开，因为它是一个开源的图像处理库，把切割、旋转、平移、仿射变换、透视变换、边缘检测、直线检测等传统算法都集成好了。大家常用的 Photoshop 对图像做斜切、剪切等操作，背后其实就是这些数字图像处理技术，只是被封装成了软件。本课程将介绍的内容包括基本的图像处理方法、几何变换、形态学变换、图像平滑、图像直方图特征、模板匹配、霍夫变换、特征提取与描述（Harris 角点、SIFT 等算法、角点检测等），在 OpenCV 中都有现成函数可直接调用。

### 图像的定义、图像类型与数字图像的历史

**图像的定义**（教材说法）：图像是人类视觉的基础，是自然景物的客观反映，是人类认识世界和人类本身的重要源泉。**图**是物体反射或透射的光的分布；**像**是人的视觉系统所接受的图在人脑中形成的印象或认识。照片、绘画、剪贴画、地图、书法作品、手写汉字、传真等都属于图像。

**历史脉络**：

- 最早是模拟图像。1826 年发明了第一张可以永久保存的照片，属于模拟图像。模拟图像又称连续图像，通过光、电的强弱变化记录亮度信息，因此是连续变化的，缺点是容易受干扰（老式相机用底片/胶片，拍完还要冲洗，而且是黑白的）。
- 1921 年，通过海底电缆把图像从一地传到另一地，形成了第一张数字图像：其亮度用离散数字表示，把图片编码成 5 个灰度级，发送端把图片编码到打孔记录带上，传输到接收端后用特殊打印机恢复成图像。
- 1950 年左右，世界上第一台计算机在宾夕法尼亚大学被发明，数字图像处理科学正式诞生。

**数字图像的表示**：计算机中采用 0/1 编码，数字图像也用 0/1 记录信息。通常接触的是 8 位图像，包含 $0\sim255$ 的灰度，其中 0 代表最暗、255（最亮）代表最白；把 $0\sim255$ 归一到 $0\sim1$ 也常见。人眼对灰度的敏感范围大约在 16 位到 32 位之间，但常用数字图像是 $2^8 = 256$ 级。若用 16 位则是 65536 级。

三类常见图像：

- **二值图像**：非黑即白，像素值只有 0 或 1，常见于条形码、二维码、黑白文档。
- **灰度图像**：每个像素只有一个采样颜色的图像，即通常说的黑白图；但与二值图像不同，灰度的黑白之间存在许多级颜色深度，一般是 8 位、256 级。灰度值常用来衡量可见光波段每个像素的亮度，通常以每个采样像素 8 位的非线性尺度保存。
- **彩色图像**：由三原色三通道构成，每个像素通道由红、绿、蓝三个分量表示，每个分量取值 $0\sim255$；RGB 图像与索引图像一样都可以用来表示彩色图像。

小结：图是物体反射或透射光的分布，像是视觉系统所接受的图在人脑中形成的印象和认识；模拟图像与数字图像分别是连续存储与分级（离散）存储；数字图像有位数之分，常见 8 位，分为二值图像、灰度图像和彩色图像。

### OpenCV：来源、模块体系与基本操作

**OpenCV 是什么**：由英特尔公司俄罗斯团队发起并参与维护的计算机视觉处理开源软件库，支持与计算机视觉、机器学习相关的众多算法，并在不断扩展。另一个著名库是 Halcon（德国团队发起），更多用于工业现场检测；从原理学习角度，用 OpenCV 已经足够，而且 OpenCV 也被越来越多地应用到工业现场。

- 编程语言：最初基于 C++ 实现，早期用 C++ 开发，后来提供了很好的 Python API，现在用 Python 调用非常方便，直接 pip 或 conda 安装 `opencv-python` 即可。
- 跨平台：Windows、Linux、macOS、Android、iOS 都可以使用，现在也支持 CUDA。
- API 丰富：覆盖传统计算机视觉（机器视觉）算法，涵盖主流机器学习算法，同时加入了对深度学习的支持。
- 安装验证：`import cv2`，用 `cv2.imread` 读图、`cv2.imshow` 显示，`cv2.waitKey(0)` 中参数为 0 表示一直等待，当等待 0 毫秒即无键盘操作时图像直接消失；如果要使用某些额外功能，还需要安装 OpenCV 的扩展包（contrib）。

**模块体系**：最基础的是 core、imgproc、highgui 三个模块。core 模块实现最核心的数据结构及基本运算和绘制，以及图像数组操作相关函数；其余模块负责任务包括图像的读取、显示、存储，滤波、几何变换、平滑、分割、形态学处理、边缘检测、目标检测、运动分析、对象跟踪等。更高层次还有 ml 模块（支持向量机、决策树等机器学习算法）和 3D 模块（相机模型标定、三维重建，包含多视角几何算法、立体摄像头标定、物体姿态估计、立体匹配、3D 信息重建等，相机校准时会用到）。

**基本操作**：

- 图像 IO：读取 `cv2.imread(路径)`；显示 `cv2.imshow(窗口名, 图像)`；保存 `cv2.imwrite(路径含文件名, 图像)`。
- 绘制几何图形：
  - 直线 `cv2.line(img, 起点, 终点, 颜色, 线宽)`；
  - 圆 `cv2.circle(img, 圆心, 半径, 颜色, 线宽/填充)`，当线宽参数为 $-1$ 时生成填充颜色的实心圆；
  - 矩形 `cv2.rectangle(img, 左上角坐标, 右下角坐标, 颜色, 线宽)`，目标检测、目标跟踪中框住目标就靠它，要注意参数是左上角和右下角坐标；
  - 文字 `cv2.putText(img, 文本, 位置, 字体, 字号, 颜色, 线宽)`，目标检测时通常在框上写类似 `cat: 0.9` 表示类别与置信度。
- 绘制示例：用 `np.zeros((512,512,3), np.uint8)` 生成 $512\times512$ 三通道全黑图像，画蓝线（起点 $(0,0)$、终点 $(511,511)$）、绿色矩形框、实心红圆，并写入白色文字 "OpenCV"。**颜色顺序是重点**：OpenCV 通道顺序为 BGR，Matplotlib 等为 RGB，两者需要反转（`img[:, :, ::-1]`）才能用 Matplotlib 正确显示。
- 像素与通道操作：图像读取后本身就是 NumPy 数组，所以取某个像素点的值、修改某个像素（例如把某点亮度和颜色改成白色）以及按切片修改一块区域，本质都是数组操作；图像属性包括行数、列数、通道数、数据类型、形状大小，可直接调用；通道可以拆分（BGR 三个通道分别得到三个二维数组）与合并。
- 颜色空间转换：OpenCV 中有 150 多种颜色空间转换方法，最常用的是 BGR 转灰度、BGR 转 HSV，调用 `cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)` 或 `cv2.COLOR_BGR2HSV`。

### 图像的算术运算与混合

主要掌握图像的加法和混合。

**图像加法**：可用 `cv2.add` 把两幅图像相加，也可以直接用 NumPy 的数组加法（因为读进来就是数组，且是 uint8 等格式）。两幅图像相加要求大小和类型相同，或者第二个操作数是一个标量。两者的关键差异是：**OpenCV 的加法是饱和（截断）操作，NumPy 的是模运算**。例如 $250+10$，用 `cv2.add` 得到 255（$260$ 被截断到最大值），而 uint8 用 NumPy 相加则做 $\bmod 256$ 运算得到 4。这个差别在两幅图像叠加时表现得非常明显。

实例：读取一张晴天图像和一张"下雨"图像，分别用 `cv2.add` 和 NumPy 直接相加，再把两种结果画出来对比——OpenCV 版本得到的是两幅图像叠加的下雨效果，NumPy 版本因为取模运算结果就不对。结论：两幅图像叠加时要用 `cv2.add`。

**图像混合**：本质也是加法，不同之处是两幅图像的权重不同，从而产生混合、透明的视觉效果。公式为

$$
g(x) = (1-\alpha) f_0(x) + \alpha f_1(x)
$$

两个系数之和为 1（一个 $\alpha$、一个 $1-\alpha$），修改 $\alpha$ 就能得到很炫酷的混合效果。例如把第一幅图权重取 0.7、第二幅取 0.3，调用 `cv2.addWeighted` 相加并展示：只给第一幅图加较大权重时像"晴天在下雨"，两幅都按 0.7/0.3 混合后就是非常像阴雨天的下雨效果。

**本节小结**：图像 IO 操作（读取、显示、保存）；在图像上绘制直线、圆、矩形、文字；获取并修改像素；图像属性；通道拆分与合并；颜色空间转换；图像加法 `cv2.add` 与图像混合 `cv2.addWeighted`（注意两者都要求两幅图像大小相同）。
