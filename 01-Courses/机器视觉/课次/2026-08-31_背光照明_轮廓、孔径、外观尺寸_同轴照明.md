## 关键概念

- **背光照明**: 光源置于被检测物体背面,物体遮挡后的透光边缘被镜头捕捉 → 成像高对比;用于**轮廓、孔径、外观尺寸**检测。
- **同轴照明**: 内置**分光镜**使光源路径与成像路径同轴,直射高反光平面而不产生杂乱反射;用于高反光材质表面质检。
- **打光选型口诀**: 看轮廓用背光,查划痕用低角度,高反平面用同轴,字符条码高角度,弧形反光用穹顶。
- **颜色光照技巧**: 打白光得完整黑白图;打红/蓝/绿光时同色部分被吸收——利用颜色互补提取特定图案(Logo 案例)。
- **偏光技术**: 光源与被测物之间加偏光板、镜头前加可调偏光镜片,消除定向明亮反光;典型用于反光塑料表面、电路板字符。
- **相机标定(预告)**: 建立**像素坐标↔世界坐标**换算关系(如 100 像素=1 厘米);尺寸测量、视觉引导的前提。
- **视觉引导**: 相机获取目标点位置/方向/抓取点 → 控制器规划机械臂轨迹 → 完成定位抓取、装配、焊接、码垛。
- **特斯拉 FSD 纯视觉方案**: 车载摄像头识别车道线/车辆/行人/信号灯 → 传给规划系统;背后含场景分割与 occupancy(空间占用栅格)算法;国内主流为"激光雷达+视觉"融合。
- **无人机巡检要素**: 机巢定时定点自主飞行 → 视频逐帧分析 → 缺陷/火点检测 → 北斗/GPS 定位落图 → 大模型生成维修建议;热成像同样是"图像",同属机器视觉处理对象。
- **视觉基础模型(如 SAM)**: 具备通用分割能力,通过点选等提示快速识别任意目标,减少数据标注与重新训练 → 推动机器视觉"通用化、低门槛"。
- **三维高斯重建**: 从图像/视频恢复几何结构、相机位姿、表面纹理 → 服务数字孪生/VR/机器人导航;当前最大短板是**只能离线、难以实时**。
- **多模态与具身智能**: 视觉+语音+动作统一建模,使机器人/自动驾驶从"感知"走向"行动"——老师点名的未来重点方向。

## 要点详述

### 1 打光技术收尾(02:03–08:51)

- **背光照明**: 物料装在袋中时,前向/高低角度照明都会引入杂乱表面反射;背光只让**待测孔径/边缘的光透过**被镜头捕捉 → 清晰提取孔数量、孔径大小、外观轮廓尺寸。
- **同轴照明**: 分光镜让"照射光路=反射回镜头的光路",有效照射高反射率平面、避免反光;用于高反光材质表面质检。
- **选型口诀**(必记): 看轮廓用背光 / 查划痕用低角度 / 高反平面用同轴 / 字符条码高角度 / 弧形反光用穹顶。按被测对象特点与任务需求选光源和打光方式,保证成像效果事半功倍。
- **颜色运用**: 白光→Logo 完整黑白图;红光→红色部分吸收只剩其他色;蓝/绿同理 → 按目标颜色特性选光源颜色。
- **偏光应用**: 偏光板+可调偏光镜片,旋拧至反光消除:案例①反光皮带轮表面;②电路板芯片字符(本应低角度照明,但反射导致模糊,加偏光后清晰可读)。

### 2 机器视觉应用全景(09:42–34:28)

- **工业制造**:
  - 表面缺陷检测:稳定光源下采集图像,算法依据颜色/纹理/灰度/边缘识别氧化皮、斑块、开裂、夹杂、划痕;能连续检测高速生产线产品、减少人工漏检、保持判定标准一致。案例:轮胎X光内部缺陷、瓶盖 NG/OK 判定、焊接缺陷点检测。
  - 尺寸/形状/装配精度测量:必须先**相机标定**得到像素↔真实长度换算;非接触式,适合精密制造,提高效率、减少人工误差;展示教师团队自研尺寸检测系统。
  - 分拣:机械臂+检测台+环形光源闭环——识别类别/形状 → 求空间坐标 → 放到对应位置。"完美的闭环机器视觉系统"= 感知(光源/镜头/相机)→ 分析(识别检测)→ 坐标转换 → 执行抓取。
  - 机器人视觉引导:获取目标点位置方向与抓取点 → 规划轨迹 → 定位抓取/装配/焊接/码垛;视觉反馈使机器人能按工件位置与环境实时调整;核心仍是**视觉坐标系→三维空间坐标系的转换(相机标定)**。
- **交通与城市管理**: 车辆/行人/非机动车检测、车牌与限速等标识识别 → 支撑流量统计、违法分析、风险预警;智慧交通一体化调度平台靠视觉感知实时汇报,定位城市堵点、提升通行效率;视觉传感器是其中最关键的传感器。
- **自动驾驶**: 特斯拉 FSD 纯视觉(摄像头感知→规划转向/变道/避障);案例视频:窄路对向会车时自主倒车让行、判断可通过后自主通过。背后是识别+场景分割+三维成像+ occupancy 全空间占用计算,可视化界面只是"为了好看"。国内主流路线为激光雷达+视觉融合。教师课题组在无人物流车感知、环视端到端轨迹决策规划方向招生研究兴趣(课后联系)。
- **无人机巡检**: 城市周边布设机巢 → 按标定航线自主飞行 → 采集视频逐帧分析 → 检出道路裂缝、护栏偏移;无人机自带定位,接入实时地图后定位具体路段,结合大模型给出维修建议并派员检修。消防方向:搜索烟雾火点/异常高温,热成像定位火点 → 指挥中心一键精准派遣+规划路径;测绘方向:三维地形地貌生成(高精度模型可叠加高德/百度地图)。
- **农业/生态**: 玉米种子裂纹检测定位,统计裂纹数量/长度/方向/分布 → 种子质量评价、粮食分级、生产线自动筛选(类比工业缺陷检测);野生动物 AI 无人巡护:检测到动物自动切换 3 倍/7 倍焦距,视频关键帧抽取分析。
- **医疗**: CT/MRI 影像检测疑似病灶并标注位置范围,辅助医生筛查诊断;结合大模型可进一步输出分析与治疗建议(机械学院有医工结合方向)。
- **物流**: 条形码识别、包装外观检测、尺寸位置估计 → 引导传送分拣与装卸,提高仓储周转、减少错分漏检;竞赛中常要求识别+统计分析+给出物流线改进建议。

### 3 当前痛点(34:23–38:32)

- **恶劣天气与工况**: 雨雪/浓雾/强光弱光/镜头污染降低对比度、丢失特征;激光雷达点云缺失;北方沙尘地区镜头污染更严重(无人物流车在封闭园区同样受影响)。相机怕光照、激光雷达怕雨雪散射、毫米波雷达稳定但分辨率有限——传感器各有软肋。
- **遮挡与盲区**: 目标被大型物体遮挡 → 信息物理缺失;单车视觉无法看穿障碍 → 漏检;现状是多目视觉感知。
- **远距离小目标**: 成像只占少量像素、激光点云稀疏 → 特征不完整、定位误差大;提高分辨率又增加计算量——顶会热点,每年都有新算法。
- **二维图像深度歧义**: 二维图只记录投影,缺尺度与深度;不同距离的物体可能成像相似;解决:深度相机(本质是**双目**,类似人眼估计距离)。

### 4 未来方向(38:33–41:58)

- **视觉基础模型**: SAM 为代表,通用分割、提示即用,少标注少重训 → 通用化、低门槛。
- **三维视觉与空间理解**: 三维重建恢复几何/位姿/纹理;三维场景理解还要估计物体空间位置、尺寸、朝向与相互关系,支撑机器人导航、智能家居、自动驾驶。三维高斯重建当前"只能离线不能实时"是最大难点 → 实时化是研究热点。
- **多模态与具身智能**: 视觉/语音/动作统一建模 → 从感知走向行动;老师建议:想发亮眼学术成果或找高薪工作,往**多模态大模型+三维视觉/三维重构**方向走。
