## 关键概念

- **批归一化 (Batch Normalization, BN)**: 插在层与层之间的归一化层。训练时统计该小批量数据在这一层输出的均值与方差，把输出规范化为零均值、单位方差的数据，再做缩放与平移，使各层输出分布稳定在同一尺度上。
- **归一化输入与分布漂移**: 图像像素值原本是 $0\sim255$，一般先做归一化；但经过权重、卷积操作和非线性激活后，层与层之间输出的取值范围会不断变化（例如从 $0.0x$ 量级掉到 $0.001$，又回到 $0.0x$ 量级），造成分布不均匀、权重不稳定，这正是 BN 要解决的问题。
- **级联 (Concatenation)**: 特征融合方式之一，把不同输入特征按维度直接叠加，例如两个 $1\times100$ 的一维向量级联得到 $1\times200$。
- **合并**: 另一种融合方式，要求参与融合的特征形状一致，通过相加、取最大值或卷积运算得到最终输出；残差网络是典型代表，主要解决深层网络的退化问题。
- **残差网络 (ResNet)**: 何恺明提出，核心思想是让网络具备学出 $F(x)=0$ 的能力——希望输出仍等于输入 $x$ 时，用权重去拟合一个恒等映射，再把 $x$ 与分支输出合并，而不是把权重全置 0（那样网络就废了）。合并时两边特征图尺寸必须一致。
- **张量 (Tensor)**: PyTorch 的基本数据结构，与 TensorFlow 中的 tensor 同义，可以理解为能在 GPU 上并行计算的矩阵；对没用过的人，最直观的类比是"GPU 版 NumPy"，两者操作高度相似且通常配套使用。
- **autograd 与 `requires_grad`**: 自动求导机制，把课上讲的链式法则整条反向传播封装在 `backward()` 里；张量需要 `requires_grad=True`（缩写 grad）才参与梯度计算，且只要它被用在计算图中，相关变量的梯度也会自动被标记。
- **全连接层 (`nn.Linear`)**: 线性回归本质上就是一个不加激活函数的全连接层；模型继承 `nn.Module`，在初始化中定义层、在 `forward` 中定义前向传播，是 PyTorch 搭网络的标准套路。
- **mini-batch 与 `DataLoader`**: 用 `DataLoader` 按 `batch_size` 把数据集切成小批量送进网络；`shuffle=True` 表示每次构建 loader 时把数据打乱，保证每批内部是乱序的，同时每个 epoch 仍会完整遍历所有数据。

## 要点详述

### 批归一化：层间分布不稳定带来的问题与解法

神经网络训练时要加入大量权重和非线性激活函数，这会导致层与层之间的特征分布不稳定。输入图像先做归一化，但经过权重、卷积核操作和非线性激活之后，到达某一层时数值量级可能已经从 $0.0x$ 变成 $0.001$，再往后又回到 $0.0x$ 范围，取值范围前后不一致，使分布不均匀、权重不稳定。

解决办法是在层与层之间插入一个归一化层（即批归一化层）：不管上一层输出是多少，都把这些输出归一到 $0\sim1$ 的范围内，从而保证层与层之间的输出规范化。工作原理是：在训练过程中先计算该层输出的均值与方差，据此对每个小批量数据在该层的输出做统计计算，将输出转化为具有零均值和单位方差的数据，最后对规范后的数据应用缩放和平移操作，使模型仍能学到适当的变化：

$$
\hat{x} = \frac{x-\mu}{\sigma}, \qquad y = \gamma \hat{x} + \beta
$$

两方面的收益：一是克服梯度消失和梯度爆炸问题，加速训练收敛；二是规范化效果有助于模型泛化，在一定程度上充当正则化的角色——这与之前讲过的防过拟合正则化目标一致（在损失中加入权重平方乘系数的惩罚项，$\lambda\lVert w \rVert^2$），本质都是让权重更均衡。

放置位置：在上一层最终输出与下一层输入之间，即"上一层输出 → 非线性激活函数 → BN → 下一层输入"，主要应用于卷积神经网络和全连接神经网络的隐藏层。

### 卷积网络的扩展：区域切分与多分支多尺度融合

卷积神经网络还可以做区域切分：对图像的不同区域使用不同的卷积运算。例如室外拍摄的图像，下半部分通常近景、上半部分多是天空或建筑物等远景；对特定区域做特定的卷积计算，最典型的应用就是深度预测（深度图的深度预测），这类网络在深度估计中经常使用。

另一种扩展是多分支、多尺度融合，代表结构是 GoogLeNet（当时在图像分类和目标检测中经常使用的网络结构）。输入特征同时走多个分支：可以直接到输出，可以在中间加卷积，也可以在外层再加卷积，最后把多个分支融合。每个分支代表对当前特征不同程度、不同层次的过滤——有的学到浅层特征，有的拿到深层特征，深层特征再用不同的卷积核继续运算，最后把浅层与深层的分层特征融合起来。这样能学习到更多套参数，对不同特征采用不同网络使特征增强，对图像的描述能力也随之增强。

### 特征融合的两种方式：级联与合并

融合方式有多种，最常用两种：

1. **级联（拼接）**：把不同输入的特征简单叠加，例如 $1\times100$ 的向量与 $1\times100$ 的向量级联成 $1\times200$。
2. **合并**：要求参与运算的特征形状一致，通过加减、取最大值或卷积运算得到输出。

合并的代表是残差网络（ResNet），是计算机视觉领域何恺明提出的、学术引用量最高的工作之一，达到万级引用量。其核心思想是学会 $F(x)=0$ 的能力：希望输出仍为 $x$ 时，用权重去模拟 $F(x)=0$ 的恒等映射，再把 $x$ 与本分支输出合并；如果改成让权重全为 0 使输出为 0，网络实际上就废掉了。做合并时要求两个特征图尺寸一致，例如 $3\times3$ 与 $3\times3$ 合并后仍是 $3\times3$。

### 卷积神经网络小结

- 使用非线性激活函数，通常用 ReLU。
- 本质上是一层层不断加深的过程：特征图通道数变大、尺寸（size）变小，相当于对数据进行特征提取与吸收压缩。
- 参数量对比：在全连接网络的例子中，卷积网络能把参数量缩小约 25 倍。
- 批归一化把各层特征的尺度按均值与方差统一到一定范围。
- 区域分割：对不同区域独立学习；融合：把分开的区域重新合并。
- 上采样（放大、生成特征图的过程）在生成类网络中接触比较多。

### MNIST 实例的网络结构设计

以 MNIST 手写数字分类为例，整体结构是：输入图像（本节按 $32\times32$ 讲的）→ 卷积（$5\times5$ 卷积核）→ 池化 → 再卷积 → 再池化 → 全连接层 → 输出长度为 10 的列向量，对应 10 个类别，采用 one-hot 编码（例如某类的输出形如 01000…，长度 10）。在实现这个卷积神经网络之前，先要掌握搭建网络的深度学习框架 PyTorch。

### PyTorch 入门：张量、GPU 与基本操作

- **定位**：logo 是火炬；核心数据结构是张量（Tensor），与 TensorFlow 中的 tensor 是一个意思，可以当作能在 GPU 中计算的矩阵来理解。对没用过的人，最直观的类比是"GPU 版 NumPy"。
- **意义**：主要是帮我们在 GPU 上做并行训练；当然在 CPU 上也能跑，只是运行效率差很多。教师本机没有安装 CUDA，所以课上的演示都是 CPU 版本，这些例子本身 CPU 都能跑通。
- **生态地位**：与 TensorFlow 的对比中，PyTorch 目前已占据统治地位，GitHub 上的开源代码、学术研究大多使用 PyTorch。
- **安装**：可用 pip 安装，也可以按官网指引用 conda 安装，网上教程很多。
- **常用操作**：
  - 查看版本；创建 $5\times3$ 的矩阵直接用 `torch.rand(5,3)`，取值在 $0\sim1$ 之间（类比 NumPy 的 random）。
  - 初始化全 0 矩阵用 `torch.zeros`；也可以直接传入 Python 列表（例如用 `torch.tensor` 把一个数值列表转成张量）。
  - 基本运算可调用 `torch.add`，也可直接用 `+`，与 NumPy 一致。
  - 索引：按"第几个样本、第几列"取值，例如取第二列。
  - `view`（变形操作）最常用：把 $4\times4$ 矩阵展平成长度 16 的一维向量，在卷积网络中意义重大——网络中间输出都是张量，但最终分类要输出长度为 10 的列向量，接到全连接网络之前必须展平；也可以只指定一个维度，例如 `view(-1,8)`，让长度为 16 的数据自动变成 $2\times8$。
  - NumPy 与 PyTorch 可以互转（把数组转成张量、再用 numpy() 转回数组），训练卷积网络时涉及大量高维数据（三维、四维），这些转换非常常用。

### autograd：让框架接管反向传播

前向传播和反向传播过程中：前向传播时各个节点的输出都要保留下来，因为反向传播要用到这些结果；同时要根据损失函数和目标函数更新权重，更新后的各节点梯度与参数也要保留，用于下一次前向与反向计算。PyTorch 把这些机制全部封装在 `backward()` 里，我们只需要把网络架构搭好、按自定义流程组织数据、定义网络结构、目标函数和迭代次数，剩下的交给网络自己去学习。

使用要点（以 $3\times4$ 张量的求和为例）：

- 张量默认不带梯度，需要显式声明 `requires_grad=True`（grad 是 gradient 的缩写）才参与反向传播计算；只要某个变量被用在计算图中，它本身相关的变量也会被自动纳入梯度计算。
- 令 $t = x + b$（`x`、`b` 均为 $3\times4$ 的随机张量），对 $t$ 求和得到 $y$，再对 $y$ 调用 `backward()`，就能取出 $b$ 的梯度。
- 求和操作的梯度全为 1：因为 $y = x_1 + x_2 + \cdots + x_{12}$，所以 $\frac{\partial y}{\partial x_i} = 1$。

### 线性回归全流程：从造数据到收敛

以最简单的网络 $z = wx + b$ 为例说明梯度：

$$
z = y + b, \quad y = wx \quad\Rightarrow\quad \frac{\partial z}{\partial b}=1,\ \frac{\partial z}{\partial y}=1,\ \frac{\partial z}{\partial w}=x,\ \frac{\partial z}{\partial x}=w
$$

（相加项求导为 1，相乘项求导交叉取另一项，即链式法则。）

完整实例：构造 $0\sim10$ 共 11 个数作为 $x$，转成 NumPy 列向量后 shape 为 $11\times1$；$y$ 由 $2x+1$ 生成，即构建一个需要拟合的函数 $y = 2x + 1$。模型构建套路：

1. 定义类并继承 `nn.Module`（`nn` 是 neural network 的缩写），这样才能用框架内置的函数；
2. 在初始化中定义线性层 `nn.Linear(1,1)`（输入维度 1、输出维度 1），线性回归本质就是不接激活函数的全连接；
3. 定义 `forward` 前向传播。

训练配置：优化器用 `torch.optim.SGD`（随机梯度下降，加载模型权重参数 `model.parameters()`，学习率 0.01），损失函数用均方误差（回归问题），循环迭代 1000 次。每次迭代必须做的事：

- 输入和标签都要转成张量；
- **梯度清零 `zero_grad()`**：上一次的梯度已经用不到，如果不清零会一直累积，显存会不够用；
- 前向传播 → 计算损失 → `backward()` 反向传播 → 更新权重参数。

结果：损失从约 $10^{-2}$ 稳定下降到 $10^{-7}$ 量级。验证时 $x=0$ 预测值约 1、$x=1$ 预测约 3、$x=2$ 预测约 5，输出的是奇数序列 $1,3,5,7,9,\dots,21$，与真实值误差很小，说明学到了正确的权重参数。

模型保存与加载：`torch.save(model.state_dict(), 'xxx.pt')`，参数字典形式保存各层权重参数，后缀常用 `.pt`（也可用 `.pth`）；加载时用 `model.load_state_dict(torch.load(路径))`。

### GPU 版本改造、张量的常见形式与 MNIST 数据集

**GPU 版本**：CPU 计算时数据放在内存、由 CPU 运算；改用显卡则要先把数据放到显存，再调用 CUDA 核心计算。代码上模型结构与维度完全一致，区别只在于：加载完模型后增加设备判断（用 `torch.cuda.is_available()` 检测 CUDA 是否可用），可用就 `.to(device)` 搬到 GPU，否则仍用 CPU；模型和数据都要搬，训练循环、损失函数、学习率、优化器都不变。

**张量的常见形式**：常数（0 维，取元素值用 `.item()`）、向量（1 维，在深度学习中通常表示特征，例如某一样本的某一维特征，长度为 3 的列表转成张量后 shape 就是 3）、矩阵（2 维）、三维张量（例如一张彩色图像的各通道数据）、四维张量（在三维张量外再包一层，即一批样本）。还可以有更高维，但训练卷积神经网络时四维通常就足够了。

**MNIST 数据集**：用 `torchvision`（通常装 PyTorch 会一并安装）内置的常见数据集，如 MNIST 等，也内置了成熟的网络结构和权重参数（如 ResNet、卷积网络）可直接使用；数据展示用 Matplotlib。加载流程：

- 调用 `datasets.MNIST` 下载数据集，指定存放路径、`train=True/False` 分别取训练集与测试集，并把数据转成张量；
- 用 `DataLoader` 加载：设置 `batch_size=64`，即一次给网络 64 张图片作为一个输入，此时网络输入的维度是 $32\times32\times3\times64$（按本节讲法）；`shuffle=True` 表示加载时打乱顺序；
- 展示：把图像维度调整为 $(32,32,3)$ 形式后用 Matplotlib 按 $8\times8$ 网格画出 64 张图片，并打印对应的标签。

**最后的网络结构**：定义一个全连接网络，图像展开成长度为 784 的向量（本节按 $32\times32$ 计），全连接层从 784 维输入映射到 10 维输出，中间设计了一个规模相近的隐藏层；分类任务最后接 Softmax，损失函数用交叉熵损失。前向传播部分讲到此处下课。
