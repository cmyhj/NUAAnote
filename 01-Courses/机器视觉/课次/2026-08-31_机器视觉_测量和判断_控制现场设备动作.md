## 关键概念

- **机器视觉(MV)**: 用机器代替人眼做**测量和判断**;通过光学装置和非接触传感器自动接收并处理真实物体图像,分析获得目标特征,进而**控制现场设备动作**。关键词是"测量+判断+控制"。
- **计算机视觉(CV)**: 研究"如何使机器学会看"的学科,用照相机+计算机获取被拍对象的数据与信息(眼=相机,大脑=视觉处理算法),典型如火星机器人/天问一号。
- **数字图像处理**: 用计算机对图像去噪、增强、复原、分割、特征提取的技术;在光照差、深度学习太慢或精度不够的工业场景仍是主力(第5章专门讲)。
- **像素与图像的本质**: 图像在计算机中是**张量(多通道矩阵)**;分辨率=横纵像素格数(720p/1080p/2K/4K);灰度图=单通道矩阵,RGB 图=三通道。
- **卷积神经网络(CNN)与 PyTorch**: 图像领域最常用的神经网络是 CNN;深度学习框架现以 PyTorch 为主(Caffe/TensorFlow 为早期),开源生态好,可编译成 C 部署到无人小车、机械臂等嵌入式边缘端。
- **尺寸检测=边缘检测**: 工业现场最常用的视觉任务,本质是边缘检测。
- **目标检测算法发展线**: SVM → R-CNN 系列 → SSD 系列 → YOLO 系列,各有优缺点;竞赛中"拿来就用"的 YOLO 本课要讲清原理。
- **智能摄像头**: 把成熟视觉软件内嵌到相机传感器中,任务固定、即装即用,适合成熟工程检测;学术研究仍用普通相机+自研算法。
- **亮视野/暗视野照明**: 亮视野=反射直射光进镜头(背景亮);暗视野=直射光被反射走,只有细微凹凸的散射光进镜头(缺陷亮)。
- **LED 光源**: 色温可调、能效与寿命最佳(约3万小时)、瞬间启动可做频闪、形状/颜色/亮度灵活可计算机控制——工业首选。

### 3 相关学科关系(18:38–22:48)

- 学科间有交叠、相互支撑:AI(含 NLP、语音识别、模式识别、多模态大模型)包含视觉内容;CV 把图像放计算机上处理(检测/跟踪);MV 会应用 CV 的成熟算法(如 YOLO),并**进一步控制现场设备**(机械臂定位抓取、AGV 导航);当光照条件差、深度神经网络处理太慢或精度不够时,借助**传统数字图像处理/机器学习算法**兜底。
- 外围支撑学科:图像本身是信号(信号与系统)、成像技术(物理学)、神经生物学(神经网络基础)、数学、机器学习、机器人自动控制。

### 4 CV 与 MV 的区别(22:56–31:04)

- CV:让机器"学会看",典型成果如天问一号火星机器人;2015-2016 年的热点(表情识别、交通目标检测、机器狗)如今工程上已有现成算法、学术上再研究缺乏创新性。
- MV:用机器代替人眼做**测量和判断**——不只是"把检测结果标出来就 OK"(CV),还要把信息**反馈给机器去执行动作**(如识别抓取、合格放行/不合格剔除到缺陷区)。
- 归纳:**CV 侧重"质"**(分类:杯子还是人还是狗;身份确认;人脸/车牌识别;行为分析如人群徘徊、遗留物、聚集),**MV 侧重"量"**(器件统计、零件内外径检测、三维形貌测量)。MV 系统本质是基于视觉的工业测控装备。
- 老师观点:现阶段工程研究中严格区分二者没有意义,但课程仍要讲清概念差异。

### 5 机器视觉系统构成(31:05–38:40)

- 工作流程:光源照射检测对象 → 相机采集 → 图像传到计算机 → 预处理(降噪/增强/分割)→ 算法分析 → 交互界面显示与存储 → **输出控制指令**(机械臂/AGV/人形机器人,看视觉传感器装在哪台机器上)。
- 硬件六环节:**光源、镜头、相机、图像采集模块、图像处理模块、交互界面**。
- 演进:传统系统需要图像采集卡做模数(A/D)转换;数字相机一步到位直接输出数字图像;**智能摄像头**把常用视觉软件内嵌进传感器,任务出厂已定,适合成熟的工程检测(孔径/外观尺寸/缺陷检测可直接买来用)。
- 案例:机械臂把被检测对象放上检测台 → 打光 → 镜头相机成像 → 孔径检测 → 全部合格进入下一道,不合格则控制机械臂抓取放入次品区。

### 6 光源与照明技术(38:45–53:01)

- **光源三类对比**:
  - 高频荧光灯:色温低;**色彩还原差**(会引起颜色偏差,颜色识别精度要求高的场景少用);能效低、寿命短、易坏;启动慢(镇流器)。
  - 卤素灯:色温高、发热明显;**色彩还原最好**(能准确再现真实颜色)→ 对颜色识别要求高时选它。
  - LED:色温可调;色彩还原取决于光谱特性(可按需选白/红/蓝/绿/混合光);能效与寿命一骑绝尘(约3万小时,间断使用更长);瞬间启动、可做频闪灯;可做成各种形状/尺寸/照射角度,亮度可调、散热好;可计算机控制、支持特殊定制 → **机器视觉应用中的首选光源**。
- **照明方式**:
  - 亮视野:光源反射的直射光进入镜头,背景明亮 → 通用产品外观、轮廓、颜色、印刷、表面较大缺陷与整体形貌、字符条码、高对比图像。
  - 暗视野:光滑表面把直射光反射走,只有凹槽/划痕处的散射光被镜头捕捉 → 金属划痕、玻璃/晶圆片疤痕凹槽、透明物体内部异物(玻璃内杂质)、高精度边缘检测与测量(孔洞边缘、精密件尺寸)。
  - 复杂表面可按区域组合打光、多角度拍摄多张图综合分析。
- **打光方式(五种)**:
  - 高角度照明(>45°,前向直射,常用环形光):如罐/瓶盖顶字符识别;背景亮、凹陷字符模糊。
  - 低角度照明(<45°,即暗视野):突出划痕、凹凸边缘(芯片、硬币检验:低角度下划痕/凸起极亮)。
  - 背光照明(光源在物体背面):下一节详述。
  - 同轴照明(内置分光镜):下一节详述。
  - 前向漫反射照明(穹顶灯/碗灯):曲面高反光物体(如药板铝箔包装),消除定向反光、成像清晰。
- **核心工程结论**:光源选得好+打光方式正确 → 成像对比度高 → 后续检测算法要求大幅降低 → **事半功倍**;反之再强的算法也难补救成像缺陷。
