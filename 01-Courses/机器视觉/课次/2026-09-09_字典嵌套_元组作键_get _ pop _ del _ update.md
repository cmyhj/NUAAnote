## 关键概念

- **字典嵌套 (nested dict)**：字典的值可以再是字典，形成多层结构。这正对应深度学习里"大网络套小网络、一个 block 里有线性层或卷积层"，因此可以通过键逐层取到权重参数。
- **元组作键 (tuple as key)**：元组是有序且不可变的，所以可以作为字典的键，用一个元组把多个特征（振动信号、主轴转速、温度等）绑在一起映射到一个输出值，例如轴承寿命预测、股票预测这类"多特征 → 单一输出"的任务。
- **get / pop / del / update**：`get` 键不存在时返回 `None` 或指定的默认值且不改变原字典，而直接按键索引键不存在会报错；`pop` 按键弹出值并可指定默认参数；`del` 按键删除某个键值对；`update` 对多个键做批量处理——已有的键改值，没有的键直接新增。
- **pprint**：把字典以换行、缩进的结构化形式打印，便于查看庞大的网络结构或权重；普通 `print` 的键值对挤在一行，参数一多就看不清。
- **keys / values / items**：`keys()` 返回所有键的列表，`values()` 返回所有值的列表，`items()` 返回所有键值对组成的元组列表；遍历字典的典型写法是 `for k, value in a.items()`，这里用到元组的打包与解包。
- **集合 (set)**：无序序列，元素具有唯一性，重复元素只保留一个；为保证能判断是否重复，集合中的元素只能是不可变对象。用 `set()` 创建空集合——`{}` 是空字典而不是空集合。
- **集合运算**：并集 `union` 或 `|`（合并并去重）、交集 `intersection` 或 `&`、差集 `a - b`（去掉两者共有部分）、对称差 `symmetric_difference` 或 `^`（只在其中一个集合中出现的元素）。包含关系用 `issubset`（子集，也可写 `<=`）和 `issuperset`（超集，也可写 `>=`），但只能测子集，不能测真子集。
- **列表/集合/字典推导式 (comprehension)**：用一行表达式配合循环生成容器。结果一定是列表时用方括号，方括号里生成单个元素则是集合，写成"键: 值"形式则是字典；可在末尾追加 `if` 条件筛选参与推导的元素。
- **生成器表达式 (generator expression)**：与推导式写法几乎一样，只是去掉方括号，不会一次性生成整个列表，节省内存和时间。
- **continue 与 break**：`continue` 满足条件时跳过本次循环剩余语句、回到循环开头进入下一轮；`break` 无条件跳出整个循环，不判断循环条件是否还成立。
- **不定参数与关键词参数**：`*args` 让函数接收任意数目的位置参数，函数内部把第一个参数之后的参数当成一个元组；`**kwargs` 让函数接收任意数目的键值对参数，内部当成一个字典。
- **模块 (module) 与 `__name__`**：每个 `.py` 文件就是一个模块，用 `import` 或 `from ... import ...` 导入；借助 `__name__` 属性，同一个文件既可以当脚本直接运行，也可以被当作模块导入。
- **文件访问模式**：`r` 只读（默认，指针在开头）、`w` 写入（已存在则覆盖、不存在则新建）、`a` 追加（写到已有内容之后）、`rb/wb/ab` 为二进制读写与续写、`r+` 既可读又可写，文件操作结束后必须关闭文件流。

## 要点详述

### 一、字典进阶：嵌套结构与元组当键（00:50-04:43）

先看一个字典里套字典的例子：定义四个键值对本身就是一个字典，同时还可以把这个字典整体作为某个键的 value 传给另一个新字典。打印后可以看到，外层某个键的值是 500，另一个键的值又是一个字典（键值 460、其 value 仍是字典）。老师指出这就是深度学习的常见结构——大网络里有小网络，某个 block 里又有线性层、卷积层、三维卷积，因此可以按层级键名逐层取到权重参数。

第二个例子是"人员信息"：构建一个列表，列表中的每个元素都是一个字典，每个字典里分别有三个键值对，也就是用字典描述一条记录。

字典的初始化可以直接调用内置函数 `dict()`，其中传入一个列表，列表里放的是元组，每个元组构成一个键值对：

```python
d = dict([('name', 'Lily'), ('gender', 'female'), ('age', 32), ('address', 'Beijing')])
```

打印后就是 `name: 李莉、性别: 女、年龄: 32、地址: 北京` 这样的结构。用键索引取值后还可以做增量赋值，例如把年龄 32 加 1 变成 33。

字典也允许用**元组作键**：先定义一个空字典，再把一个元组作为键、给它一个 value（如 100）。这样做有实际意义——可以用多个特征共同描述一个输出结果，例如轴承寿命预测、股票预测，输入是振动信号、主轴转速、温度等多项特征，最终输出一个数值；把这些特征放进一个元组作为键，就能把它们与对应的结果值绑定起来。元组可以用作键的根本原因在于**元组有序**（顺序不同即为不同的键）。

### 二、字典的取值、删除与更新（04:45-09:51）

- **按键取值与报错**：直接用键索引可以取到 value，但如果字典中没有这个键就会报错。例如字典里有 `first` 和 `second`，突然去取 `third` 就会报"没有这个值"的错。
- **get**：`a.get('third')` 在键不存在时返回 `None`，不会报错。它还可以指定默认参数：`a.get('third', 0)` 在键不存在时返回 0——注意原字典 `a` **不会**因此改变，只有把结果赋给另一个变量，该变量才拿到默认值。
- **pop**：弹出字典中某个键对应的值，也可以指定默认参数；对不存在的键弹出，会返回默认值（转写为"返回一个 None"一类）。例如 `c = a.pop('first')`，`a` 中这一对键值对被移除，只剩 `second` 等剩余项。
- **del**：与列表、元组使用索引删除不同，字典是通过键删除特定的键值对，例如直接删掉 `first` 那一对。
- **update**：按键插入或修改**单个**值很方便，但要一次改多个键就麻烦，于是有内嵌的 `update` 方法。例如原字典有姓名、性别、年龄、地址，现在想把姓名改成 Lucy，同时新增一个"婚姻状态：单身"属性，就定义一个只含这两项的新字典，用原字典去 update 它：已有的键（姓名）被更新成 Lucy，其余的键值对不变，没有的键（婚姻状态）被直接添加进来。

老师特别点出：**这正是神经网络权重参数更新的机制**，也是权重参数保存时要采用字典结构的原因——字典非常适合对不同的网络模块、不同的网络层、不同的偏置项和其他关键参数做定向更新。

### 三、字典的查看与遍历（09:54-12:55）

- **pprint**：比普通 print 多一个 p，打印结果更漂亮、结构化（换行、缩进），便于看清地址、年龄、婚姻状态、姓名、性别等各个键。写代码时要保证中间输出结果结构合理才好看，而普通 print 把键值对挤在一行会让人眼花缭乱——键值对少还好，神经网络那种庞大的网络结构里各种键值对根本分不清。
- **in**：判断字典中是否有某个特定的**键**。这和列表、元组不同：列表和元组的 `in` 判断的是元素值，字典判断的是键。
- **keys / values / items**：`keys()` 返回所有键的列表，`values()` 返回所有值的列表，`items()` 返回**所有键值对组成的元组**所构成的列表。
- **遍历**：编程中遍历字典常用 `for k, value in a.items():` 再打印 key 和 value，这实际上用的就是元组的打包与解包。

老师提醒：后面学习神经网络、做数据处理，或者查看网络权重时，会更多地接触到字典结构。

### 四、集合：唯一性、创建与集合运算（12:59-22:52）

**定义与性质**：前面讲的列表、字符串都是有序序列，集合则是**无序序列**。既然无序，就必须保证元素的唯一性——里面同时有十个 1，也只表示集合里有 1。集合中存在两个甚至多个相同元素时只保留一个；同时为保证能判断是否重复，集合中放入的元素只能是确定的**不可变对象**。

**创建方式的两个坑**：

- 可以调用内置函数 `set()` 定义空集合；也可以用 `set(列表)` 由列表生成集合，返回一个新的集合。
- 集合用大括号表示，但**不能用 `{}` 创建空集合**：字典也是大括号，如果允许 `{}` 表示空集合，Python 就无法区分谁是集合谁是字典。在 Python 中 `{}` 创建的是空字典，`s = {}` 的类型就是 dict。所以创建空集合只能用 `set()`。

**集合运算**（学过高中数学都不陌生）：

- **并 (union)**：两个集合合并，可以用 `a.union(b)` 方法，也可以用竖线 `a | b`；合并后要去重（元素唯一性）。两种写法得到的集合相等。
- **交 (intersection)**：返回两个集合共有元素组成的集合，用 `intersection` 方法或 `&` 符号。
- **差**：`a - b` 去掉 a 与 b 共有的部分，剩下的属于 a 的元素；`b - a` 同理。
- **对称差 (symmetric difference)**：抛弃交集后剩下的元素，即"在 a 中或在 b 中、但不同时在两者中"的元素集合，用 `symmetric_difference` 方法或 `^` 符号。
- **包含关系**：判断子集用 `issubset`（sub 是"亚/次"的意思，set 是集合）或直接写 `<=`；判断超集用 `issuperset` 或 `>=`。这个方法只能测子集，不能测真子集——例如 $a \subseteq a$ 返回 `True`，但 $a \subset a$ 这种真子集判断会返回 `False`。

**增删方法**：

- `add`：向集合添加**单个**元素，和列表的 append 类似。已有该元素则集合不变。例如集合里已有 1、3、4，再 add 4 结果仍是 1、3、4；add 一个新元素 5 则变成 1、3、4、5。
- `update`：向集合添加**多个**元素，类似列表的 extend。
- `remove`：移除单个元素（按元素值）。
- `pop`：删除并返回集合中的**任意一个**元素。因为集合没有顺序、没有索引，不能像列表那样按位置弹出，所以只能是任意一个；集合为空时执行 pop 会报错。
- `discard`：与 remove 一样，区别在于它同样按元素值删除指定元素。
- `difference_update`：从 a 中去除所有属于 b 的元素。例如 $a = \{1,2,3,4\}$、$b = \{2,3,4,5\}$，把 b 中有的 2、3、4 全部去掉，结果只剩 $\{1\}$。

### 五、条件判断、推导式与生成器表达式（23:23-32:37）

**条件判断**：任何编程语言都有，求职刷题时最常用的就是 `if / else`。语法非常简单：`if 条件:` 后跟结果，需要多分支就加 `elif`，最后 `else`。可以用 `and`、`or`、`not` 结合多个判断语句——例如令 $a = 10$、$b = -5$，则 `a > 0 and b < 0` 为 `True`，`not (a > 0)` 为 `False`（因为 `a > 0` 本身是 True），`a < 0 or b < 0` 为 `True`（因为 $b<0$）。

**平年闰年示例**：判断某一年是不是闰年（课上对平年/闰年的说法有混淆，按标准规则理解）：

$$\text{闰年} \iff (n \bmod 400 = 0) \ \text{或}\ (n \bmod 4 = 0 \ \text{且}\ n \bmod 100 \neq 0)$$

否则为平年。老师举 1900 年作为例子讨论该条件是否成立。

**列表是否为空**：判断列表是否为空，主要就是判断它的长度是否大于 0。

**列表推导式**：朴素写法是先建空列表，再 `for x in values` 遍历、对元素做运算后 append，例如把列表里的值逐个求平方（$3^2=9$、$8^2=64$、$10^2=100$、$14^2=196$）。更简洁的写法是列表推导式：

```python
squares = [x ** 2 for x in values]
```

因为结果一定是列表，所以外面用方括号。老师对简洁写法有保留意见：它容易忘掉前后顺序，如果天天编程、记得住就没问题，但凡隔一两个月不编程再回来，一定会忘——他用高考公式做类比：当年对热力学第一、第二定律公式、磁场公式、阿伏加德罗常数、人体三大调节（水、温度等）烂熟于心，现在也全都忘光了，想用还得回去翻书。编程同理，最终还是要根据自己的熟练度在"简洁"和"不易忘"之间取舍。

**带筛选条件的推导式**：在末尾追加 `if`，只对满足条件的元素做运算，例如只对小于等于 10 的元素求平方，或要求平方结果不超过某个阈值才放进结果里：

```python
[x ** 2 for x in values if x <= 10]
```

**集合推导式与字典推导式**：把外面的方括号换成大括号，如果里面生成的是单个元素，结果就是**集合**；写成 `x: x ** 2` 这种"键: 值"的形式，结果就是**字典**。例如对小于 10 的元素求平方并生成字典，可得到 $10 \to 100$、$4 \to 16$、$7 \to 49$ 这样的映射。

**生成器表达式**：对推导式结果直接求和时，Python 会先完整生成这个列表再求和，列表随后进入垃圾回收，是一种浪费。解决方式与 range 类似——使用生成器表达式，写法上就是把方括号去掉：

$$\texttt{sum}(x \ast 2 \ \texttt{for} \ x \ \texttt{in} \ \texttt{values})$$

它不会一次性生成整个列表。课上现场对比了两者用时，去掉方括号后耗时进一步缩小。

### 六、循环结构与 continue / break（32:43-37:04）

- **for**：最常见，例如 `for i in range(...)` 做累加。
- **while**：Python 上来就执行循环，直到条件不满足为止。例如让 i 不断自增，当 `i > 100` 时停止，实现的是 0 到 100 的累加，结果为 5050。
- **用 while 读空容器**：对空集合执行 pop 会报错，因此可以用 while 循环依次弹出容器中的所有元素——只要集合里还有元素就继续弹出，弹空之后不再满足条件，循环自然结束。
- **continue**：遇到 continue 时程序返回循环最开始、重新执行。典型例子是取列表中的偶数：遍历元素，如果是偶数就继续执行后面的打印，如果是奇数就直接 continue 回到循环开头。例如 7 对 2 取余不为 0，不执行打印进入下一轮；6 对 2 取余为 0，执行打印，最终输出 6、4、2。
- **break**：遇到 break 语句程序跳出循环，**不管循环条件是否满足**。例如遍历一个列表，当取到的元素值为 stop 时立刻跳出，后面的打印不再执行，最终输出 start、1、2、3、4 就结束了。

老师强调：循环大家见得多，重点是 `while` 里 `continue` 与 `break` 到底是什么意思，**这两个很多同学会搞混**。现在做开发拿到的多是现成程序，跑通就行，对细节不深究；一旦某天脱离工具、脱离 AI 自己去设计一段程序或实现一个算法，就会纠结 continue 是什么意思、break 是什么意思。这时最简单的办法就是举个小例子试一下。

### 七、函数：定义、传参与不定参数（37:04-46:00）

**为什么要函数**：编程大师马丁先生说过，代码有很多种"坏味道"，其中**重复是最坏的一种**。减少重复的办法就是定义函数——某段功能这块要用、那块也要用，不可能每次都重写一遍，定义一个函数直接调用即可，例如把变量交换封装成一个函数。

**基本语法**：用 `def`（define 的缩写）这个关键字定义函数。函数参数相当于数学上函数的自变量，用 `return` 关键字返回一个值，相当于数学上的因变量。例如定义 `add(a, b)` 实现两数相加并返回 `c`；使用时把参数换成具体值传入（`add(2, 3)`）。两个字符串也可以相加（拼接）。

**两种传参方式**：

- **按位置传参**：按顺序对应第一个参数、第二个参数。
- **关键词传参**：显式指定参数的值，例如 `add(a=2, b=3)` 或 `add(b=3, a=2)`（写法颠倒也不影响结果）。但如果只给一个参数（如 `add(a=3)`），会报错——函数不知道 b 是什么。

老师提醒：尽量别用"靠位置记忆"这种写法，要么用变量名明确赋值，要么明确知道这个函数第一个参数是什么、第二个是什么。

**默认参数**：定义时可以给参数设默认值。例如定义一个求平方的函数 `f(x, a=1, b=0, c=0)`，返回

$$f(x) = a x^{2} + b x + c$$

传入 $x = 2$ 时用默认值得到 $1 \times 2^2 = 4$；传入 $x = 2$ 且把第二个参数改成 3 时，相当于 $a = 3$，得到 $3 \times 2^2 = 12$。默认值一开始定义好，也可以修改、也可以重新传参。

**不定参数 `*args`**：让函数接受不定数目的参数，类似 Java 的多参数，但 Python 简单得多，用一个星号加 args 组合，参数数目不定，函数内部把第一个参数之后的参数当成一个**元组**看待，遍历其中的元素累加即可。例如 `add(1,2,3,4,5)` 相当于 $1+2+3+4+5$；`add(1,2)` 相当于 $1+2=3$。

**关键词参数 `**kwargs`**：两个星号加关键词参数（keyword 的缩写）。因为传入的是"a=1、b=2、c=3"这种形式，既有键又有值，所以在函数内部相当于一个**字典**，遍历时要使用 `items()`——这正是字典遍历的典型结构，返回的是元组的键值对。例如 `add(1, a=2, b=3)`，先处理位置参数再处理关键词参数，最后输出 $1+2+3=6$。

**同时支持两类参数**：Python 可以接收任意数目的位置参数和键值对参数。例如 `func(2, 3, a=8, b=10)`，位置参数打包成元组 `(2, 3)`，关键词参数收集为字典 `{'a': 8, 'b': 10}`。

**返回多个值**：Python 支持函数返回多个值，本质上就是元组的打包。例如输入 $x, y$，返回 $\sqrt{x^{2}+y^{2}}$ 和 $x+y$ 两个值，Python 把这两个值变成元组返回。

**用 `*` 与 `**` 展开**：列表也可以像元组一样对应赋值（`a, b, c = 1, 2, 3`）；把元组作为位置参数展开传给函数时，**必须在前面加一个星号**——不加星号 Python 会认为你只传了一个参数。同理，用字典做关键词参数展开时前面要加**双星号**，否则也会被当作只传了一个参数，而函数需要两个参数。

### 八、map、模块与文件读写（46:01-52:07）

**map 函数**：`map` 会根据提供的函数对指定序列做映射，第一个参数是函数、第二个参数是序列。例如对一个列表的 2、3、4 求平方，得到 4、9、16。注意它最后得到的是一个**对象**，想知道里面的值还需要把结果转换成 list 格式再输出。根据函数参数个数的不同，map 还可以接受**多组序列**，把各序列对应位置的元素作为参数传入函数。

**模块**：

- Python 中每个文件代表一个模块，所有 `.py` 后缀的文件被认定为 Python 代码文件。使用函数时通常用 `import` 关键词导入指定模块，或用 `from 模块 import 名字` 的形式。
- `__name__` 属性：有时一个 `.py` 文件既要当脚本运行又要当模块使用，这时可以用 `__name__` 属性来处理。
- 例子：在 `ex.py` 里定义全局变量 `PI = 3.14` 和一个对列表求和的函数 `get_sum`，保存后就可以 `from ex import PI, get_sum`，直接打印得到 3.14，对 2 和 3 求和得到 5。也可以用 `os` 把该文件移除。这就是把自己写的代码模块化的方法。

**文件**：

- **为什么需要文件**：程序执行时调用的数据全都放在内存中，程序一旦终止这些数据就全部消失；要长期保存数据就必须存到硬盘上，文件是数据在硬盘中存储的主要形式。文本文件后缀为 `.txt`，二进制文件一般为 `.dat`。
- **打开方式**：调用 `open` 函数。`r` 是文本读，`rb` 是按二进制形式读；写用 `w`（write 的缩写）表示文本写，`a` 表示追加。
- **必须关闭**：文件的打开、读、写等所有操作完成后，一定要关闭文件流。
- **标志位语义**：`w` 表示每次都要重写文件，如果要在文件后继续写则需要用 `a` 标志位；`wb` 是二进制写，`ab` 是二进制续写，加 `b` 就是二进制、不加 `b` 就是非二进制。
- **访问模式总结**：
  - `r`：只读方式打开文件，文件指针放在文件开头，这是默认模式；
  - `w`：打开文件用于写入，文件已存在则覆盖，不存在则创建新文件——这是最常用的写模式，例如要把一些结果存下来；
  - `a`：打开文件用于追加，文件存在则把新内容写到已有内容的结尾之后，不存在则创建新文件写入；
  - `rb` / `wb` / `ab`：在原先语义基础上加二进制（二进制读、二进制写、二进制续写）；
  - `r+`：打开一个文件用于读写，文件指针在开头，加号表示既可读又可写。

老师总结：这些模式非常容易区分。本节内容到此结束。
