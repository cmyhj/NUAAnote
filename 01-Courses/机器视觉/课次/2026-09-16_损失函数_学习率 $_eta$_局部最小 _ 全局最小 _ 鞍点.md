## 关键概念

- **损失函数**：网络训练的优化目标，本节算例采用平方误差 $L=\frac{1}{2}(y-\hat y)^2$，它把"输出与标签的差距"变成可求导的标量，是反向传播回传梯度的起点。
- **学习率 $\eta$**：权重更新式 $w' = w - \eta\,\partial L/\partial w$ 中的步长系数，决定每一步下降的幅度；过小则迭代次数内到不了最优点且易陷局部，过大则越过极小点直接发散。
- **局部最小 / 全局最小 / 鞍点**：目标函数可能同时存在局部最小与全局最小，优化目标是全局最低点；$x^3$ 这类曲线上 $x=0$ 处导数为 0 却并非极小值——导数为 0 不一定是极值点，也可能是鞍点。
- **随机梯度下降（SGD, Stochastic Gradient Descent）**：实际训练中样本与标签都带噪声，因此在按梯度更新权重时叠加随机扰动并仍能收敛到最优区域，这是工程上最常用的优化方法之一。
- **动量（Momentum）**：给权重更新加一个"惯性"项 $v$，让下降方向由梯度方向与动量方向合成，从而抑制病态曲面上"一个方向走得慢、另一个方向来回震荡"的问题。
- **链式法则与计算图（Computational Graph）**：把复合函数拆成基本运算节点，每个节点只负责自己的局部导数，反向时用 $\partial z/\partial x = (\partial z/\partial y)(\partial y/\partial x)$ 逐节点相乘，即可得到输出对所有输入的梯度。
- **反向传播（Backpropagation）**：从损失值出发、沿与前向传播相反的方向逐层求各权重参数梯度的算法；算例中单隐层网络只迭代一轮就把损失从 2.205 降到 0.15。
- **卷积核（Convolution Kernel）与特征图（Feature Map）**：从输入数据上计算的算子（常见二维，也可一维或三维），尺寸由用户定义、厚度必须等于输入通道数、核内数值随机初始化后靠反向传播更新；一个卷积核卷积出一张特征图，多个卷积核的特征图叠成特征张量。
- **全连接网络 vs 卷积网络**：全连接网络输入的是展平后的向量，图像也能这样做，但卷积在分类与检测任务上的效果更好，本节说明它是处理图像任务的更优选择。

## 要点详述

### 一、上节回顾：训练配件与学习率的选择

上一节从线性回归出发，加入非线性激活函数得到非线性回归，从而搭起传统的全连接神经网络。网络搭好之后最关键的是两件事：一是权重参数的更新，二是"配件"的选择。

- 第一个配件是**损失函数**——决定我们优化什么；
- 第二个是**学习率**——决定每次更新的幅度；
- 第三个是**动量（momentum）**；
- 此外还有解决过拟合的**正则化与 Dropout**。

优化目标上必须分清局部最小与全局最小。对任何一个目标函数，我们的目标是找到全局最低点；但对于某些曲面（如含 $x^3$ 项或更复杂的鞍形曲面），$x=0$ 处的导数同样为 0，却并不是最低点。也就是说：导数为 0 不一定是极值点，也可能是鞍点，所以不能只看一阶导数为零就认定到达了最优。

**学习率怎么选：过小陷在局部最优跳不出来，过大直接越过极小点发散。**

以 $f(x)=x^2$ 为例，从 $x=10$ 出发，沿梯度的反方向迭代去逼近最优点：

- **学习率过小**：在给定的迭代次数内很难走到最优点，要继续逼近就得继续迭代、增加学习次数，这既浪费计算资源，又容易陷在局部最优解里跳不出来；
- **学习率过大**：起点出发本该收敛到全局最小点，但由于步长被调得太大，更新直接越过了全局最小点跳出去，目标函数非但不收敛，数值还会越来越大，也就是发散。

因此学习率既不能太小也不能太大，需要通过试验确定合适的量级。在后续讲动量时也能看到，单纯调学习率会陷入"调大就发散、调小就太慢"的两难。

### 二、从理想曲面到实际训练：随机梯度下降

先看理想情形。以 $f(x_1,x_2)=x_1^2+2x_2^2$ 为例，它在三维空间中是一个碗状曲面，全局最小点就是 $(0,0)$；从 $(-5,2)$ 出发，只要设定合适的学习率，沿梯度下降就能迭代到 $(0,0)$。

但这是理想情况——我们事先知道目标函数长什么样。实际训练网络时，网络是一个**黑盒模型**：我们手里只有"一堆样本 + 对应的标签"，样本和标签本身都带噪声，我们靠这些样本和标签去拟合网络、寻找它的最优参数。

为了模拟这种情形，课堂仍然用这个碗状曲面来演示随机梯度下降：在按梯度更新权重时，给 $x_1$、$x_2$ 的更新各加一个 $0\sim0.1$ 之间的随机噪声：

$$x \leftarrow x - \eta \nabla f(x) + \epsilon,\qquad \epsilon \sim U(0,\,0.1)$$

可以看到，加上噪声后下降轨迹变得更加曲折，但最终仍能走到最优区域。这正是训练中常用的随机梯度下降（SGD）的直观形态。

### 三、病态曲面与动量

把曲面改成 $f = 0.1x_1^2 + 2x_2^2$，即 $x_2$ 方向的斜率远大于 $x_1$ 方向。用同一个学习率做梯度下降时会出现明显的病态现象：

- 竖直方向（$x_2$）震荡幅度很大，但仍能收敛到 $x_2 \approx 0$；
- 水平方向（$x_1$）自变量每步移动极小，最终只走到大约 $-0.9$，远没到 0 这个点。

原因在于两个方向斜率差异过大：给定同一个学习率时，自变量在竖直方向的变化幅度大、在水平方向的变化幅度小，于是水平方向上的移动非常慢。若把学习率调大，$x_1$ 方向虽然能往零走，$x_2$ 方向却直接开始发散（从 $(-2,-5)$ 一类起点出发很快就发散）。

为此引入**动量**。权重参数的更新不再只看当前梯度，而是引入动量 $v$：

$$v_{t+1} = \gamma v_t + \eta g_t,\qquad w_{t+1} = w_t - v_{t+1}$$

其中 $g_t$ 是当前位置的梯度，$\gamma$ 是动量系数。当 $\gamma = 0$ 时没有动量，$v_{t+1} = \eta g_t$，公式退化为普通梯度下降的更新。而加了动量之后，新的下降方向是**梯度方向与动量（惯性）方向的向量合成**，轨迹因此更平缓。

直观理解：站在当前点寻找全局最优点时，目标不仅是朝最陡的方向走，还要照顾自己的惯性——如果惯性方向和梯度方向都比较大且彼此重合，就很容易来回震荡，动量正是用来压住这种震荡的。课堂取学习率 0.6、动量系数 0.5 做演示，从 $(-5,2)$ 附近出发，通过迭代优化找到 $(0,0)$ 就相对容易多了。

### 四、为什么图像任务要用卷积

全连接网络输入的是一个展平的向量。对图像当然也能用全连接网络：把 32×32 的图像直接展平成一维列向量，后面接全连接层即可。但对图像这一类的任务，用卷积的分类效果、检测效果都会更高。

手写数字（或字母）识别的典型流程是：输入 → 用二维滤波器做二维卷积 → 得到中间特征 → 再做池化（最大池化、最小池化或均值池化）使尺寸缩减 → 继续卷积 → 最后展平，输出一个长度为 10 的列向量，用来判断它属于哪一类，并与真实结果比对。本例用两个卷积核，第一个、第二个卷积核各得到一组中间特征。

本节的学习目标：先讲清上一节留下的反向传播算法；掌握卷积神经网络**卷积层的结构特点、关键参数以及卷积层间的连接方式**；了解不同卷积网络功能层的作用；会进行简单的卷积神经网络结构设计；能够用 PyTorch 跑通 MNIST 数据集的分类案例。教师提示：对已经在本科阶段接触过的同学来说，网上可以搜到很多开源代码，这个案例并不难，重点是借它把原理讲透。

### 五、反向传播的理论基础：链式法则与计算图

**链式法则**：对 $y=f(x)$、$z=g(y)$ 这样的复合函数，

$$\frac{\partial z}{\partial x} = \frac{\partial z}{\partial y}\cdot\frac{\partial y}{\partial x}$$

对一个神经网络来说，从输入到输出一层层往后传播，任意一个中间层都是后一层的输入，整体是一个非线性的复合函数，正常求导是求不出来的；但只要定义好每层局部的导数，就可以把链式法则一直往前套：先算输出对中间层的偏导，再乘该层对输入的偏导，一层层迭代下去，最终得到损失对每个权重参数的梯度。

**算例 1（乘法型结构）**：目标函数含 $x,y,z$ 三个量，形式为"$x$ 加 $y$ 的和再乘以 $z$"。构造中间变量 $q = x+y$、$m = qz$，则 $\partial q/\partial x = \partial q/\partial y = 1$，$\partial m/\partial q = z$，$\partial m/\partial z = q$。以 $q = 4$、$z = -2$ 为例：

- $m$ 对 $q$ 的梯度为 $z = -2$；$m$ 对 $z$ 的梯度为 $q = 4$；
- 继续往回传：$\partial q/\partial x = \partial q/\partial y = 1$，所以 $x$、$y$ 处的梯度都是 $-2\times1 = -2$。

含义很直接：$x$、$y$ 增大对目标函数起**负相关**作用，$z$ 增大起**正相关**作用。所以想让目标函数变小，就希望 $x$、$y$ 变大、$z$ 变小。用权重更新式 $w' = w - \eta\,\partial f/\partial w$ 验证：$x$ 处梯度是 $-2$，则 $x' = x - \eta(-2)$，$x$ 确实在增大，与结论一致。同时也能看出**梯度绝对值的大小决定了同一学习率下谁更新得多、谁更新得少**。

**算例 2（含指数、倒数、常数与 max 门）**：函数为

$$f = \frac{1}{e^{-u}},\qquad u = (x_1+x_2)w + \max(y_1,y_2)$$

给定 $x_1+x_2 = 1.5$、$w = 2$、$y_1 = -2$、$y_2 = -5$。前向计算：$1.5\times2 = 3.0$；$\max(-2,-5) = -2$；$3.0 + (-2) = 1$；乘以 $-1$ 得 $-1$；$e^{-1} = 0.368$；取倒数得 $2.72$——这就是整个前向传播过程得到的函数值。

反向按链式法则逐个节点回传：

- **倒数节点**：$(1/x)' = -1/x^2$，前向时 $x = 0.368$，于是 $1\times(-1/0.368^2) = -7.39$；
- **指数节点**：$(e^x)' = e^x$，前向输入为 $-1$，于是 $-7.39\times e^{-1} = -2.72$；
- **乘常数节点**：前向乘的是常数 $-1$，回传时就乘这个常数，$-2.72\times(-1) = +2.72$；
- **求和分支**：两条支路的局部导数都是 1，各得 $2.72\times1 = 2.72$；
- **乘法节点（$\times w$）**：对 $(x_1+x_2)$ 这一支的导数是 $w = 2$，得 $2.72\times2 = 5.44$，再各乘 1 分给 $x_1$ 与 $x_2$，故 $\partial f/\partial x_1 = \partial f/\partial x_2 = 5.44$；对 $w$ 的导数是 $(x_1+x_2) = 1.5$，得 $\partial f/\partial w = 2.72\times1.5 = 4.08$；
- **max 门**：只有取到最大值的那一路（$y_1 = -2$）参与后续计算，其梯度为 $2.72$；$y_2$ 因为值更小、没有参与计算，梯度直接为 0——不管 $y_2$ 怎么变，只要它小于 $y_1$，对输出就没有任何影响。

至此 $x_1$、$x_2$、$w$、$y_1$、$y_2$ 在目标函数该点的梯度全部求出，并且可以看出：若想让这个目标函数变小，$x_1$、$x_2$、$w$、$y_1$ 都起正相关作用（都希望减小），而 $y_2$ 完全不起作用。

### 六、单隐层网络的完整一轮前向与反向

前面构造的函数是"知道模样"的函数，可以一步步求导；而真实网络我们只知道网络结构，不知道目标函数的样子，那么反向传播怎么做？课堂用一个只有一层隐藏层的网络演示。

网络结构：输入二维 $x_1$、$x_2$，隐藏层两个神经元 $h_1 = w_1x_1+w_2x_2$、$h_2 = w_3x_1+w_4x_2$，输出一维 $y = w_5h_1+w_6h_2$。样本为 $x_1 = 0.5$、$x_2 = 1.0$，真实标签 $\hat y = 0.8$。

**第一步：正向传播。** 初始权重为 $w_1\sim w_6 = (1.0,\ 0.5,\ 0.5,\ 0.7,\ 1.0,\ 2.0)$，则

$$h_1 = 1.0\times0.5 + 0.5\times1.0 = 1.0,\qquad h_2 = 0.5\times0.5 + 0.7\times1.0 = 0.95$$

$$y = 1.0\times1.0 + 2.0\times0.95 = 2.9$$

与希望的 0.8 相差很远。损失用平方误差：

$$L = \frac{1}{2}(y-\hat y)^2 = \frac{1}{2}(2.9-0.8)^2 = 2.205$$

**第二步：反向求梯度并更新。** 先算损失对输出的导数 $\partial L/\partial y = y - \hat y = 2.1$。

以 $w_5$ 为例：$\partial L/\partial w_5 = (y-\hat y)\cdot h_1 = 2.1\times1.0 = 2.1$。取学习率 0.1：

$$w_5 \leftarrow 1.0 - 0.1\times2.1 = 0.79$$

再往前推一层，以 $w_1$ 为例：$\partial L/\partial w_1 = \partial L/\partial y \cdot \partial y/\partial h_1 \cdot \partial h_1/\partial w_1 = 2.1\times1.0\times0.5 = 1.05$，因为 $h_1 = w_1x_1+w_2x_2$ 对 $w_1$ 的导数是 $x_1 = 0.5$。于是

$$w_1 \leftarrow 1.0 - 0.1\times1.05 = 0.895$$

同理算出其余参数：$w_2 \leftarrow 0.5-0.1\times2.1 = 0.29$、$w_3 \leftarrow 0.5-0.1\times2.1 = 0.29$、$w_4 \leftarrow 0.7-0.1\times4.2 = 0.28$、$w_6 \leftarrow 2.0-0.1\times1.995 \approx 1.8$。一轮之后，权重从 $(1.0,0.5,0.5,0.7,1.0,2.0)$ 变为约 $(0.895,0.29,0.29,0.28,0.79,1.8)$。

**第三步：再前向一次看效果。** 用新权重重算：$h_1 = 0.7375$，$h_2 = 0.425$，$y \approx 1.348$，

$$L = \frac{1}{2}(1.348-0.8)^2 \approx 0.15$$

损失从 2.205 降到 0.15，说明误差在快速下降。在此基础上再求一次各参数的梯度、再更新一轮，再前向、再反向，如此循环，直到损失下降几乎不明显，或者达到预先设定的迭代次数。

### 七、反向传播的总结与实现要点

过程总结：①有一个初始的网络参数；②先做正向传播，计算各神经元的输出；③根据正向传播结果，从输出端往回求每个参数位置的梯度；④按参数更新公式更新网络权重；⑤再进入下一轮正向、反向迭代。

两个必须记住的结论：

1. **计算顺序与前向传播相反**，是从损失值朝输入的方向计算；
2. **编程实现时要缓存三类量**：(a) 前向传播各节点的输出值——反向求各点梯度时要用；(b) 反向传播过程中各权重参数的梯度——前一层的梯度依赖后一层梯度与该层的输入；(c) 激活函数的梯度。这些量都要在代码里存下来，因为前后层之间存在依赖关系。

补充说明：为计算方便，本节算例中的神经网络没有加非线性激活函数；但 Sigmoid、ReLU 等激活函数的导数我们都是已知的，反向传播时只是多一步计算，加与不加激活函数在传播机制上没有本质区别。教师点评：反向传播算法从今天的角度看非常简单，但在当年很多人都想不到。

### 八、卷积层与卷积核

进入卷积神经网络后，先要弄清三件事：什么是卷积层、由哪些部分组成、受什么影响、有什么特点、如何计算。

以三通道 32×32 的图像为例，通过一个卷积核做卷积操作，输出从 32×32 变成单通道的 28×28，也就是由旧的特征输入通过卷积运算得到一个新的**特征图（feature map）**。在卷积神经网络的隐含层（隐藏层）里，输出通常被称作特征图；一个卷积核得到一个特征层，多个卷积核就得到多个特征层，把它们叠起来就是一张特征张量。因此输入层与输出层之间，是由多个卷积核在反复做卷积运算。

卷积核的特点：

- 它是从输入数据中计算的**算子**，通常是一个二维算子，也可能是一维算子（如 $1\times1$），还可能是三维算子（如输入有 5 个通道时需要 $5\times3\times3$）；
- **尺寸大小由用户定义**，深度（厚度/通道数）由输入数据决定，两者都需要定义；
- **核矩阵的数值就是卷积神经网络的参数**：初始值随机生成，之后通过反向传播更新。

标准卷积运算的形态：输入是 $100\times100\times m$ 的特征张量，用 $n$ 个 $3\times3\times m$ 的卷积核，每个卷积核扫描一遍得到一个特征层，卷积核的尺寸可以自定义为 $3\times3$、$5\times5$、$7\times7$ 等，但**通道数（深度）必须与输入的通道数一致**；输出中间层的深度（通道数）由卷积核的个数 $n$ 决定。

卷积核的选择经验（本节末尾，第 6 节继续展开）：

- **尺寸**：一般取 $3\times3$、$5\times5$、$7\times7$，也可用到 $9\times9$、$1\times1$；一般取奇数，这样卷积运算能满足对称；具体大小根据输入数据确定；
- **厚度**：必须与输入特征（输入数据）的通道数保持一致；
- **覆盖范围**：一般要覆盖全部输入，无死角；特殊情况下只覆盖局部区域——有些位置可以忽略，这涉及掩码机制，后续学注意力机制、Transformer 结构时会用到。
