## 关键概念

- **机器视觉算法的两条路线**：课程研究的算法分为传统机器学习算法与深度学习（深度神经网络，DNN）算法两大类。无论走哪条路线，图像任务的实现都离不开编程语言，课程统一选定 Python。
- **脚本语言（Script Language）**：位于高级语言之上的一类语言，语法更简洁、编程逻辑更清晰；但要把高级语言编译为汇编语言，再转成机器语言才能真正执行，这是它执行链路上的代价。Python、JavaScript 都属于这类语言，Python 是 C 的脚本语言。
- **机器语言 / 汇编语言 / 高级语言的分层**：计算机只识别 01 组成的机器语言；用户书写的是高级语言（C、C++、Java 等）；高级语言先转为面向操作系统的汇编语言，再转为 01 代码去控制计算机电路的通断。
- **保留字（关键字）与代码量优势**：Python 只有 33 个保留字，实现相同功能的代码行数仅为其他语言的 1/5 至 1/10，行数更少、表达更简洁，可减少程序错误、缩短开发周期；同时免费、开源、扩展性好。
- **镜像源与 wheel 文件**：清华镜像源提供各版本 Python 及第三方库的 wheel 镜像文件，位于国内、下载速度快；不使用镜像源时下载缓慢，且即使下载成功也可能因库版本冲突导致算法跑不起来。
- **Anaconda 与 conda 虚拟环境**：Anaconda 集成 Python 与主流库、附带 150 多个科学计算包及其依赖；conda 既是包管理器（安装、卸载、更新第三方包）也是环境管理器，可为一个基础 Python 建立多个互相隔离的虚拟环境。
- **整型与浮点型**：Python 只有两种数值类型。整型是不带小数点的数字，浮点型是带小数点的数字，判断依据就是"有没有小数点"，67.0 属于浮点型。
- **表达式、增量赋值与优先级**：操作数与运算符组合而成的形式称为表达式；增量赋值是把变量增加 n 后再赋值回该变量，即 $y = y + n$ 写成 y += n；优先级为括号 > 幂 > 乘除求余 > 加减，同级从左向右。
- **整除 // 与求余 %**：整除运算符的结果是去掉小数的整数（5 // 2 = 2），求余运算符的结果是相除后的余数（5 % 2 = 1）且结果非负，若余数为负需加上除数。
- **三类常见错误**：语法错误（文法和标点错误，编辑时即可报错，最好改）、运行时异常（运行时报错并终止，如 0 作除数、变量未创建就增量赋值）、逻辑错误（程序能跑但结果与预期不符，频率最高、最难找）。
- **垃圾回收机制**：变量名是指向内存数值对象的引用。重新赋值时，Python 采取"另分配一块地址存放新值、让引用指向新地址"的做法，原来的内存失去引用后被垃圾回收机制清空回收。

本节要讲的知识点依次为：Python 简介（是什么、来源、现阶段使用情况），以及在 Python 中的数值、字符串、列表、元组、文件，还有此前绪论中提到过的科学计算库。

热度榜方面，编程语言排行榜依据互联网上有经验的程序员课程、第三方厂商的数据，并使用搜索引擎以及亚马逊、YouTube 等统一统计排名，只反映某门语言的热门程度，不反映语言好不好，本质是"谁用得多"。榜单自 2002 年开始统计至今，代表 Python 的蓝色曲线在 2017—2018 年之后使用量越来越高，而 C、Java、C++ 相对稳定；2025—2026 年的排位中 Python 占比第一。教师提醒，将来走上工作岗位从事相关开发，Java、Python、C/C++ 至少都要了解。

### 四、版本演进与 Anaconda 开发环境（22:12-31:06）

版本时间线：最早的诞生可追溯到 1991 年的初代版本；2000 年 10 月发表 2.0；2.7 是 2008 年以前非常稳定的经典版本，当时研究 CV 用的都是 2.7；2008 年之后出现 3.0 版本，且与 2.x 不兼容，此前基于 2.7 开发的一些算法若直接改用 3.x 就不能用；2015 年发布 3.5，对 3.0 做了一些修复；2019 年有 3.7；2020 年彻底终止对 Python 2 的支持；此后 2021—2022 年有 3.11，2023 年 3.12、2024 年 3.13、2025 年 3.14。教师指出 3.6/3.7 是比较明显的分水岭，有些定义与特性在新版本不再支持，因此本课程学习时可以选择 3.12 版本，3.10 或最新的 3.14 也都可以。

环境方面，提到 Python 就不可避免要提 Anaconda。它把 Python 和一些主流库都包含在里面，同时支持创建多个虚拟环境，也支持添加第三方库。如果直接去官网下载 Python，得到的是纯净版，只包含 Python 最基本的计算能力，而基于 Python 开发的众多库——包括 NumPy、OpenCV、机器学习相关的第三方库，以及后面要用的深度学习框架 PyTorch——在纯净版里都是没有的。Anaconda 帮用户把这些全部集成，并附带了一大批常用的数据科学包。教师给出两点价值：第一，Anaconda 附带了 conda、Python 和 150 多个科学计算包及其依赖，因此可以立即开始处理数据；第二，conda 本身是一个包管理器和环境管理器，在数据分析中会用到很多第三方包，conda 可以帮助安装、卸载和更新；更重要的是管理环境，可以为不同项目建立不同的运行环境。

教师现场打开 GitHub 上任意一个开源项目演示：项目里都有 README 文件，以及 requirements 文件，其中会定义这段代码需要的版本，例如 NumPy 的版本、OpenCV 的版本等。任何一个项目在建立时用的都是开发者自己的电脑和环境，因此每个项目所需第三方计算库的版本都不同，版本之间可能存在冲突。如果每跑一个项目就装一套 Python 和依赖，电脑会被装得一团乱，每次还要去切换环境。正确的做法是保留一个基础的纯净 Python，用 conda 为每个项目建立虚拟环境，在一个 Python 的基础上建立多个互相隔离的环境。

镜像源方面，清华镜像源针对不同 Python 版本提供第三方库的镜像，文件格式是 wheel。因为服务器在国内，下载很快。如果不使用清华镜像源，安装任何一个第三方库（例如用 Python 的包管理工具安装）都会非常慢，而且即使下载下来，也可能因为其他库的版本冲突而跑不起来。

### 五、数值类型与算术运算（31:08-36:22）

Python 有两种数值类型，非常简单：整型与浮点型。整型就是没有小数点的数字，浮点型就是带有小数点的数字。例如 1238966 不带小数点，是整型；只要带小数点就是浮点型。Python 中对整型可以直接进行加减乘除运算。

课堂上教师插入一个提问：67.0 是哪种类型？请认为是浮点型的同学举手，又请认为是整型的同学举手，随后给出判断依据——要看它的定义，带有小数点的就是浮点型。

为了验证，教师在 Jupyter Notebook 中现场编码。选择 Notebook 是为了讲课时方便，安装 Anaconda 时会自带这个交互式编辑器，好处是可以实时在线修改与编译运行。把变量赋值为 67.0，运行后输出直接显示为浮点型，验证了"只要带小数点就是浮点型"。作为对照，Java 中定义数值非常复杂，要先声明是整型还是浮点型，还分长整型、短整型、单精度与双精度浮点数等，而 Python 直接赋值即可。

算术运算符包括加、减、乘、除，以及幂运算（两个星号表示幂次，例如 $**$ 是幂运算）。操作数和运算符组合而成的形式称为表达式。教师提醒一个细节：表达式中的空格不影响 Python 计算的结果，空格的存在只是让你阅读代码时能迅速看清哪些是运算。运算规则上有一个注意点：如果两个运算操作数都是整数，结果就是整数；如果其中一个是浮点数，结果就是浮点数；0 不能做除数。

### 六、变量、命名规范与内置函数（36:24-42:33）

变量定义方面，C 或 C++ 中定义变量前面都要给出类型，而 Python 中变量就是一个名称，对应存储在内存中的一个数据，变量的目的是便于运算。

命名规则：使用字母、数字和下划线，但起始字符不能是数字。教师指出这其实是很多编程语言统一的规则，不只 Python，Java、C++ 等都是这样。

常见命名风格有两种。第一种是驼峰命名，除第一个单词外，其余单词的首字母大写——命名最好对变量所描述的内容有说明，因此常常是多个单词的组合，一般选择第一个单词全小写、后面每个单词首字母大写，这就是驼峰命名格式。第二种是下划线命名，用下划线把多个单词连接起来。变量名区分大小写，大小写不同即为两个不同的变量。Python 的关键字不能做变量名，如循环中使用的 for、while 等。

命名建议上，变量名应既简短又具有描述性，例如 name 比 n 好。教师解释：n 行不行？可以，但现在你清楚它是什么，明天还好，过了一周你就忘了这个 n 是什么了，所以一开始定义变量时就要用规范的命名把含义表达清楚。同样，student_name 比 sn 好；数据标注、读取特征时某一列直接叫 name 就够了，而 length_of_person_name 这种写法过于复杂，需要适当缩减。另外要慎用小写字母 l 和大写字母 O，因为它们很容易被误看成数字 1 和 0。

关键字方面，教师列举了若干常见关键词，包括 break（中断）、class（类）、def（定义函数）、del（删除）、else、from、global（定义全局变量）、import、in（判断是否在字符串或列表中）、if 等，并强调这些关键字要慎用，不能用来命名变量。

内置函数部分讲了三个。abs 是取绝对值函数，对应数学运算中的求绝对值，例如 -5 的绝对值是 5，-2.56 的绝对值是 2.56。int 保持整数不变，将小数点部分丢掉转为整型，例如 int(9.5) = 9，int(-8.8) = -8（注意是截断小数部分，不是四舍五入）。round 是四舍五入函数，它有两个参数 x 与 n，n 表示要保留的小数位数；如果只给一个参数，就把数值四舍五入去掉小数，例如 round(2.7) 的结果是 3，round(2.322, 2) 保留两位则得到 2.32。教师特别提醒要理解 x 与 n 的关系：x 四舍五入到小数点后 n 位，若没有给 n 则四舍五入到整数。

### 七、增量赋值、整除与求余（42:36-46:57）

增量赋值的含义是：给变量增加 n，然后把增量后的结果重新赋值给该变量，也就是 $y = y + n$ 写成 y += n。除加法的赋值之外，减法、乘法、除法以及幂都有相应的增量运算。

这里有一段重要的概念澄清。教师回顾当年学编程时，老师不允许写 a = 90，因为它的意思是"给变量 a 赋值 90"，并不是说"a 等于 90"；后面如果 a 的值发生变化，a 还会发生变化，所以"a 等于 90"和"给 a 赋值 90"是两个概念。从后来实际的编程实践看，说 a 等于 90 也没什么错，但大家一定要清楚：本质是给 a 这个变量所指定的内存地址放了一个数据。例如给 a 赋值 90 之后，执行增量赋值 10 就是 90+10 再赋值给 a，此时打印 a 的结果是 100；再做减法增量赋值 3 就是 87；再乘 5 就是 450。

书写要求有两条：增量赋值运算符是两个符号的组合，中间不能有空格，而前面讲普通加减乘除时表达式中可以有空格、没有关系；除法增量赋值时右边的操作数 n 不能是 0，也就是说 0 不能做除数。

接着是两个特殊的整型运算符。第一个是整除，即两个斜杠连在一起，区别于单个斜杠的除法运算符，整除的结果是去掉小数的整数，例如 5 // 2 的结果是 2，而实际上 5 除以 2 是 2.5，整除把它的小数部分去掉。第二个是求余运算符，用百分号表示，运算结果是被除数除以除数得到的余数，例如 5 % 2 的余数是 1。

关于求余有两个注意点。一是要分清整除运算符与除法运算符的区别；二是求余运算的结果是非负的，即如果余数是负数，则加上除数才是求余的结果——这里加的是除数，不是被除数。教师借此提醒：不要把除数和被除数搞混，例如 6 ÷ 3 = 2 中 3 是除数，很多人会把两者搞反，这是小学的知识但很多人出错。

### 八、运算符优先级、三类错误与垃圾回收（47:00-52:10）

优先级方面，学过 C 或 C++ 的同学知道优先级是考试的重点。教师明确：在 Python 中所有的优先级都不需要背，搞不懂的时候就加一个括号，全部解决。当表达式中有括号时，算术运算的优先次序是：第一是括号，优先级最高，先算括号内、由内向外；第二是幂运算；第三是乘法、除法、求余；最后是加减。多个同级的运算符之间从左向右进行计算，例如除法与乘法同级时按从左到右处理，但如果想让后面的幂运算先算，直接把它括起来即可。教师强调，好的编程习惯是尽可能使用括号，这样就不需要去算优先级，代码出错查找问题时也非常清晰。

课程的收尾部分归纳了 Python 编程中常见的三种错误：

1. **语法错误**：文法和标点错误称为语法错误。使用主流的编程编辑器在编辑的时候就会报错提示，例如函数调用时括号使用不当会立即报错。语法错误相对来说很好改，也最容易被发现。
2. **运行时异常**：一些语句的错误不是语法错误，但会在运行时报错并使程序终止。例如 0 不能做除数，或者变量 x 尚未创建时就给它执行增量赋值——x 都没有初始值，执行增量赋值肯定不行。
3. **逻辑错误**：程序可以正常跑，但跑出来的结果和你预期的结果不一样，这就是逻辑错误。教师指出逻辑错误发生的频率相对最高、最难找，因此需要在编程之前进行严格的设计；一旦出现错误，可以使用断点检测的方法进行 debug（调试），一步一步调试各个量的变化，看它和你当时想象的是不是一样。

最后讲垃圾回收机制。示例中有两段代码：先给 n 赋值 5，紧接着又给 n 赋值 7。变量 n 是指向内存数值对象的引用。执行给 n 赋值 5 时，程序在内存中分配一块区域放置数值 5；当执行给 n 赋值 7 之后，内存会重新分配一块区域放 7，但变量 n 的引用会指向 7，那么存放数值 5 的那块内存就被丢弃了。最终 Python 会通过垃圾回收机制，把没有引用指向的内存回收、清空。机制讲完后，教师宣布休息 5 分钟。
