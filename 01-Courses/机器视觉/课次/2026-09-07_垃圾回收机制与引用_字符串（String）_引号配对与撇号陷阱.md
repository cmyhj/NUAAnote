## 关键概念

- **垃圾回收机制与引用**：变量名是指向内存数值对象的引用。重新给变量赋值时，Python 不在原地址上擦除内容再写入新值（那样效率低），而是另分配一块地址放新值并让引用指向新地址，原内存失去引用后由垃圾回收机制回收清空。
- **字符串（String）**：字符串是由字符构成的序列，并被当作一个整体处理。字符包括字母、数字、标点符号、空格和其他特殊字符，可对照 ASCII 编码表；字面值必须用一对双引号或一对单引号括起，不能混用。
- **引号配对与撇号陷阱**：字符串内容若含单引号，外部要用双引号；若含双引号，外部用单引号。若是单引号括起的字符串中包含撇号，Python 会把第一个单引号与撇号之间的内容视为字符串，余下文本被当作代码，从而引发语法错误——因为撇号与单引号在键盘上是同一个键。
- **索引与反向索引**：字符串在内存中顺序存储，可用下标索引每个字符，下标从 0 开始。Python 还支持从右向左的负数索引，最右端字符的索引是 −1，向左依次为 −2、−3。
- **切片与左闭右开**：切片 str[m:n] 表示从第 m 个字符开始、到第 n−1 个字符结束（包含第 n−1 个字符），即左闭右开。m 与 n 均可省略（省略 m 默认从 0 开始，省略 n 默认到最右端，全省略即整个字符串）；两个冒号的第三个参数为步长，默认为 1，可为 −1 表示反向取值（实现字符串反转）。
- **索引不可越界，切片可以越界**：单个字符索引越界会报错并返回 IndexError: string index out of range；但切片允许越界——左索引过小则从字符串首字符开始，右索引过大则一直到字符串结尾，不报错。
- **不可变对象与可变对象**：字符串不可修改，不能通过索引赋值改变其中某个字符，只能通过索引或切片取出新值；列表则可以按索引修改元素值，这是列表与字符串最本质的差别。
- **列表（List）**：Python 中接触最多的对象，是有序序列，元素可以为任意类型且不要求类型一致（可同时放整型、字符串、元组，甚至嵌套列表、字典）。语法用中括号括起元素，元素之间用逗号分隔，下标同样从 0 开始。
- **split 与 join**：split 把字符串按分隔符拆成由子串组成的列表（字符串→列表）；join 把列表中的子串用分隔符连接成一个字符串（列表→字符串），任何字符都可作分隔符。这两个方法是后续编程必须掌握的方法。
- **列表切片赋值与元素个数约束**：连续分片（步长为 1）赋值时，Python 采用诊断替换的方式，两侧元素个数不必相同，也可以用空列表替换某一片段实现删除；而步长不为 1 的切片进行修改时，两侧元素个数必须一致。

## 要点详述

### 一、垃圾回收机制的形象化复习（00:00-04:47）

教师用炒菜作类比来讲解计算机运行代码的过程：人相当于操作者，案板上的食材相当于硬盘中的数据，灶台相当于 CPU，灶台上放一口锅，锅就相当于内存（RAM）。案板上有很多烹饪材料，材料要先处理好放进锅里，才能被厨师炒——对应到程序里，就是数据要先从硬盘读入内存，才能被 CPU 处理。整个炒菜的平台（灶台）就是执行单元。

接着回到变量赋值。给 n 变量赋值 5，相当于在内存条上找一个地址，把 5 放进去；随着计算要求，再给 n 赋值 7。教师比较了两种做法：一种是把原来地址里的内容擦除，再放一个 7 进去，但这样执行效率很低；执行效率高的做法是另找一块地址，把 7 放进去，此时 7 已经"在锅里"，而 5 就不再需要了，直接抛弃即可。这就是垃圾回收机制，这样的效率比较高。

### 二、字符串的引入与定义（04:47-09:45）

教师先小结：此前讲了整型、浮点型以及它们的运算符、优先级。随后进入字符串变量。他强调字符串变量在程序中不可缺少，尤其在机器学习或深度学习研究中，因为要大量处理样本、大量"梳理"样本，训练集与测试集的标签都涉及字符串。他举例：做天气预测、学生性格分析这类任务时要收集很多样本，样本的某个特征如姓名、年龄、爱好、读哪些书、看哪些电影等，都要用文本去描述并据此分类或分析性格。因此样本有时候是文本，有时候是图像，有时候是语音；而语音本质上最后也要转化成信号，这些信号又可能用文本形式或 01 的形式（数值形式）描述。所以在接触深度学习或神经网络学习的过程中，样本通常都以字符串的形式描述，包括在文件里面。字符串在深度学习、神经网络程序以及图像处理过程中非常常见。

字符串的定义：字符串是由字符构成的一个序列，并且被看作一个整体。这里的字符是所有的字符，包括字母、数字、标点符号、空格和其他特殊字符，可以参照 ASCII 编码表。例如姓名是字符串，数字加上引号之后也成了字符串，一整句话也是字符串。

引号规则有三点。第一，字符串的字面值用双引号或单引号括起，必须有引号而且必须配对，不能混合使用。第二，如果字符串中含有单引号，则外部需要用双引号；如果内容含双引号，外部就用单引号，要看具体情况。第三，在单引号括起的字符串中，如果包含撇号就会导致错误——Python 会把第一个单引号和撇号之间的内容视为一个字符串，进而把余下的文本视为 Python 代码，从而引发错误。教师现场演示：外面本身就是单引号，内容里再出现一个撇，程序就分不清哪里是字符串边界并报错；原因在于撇号和单引号在键盘输入时是同一个键。

### 三、索引、切片与不可修改性（09:47-16:48）

字符串支持切片和索引：可以通过切片与索引获得字符串的子串，或寻找某个子串在字符串中的位置。

切片语法为：字符串后面加中括号，括号内是两个数字、中间用冒号分隔，表示从第 m 个字符开始到第 n−1 个字符结束的所有字符，包含第 n−1 个字符。教师举了一个长度为 11（含两个空格，空格也占字符位）的字符串为例，其索引从 0 到 10；例如取索引 2 到 7 的切片，得到从索引 2 开始的字符直到索引 6。随后抛出讨论题：当 m 大于等于 n 时会得到什么？请同学探讨。

查找方面，find 在字符串中从左向右寻找某子串第一次出现的位置，rfind（带 r，即 right 的意思）则从右向左寻找，找不到则返回 −1，返回的是索引值。

字符串在内存中是顺序存储的，可以使用下标索引每一个字符，索引下标从 0 开始。关键限制是：不可对字符串的索引赋值，字符串中的字符无法直接修改。也就是说不可以通过索引去改某个字符的值，这是不允许的；只能对它进行切片或索引，得到的都是新的值，而它本身的值不会改变。

反向索引：除正向索引外，Python 还支持从右向左使用负数索引，最右端字符的索引值是 −1，其左边是 −2，以此类推。教师以同一个 11 字符的字符串为例演示从右向左索引，例如取 −9 到 −2 的切片，同样遵循不包含右端点的规则，即包含 −9、到 −3 结束，说明切片是左闭右开的。

切片的默认边界：切片表达式中 m 和 n 任何一个边界都可以省略，甚至可以都省略。省略 m 即左边的边界没了，默认从 0 开始；省略 n 则默认到最右边；两个都省略，得到的就是整个字符串本身。

索引与切片的越界行为差别是本节的重点结论：Python 不允许字符串的单个字符索引越界，但允许切片索引越界。教师以 6 个字符的字符串（Python 一词）为例：合法索引是 0 到 5，反向是 −1 到 −6，如果写 7 或 −7 都会返回报错，因为长度只有 6，最小也只能到 −6。但切片可以越界：如果左索引过小，切片会从这个字符串的首字符开始；如果右索引过大，则一直到字符串结尾，例如从索引 2 切到 100，会得到从下标 2 到结尾的全部内容而不会报错。

### 四、字符串操作与 Python 的核心对象（16:51-18:28）

字符串的常用操作有三类。第一是拼接，直接用加法；第二是复制，把字符串乘 n（或 n 乘字符串），相当于把该字符串进行 n 次拼接；第三是成员判断，用 in 判断某个字符或子串是否在字符串中，即判断它是否为该字符串的子串，是则返回 True，不是则返回 False。教师总结：字符串的操作中，用得最多的是拼接、复制以及判断子串是否在字符串中。

随后引出 Python 的对象体系：Python 的对象用于代表一种数据类型的任意实例，其核心对象是数值、字符串、列表、元组和文件。教师给出直观印象：列表就是一个括号里有很多用逗号隔开的元素；元组是一个圆括号里的一些值（转写中亦作"原组"）；文件则是文本文件或二进制文件。后面会继续给出直观展示。

### 五、代码验证：索引、越界、切片与步长（18:49-27:42）

教师在 Jupyter 中演示。定义一个字符串变量，首先用 type 函数查看它的类型，输出为字符串类型；教师强调 type 在后续会经常用到——拿别人的代码来修改或改进时，不清楚某个量是什么类型，可以加一个 type 查看。

索引验证：对字符串取下标 0，得到第一个字符（小写字母）；取 −2，得到倒数第二个字符。随后演示越界：取一个超出范围的索引，程序报错，提示索引超出范围（string index out of range），说明字符索引不能越界；教师现场数出该字符串的反向索引范围，指出在范围内的负数索引有值，一旦超出范围就报错。

最后演示不可修改性：直接对字符串按索引赋值（例如把第三个索引的字符改掉），程序报错，说明字符串不能进行索引赋值修改，只能做索引和切片来取子串。

### 六、列表的定义、方法与与字符串的区别（28:09-34:31）

教师小结字符串部分：讲了索引、切片以及字符串的操作，其中用得最多的是拼接、复制、判断子串是否在字符串中。随后进入列表，指出在 Python 处理中接触最多的对象就是列表。

列表是 Python 中的一个有序序列，其中的对象可以是任何类型，并且不要求类型必须一致：可以放整型，也可以放字符串、元组，甚至可以放列表，还可以放后面要讲的字典。语法是使用中括号把所有元素括起来，元素之间用逗号隔开；如果元素本身是列表，则内部的列表要用方括号括起来。示例中一个列表里同时出现两个浮点型和一个字符串，说明元素类型可以不一致。

列表的元素可以使用下标索引，下标序号同样从 0 开始，与字符串一致。

列表常见操作逐一说明：第一是求元素个数，用 len 函数（英文单词 length 的缩写）；第二是求最大值，但这要求列表中的元素都是可比较的，即元素类型要一致——整型无法与字符串比较；第三是最小值，同样要求元素类型相同；第四是求和，要求元素类型必须都是数字；第五是统计对象首次出现的次数，类似 count 统计的意思；第六是获取某个对象首次出现的索引值，即 index；第七是逆序，用 reverse。教师顺势强调命名的直观性：定义函数、变量时要采用直观的名字，如 len 就是长度的意思。其余方法包括：清空列表用 clear；在末端插入对象用 append（"加入"的意思，后面会经常用到）；在末端插入新的列表用 extend（带有扩展的意思）；删除给定索引位置上的元素，直接调用相应函数并给出索引值；删除第一次出现的对象用 remove；在给定的索引位置上插入新的元素用 insert，给出索引值与要插入的元素，插入后剩下的元素依次后移；两个列表中间加号即可连接拼接，效果相当于在第一个列表后面扩展一个新列表；列表的重复用乘 n，把列表重复 n 次变成一个新的列表。

教师特别提醒最后一点：字符串和列表经常被混淆。字符串可以索引、可以切片，列表也可以索引、可以切片，唯一的差别在于列表可以根据索引修改元素值，也就是说列表是可修改的，而字符串不可修改。

列表的切片由冒号语法表示，得到子列表，用法与字符串切片非常类似：list[m:n] 表示下标从 m 到 n−1 的子序列；冒号两边都不写表示整个列表；冒号加后面的 m 表示从 m 开始到最右边界的所有元素；冒号加前面的 m 表示下标 m−1 之前的所有元素（不包括 m−1 之后的写法）。理解了字符串切片，列表切片就非常类似。

### 七、split 与 join 的工程意义（34:31-42:44）

教师强调 split 与 join 这两个方法是必掌握的，后续编程过程中一定会用到。split 是从字符串到列表：它把一个字符串拆成由子串组成的列表，例如一个字符串中间有逗号分隔的元素，用逗号进行剥离，最终得到一个列表。join 是从列表到字符串：将字符串的所有子串元素通过分隔符连接成一个字符串，例如对一个列表直接用逗号点 join，就可以用逗号把这些元素拼到一起。任何字符都可以做分割符：空白字符串由换行符、制表符和空格组成。

应用背景非常常见，且主要针对训练样本。第一个背景是文件命名。以分类任务为例，文件常用下划线命名，如 person_ok_00001.jpg、person_running_0001.jpg、cat_... 这类名字由"类别＋行为＋标号"构成。当只想分析类别或只分析行为时，从硬盘读到的是这些文件名，也就是一个字符串（含扩展名）。要取出行为，就对文件名字符串调用以 name 形式保存后按分隔符（下划线）分割的方法（split），得到的是一组子串，再按索引取出所需的那一项，例如取索引 1 就得到行为。这就是 split 在文件名解析中的典型用法。

第二个背景是目标检测的标注。对一张图像，检测出目标后要进行标定：以行人为例，需要得到它的左上角坐标 x、y 和宽高 w、h，代表它在这张图中的位置；如果图中还有一只猫，则同样有它对应的 x、y、w、h。这些标注好的训练集样本标签，通常以"类别，x，y，w，h"这样以逗号分隔的形式存起来，存放在 txt 文件中。从文件中读到的 label 往往就是字符串，而字符串不能参与运算，必须转换成列表（可索引、可修改值），再转换成数组或矩阵形式才能运算。因此读取时要按分隔符（逗号或分号等）调用 split。反过来，当需要把预测输出的值存成文件，或者把标注软件标注的结果存进 txt 文件时，就要调用 join，把列表形式的数据变回字符串写入文档。这就是为什么要把 split 与 join 单独拿出来讲。

### 八、代码验证：列表的修改、切片赋值与删除（42:44-52:08）

教师在 Jupyter 中演示列表操作。第一步创建列表：直接调用 Python 自带的 list 函数可以得到一个空列表，也可以直接用中括号定义一个空列表，或者定义一个变量并赋值一个空列表，有多种方法。

第二步查看列表长度与拼接：定义两个列表后可以把它们拼接，直接采用加号，效果相当于调用第一个列表的 extend 方法把第二个列表扩展进去；也可以对列表乘以 3 进行重复扩展。随后用 len 这个内置函数求列表长度（length 的缩写）。教师说明其工程意义：做训练时要清楚样本量有多大，样本通常都放在一个列表中，训练集是一个列表，训练集与测试集分别对应的标签也是列表。

第三步验证索引与可修改性：列表的反向索引与字符串一致，取 −1 得到最后一个元素，同样不能越界（因为索引一旦确定，越界就无法取值）。接着演示列表与字符串最不一样的地方——列表可以修改：把一个元素列表的第一个元素赋值为 100，运行后列表由原来的内容变为新值；这种赋值同样适用于切片，例如把索引从 1 到 3 之前的两个元素分别修改为 200 和 300，最终列表变为 100、200、300。

第四步演示分片替换：对于连续的分片（步长为 1），Python 采用诊断替换的方法，两侧的元素个数并不需要相同。例如列表中原有 11、12 两块，把这一片替换成 1、2、3、4 也可以，结果是前面的元素不变、中间的被替换、后面的元素仍然保留。基于这个方法还可以实现删除：用一个空列表对列表中某一块进行替换，就能把该片段删掉，只保留其余元素。

第五步演示步长分片：对于下标不连续、间隔不唯一的切片进行修改时，两侧的元素数量必须一致。例如以间隔为 2、从索引 1 开始的切片取到的是两个元素，那么替换时也必须是两个元素，这样才可以完成替换。

最后补充列表的删除与判断方法：Python 提供了根据索引删除列表中元素的方法（del），也可以删除间隔的元素，还可以对列表调用 reverse 反转；用 in 判断某个元素是否在列表中，不在则用 not in 返回 False；列表中可以包含不同类型的对象，甚至包含列表这样的嵌套结构；此外还有统计长度、统计某个值出现的次数、获取某个元素第一次出现的索引位置等方法（若不存在则会报错），以及向列表中添加元素的方法——做统计类任务时通常一开始建立一个空列表，一旦判断需要就向其中添加元素，这类操作会经常用到。
