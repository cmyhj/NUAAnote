## 关键概念

- **NumPy(ndarray)**: Python 生态中数据分析、机器学习与科学计算的基础库，本身由 C 实现，同样是纯 Python 代码做同量级计算时它更快。其核心数据结构是 N 维数组 ndarray。
- **广播机制(broadcasting)**: 数组与标量、或形状不同的两个数组之间运算时，NumPy 自动把较小的那一维（该维度必须为 1 或直接是标量）复制扩展到参与运算的形状。例：全部以英里为单位的数组乘 1.6 即得千米值。
- **逐元素运算(position-wise)**: 同尺寸矩阵间的加减乘除按对应位置元素逐个计算，与矩阵乘法是两回事。矩阵乘法必须用 `np.dot`，且相乘时内侧维度必须相等。
- **`axis` 参数**: 矩阵聚合时决定沿哪个方向求和/取极值，是图像处理中张量拼接、通道连接、级联等操作的常用参数。具体哪个数值对应行、哪个对应列要以实际代码结果为准。
- **reshape 与 $-1$**: 用于按需改变矩阵维度。把一个维度写成 $-1$ 时，NumPy 会根据元素总数自动推算该维度大小，无需手工计算。
- **均方误差(MSE, 均方差公式)**: 回归问题最常用的损失函数，形式为 $\frac{1}{n}\sum_{i=1}^{n}(y'_i-y_i)^2$，衡量预测值与真实值距离。NumPy 可整批向量化计算，不关心样本数是 1 还是 1000，只要两数组 size 相同。
- **梯度(gradient)**: 函数值增大最快的方向，其大小代表陡峭程度；一维退化为一元导数，高维对各个变量的偏导数构成梯度向量。梯度下降即沿梯度反方向寻找极小值。
- **梯度消失(vanishing gradient)**: 使用 Sigmoid 时，输入绝对值较大（如 $|x|>5$）后其导数趋近于 0，使权重参数几乎不更新、损失难以下降的现象。
- **激活函数**: 在纯线性变换之间插入的非线性函数，用于打断线性层之间的联系，使网络具备拟合非线性关系的能力。常见有 Sigmoid、Tanh、ReLU、Leaky ReLU。

## 要点详述

### NumPy 的定位与数组创建

上节课的重点对象是 Python 的字符串、列表、元组、字典、集合、函数定义、列表推导式与循环/判断结构。本节进入另一个工具：只要用 Python 做机器学习、深度学习或其他算法研究并要保证效率，NumPy 是绕不开的科学计算库。它是 Python 生态中数据分析、机器学习与科学计算的主力，极大简化了向量和矩阵的操作处理；SciPy、pandas、scikit-learn 等主要软件包都以 NumPy 作为架构的基础部分，会用 NumPy 也为处理这些库中的高级案例带来便利。NumPy 本身不是用 Python 写的，而是基于 C 的科学计算库，因此同等数据量、同等代码量下比纯 Python 更快。

创建数组的常规写法是 `import numpy as np`，随后 `np.array(...)` 传入列表得到一维数组；也可用 `np.ones`、`np.zeros`、`np.random` 直接初始化，只需传入要生成的元素个数，例如生成三个元素全为 1 或全为 0 的一维数组，或取值在 $0\sim1$ 之间的随机数组。

### 数组运算、广播与切片聚合

两个数组相加即对应元素相加（$1+1$、$2+2$……），加减乘除同理，都是逐元素进行。数组与单个数字之间也可以运算，即向量与标量运算：例如单位是英里的数组要换算成千米，直接乘 1.6 即可，效果等价于乘以一个同维度、元素全为 1.6 的数组——这就是广播机制。

索引与切片和 Python 列表一致：`data[0]` 是第一个元素，`data[:2]` 取索引 0、1，`data[1:]` 取从索引 1 到末尾（切片不必担心越界）。聚合功能包括 `max`、`min`（maximum/minimum 的缩写）、`sum` 求和，以及求平均值、`prod` 元素乘积、`std` 标准差。

### 二维数组、矩阵运算与索引切片

`np.array([[1,2],[3,4]])` 得到 $2\times2$ 的二维数组；`np.ones((3,2))`、`np.zeros`、`np.random` 传入的必须是**元组**，第一个数是行、第二个是列，即三行两列全 1、全 0 或随机值。尺寸相同的矩阵可以直接加减乘除，属于基于位置的运算；广播机制在这里同样成立，例如 $3\times2$ 矩阵加上行向量，相当于行向量在列方向被广播后逐元素相加。广播的前提是参与运算的一方某个维度为 1（只有一行或一列），且另一维度相同。

算术运算与矩阵运算的关键区别是：矩阵乘法要用 `np.dot`（每个矩阵都带有这个方法）。以 $1\times3$ 乘 $3\times2$ 为例，结果的每一个元素是一行与一列对应元素相乘再相加，最终得到 $1\times2$；乘法的前提是内侧维度相同（$3$ 与 $3$），不满足就不能相乘。

矩阵的索引与切片要用逗号区分维度：`a[0,1]` 表示行索引 0、列索引 1 的那个元素；`a[1:3]` 只给一个范围时默认作用在最前面的维度（行方向），取第 1、2 行；写成 `[:, 0]` 则意味着一列在列方向取索引 0，`[0:2]` 取 0、1 得到对应元素。要点是：索引时直接在一个方括号里给出行列；切片时若有逗号就按维度分别解释，没有逗号则默认在第一个维度上。

矩阵同样可做整体聚合（求最大、最小、求和），并且可以用 `axis` 参数实现跨行或跨列的聚合。这一参数在后续图像处理里经常出现，例如把两个张量或两张图像拼接、做通道连接与级联时都会用到。

### 转置、reshape 与 N 维数组的实际意义

处理矩阵的常见需求是转置，`.T` 直接得到转置结果，$3\times2$ 的矩阵变成 $2\times3$。更高级的情形需要改变特定维度的形状，例如模型对输入形状的要求与数据集不一致时，可用 `reshape`：把所需的新维度赋给它即可；把某个维度写成 $-1$，NumPy 会根据元素总数推算正确结果。例如 6 个元素可以 reshape 成 $2\times3$ 或 $3\times2$；若只确定需要 2 行，把另一维写成 $-1$ 也会自动算出 $2\times3$。

这一点有实际意义：在全连接网络中，$32\times32$ 的图像需要展平成 $32\times32=1024$ 长的列向量才能输入线性层，之后在中间层又可能变回矩阵形状。NumPy 可以在任意维度上完成这些操作，其核心数据结构因此被称为 N 维数组(ndarray)。增加一个新维度往往只需在构造函数里多加一个逗号，例如 `(4, 3, 2)` 表示 $4\times3$ 且有两个通道，配合 ones/zeros/random 就能构造三维数组。

### 均方误差：NumPy 的关键用例

用数组实现向量与矩阵的数学公式是 NumPy 的关键用例。以均方误差为例，它是机器学习处理回归问题的核心：回归希望预测值与真实值距离尽可能小，损失函数常取

$$\text{MSE}=\frac{1}{n}\sum_{i=1}^{n}(y'_i-y_i)^2$$

假设一次传入 100 个样本，网络输出 100 个预测值 $y'_1 \sim y'_{100}$，对应标签 $y_1\sim y_{100}$，两者都是列向量。用 NumPy 只需把预测值减标签、`np.square` 求平方、再求和除以 $n$ 即可，不必写循环。好处正是 NumPy 不关心预测值和标签里装的是 1 个值还是 1000 个值，只要 size 相同就能整批一次算完。课件例子中预测与标签各含三个值（$n=3$），直接得到平方和结果。

### 数据在数组中的表示：表格、音频、图像

需要处理的数据类型很多——电子表格、图像、音频等——其中大部分都适合用 N 维数组表示：

- **电子表格**是二维矩阵，每个工作表可看成一张表，表头是属性、列向下是属性的值，可以用 pandas 这类在 NumPy 之上构建的第三方库来操作。
- **音频与时间序列**：音频文件是一组样本，每个样本是一个数字，代表音频信号的一小部分。CD 质量音频每秒 44100 个样本，每个样本是 $-65535\sim65536$ 之间的整数；一段 10 秒的 CD 质量音频可加载成长度约 $10\times44100$ 的数组中，要提取某一段音频只需按切片取出。
- **图像**是高度乘宽度的像素矩阵。黑白图像每个像素用一个数字表示，通常 0 为黑、最亮为白；要裁剪左上角或图中某个区块，直接用 NumPy 的切片与索引即可。彩色图像是三维的（高、宽、通道），每个像素由红绿蓝三个数字表示，因此需要三维数组（每个单元格只能放一个数字），尺寸为“高 × 宽 × 3”。

### 为什么先讲深度学习基础，再讲 PyTorch

上节课提到的另一个工具是 PyTorch。要真正理解 PyTorch，必须先理解深度学习的基本原理：神经网络是怎么工作的、反向传播是什么样的机制；否则直接讲框架难以理解。课程随后的路线是：传统神经网络与线性回归 → 从线性到非线性（线性回归的局限性）→ 如何构建一个神经网络、需要哪些“配件” → 链式反向梯度求导 → 图像领域常用的卷积神经网络（卷积层与池化等功能层）→ 以手写数字分类(MNIST)为例的完整案例。

网络家族的发展脉络也被点明：从全连接网络开始，加入非线性激励后构成多层网络，随后发展出卷积神经网络(CNN)，再在神经网络中加入记忆得到循环神经网络(RNN)，加入记忆的遗忘与更新得到长短时记忆网络(LSTM)，并有序列到序列的结构。CNN 更多用于目标检测、目标分类、图像生成、视频分类，也用于增强学习（下围棋、象棋、扑克等）；当下多模态大模型场景下还用于图像描述与图像生成。本节课重点是“从线性回归到神经网络，再到卷积神经网络”，后续结构掌握原理后大同小异。

本节的学习目标有三条：一是理解从线性回归到非线性回归的转化；二是明白如何构建一个神经网络，了解不同激励函数的区别与联系；三是掌握各配件对神经网络性能的影响，包括损失函数、学习率、动量、过拟合，核心是“会调参”——构建网络人人都会，训练效果好不好主要看能否用好这些配件。

### 线性回归、梯度与参数更新

线性回归用线性关系描述输入到输出的映射，可用于网络分析、风险分析、股票预测、天气预报等。典型例子是目标方程

$$y = ax_1 + bx_2 + cx_3 + d$$

输入是 $x_1,x_2,x_3$，输出是 $y$，待求的权重参数是 $a,b,c,d$。问题是：手上有 $n$ 个样本（每个样本三个维度）及其标签值，要找到一组 $abcd$，使对几乎所有输入都能得到对应的 $y$。做法是让预测值与真实值之间的距离越来越小，通过优化方法循环迭代，使误差接近 0——这个过程就是线性回归。

理解优化前先理清三个层次：**导数**是曲线在某点的切线方向，如 $y=x^2$ 的导数为 $y'=2x$，$x=1$ 处为 2、$x=-1$ 处为 $-2$；**偏微分**针对高维函数，如 $z=y^2-x^2$ 对 $x$ 的偏导是 $-2x$、对 $y$ 的偏导是 $2y$（该处口述的符号待核对），在点 $(1,1)$ 处偏微分为 $-2$ 和 $2$；**梯度**是函数值增大的方向，代表陡峭程度，可以用箭头表示。以曲面为例，取值越大处梯度越大、方向朝外。

优化时采用梯度下降，即朝梯度的反方向走：对 $y=x^2$ 这类函数，若朝梯度正方向走函数值越来越大，要找到全局最小点就必须朝反方向走；推广到 $z=x^2+y^2$ 这样的碗状曲面，碗底往外都是梯度增大的方向，无论从哪个点出发都朝梯度下降方向逼近碗底。参数更新的写法是

$$m' = m - \eta \,\nabla m$$

其中 $\eta$ 就是学习率。完整流程是：随机初始化一组参数 → 代入数据求出预测值 → 对各参数求导 → 按更新公式逐步迭代 → 若损失已足够小则停止，否则继续寻找最低点。直观类比：把损失函数看作山的高度（也叫价值函数/损失函数，越小说明预测值与真实值越接近），山峰位置对应参数 $x,y$，山坡最低点就是目标参数。

梯度概念在图像处理里也有直接对应：图像的边缘处灰度与两侧明显不同，条纹状结构会出现中间高两侧低（或反之）的陡峭变化，找到梯度的方向就等于找到了图像中的线条——这也是后面讲边缘检测时传统图像处理算法要用到梯度的原因。

### 从线性到非线性：激活函数

多目标输出时，线性回归同样写成矩阵形式 $Y = WX + b$：$y$ 是 $1\times1$ 时 $W$ 为 $1\times3$、$b$ 为 $1\times1$；若输出变成 $2\times1$，$b$ 也必须是 $1\times2$ 或相应形状，$W$ 相应扩展为多列。（本处口述的维度数字前后不一致，具体形状安排待核对。）多目标还可以把多个损失任务合并，往往比单个模型效果更好。

线性回归的局限是明确的：对线性可分的问题，能找到一条直线把两组数据分开；但对非线性分布的数据，很难在原始维度上找到 $y=kx+b$ 这样的线把数据分开，直观上需要一个椭圆或圆环才能分开。现实中遇到的更多是非线性问题、非线性系统，于是要在 $x$ 乘 $W$ 之后、加偏置之前插入非线性激活函数。常见激活函数及其取舍：

- **Sigmoid**: $\sigma(x)=\dfrac{1}{1+e^{-x}}$，把输出映射到 $0\sim1$，在 $x$ 处于 $-5\sim5$ 之外的值几乎归零；好处是数值被压在 $0\sim1$，梯度下降效果明显，但致命缺点是**梯度消失**——由 $W' = W - \eta\,\Delta W$ 可见梯度 $\Delta W$ 趋近 0 时权重几乎不更新，损失也就不会有太大变化。
- **Tanh**: 与 Sigmoid 类似，但把所有输出映射到 $-1\sim1$，梯度衰减同样明显。
- **ReLU(修正线性单元)**: $x>0$ 时输出 $x$，$x\le0$ 时输出 0。它正向截断负值、不损失正向特征，计算比其他激活函数简单得多；因为保持正值输入处梯度为 1，能有效缓解 Sigmoid 在深层网络中的梯度消失问题。缺点是 ReLU 神经元在训练中可能出现“死亡”现象、永远不被激活，且它并非对所有数据和问题都最优——处理序列、文本时一般不用 ReLU，而处理图像时常用，因为图像像素值天然大于 0。
- **Leaky ReLU**: 与 ReLU 的区别在于 $x<0$ 时不是直接输出 0，而是乘一个系数 $k$（如 0.01）做衰减，从而避免神经元完全“死掉”。
