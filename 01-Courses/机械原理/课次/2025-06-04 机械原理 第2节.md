## 关键概念
- **静平衡（单面平衡）**：转子在一个平面内平衡，惯性力合力为0
- **动平衡（多面平衡）**：转子在多个平面内平衡，惯性力和惯性力矩都为0
- **平衡条件**：转子分布质量的静矩和为0，或惯性力总和为0
- **单面平衡**：当b/d < 1/5时，可简化为单面平衡
- **多面平衡**：当b/d > 1/5时，需要考虑多面平衡
- **惯性力**：转子旋转时产生的离心力
- **惯性力矩**：惯性力对某点取矩产生的力矩
- **轴向力偶**：两个大小相等、方向相反、不在同一直线上的力组成的力偶

## 要点详述

### 静平衡（单面平衡）
**概念**：转子在一个平面内平衡，惯性力合力为0。

**平衡条件**：
- 转子分布质量的静矩和为0
- 或惯性力总和为0
- Σm·r = 0（质量×半径的矢量和为0）

**应用条件**：
- 当转子宽度b与直径d之比b/d < 1/5时
- 可简化为单面平衡问题
- 例如：薄圆盘、风扇叶片

**平衡方法**：
- 在不平衡质量的对面添加平衡质量
- 或在不平衡质量的对面去除材料
- 使质心回到旋转轴线上

### 动平衡（多面平衡）
**概念**：转子在多个平面内平衡，惯性力和惯性力矩都为0。

**引入原因**：
- 当转子宽度b与直径d之比b/d > 1/5时
- 质量分布在不同平面内
- 单面平衡无法消除惯性力矩

**平衡条件**：
- 惯性力合力为0：ΣF = 0
- 惃性力矩合力矩为0：ΣM = 0
- 需要在两个平面内进行平衡

**应用条件**：
- 电机转子、汽车轮子、多缸内燃机
- 任何宽度较大的旋转部件

### 动平衡与静平衡的区别
**静平衡**：
- 只考虑惯性力的平衡
- 力平衡：ΣF = 0
- 力矩可能不平衡：ΣM ≠ 0
- 适用于薄圆盘类转子

**动平衡**：
- 同时考虑惯性力和惯性力矩的平衡
- 力平衡：ΣF = 0
- 力矩平衡：ΣM = 0
- 适用于宽度较大的转子

**判断标准**：
- b/d < 1/5：静平衡
- b/d > 1/5：动平衡

### 动平衡的力学基础
**力的平衡与分解**：
- 一个力可以分解为两个分力
- 分力的大小和方向取决于分解点的位置
- 力矩平衡：P1×l1 = P2×l2

**动平衡原理**：
- 将不平衡质量分解到两个平衡平面
- 在每个平面内分别进行平衡
- 使惯性力和惯性力矩都为0

**平衡计算**：
- 确定不平衡质量的位置和大小
- 选择两个平衡平面
- 计算每个平面需要添加的平衡质量

### 动平衡条件
**几何条件**：
- 转子宽度b与直径d之比b/d > 1/5
- 质量分布在不同平面内
- 不能简化为单面平衡

**物理条件**：
- 惯性力合力不为0：ΣF ≠ 0
- 惯性力矩合力矩不为0：ΣM ≠ 0
- 产生轴向力偶

**典型应用**：
- 电机转子：宽度较大，需要动平衡
- 汽车轮子：高速旋转，需要动平衡
- 多缸内燃机：多个气缸，需要整体动平衡
