## 关键概念
- **当量摩擦系数**：考虑接触面几何形状后的等效摩擦系数，Fv = Ff/N
- **楔形块摩擦**：Fv = f/sinα，α为楔形块倾斜角，增大接触面积可增大摩擦
- **螺旋副摩擦**：矩形螺纹Fv = f，非矩形螺纹Fv = f/cosβ，β为牙侧角
- **转动副摩擦**：Fv = f/√(1+f²)，考虑轴与轴承接触的几何特性
- **径向轴承**：载荷垂直于轴线的轴承，轴被"托起"转动
- **止推轴承**：载荷平行于轴线的轴承，轴被"抱住"转动
- **摩擦力矩**：摩擦力对转动中心的力矩，Mf = Ff·r
- **摩擦圆**：以ρ = fv·r为半径的圆，总反力必与摩擦圆相切
- **机械效率**：η = W输出/W输入 = P输出/P输入
- **串联系统**：总效率等于各部分效率之积，η总 = η₁×η₂×...
- **并联系统**：总效率等于各部分效率之和，η总 = η₁+η₂+...

## 要点详述

### 当量摩擦系数概念
当量摩擦系数是将复杂接触面的摩擦等效为平面摩擦的系数。基本思想：已知法向力N和摩擦力Ff，定义Fv = Ff/N，使其满足Ff = Fv·N的形式。

**物理意义**：通过改变接触面几何形状，可以在相同法向力下产生更大的摩擦力。例如：
- 平面摩擦：Fv = f（基本摩擦系数）
- 楔形摩擦：Fv = f/sinα（α为楔形角）
- 螺旋摩擦：Fv = f/cosβ（β为牙侧角）

**应用价值**：当量摩擦系数使得摩擦力计算统一化，便于工程应用。

### 楔形块摩擦
当滑块在V形槽中滑动时，接触面变为两个斜面，摩擦力增大。

**当量摩擦系数**：Fv = f/sinα，其中α为楔形块倾斜角。

**物理分析**：
- 法向力N分解为两个斜面的正压力
- 每个斜面的正压力为N/sinα
- 总摩擦力为2×f×(N/sinα) = f×N/sinα
- 当量摩擦系数Fv = f/sinα

**应用**：皮带传动、V带轮、制动器等。

### 螺旋副摩擦
螺旋副是将旋转运动转化为直线运动的机构，其摩擦特性与螺纹形状有关。

**矩形螺纹**：
- 接触面为水平面
- 当量摩擦系数Fv = f
- 摩擦力与平面摩擦相同

**非矩形螺纹**（三角螺纹、梯形螺纹等）：
- 接触面为斜面
- 当量摩擦系数Fv = f/cosβ，β为牙侧角
- 摩擦力增大，自锁性更好

**应用**：螺栓连接、螺旋千斤顶、丝杠传动等。

### 转动副摩擦
转动副是轴在轴承中转动的连接方式，其摩擦特性与接触几何有关。

**当量摩擦系数**：Fv = f/√(1+f²)

**物理意义**：
- 轴与轴承的接触为圆柱面
- 接触点处的法向力与摩擦力合成后，等效摩擦系数增大
- 适用于径向轴承和止推轴承

### 轴承分类
**径向轴承**：
- 载荷垂直于轴线（径向力）
- 轴被"托起"在轴承中转动
- 主要承受轴的重量或齿轮径向力

**止推轴承**：
- 载荷平行于轴线（轴向力）
- 轴被"抱住"在轴承中转动
- 主要承受齿轮轴向力或蜗杆推力

### 摩擦圆概念
摩擦圆是将力和力矩等效为偏移力的几何工具。

**基本原理**：
- 轴颈受力：径向力Q和力矩M
- 等效为偏移力Q'，偏移量h = M/Q
- 当h = ρ = fv·r时，Q'与摩擦圆相切
- 摩擦圆半径ρ = fv·r

**物理意义**：
- 摩擦圆表示摩擦力矩的作用效果
- 总反力必与摩擦圆相切
- 可简化受力分析，避免直接计算摩擦力矩

### 摩擦圆应用
**判断轴颈运动状态**：
- h = ρ：匀速转动或静止
- h > ρ：加速转动（动力矩 > 阻力矩）
- h < ρ：减速转动（动力矩 < 阻力矩）

**画摩擦圆步骤**：
1. 确定轴承中心和半径r
2. 计算当量摩擦系数Fv
3. 计算摩擦圆半径ρ = Fv·r
4. 画摩擦圆
5. 根据运动趋势确定总反力方向（与圆相切）

### 机械效率
**定义**：机械效率η = W输出/W输入 = P输出/P输入

**能量关系**：
- 输入功 = 输出功 + 损耗功
- W输入 = W输出 + W损耗
- η = W输出/W输入 < 1

**影响因素**：
- 摩擦损耗：最主要因素
- 振动、噪声等其他损耗
- 启动和制动阶段损耗更大

### 机械效率计算
**串联系统**：
- 效率依次相乘：η总 = η₁×η₂×...×ηₙ
- 总效率小于任何单个效率
- 例如：齿轮传动链，每级效率0.95，三级效率 = 0.95³ ≈ 0.857

**并联系统**：
- 效率按功率分配加权平均
- 简化情况：η总 = η₁+η₂+...+ηₙ（各支路功率相等时）
- 总效率高于任何单个效率

**应用**：
- 串联系统：多级齿轮减速器、传动链
- 并联系统：多路传动、功率分流
