## 关键概念
1. **工艺尺寸链**：由相互联系的尺寸在零件加工过程中形成的封闭尺寸组合
2. **封闭环**：在加工过程中间接获得的尺寸（不能直接测量，需要通过计算得到）
3. **组成环**：在加工过程中直接获得的尺寸（可以直接测量或查表得到）
4. **增环**：尺寸闭合时同向增加的环（在封闭环方程中用“-”表示）
5. **减环**：尺寸闭合时反向减少的环（在封闭环方程中用“+”表示）
6. **被包容表面**：加工后表面被包在内部的表面（如轴的外圆），采用入体原则
7. **包容表面**：加工后表面包住内部的表面（如孔的内圆），采用出体原则

## 要点详述

### 工艺尺寸链的基本概念
**封闭环与组成环的区别**：
- 封闭环：间接获得的尺寸，例如毛坯尺寸、某些中间过渡尺寸
- 组成环：直接获得的尺寸，例如已加工表面的尺寸、可以查表得到的公差

**判断方法（傻瓜式判断法）**：
1. 设想某个环增大（或减小）
2. 观察封闭环是增大还是减小
3. 如果封闭环也增大 → 该环为增环（用“-”表示）
4. 如果封闭环减小 → 该环为减环（用“+”表示）
5. 口诀：同向为减环，反向为增环

**尺寸链方程**：
- 封闭环的基本尺寸 = Σ中环基本尺寸 - Σ减环基本尺寸
- 封闭环的上偏差 = Σ中环上偏差 - Σ减环下偏差
- 封闭环的下偏差 = Σ中环下偏差 - Σ减环上偏差
- 封闭环的公差 = Σ组成环的公差

### 被包容表面与包容表面的尺寸标注
**被包容表面**（轴的外圆、板的厚度等）：
- 入体原则：以实体为基准
- 上偏差 = 0
- 下偏差 = 负值（实际尺寸 ≤ 基本尺寸）
- 标注形式：基本尺寸 +0/-值

**包容表面**（孔的内圆、槽的宽度等）：
- 出体原则：以空间为基准
- 上偏差 = 正值（实际尺寸 ≥ 基本尺寸）
- 下偏差 = 0
- 标注形式：基本尺寸 +值/-0

### 尺寸链计算步骤（举例：轴的加工工艺）
**已知条件**：
- 轴的直径：50mm
- 公差等级：IT5
- 表面粗糙度：Ra0.04μm
- 加工工艺：出车 → 半径车 → 高频淬火 → 氮化 → 研磨

**计算过程**：
1. **查表得出各工序余量和公差**：
   - 出车：余量4.5mm，公差IT13
   - 半斤车：余量1.1mm，公差IT11
   - 触摸：余量0.3mm，公差IT8
   - 要筋膜：余量0.1mm，公差IT6
   - 研磨：余量0.01mm，公差IT5

2. **从后往前反推（逆推法）**：
   - 研磨后尺寸 = 50.00mm
   - 要筋膜后尺寸 = 50.00 + 0.01 = 50.01mm
   - 触摸后尺寸 = 50.01 + 0.3 = 50.31mm
   - 半斤车后尺寸 = 50.31 + 1.1 = 51.41mm
   - 出车后尺寸 = 51.41 + 4.5 = 55.91mm ≈ 56mm（毛坯尺寸）

3. **各工序尺寸公差计算**：
   - 每道工序的尺寸公差 = 该工序的制造公差
   - 例如：出车后尺寸公差 = IT13对应的数值

### 特殊情况说明
**封闭环的极限尺寸计算**：
- 最大极限尺寸 = Σ中环最大尺寸 - Σ减环最小尺寸
- 最小极限尺寸 = Σ中环最小尺寸 - Σ减环最大尺寸

**公差的叠加规律**：
- 封闭环的公差等于所有组成环公差的代数和
- 这是因为尺寸链中的误差会相互叠加

**实际应用注意事项**：
1. 先画出尺寸链图，标明各环的方向（增减）
2. 明确哪些是封闭环（要求求解的），哪些是组成环（已知的）
3. 应用被包容/包容表面的入体/出体原则
4. 计算时注意正负号的正确使用
5. 验证结果的合理性（如毛坯尺寸应大于成品尺寸）
