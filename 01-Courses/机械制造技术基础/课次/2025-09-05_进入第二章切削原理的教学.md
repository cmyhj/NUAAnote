## 要点详述

### 一、切削运动回顾（01:18–07:10）

**切削运动 = 主运动 + 进给运动 + 辅助运动**

| 运动类型 | 定义 | 举例 |
|---------|------|------|
| 主运动 | 速度最高、消耗功率最大的运动，一般只有1个 | 车外圆时工件旋转 |
| 进给运动 | 配合主运动，连续切除多余材料的运动 | 车外圆时刀具轴向移动 |
| 辅助运动 | 实现机床各种辅助功能 | 退刀、换刀、切线等 |

> **主运动决定刀具角度的标注**——判断前角、后角、切削平面时，首先确定主运动方向。

**三种表面**：
- **待加工表面**：即将被加工的表面
- **已加工表面**：已经加工完成的表面
- **过渡表面**（加工表面）：正在被切削的表面——**过渡表面 = 加工表面**，只是不同说法

> 标注题时，三种表面 + 刀具角度至少考 **10–15 分**。

### 二、切削三要素（07:10–12:06）

这是**填空/简答必考**内容，每年送分题。

**① 切削速度 v_c**：
v_c = π × d × n / 1000（单位：m/min）
- d = 工件最大直径（mm）
- n = 转速（r/min）
- 计算时取最大直径（虽然不同半径处速度不同，但差异很小，近似处理）

**② 进给量 f**：
- 工件每转一转，刀具沿进给方向移动的距离（mm/r）

**③ 背吃刀量 a_p**：
- 已加工表面与待加工表面之间的垂直距离（mm），即切削深度

**切削区域几何关系**：
- 切削层截面近似为平行四边形
- **A_c = a_p × f = a_w × a_c**（四个量考 2 个，三年至少考两次）

**加工策略**：
- **粗加工**：以效率为主 → 大的 a_p 和 f，低的 v_c
- **半精加工/精加工**：以质量为主 → 小的 a_p 和 f，较高的 v_c

> 例题约 **5 分**，"小学算术题"——只要理解切削概念，计算本身很简单。

### 三、刀具结构——三面两刃一尖（12:06–16:55）

教师用实物刀具进行了直观展示。

| 结构 | 名称 | 定义 |
|------|------|------|
| **三面** | 前刀面 A_γ | 切屑流过的表面 |
| | 主后刀面 A_α | 与过渡表面相对的表面 |
| | 副后刀面 A_α' | 与已加工表面相对的表面 |
| **两刃** | 主切削刃 | 前刀面与主后刀面的交线 |
| | 副切削刃 | 前刀面与副后刀面的交线 |
| **一尖** | 刀尖 | 主、副切削刃的交点 |

> 刀具角度标注的本质：将刀具"切开"（剖面），从截面中观察前角和后角的大小。

### 四、三个辅助平面（16:55–18:50）

为了测量和定义刀具角度，需要建立三个辅助平面。

**切削平面 P_s**：过切削刃上选定点，与**加工（过渡）表面相切**的平面
- 主运动速度方向一定在这个平面内

**基面 P_r**：过切削刃上选定点，与**主运动速度方向垂直**的平面

**正交平面 P_o**（法剖面）：同时**垂直于切削平面和基面**的平面

> 三个平面互相垂直，构成正交坐标系。前刀面和后刀面是刀具上实际存在的面，而切削平面、基面、正交平面是通过相对运动关系定义的虚拟面。

**正交平面的存在意义**：从刀具的正面视图中，前角和后角"叠在一起"看不清楚——需要将刀具沿主切削刃方向"剖开"，在正交平面截面中才能清楚看到前刀面和后刀面的俯仰状态。

### 五、刀具标注角度定义（18:50–34:50）

#### 前角 γ_o（18:50–21:24）

- **定义**：在正交平面内测量的**前刀面与基面的夹角**
- **物理意义**：反映前刀面是"翘起来"还是"凹下去"
  - γ_o > 0（正前角）：前刀面在基面之下 → 切屑"往上勾"
  - γ_o < 0（负前角）：前刀面在基面之上 → 挤压切屑
  - γ_o = 0：前刀面与基面重合

> "为什么要定义前角？因为前刀面到底是翘起来了还是凹下去了，直接影响切削效果。"

#### 后角 α_o（21:24–24:09）

- **定义**：在正交平面内测量的**主后刀面与切削平面的夹角**
- **物理意义**：反映主后刀面是否与加工表面"干涉"
  - α_o > 0（正后角）：后刀面在切削平面之外，不干涉 → 正常切削
  - α_o < 0（负后角）：后刀面凸入切削平面 → 干涉 → 无法正常切削
  - α_o ≈ 0：后刀面几乎与切削平面相切

> 后角一般为正值。特殊情况：微量负后角（1–2°）用于抑制切削振动。

#### 主偏角 κ_r（24:09–33:00）

- **定义**：在基面内测量的主切削刃投影与进给方向的夹角
- **物理意义**：影响**切削力的方向分配**
  - κ_r 大（接近 90°）：切削力主要沿轴向 → 适合**细长轴**加工
  - κ_r 小：切削力有较大的径向分力 → 容易导致工件弯曲变形

> **常考题**：车削细长轴时应选用较大还是较小的主偏角？（答：较大主偏角，因为细长轴刚性弱，径向力大会导致弯曲。）

#### 副偏角 κ_r'（29:19–33:00）

- **定义**：在基面内测量的副切削刃投影与进给反方向的夹角
- **物理意义**：主要影响已加工表面质量（影响残留面积高度）

#### 刃倾角 λ_s（33:00–34:50）

- **定义**：在切削平面内测量的主切削刃与基面的夹角
- **符号**：刀尖为最高点时为正，刀尖为最低点时为负
- **物理意义**：控制切屑流出方向

### 六、正负前角/后角的物理意义（34:50–39:44）

| 角度 | 正值 | 负值 |
|------|------|------|
| 前角 γ_o | 前刀面在基面下方 → 切削顺畅，适合加工塑性金属 | 前刀面在基面之上 → 挤压切削，适合加工脆性材料（如铸铁） |
| 后角 α_o | 正常切削（几乎总是正值） | 后刀面干涉 → 无法正常工作 |

> 负前角刀具常用于加工脆性材料：通过挤压使脆性材料表现出塑性变形特性，切削效果更好。
