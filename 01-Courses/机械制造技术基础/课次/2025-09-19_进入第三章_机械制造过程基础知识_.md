### 二、机床的基本概念（02:20–08:40）

**机床 = 工业母机**

- 金属切削机床简称机床，是制造机器的机器
- 又称"工业母机"或"工具机"

**机床分类体系**：

| 分类依据 | 分类 |
|---------|------|
| 加工性质 | 12 大类（车/钻/镗/磨/齿轮/螺纹/铣/刨/拉/电/锯/其他） |
| 通用性 | 通用机床 → 专门化机床 → 专用机床 |
| 精度 | 普通 → 精密 → 高精密 |
| 尺寸/重量 | 普通/大型/重型/超重型 |

**型号编制方法**（了解即可，不考）：
类代号（拼音大写） + 通用特性代号 + 组别 + 主参数 + 设计序号

### 三、数控机床与三大数控系统（08:40–18:30）

教师以自己在国外使用的五轴联动机床为例，介绍了现代数控机床的关键技术：

**对刀过程**：
1. **激光对刀**：通过激光束遮挡/恢复来测量刀具的长度和直径
2. **雷尼绍探头**：用红宝石探头触碰工件表面，确定工件的三维坐标位置
3. 系统自动进行刀具补偿

**三大数控系统**：

| 系统 | 国家 | 特点 |
|------|------|------|
| **西门子 SINUMERIK** | 德国 | 操作友好，应用最广泛 |
| **海德汉 Heidenhain** | 德国 | 五轴加工性能优异 |
| **法兰克 FANUC** | 日本 | 稳定可靠 |

> 五轴联动加工需要大量坐标变换和实时补偿运算，对数控系统的计算能力要求极高。

### 四、机床的基本组成（18:30–25:20）

| 组成部分 | 功能 | 示例 |

### 五、外圆车削加工（25:20–50:50）

**车削的地位**：
- 盘套类零件外圆加工**最主要的工序**
- 加工费时最多的工序
- 过程平稳、效率高、适应性广

**零件分类**（6 类）：轴类、套类、支架类、箱体类、六面体类、特殊零件类

**车床类型**：

| 类型 | 特点 |
|------|------|
| 卧式车床 | 最常用，工件水平夹持 |
| 立式车床 | 工件垂直夹持，适合大型盘类 |
| 转塔车床 | 多把刀具顺序加工，提高效率 |
| 自动/半自动车床 | 批量生产 |
| 仿形车床 | 样板仿形加工 |
| 专门化车床 | 如曲轴车床 |

**车刀类型**：

| 结构类型 | 特点 |
|---------|------|
| 整体式 | 整体高速钢制造，可磨得锋利 |
| 焊接式 | 硬质合金/高速钢刀片焊接，结构紧凑 |
| 机夹式 | 避免焊接应力，刀杆利用率高 |
| **可转位** | 刀片快速转位，生产率最高（现代主流） |

**工件装夹方式**：

| 方式 | 适用场景 |
|------|---------|
| 三爪卡盘 | 规则圆柱形，自动定心，装夹迅速 |
| 四爪卡盘 | 不规则形状，各爪独立调节 |
| 花盘 | 单件小批量复杂/不规则形状 |
| 顶尖 | 增加细长轴刚性，配合卡盘使用 |
| 心轴 | 套筒类零件外圆加工，避免夹紧变形 |

**车削精度**：
- 粗车：IT13–IT11，Ra 12.5–50 μm
- 半精车：IT10–IT8，Ra 3.2 μm
- 精车：IT8–IT7，Ra 0.8 μm
- 单晶金刚石车：可达纳米级镜面加工
