## 关键概念

- **切削力经验公式 (p-β 公式)**: 切削力 F 与切削深度 ap、进给量 f、切削速度 v 之间的指数关系，形如 F = C * ap^x * f^y * v^z
- **对数线性化**: 将指数关系取对数转化为线性形式 logF = logC + x*log(ap) + y*log(f) + z*log(v)，便于通过直线拟合求参数
- **单因素实验法**: 固定其他参数，只改变一个因素（如 ap），获取该因素对切削力的单独影响
- **截距 (a)**: 在对数坐标中，当 x=0（即该因素值为1）时的纵坐标值
- **斜率 (b)**: 在对数坐标中直线的斜率，即该因素的指数

## 要点详述

### 微型块自由度回顾

- 短微型块限制两个移动自由度（左右和上下，即沿 Z 和 X 方向）
- 长微型块限制除了沿轴线旋转和移动之外的自由度
- 两个短微型块组合相当于一个长微型块
- 套筒结构类似，限制除轴线旋转和移动外的自由度
- 顶尖组合：一端限制两个移动和一个转动，配合端限制两个移动，带披口一端限制全部自由度（含轴线移动）

### 切削力公式与数据处理

本节课核心是切削力实验的数据处理方法。切削力的一般形式为：

F = C * ap^x * f^y * v^z

处理步骤：
1. 对原公式两边取对数：logF = logC + x*log(ap) + y*log(f) + z*log(v)
2. 进行单因素实验，例如固定 f 和 v，只改变 ap，得到曲线
3. 在对数坐标系中，该曲线变为直线，其斜率为 x（ap 的指数），截距对应其他参数固定时的综合贡献
4. 同理可得 y（f 的指数）和 z（v 的指数）
5. 通过两条单因素曲线的交点（共同点）或简单平均，得到统一的系数 C

**关键易错点**:
- 读截距时，x=0 对应的是该因素值为 1（即 ap=1, f=1, v=1）时的值，而非图表上原点位置
- 由于曲线并非理想直线，拟合会有误差，因此两个单因素曲线算出的 C 值可能不同，需要取平均
