## 要点详述

### 一、平面加工方法概述（01:06–03:42）

| 方法 | 特点 |
|------|------|
| 车端面 | 工件旋转，刀具径向移动，适合盘类零件 |
| **铣削** | 最广泛的平面加工方法，效率高 |
| 刨削 | 刀具直线往复运动，适合单件小批量 |
| 拉削 | 一次行程成型，效率高但拉刀成本高 |
| 磨削 | 精加工，精度最高 |

### 二、铣削加工（03:42–10:20）

**铣床运动分析**：
- **主运动**：铣刀旋转（高速，可达 1–2 万转/分）
- **进给运动**：工件或铣刀的直线移动

**铣床类型**：

| 类型 | 特点 |
|------|------|
| 卧式升降台铣床 | 主轴水平，工作台可升降/左右/前后移动 |
| 立式升降台铣床 | 主轴垂直，适合加工端面 |
| 龙门铣床 | 适合加工大型结构件 |
| 万能工具铣床 | 配备可倾斜工作台、分度头等 |

**铣刀类型**：整体式 → 机夹式 → 可转位式（现代主流，用完即弃或回收）

**铣削应用**：平面、台阶面、沟槽（U 型/V 型/T 型）、齿轮、成形面、切断、自由曲面（球铣刀）

### 三、圆周铣 vs 端铣（10:20–11:30）

| 方式 | 切削部位 | 加工表面 | 典型应用 |
|------|---------|---------|---------|
| **圆周铣** | 铣刀圆周上的刀齿 | 侧面 | 铣削沟槽侧面 |
| **端铣** | 铣刀端面上的刀齿 | 端面/平面 | 铣削平面 |

> 圆周铣加工侧面，端铣加工端面——考试可能考"什么是圆周铣/端铣"。

### 四、顺铣 vs 逆铣（11:30–15:57）⭐ 重点考点

| 特征 | **逆铣（Up Milling）** | **顺铣（Down Milling）** |
|------|----------------------|------------------------|
| 定义 | 切削速度方向与进给方向**相反** | 切削速度方向与进给方向**相同** |
| 切削厚度 | 从 **0 → 最大** | 从 **最大 → 0** |
| 刀具磨损 | 初期有滑擦→磨损较快 | 磨损较均匀 |
| 垂直分力 | 使工件**上台**→不利于夹紧 | 使工件**压下**→利于夹紧 |
| 水平分力 | 与进给方向相反→**消除丝杠间隙**，进给平稳 | 与进给方向相同→可能引起窜动 |
| 适用场景 | 一般情况下优先选用（进给平稳） | 工件刚性好、夹紧可靠时可用 |

**逆铣的特点**：
- 切削厚度从 0 逐渐增大
- 初始切入时有**滑擦**（刀刃在工件表面滑动），加剧磨损
- 垂直分力使工件上抬 → 不利于夹紧
- 水平分力与进给方向相反 → 消除丝杠间隙 → 进给平稳

**顺铣的特点**：
- 切削厚度从最大逐渐减小到 0
- 垂直分力使工件压向工作台 → 利于夹紧
- 水平分力与进给方向相同 → 可能引起工件窜动（需消除丝杠间隙）

> "顺铣和逆铣是考试常考内容，要么考你顺铣，要么考你逆铣。"
