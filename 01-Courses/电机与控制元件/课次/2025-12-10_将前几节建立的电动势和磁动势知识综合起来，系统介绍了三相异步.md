## 本节主线

本节课将前几节建立的电动势和磁动势知识综合起来，系统介绍了三相异步电动机内部的电磁关系。核心内容包括：主磁通与漏磁通的概念区分、定子与转子的电压平衡方程、转差率对转子频率和电动势的影响、以及定转子旋转磁动势在空间以同步转速同步旋转从而可进行矢量合成的关键结论。教师特别强调：**在电压和频率恒定时，异步电动机内部的主磁通基本恒定**——这一结论是分析电机运行特性的基础。最后通过一道绕线型异步电动机的例题，综合考察了转差率、转子电动势、转子频率等概念的计算。

## 要点详述

### 一、主磁通与漏磁通（00:58–05:11）

**主磁通**：
- 路径：定子铁芯 → 气隙 → 转子铁芯 → 气隙 → 定子铁芯
- 同时与**定子绕组**和**转子绕组**交链
- 是实现机电能量转换的媒介
- 设计良好的电机中，主磁通占总磁通的 **95% 以上**

**漏磁通**：
- 仅在定子侧（或转子侧）闭合，不与另一侧绕组交链
- 包括**槽漏磁**、**端部漏磁**等
- 不参与能量转换，设计时应通过工艺手段尽可能减小

### 二、定子电压平衡方程（05:11–11:22）

当定子绕组通入三相交流电后，旋转磁场在定子绕组中产生感应电动势（反电动势）：

**U₁ = E₁ + I₁ R₁ + j I₁ X₁**

其中：
- U₁ = 定子相电压
- E₁ = 定子感应反电动势（主磁通产生）
- I₁ R₁ = 定子电阻压降（很小）
- j I₁ X₁ = 定子漏抗压降

**反电动势公式**（来自 5.5 节）：

E₁ = 4.44 f₁ Φ N_eff k_w1

**重要结论** ≈ **恒压恒频下主磁通恒定**：
- 电源电压 U₁ 一定，频率 f₁ 一定
- 漏阻抗压降很小，可近似认为 U₁ ≈ E₁
- 因此 Φ ≈ U₁ / (4.44 f₁ N_eff k_w1) = **常数**

> "对于一个三相异步电动机来说，它内部的磁通密度是几乎不变的，这个结论很重要。"

**工程意义**：
- 电机设计时，磁路工作点通常选在磁化曲线的**拐点**附近
- 若电压过高 → 磁通过大 → 工作点进入饱和区 → 功率因数下降、效率下降

### 三、转差率与转子频率（14:50–17:25）

**同步转速**：n₀ = 60 f₁ / p（r/min）

**转差率**：s = (n₀ − n) / n₀

**转子频率**：转子感应电动势和电流的频率与转差率成正比

f₂ = s f₁

**额定运行状态**：
- s ≈ 0.01–0.05（很小）
- 例如：s = 0.01，f₁ = 50 Hz → f₂ = 0.5 Hz
- 转子电流频率很低（约 0.5–2.5 Hz）

**起动状态**（n = 0）：
- s = 1
- f₂ = f₁ = 50 Hz
- 转子频率等于定子频率

> "转差率很小，所以转子内部的感应电动势和感应电流的频率也很低。"

### 四、转子电压平衡方程（12:51–21:41）

**转子感应电动势**：

E₂s = s E₂

其中 E₂ 为转子静止（s=1）时的感应电动势。

**转子漏抗**：

X₂s = s X₂

**转子电压平衡方程**：

E₂s = I₂ (R₂ + j X₂s)

= s E₂ = I₂ (R₂ + j s X₂)

### 五、磁动势平衡——核心结论（22:30–32:51）

**定子旋转磁动势**：
- 由定子三相对称电流产生
- 转速 = 同步转速 n₀
- 旋转方向由电流相序决定

**转子旋转磁动势**：
- 转子感应电流也是三相对称的
- 相对于**转子本身**的转速 = 60 f₂ / p = s n₀
- 而转子本身以 n 旋转
- 所以转子磁动势相对于**空间**的转速 = n + s n₀ = (1−s)n₀ + s n₀ = n₀

**❗ 关键结论**：
- **定子旋转磁动势与转子旋转磁动势在空间上以相同速度（n₀）、相同方向旋转**
- 二者**相对静止**，因此可以进行矢量合成
- 合成磁动势产生主磁通

**磁动势平衡方程**：

空载时：转子电流为 0，只有定子产生磁动势 F₁₀
负载时：定子磁动势 F₁ + 转子磁动势 F₂ = F₁₀（合成磁动势不变）

**物理意义**：
- 电压和频率恒定时，合成磁动势（主磁通）**恒定不变**
- 负载增加 → 转子电流增大（转子磁动势增大）→ 定子电流自动增大以补偿（去磁→增磁）→ 合成磁动势保持不变

### 六、例题讲解（32:51–41:10）

**题目**：一台绕线型三相异步电动机
- 型号 Y280N-4（4 极，即 p=2）
- P_N = 75 kW，U_N = 380 V，Δ 接法
- n_N = 1485 r/min，f = 50 Hz
- cos φ_N = 0.88，η_N = 92.5%
- 转子开路电压 U₂₀ = 354 V（线电压），Y 接法

**求解**：

**① 转差率 s_N**：
同步转速 n₀ = 60 f / p = 60 × 50 / 2 = **1500 r/min**
s_N = (n₀ − n_N) / n₀ = (1500 − 1485) / 1500 = **0.01**（1%）

**② 转子每相感应电动势（额定运行时）**：
转子开路相电压：E₂ = 354 / √3 ≈ **204.4 V**
额定运行时：E₂s = s × E₂ = 0.01 × 204.4 ≈ **2.04 V**

**③ 转子频率 f₂**：
f₂ = s × f₁ = 0.01 × 50 = **0.5 Hz**

**④ 输入功率 P₁**：
P₁ = P_N / η_N = 75 / 0.925 ≈ **81.08 kW**

**⑤ 额定电流 I_N**：
P₁ = √3 × U_L × I_L × cos φ
I_L = P₁ / (√3 × U_L × cos φ) = 81080 / (√3 × 380 × 0.88) ≈ **140.0 A**

### 七、转子等效变换（44:14–48:40）

由于定子电路频率为 f₁，转子电路频率为 f₂ = s f₁，两者频率不同，直接分析不方便。

借鉴**变压器等效**的思路：
- 将**旋转的转子**等效为**静止的转子**
- 等效后转子电阻变为 R₂ / s
- 保证等效前后电磁关系和功率关系不变

经过等效变换后，定子和转子可以连接成统一的等效电路，便于分析电机的运行性能。
