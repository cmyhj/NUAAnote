## 要点详述

### 一、上节课结论回顾（01:20–03:54）

本节课开门见山，回顾了上一章的两个核心结论：

1. **电磁感应（发电机原理）**：导体切割磁感线会在导体两端产生感应电动势。对于电机而言，电枢旋转后，电刷两端会产生反电动势。
2. **电磁力（电动机原理）**：通电导体在磁场中会受到力的作用，产生电磁转矩。

这两个结论是本章分析所有电机运行特性的基础，教师强调"无论如何要把它搞清楚"。

### 二、他励直流发电机的空载特性（03:54–10:55）

**他励发电机的特点**：励磁绕组与电枢绕组各自独立供电，互不影响。

**空载特性的测试条件**：
- 原动机拖动发电机以恒定转速运行（如 1000 r/min）
- 电枢两端开路（负载电流 I = 0）
- 调节励磁电流 I_f，观察输出电压 U₀ 的变化

**空载特性曲线形状**：
- I_f = 0 时，理论上 U₀ = 0（因磁场为 0，感应电动势为 0）
- 随 I_f 增大，磁场增强，U₀ 逐渐上升
- 由于铁芯的磁化曲线存在饱和特性，U₀ 随 I_f 的变化趋势与磁化曲线一致，先线性增长后趋于饱和
- **剩磁影响**：实际铁芯中存在剩磁，因此 I_f = 0 时 U₀ 并不为 0，而是有一个小台阶（称为剩磁电压）

教师建议学生做实验时可验证：用原动机拖动他励发电机，在电枢两端接万用表或示波器，观察旋转时是否有电压产生。

### 三、他励直流发电机的外特性（12:56–20:36）

**外特性的定义**：在**转速 n 恒定**且**励磁电流 I_f 恒定（即气隙磁场恒定）** 的条件下，发电机输出电压 U 随负载电流 I 的变化关系。

**外特性推导**：
- 发电机等效电路：反电动势 E_a 经电枢电阻 R_a 后输出到负载
- 电压平衡方程：U = E_a − I_a R_a
- 转速恒定 → E_a 恒定（因 I_f 恒定 → Φ 恒定 → E_a = C_e Φ n 恒定）
- 空载时（I = 0）：U₀ = E_a
- 带载后：电流 I_a 在电枢电阻上产生压降，输出电压 U 降低
- 在额定点以内，U 随 I 近似线性下降

**超过额定点后**：由于电枢反应的去磁效应（弱磁作用），曲线会进一步向下弯曲。

### 四、电压调节率（20:36–25:12）

**定义**：
ΔU = (U₀ − U_N) / U_N × 100%

其中 U₀ 为空载电压，U_N 为额定负载电压。

**物理意义**：衡量发电机从空载到额定负载时电压的稳定程度。电压调节率越小，表示发电机带载能力越强，输出特性越"硬"。

**工程典型值**：
- 常规设计中，电压调节率通常设计为 5%–10%
- 优秀设计可达 2%–3%

**生活类比**：夏天用电高峰时，电网负载加重，电压降低，灯泡会变暗——这就是电压调节率在实际生活中的体现。现在电网供电能力强，这种现象已很少见。

### 五、例题讲解——他励发电机计算（26:17–36:46）

**题目数据**：
- 他励直流发电机
- U_N = 230 V，P_N = 16 kW，n_N = 1500 r/min
- 电枢电阻 R_a = 0.2 Ω
- 额定励磁电流恒定（磁场不变）

**第(1)问**：求额定状态下的空载电压 U₀。

**解题思路**：
1. 首先画出他励发电机的原理图，标注所有参数
2. 由额定功率和额定电压求额定电流：
   I_N = P_N / U_N = 16000 / 230 ≈ 69.57 A
3. 额定点电压平衡方程：E_a = U_N + I_N R_a = 230 + 69.57 × 0.2 ≈ 243.9 V
4. 空载时 I = 0，U₀ = E_a ≈ 243.9 V（转速不变 → E_a 不变）

**第(2)问**：当转速降为 n = 1200 r/min 时，求满载电压。

**解题思路**：
1. 磁场不变（I_f 恒定），E_a ∝ n
2. 额定转速下的 E_a(N) = 243.9 V（@1500 r/min）
3. 1200 r/min 时的反电动势：E_a' = E_a(N) × (1200/1500) = 243.9 × 0.8 ≈ 195.1 V
4. 满载时电流仍为 I_N = 69.57 A，则输出电压：
   U' = E_a' − I_N R_a = 195.1 − 69.57 × 0.2 ≈ 181.2 V

**延伸思考**（教师留给学生的思考题）：
- 在额定转速（1500 r/min）下，电压调节率是多少？
- 转速降为 1200 r/min 后，电压调节率又是多少？
- 两次的电压调节率是否相同？如果不同，为什么？

### 六、并励直流发电机（38:56–53:30）

**并励发电机的结构特点**：
- 励磁绕组与电枢绕组**并联**
- 励磁回路中串联有调节电阻，可改变励磁电流大小
- 输出电压同时加在负载和励磁绕组两端，两者电压相等

**自励建压过程**：
1. 原动机拖动转子旋转，由于铁芯中存在**剩磁**，电枢两端产生微小的感应电动势
2. 该电动势加到励磁绕组上，产生微小的励磁电流
3. 若励磁电流产生的磁场方向与剩磁方向一致（相叠加），磁场增强
4. 磁场增强 → 感应电动势增大 → 励磁电流进一步增大 → 磁场进一步增强
5. 如此正反馈，最终稳定在某一电压值（受磁路饱和限制），称为**可靠建压**

**若建压失败**：说明励磁电流产生的磁场与剩磁方向相反（抵消），此时只需将励磁绕组两个接头对调即可。

**临界电阻**：
- 并励发电机的励磁绕组电阻必须小于某一临界值，才能满足自励条件
- 临界电阻由空载特性曲线与励磁回路电阻线的交点决定
- 励磁电阻大于临界电阻 → 无法可靠建压
- 电枢电阻通常很小（零点几欧），而励磁绕组电阻通常在几百欧

**并励发电机的外特性**：
- 总电流 I = I_a（电枢电流）= I_f（励磁电流）+ I_L（负载电流）
- 电压平衡方程与电路拓扑相关，教师现场进行了推导
