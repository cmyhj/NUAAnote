## 本节主线

本节课是机械设计课程的**概论性补充**，在第一周绪论基础上系统介绍了机械零件设计的五大准则（强度、刚度、寿命、振动稳定性、可靠性），并延伸到散热设计、仿生表面织构等前沿工程话题。后半节课重点讲解了常用工程材料的分类与选用原则、零件的工艺性设计（铸造/焊接/切削加工注意事项），以及标准化、通用化、互换性在工程设计中的重要性。最后以减速器中的齿轮为例，分析了同一零件上不同表面的功能区分（工作表面 vs 连接表面）。

## 要点详述

### 一、零件的失效形式与设计准则（01:33–15:11）

**失效分析的核心逻辑**：分析零件可能的失效形式 → 确定对应的设计准则 → 选择极限应力 → 引入安全系数 → 得到许用应力。

#### 五大设计准则

| 准则 | 核心思想 | 典型应用 |
|------|---------|---------|
| **强度准则** | σ ≤ [σ] = σ_lim / S | 所有零件的基线要求 |
| **刚度准则** | 变形量 ≤ 允许变形 | 机床主轴（弯曲/扭转变形影响加工精度） |
| **寿命准则** | 预测磨损/腐蚀寿命 | 滑动轴承、齿轮接触疲劳（需实验数据+经验公式） |
| **振动稳定性** | 激励频率避开固有频率 | 高速旋转机械（如洗衣机滚筒柔性轴避开共振） |
| **可靠性准则** | 用概率方法保证可靠度 | 高安全要求场合（航空航天，串联系统可靠度相乘） |

#### 可靠性准则的深入理解

教师以**浴盆曲线**（Bathtub Curve）形象说明了产品全生命周期的失效率变化：

```
失效率
  ↑
  |  早期失效期    偶然失效期    耗损失效期
  |    (婴幼儿)      (青壮年)       (老年)
  |   /‾\            ___            /‾\
  |  /   \          /   \          /   \
  | /     \        /     \        /     \
  +----------------------------------------→ 时间
```

- **早期失效期**：设计/制造缺陷导致（"早夭"）
- **偶然失效期**：平稳运行期，失效率最低且恒定
- **耗损失效期**：磨损/疲劳累积导致失效率急剧上升

> "世间万物都是这样的——人岁数大了，身体自然会出问题。你们现在是最抗打的时候。"

串联系统的可靠度：R_系统 = R_1 × R_2 × ... × R_n。即使每个零件可靠度 99%，串联 100 个零件后系统可靠度可能只有 89%，此时需要替换薄弱环节。

### 二、散热设计与仿生表面织构（15:11–23:20）

**散热问题的背景**：功率密度越来越高（机器越做越小、功率越来越大）、轻量化要求、导热性差的材料（如钛合金）——导致散热成为瓶颈。

**三种常用散热手段**：

| 方法 | 具体措施 |
|------|---------|
| 增加散热面积 | 散热片（电脑 CPU 散热器） |
| 提升表面换热系数 | 强制风冷、水冷、油冷 |
| 循环冷却系统 | 冷却水管、喷油润滑（减速器常用） |

**仿生表面织构**（教师团队的研究课题）：

在齿轮齿面加工微小凹坑结构（约 150μm 级），实现：
1. **储油功能**：凹坑充当微小油池，改善润滑
2. **增加散热面积**：有效表面增大，促进热交换
3. **实测效果**：齿轮齿面温升降低 20%~25%（低速和高速工况均有改善）

> "教材十几年不变，但新技术都在论文里。作为工科本科生，要学会到知网上读文献。"

### 三、设计方法与流程（23:20–27:40）

| 设计方法 | 适用场合 | 特点 |
|---------|---------|------|
| **理论设计** | 基础零件强度/刚度计算 | 以力学公式为基础，确定危险截面 |
| **经验设计** | 改进型/类比型产品开发 | 参照现有成熟产品，效率高 |
| **模型实验** | 大型昂贵零件（直升机主轴） | 缩比模型先验证，降低风险 |
| **计算机辅助** | 现代设计主流（CAD/CAE/FEA） | 减少研发成本，但不能完全取代实验 |

**设计流程**：选类型 → 定载荷 → 分析失效 → 选材料 → 计算校核 → 出图 → 制造 → 实验验证。

### 四、常用工程材料与选用原则（27:40–34:50）

**材料四大类**：

| 类别 | 代表 | 特性 |
|------|------|------|
| **金属材料** | Q235, 45, 40Cr, HT200, 铜合金, 铝合金, 钛合金 | 综合性能好，最常用 |
| **高分子材料** | 塑料（尼龙、聚甲醛等） | 轻、耐腐蚀，但强度低 |
| **陶瓷** | 氧化锆、氮化硅（陶瓷轴承、陶瓷刀具） | 硬度极高、耐热好，但脆 |
| **复合材料** | 碳纤维（钓鱼竿、自行车、高铁） | 强度高、密度极低 |

**钛合金的特殊提醒**：
- 优点：强度高、密度低（航材首选）
- 缺点：钛-钛接触易发生**表面擦伤（微动磨损）**，产生灰色粉尘
- 联系实际：钛合金零件接触面上需做表面处理或加润滑

**选材四原则**：
1. **使用要求**（强度、刚度、耐磨、耐热）
2. **物理化学性质**（耐腐蚀、导电/导热性）
3. **工艺性**（铸造/锻造/焊接/切削加工性）
4. **经济性**（材料成本 + 加工成本，优先国产化）

### 五、零件的工艺性与标准化设计（34:50–45:30）

**铸造工艺注意点**：
- 减少壁厚差异（避免冷却收缩不均导致变形）
- 合理设置加强筋
- 示例：零件底部挖孔既省料又减小变形

**切削加工工艺注意点**：
- 为加工刀具预留操作空间（如螺纹孔不能太深）
- 孔的设计尽量贯通（避免盲孔增加加工难度）
- 长孔零件：只需两端支撑，中间空刀（保证同轴度的同时减少加工面）

> "这个结构是从俄罗斯的图纸上来的——它没有什么高深原理，就是为了方便套筒和轴的同轴度。"

**标准化/通用化/互换性**（考试可能涉及）：

| 概念 | 定义 | 好处 |
|------|------|------|
| **标准化** | 采用国标（GB/ISO）统一尺寸规格 | 降低成本、保证互换 |
| **通用化** | 相近规格统一为单一规格 | 减少备料种类、方便采购 |
| **互换性** | 相同规格零件可任意替换 | 维修方便、提升效率 |

### 六、零件工作表面与连接表面的区分（45:30–49:50）

以减速器齿轮为例，同一零件不同表面承担不同功能：

| 表面 | 功能 | 加工要求 |
|------|------|---------|
| **A. 内孔面** | 与轴配合，传递扭矩 | 较高精度（H7级） |
| **C. 齿面** | 与配对齿轮啮合，传递运动和力 | 最高精度，需热处理+磨齿 |
| **D. 端面** | 轴向定位（套筒/卡环限位） | 需要一定的平面度 |
| **B. 侧面（非工作面）** | 无功能作用 | 粗加工即可 |

> "齿轮装在轴上，不能让它轴向飘着——不然跟另一个齿轮啮合就偏了。"
