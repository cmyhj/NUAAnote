## 要点详述

### 一、轴承设计计算完整流程（06:00–23:00）

**全流程步骤与评分权重**（以 10 分计算题为例）：

| 步骤 | 操作内容 | 大约分值 |
|------|---------|---------|
| ① | 画简图，标 S₁、S₂ 方向 | 1 分 |
| ② | 计算 S = f(Fr) | 1 分 |
| ③ | 判断压紧/放松（写文字说明） | **3 分** |
| ④ | 求实际 Fa₁、Fa₂ | 1 分 |
| ⑤ | 比较 Fa/Fr 与 e，查 X、Y | 1 分 |
| ⑥ | 计算 P₁、P₂，取大者 | 1 分 |
| ⑦ | 考虑载荷系数 fₚ，代寿命公式 | 1 分 |
| ⑧ | 校核是否满足要求 | 1 分 |

**关键提醒**：
- P₁ 大 ≠ 轴承 1 更危险，**必须分别计算** P₁ 和 P₂
- 用**较大的 P** 代入寿命公式（安全考虑）
- 最终校核：计算寿命 Lₕ ≥ 要求寿命？或所需 C ≤ 轴承额定 C

### 二、轴承的轴向固定方式（36:00–44:00）

#### 方式 1：双支点各单向固定

```
   ┌─[挡圈]─┐          ┌─[端盖]─┐
   │  轴承  │───轴───│  轴承  │
   └────────┘          └────────┘
     0.2~0.3mm ←间隙→
```
- **特点**：两端轴承内外圈都只固定一侧
- **注意**：一端需预留 0.2~0.3mm 轴向间隙，补偿热膨胀和加工误差
- **适用**：普通温度变化不大的短轴

#### 方式 2：一端固定一端游动

```
   ┌─[固定端]─┐      ┌─[游动端]─┐
   │  轴承    │──轴──│  轴承    │
   └─────┬────┘      └─────┬────┘
   内圈+外圈都固定       外圈可滑动
```
- **特点**：固定端承受双向轴向力；游动端允许轴自由伸缩
- **游动端实现方法**：
  - 外圈不固定（箱体孔内自由滑动）
  - 直接使用**圆柱滚子轴承**（滚子可在外圈滚道内自由游动）
- **适用**：长轴、温差大的场合

#### 方式 3：两端游动

- **特点**：内外圈均不固定，轴可自由左右移动
- **适用**：人字齿轮传动（轴向力自平衡，但时有波动）

### 三、轴系结构改错——常见错误类型（30:00–55:00+）

这是**期末最后一题**（约 10~15 分），通常给出一个轴系装配图，要求找出 10 个错误。以下是戴老师总结的**必考错误类型**：

| 编号 | 错误类型 | 正确做法 / 原因 |
|------|---------|----------------|
| **①** | **轴肩过高**（≥ 内圈高度） | 轴肩高度应低于轴承内圈，否则轴承无法拆卸（拆卸工具无法勾住内圈） |
| **②** | **缺少调整垫片** | 轴承端盖与箱体之间需加垫片，用于调整轴向间隙 |
| **③** | **轴承开口方向错误** | 角接触轴承只能正装（面对面）或反装（背对背），不能同向 |
| **④** | **内外圈同时被压死**（无游动端） | 长轴需考虑热膨胀，不可两端都固定死 |
| **⑤** | **挡圈/轴肩压在外圈上** | 定位零件不能同时接触内外圈 |
| **⑥** | **装拆空间不足** | 轴肩过高导致轴承无法拆卸 |
| **⑦** | **润滑/密封问题** | 挡油环高度/位置不当 |
| **⑧** | **套杯调节不合理** | 锥齿轮轴系需用套杯 + 垫片调节顶点重合 |
| **⑨** | **键/螺纹等干涉** | 轴上零件装配顺序不合理 |
| **⑩** | **轴承类型选择不当** | 有轴向力却选深沟球等 |

### 四、锥齿轮套杯调节（45:20–55:00+）

- **目的**：通过套杯 + 调整垫片，使两个锥齿轮的**节锥顶点重合**
- **方法**：在套杯法兰与箱体之间加/减垫片，整体移动轴承座位置
- **套杯开槽原因**：减少加工面，只需保证两个支撑面精度，降低加工成本
