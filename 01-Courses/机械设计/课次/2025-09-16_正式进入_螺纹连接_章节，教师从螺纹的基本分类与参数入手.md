## 本节主线

本节课正式进入**螺纹连接**章节，教师从螺纹的基本分类与参数入手，回顾了机械原理中螺纹副的受力分析、自锁条件和效率公式。随后系统介绍了螺纹连接的四种基本类型（螺栓连接、螺钉连接、双头螺柱、紧定螺钉），并对普通螺栓连接与铰制孔螺栓连接的区别做了重点对比。后半节课详细讲解了螺栓预紧的目的、预紧力矩的构成与简化计算，以及三大类防松方法（摩擦防松、机械防松、永久防松），最后通过一个"永不松动螺母"的测试视频展示了楔形垫圈的防松原理。

## 要点详述

### 一、螺纹的基本参数与分类（01:20–05:26）

**牙型分类**：

| 螺纹类型 | 牙型角 | 主要用途 |
|---------|--------|---------|
| **普通螺纹**（三角形） | 60° | **连接用**，分粗牙和细牙 |
| **梯形螺纹** | 30° | **传动用**（机床丝杠、3D打印机导轨） |
| **锯齿形螺纹** | 33°（3°+30°） | 单向受力传动 |
| **管螺纹** | 55° | 管路密封连接（圆柱/圆锥） |

**螺纹标记示例**：

| 标记 | 含义 |
|------|------|
| M24 | 粗牙普通螺纹，大径24mm（螺距默认为3mm） |
| M24×1.5 | 细牙普通螺纹，大径24mm，螺距1.5mm |
| M24×100 | 螺栓规格：螺纹大径24mm，螺杆长度100mm |

> "如果考试考你 M24 是什么——大径24，粗牙，不加特殊标志就是标准粗牙螺纹。"

### 二、螺纹副的力学基础回顾（05:27–13:17）

教师以**滑块-斜面模型**回顾机械原理内容：

**拧紧（上升）力矩**：
```
T = Fₐ · d₂/2 · tan(λ + ρ_v)
```

**拧松（下降）力矩**：
```
T = Fₐ · d₂/2 · tan(λ - ρ_v)
```

**自锁条件**：
- **矩形螺纹**：λ ≤ ρ（螺纹升角 ≤ 摩擦角）
- **非矩形螺纹**：λ ≤ ρ_v（螺纹升角 ≤ 当量摩擦角）
  - ρ_v = arctan(f / cosβ)，其中 β 为牙侧角
- 此为**填空题高频考点**——每年都会考自锁条件

**效率公式**：
```
η = tanλ / tan(λ + ρ_v)
```
- 螺纹传动效率较低，涡轮蜗杆是螺纹传动的变形，同样效率低但能实现大减速比和空间交叉换向

### 三、螺纹连接的四种基本类型（13:17–20:41）

| 类型 | 结构特点 | 适用场合 |
|------|---------|---------|
| **普通螺栓连接** | 螺栓穿入通孔+螺母，螺栓杆与孔有间隙 | 最常用，靠预紧力产生的摩擦力承受横向载荷 |
| **铰制孔螺栓连接** | 螺栓杆与孔无间隙配合（孔需铰制加工） | 可承受横向剪切、兼做定位，强度远高于普通螺栓 |
| **螺钉连接** | 螺钉直接拧入被连接件的螺纹孔 | 不常拆卸场合，结构紧凑 |
| **双头螺柱** | 两端螺纹，一端拧入机体，另一端螺母固定 | 被连接件需经常拆卸或材料较软时使用 |
| **紧定螺钉** | 螺钉顶住轴面固定零件位置 | 传递小扭矩（如皮带轮-轴固定） |

**普通螺栓 vs 铰制孔螺栓的关键区别**（考试/工程重点）：

| 对比项 | 普通螺栓连接 | 铰制孔螺栓连接 |
|--------|------------|--------------|
| 孔-杆配合 | 有间隙 | 无间隙（铰制孔） |
| 承受横向载荷方式 | 靠预紧力产生的摩擦力 | 靠螺栓杆直接承受剪切和挤压 |
| 失效形式 | 摩擦力不足 → 连接件滑移 | 螺栓被剪断或孔壁被压溃 |
| 定位能力 | 需另加定位销 | 可自行定位 |

### 四、螺栓的预紧（29:05–38:44）

**预紧的目的**：
1. 提高连接的可靠性
2. 保证被连接件之间的紧密性（如压力容器）
3. 产生足够的摩擦力来承受横向载荷

**预紧力的控制标准**：
- 预紧力 F₀ 一般不超过材料屈服极限 σ_s 的 **80%**
- 过大预紧力可能导致螺栓拧断或螺纹滑丝

**预紧力矩的构成**（两项之和）：
1. **螺纹副阻力矩**：克服螺纹副摩擦（来源于滑块-斜面模型）
2. **支撑面摩擦力矩**：螺母/螺栓头与被连接件接触面的摩擦

**经验简化公式**（考试常用）：

```
T ≈ 0.2 × F₀ × d
```

其中 d 为螺栓大径。

**预紧力控制方法**：

| 方法 | 原理 | 适用场合 |
|------|------|---------|
| 经验手感 | 凭操作者经验判断 | 非关键连接（如家庭水管维修） |
| 测力矩扳手 | 利用杆件弹性变形量指示力矩 | 一般工业装配 |
| 定力矩扳手 | 达到设定值后内部机构打滑 | 流水线批量生产（如4S店换轮胎） |
| 测量伸长量 | 通过螺栓伸长量反推预紧力 | 高精度要求场合（如塑料螺栓） |

> "去4S店做保养，师傅用的定力矩扳手——到了设定的牛米数，它咔嗒一下就打滑了，保证每个螺栓都是一样的预紧力。"

### 五、防松方法（38:44–50:50）

螺栓在振动、冲击或变载荷下会自行松动，因此必须采取防松措施。三大类防松方法：

#### 1. 摩擦防松（最常用）

| 方法 | 原理 | 特点 |
|------|------|------|
| **弹簧垫圈** | 弹力产生附加轴向张力，增加摩擦力 | 简单廉价，防松效果一般 |
| **双螺母** | 上下螺母对顶，受力不同步 | 效果中等，占用空间大 |
| **尼龙锁紧螺母** | 尼龙嵌件弹性变形，挤压螺纹 | 效果较好，可重复使用有限次 |

#### 2. 机械防松（更可靠）

| 方法 | 原理 |
|------|------|
| **开口销+槽形螺母** | 开口销穿过螺栓孔并分开，卡住螺母槽 |
| **止动垫圈** | 垫圈外舌弯折贴紧螺母侧面，内舌贴紧被连接件 |
| **串联钢丝** | 钢丝穿过螺栓头部小孔，相互牵制（注意钢丝缠绕方向必须正确） |

#### 3. 永久防松

- **冲点法**：用冲子在螺纹副处打点，破坏螺纹
- **粘接法**：涂抹厌氧胶等防松胶水
- 适用于明确不再拆卸的场合

#### 拓展：楔形垫圈（"永不松动"螺母）

教师播放了一段对比测试视频，展示了**Nord-Lock 楔形垫圈**的防松效果：
- 两个垫圈内侧有对应的凸轮斜面（倾角 > 螺纹螺距）
- 外侧有镜像锯齿，咬合在被连接件表面
- 当振动发生时，凸轮斜面将螺栓向上推的力转化为更大的锁紧力（楔形效应）
- 测试结果：经过 80 秒高频振动，松紧度仍然保持在 60 以上（其他方法直线下滑至 0）
- 缺点：成本远高于普通垫圈（几分钱 vs 数元）
