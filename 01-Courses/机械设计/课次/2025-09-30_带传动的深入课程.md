## 本节主线

本节课是带传动的深入课程。教师首先回顾了上节课遗留问题（键的长度选择原则），然后正式展开**带传动**的系统讲解。前半部分介绍了各种带传动的类型（同步带/摩擦带、平带/V 带/多楔带/圆带）及 V 带的结构组成（抗拉体、顶胶、底胶、包布层），引入**节面/基准直径**等标准化概念。后半部分进入本节重点——**带传动的受力分析**：从初始拉力 F₀ 出发，推导紧边拉力 F₁ 与松边拉力 F₂ 的关系，引入**欧拉公式** F₁/F₂ = e^(fα)，并讨论影响带传动能力的因素（摩擦系数、包角、V 带当量摩擦角）。课程最后简要对比了 V 带与平带的当量摩擦系数，类比于三角螺纹与矩形螺纹的摩擦差异。

## 要点详述

### 一、键的长度选择回顾（00:40–01:29）

上节课遗留问题的确认：

> "键如果是作为连接用的话，是要比我的轮毂要短一点；但是你如果作为轴向有导向的话，要比轮毂长一点。"

| 使用场景 | 键与轮毂的长度关系 |
|---------|------------------|
| **纯扭矩传递**（无轴向移动） | 键长 < 轮毂宽（避免无效接触） |
| **有导向需求**（轴向移动） | 键长 > 轮毂宽（保证全程导向） |

### 二、同步带（啮合型带传动）（01:30–03:41）

同步带（synchronous belt / timing belt）的带内侧有齿，带轮上有对应的齿槽，通过**齿的啮合**传递动力。

**与摩擦型带的关键区别**：

| 对比项 | 摩擦型带 | 同步带 |
|--------|---------|--------|
| 传动原理 | 摩擦力 | 齿啮合 |
| 传动比 | 不固定（弹性滑动影响，~95% 稳定） | **固定** |
| 典型应用 | 一般工业传动 | 汽车正时、机器人关节 |

**带传动的突出优势（对比齿轮）**：
- **可实现长距离传动**：一根带即可替代多对齿轮
- 结构简单、成本低

### 三、带的类型与结构（09:28–19:25）

#### 按截面形状分类

| 类型 | 截面形状 | 特点 | 典型应用 |
|------|---------|------|---------|
| **平带**（flat belt） | 矩形 | 薄、轻、离心力小；精度较低、易打滑 | 高速场合 |
| **V 带**（V-belt） | 梯形/楔形 | 楔面效应 → 摩擦力大，承载最高 | 通用工业传动（最常用） |
| **多楔带**（multi-ribbed belt） | 平带底带多条楔形肋 | 兼具平带柔性与 V 带摩擦力 | 高精度/大功率 |
| **圆带**（round belt） | 圆形 | 结构紧凑、简单、扭矩小 | 缝纫机、磁带机 |

#### V 带的标准型号（承载递增）

**Y → Z → A → B → C → D → E**

> "你如果选 Z 型强度不够，可以往后面换 A 型或者 B 型、C 型。"

#### V 带的结构组成（从外到内）

| 组成部分 | 位置 | 功能 |
|---------|------|------|
| **包布层**（wrapping layer） | 最外层 | 保护内部结构，耐磨 |
| **顶胶**（top rubber） | 上方（弯曲时受压） | 承受压缩应力 |
| **抗拉体**（tension member） | 中间层（节面附近） | 主要承拉，由帘布或线绳构成 |
| **底胶**（bottom rubber） | 下方（弯曲时受拉） | 承受拉伸应力 |

> "带在弯曲的时候，上半部分是受拉，下半部分受压……从受拉到受压中间存在一个线，我们叫节线。"

### 四、带的标准化参数（19:25–23:47）

#### 节面（中性层）与节宽

V 带弯曲时存在一个**长度不变的中性层**，称为**节面**。节面的宽度称为**节宽 b_p**，是 V 带的标准化基准尺寸——类似齿轮的**分度圆**。

#### 基准直径 d_d

带轮上对应节宽位置处的直径称为**基准直径**（datum diameter）。同一根 V 带可适配不同直径的带轮，只要节宽对应即可。

#### 基准长度 L_d 与长度修正系数

V 带的基准长度 L_d 是指沿**节面**测量的周长。国标规定了各型号的标准基准长度系列。当实际选用长度偏离基准值时，需乘以**长度修正系数 K_L**（≤1），用于强度计算时的折扣。

### 五、带传动的几何参数（23:54–28:30）

#### 三个核心几何参数

| 参数 | 符号 | 说明 |
|------|------|------|
| **中心距** | a | 两带轮中心之间的距离 |
| **包角** | α | 带与带轮接触弧对应的圆心角 |
| **带长** | L | 带的总周长 |

#### 包角计算

```
小轮包角：α₁ = π - 2θ    （θ ≈ (d₂ - d₁) / (2a)）
大轮包角：α₂ = π + 2θ
```

其中 θ ≈ sinθ ≈ (d₂ - d₁) / (2a)，适用于小角度近似。

- 小轮包角 α₁ < 180°，大轮包角 α₂ > 180°
- 两轮直径相等时 α₁ = α₂ = 180°

#### 带长公式

带长 = 上直边 + 下直边 + 小轮包角弧长 + 大轮包角弧长。推导结果为一个复杂的三角函数表达式，**课程设计时会直接用到**。

### 六、带传动的优缺点（28:30–31:22）

| 优点 | 缺点 |
|------|------|
| ✅ 适用于长距离传动 | ❌ 外廓尺寸大 |
| ✅ 缓冲吸振（弹性好） | ❌ 需要张紧装置（带会松弛） |
| ✅ 过载打滑保护（不损伤其他零件） | ❌ 弹性滑动 → 传动比不固定 |
| ✅ 结构简单，成本低 | ❌ 寿命较短（橡胶老化） |
| ✅ 维护方便 | ❌ 效率较低（~90%，摩擦损耗） |

### 七、受力分析（本节核心）（33:36–50:40）

#### 7.1 初始拉力与紧边/松边

**静止状态**：
- 带以初始拉力 F₀ 张紧，两边拉力相等

**运转状态**（以主动轮逆时针旋转为例）：
- **紧边**（进入主动轮一侧）：被摩擦力进一步拉紧 → **F₁ = F₀ + ΔF**
- **松边**（离开主动轮一侧）：被摩擦力放松 → **F₂ = F₀ - ΔF**

**总带长不变假设**：紧边的伸长量 = 松边的缩短量 → F₁ - F₀ = F₀ - F₂

#### 7.2 有效拉力（圆周力）

```
F_e = F₁ - F₂
```

传递的功率：P = F_e × v（v 为带速）

#### 7.3 欧拉公式（挠性摩擦公式）

通过微元体受力分析（取微弧段 dα，列力平衡方程并积分）得到：

```
F₁ / F₂ = e^(fα)
```

其中：
- **f**：摩擦系数（平带用材料摩擦系数，V 带用当量摩擦系数 f_v）
- **α**：**小轮包角 α₁**（设计时以小轮为准，因 α₁ < α₂，承载能力更低）

#### 7.4 最大有效拉力

```
F_e_max = F₁(1 - 1/e^(fα)) = 2F₀ · (e^(fα) - 1) / (e^(fα) + 1)
```

打滑条件：F_e_required > F_e_max

> "需要的有效拉力大于带能提供的最大摩擦力时，就会发生打滑。"

#### 7.5 影响带传动能力的因素

| 因素 | 增加 → 影响 |
|------|------------|
| 摩擦系数 f ↑ | F_e_max ↑（如 V 带相比平带） |
| 包角 α ↑ | F_e_max ↑（设计时以小轮包角为准） |
| 初始拉力 F₀ ↑ | F_e_max ↑（但过大会缩短带寿命） |
| 带速 v ↑ | 离心力增大 → 有效拉力下降 |

#### 7.6 V 带的当量摩擦系数

V 带楔入带轮槽中，正压力被楔角放大，等效摩擦系数：

```
f_v = f / sin(φ/2)
```

其中 **φ** 为 V 带楔角（标准值一般为 **40°**，φ/2 = 20°）。

> "V 带当量摩擦系数大于平带，这是 V 带承载能力更高的根本原因——类似于三角螺纹的当量摩擦角大于矩形螺纹。"
