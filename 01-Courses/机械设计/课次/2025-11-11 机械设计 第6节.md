## 要点详述

### 一、提升轴的强度（00:00–11:00）

#### 1.1 合理布置传动方案 [01:06]

方案 a（两输出在两侧、输入在中间）与方案 b（输入在一侧）相比：
- 方案 a 的扭矩图显示：轴上任意截面承受的扭矩 = 单个输出扭矩 T₁（或 T₂），最大扭矩 = max(T₁, T₂)
- 方案 b 的扭矩图显示：从输入到远端输出之间，轴上承受的扭矩 = T₁ + T₂
- → **合理布置输入/输出位置**可有效降低轴上最大扭矩，从而减小轴径要求

#### 1.2 合理布置轴上零件 [02:10]

输入端在**中间**、输出端在两侧时，扭矩图峰值更低（仅为较大的那个输出扭矩）；输入端在**一侧**时，扭矩叠加导致峰值更大。设计中可通过调整零件位置来优化轴的受力。

#### 1.3 降低应力集中的措施 [04:06]

| 措施 | 说明 |
|------|------|
| **加大圆角半径** | 截面突变处应尽可能用圆角过渡，避免直角 |
| **加过渡段（圆锥过渡）** | 轴径变化处用圆锥段过渡，应力集中小于直角台阶 |
| **开卸载槽** | 过盈配合零件根部，在轴上开槽使其微变形，缓解压应力集中 |
| **增大局部轴径** | 应力集中严重处可将轴段直径适当加大以降低应力水平 |
| **尽量避免轴上开孔/开槽** | 轴上的紧定螺钉孔、键槽等会显著削弱轴的疲劳强度 |

> **考试提示**：前年考过问答题——"提升表面强度的方法有哪些？"满分 5 分。

#### 1.4 表面质量改善 [09:32]

- 降低表面粗糙度（如从 R<sub>a</sub>1.2 降至 R<sub>a</sub>0.8 → 0.4 → 0.1），可延缓疲劳裂纹萌生
- **表面强化处理**（列举即可作为答题要点）：
  1. **喷丸**（产生残余压应力，最常见）
  2. **渗碳 / 渗氮**
  3. **淬火**（表面硬化）
  4. **激光冲击强化**（航空领域已大量应用）
  5. **碾压 / 滚压**

### 二、工艺性设计要求（11:00–18:00）

#### 2.1 结构简化 [11:36]
- 在满足安装和定位前提下，**阶梯数越少越好**
- 阶梯数少 → 加工工序少 → 精度更容易保证 → 成本低

#### 2.2 砂轮越程槽 [13:12]
- 需要磨削加工的轴段（如轴承位）与轴肩根部交界处应开**砂轮越程槽**
- 原因：砂轮外缘有圆角，不加槽则轴肩根部磨不到
- 越程槽的形状和尺寸可查手册

#### 2.3 退刀槽 [14:43]
- 车螺纹或车外圆时，在台阶根部预留退刀槽，给刀具留空间
- 常见于螺纹段、精加工段之前

#### 2.4 倒角与圆角统一 [17:46–18:24]
- **轴端倒角**：防止划伤人手，同时方便装配导向
- 所有倒角值和圆角值应尽量取相同数值，减少换刀次数
- **键槽**：同一轴上多个键槽应布置在**同一条母线上**，方便一次装夹加工

#### 2.5 尺寸标准化 [18:28]
- 零件配合处的轴段直径应取**标准值**（如轴承内径、齿轮内孔标准系列）
- 非配合轴段直径应取**整数**（便于测量和加工）

### 三、轴承拆卸注意事项 [15:59]

- 常用工具：**拉马**（2~3 个拉爪，螺旋传动拉下轴承）
- **关键要求**：拉爪必须施力于**轴承内圈**（不能施力于外圈），否则会挤坏滚动体或座圈
- 因此**轴肩高度不能过高**——不得超过手册规定的极限值，否则拉马无法卡住内圈

### 四、轴系结构改错实战（18:00–25:00）

教师以一张典型轴系结构图为例，带领发现 **10 个错误**：

| 编号 | 错误 | 正确做法 |
|------|------|---------|
| ① | **缺少键** | 齿轮/带轮/联轴器处必须有键传递扭矩 |
| ② | **轮毂长 ≤ 轴段长** | 轮毂长度应 **>** 轴段长度（约 2~3mm），保证套筒能压紧端面 |
| ③ | **轴肩过高**（轴承处） | 轴肩高度不能超过轴承内圈外径，否则轴承无法拆卸 |
| ④ | **缺少定位轴肩** | 该处应有轴肩或套筒实现轴向定位 |
| ⑤ | **缺少垫片** | 轴承端盖与箱体之间应加调整垫片，调节轴承间隙 |
| ⑥ | **轴段过长**（轴承位） | 轴承位长度应等于轴承宽度，过长则精加工面浪费且难安装 |
| ⑦ | **伸出端误用套筒** | 轴伸出箱体外的位置不能使用套筒定位（套筒在箱内使用），应改为轴肩 |
| ⑧ | **轴端无倒角** | 轴端应倒角（防划伤+安装导向） |
| ⑨ | **零件间无间隙** | 旋转件与固定件（如齿轮与箱壁、轮毂与端盖）之间应留间隙 |
| ⑩ | **键槽位置错误** | 联轴器/带轮也应画键槽 |

> **考试信息**："一般指这错误，从左往右指或从右往左指，每看一个零件关注它的定位功能。找 10 个就行。"

### 五、轴承寿命计算课堂练习（25:00–55:00）

#### 5.1 题一：常规布置 [25:00]
- 力的作用点正好在轴承中心
- 直接按标准流程计算即可

#### 5.2 题二：力不在轴承中心（考试原题）[27:00]

**关键区别**：当轴上载荷 F₂ 的作用点不在轴承中心时，需要先用**理论力学**中的支点反力知识，将力分配到两个轴承上（转动心轴/转轴的情况）。

**完整计算流程**：

```
① 计算派生轴向力   F_d = e · F_r（按手册公式）
② 判断压紧/放松    根据轴上总轴向力 ΣF_a 与 F_d 的平衡
③ 计算每个轴承的    F_a（压紧端 / 放松端公式不同）
④ 查 X、Y 系数      F_a / F_r ≤ e 时 X=1, Y=0；> e 时查表
⑤ 当量动载荷       P = X · F_r + Y · F_a
⑥ 轴承寿命         L_h = (10⁶ / 60n) · (C / P)^ε
```

> ⚠️ **教师特别强调**：课本 338 页表下方注释——Y 值取 **F<sub>a</sub>/F<sub>r</sub> > 1** 时的对应值。

> **考试信息**："这种题目都是通用的范式，轴承必须掌握，不用翻书就能求会做。每年必考。"
