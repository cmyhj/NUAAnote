## 本节主线

本节课是带传动的**应力分析与失效机理**核心课。教师首先回顾了欧拉公式与紧边/松边概念，通过选择题巩固影响最大有效拉力的三大因素（摩擦系数、小轮包角、初始拉力）。然后系统分析了带传动中的三种应力——**拉应力**（紧边/松边不同）、**离心应力**（均匀分布在整个带上）、**弯曲应力**（小轮处更大），并详细讲解了**应力分布图**的画法（考试必考）。之后深入剖析**弹性滑动**的成因（紧边/松边变形量不同导致带与带轮微差滑动）及其与**打滑**的本质区别（弹性滑动不可避免，打滑可避免）。最后介绍了带轮结构类型、张紧方式（调中心距/张紧轮），并提及带传动的设计准则：**不打滑条件 + 疲劳强度**。

## 要点详述

### 一、回顾与选择题巩固（00:53–07:21）

#### 欧拉公式

```
F₁ / F₂ = e^(fα)
```

F₁ = 紧边拉力，F₂ = 松边拉力，f = 摩擦系数，α = **小轮包角**。

#### 决定最大有效拉力的因素（多选题）

> 下列哪些因素决定带传动的最大有效拉力？

| 因素 | 是否决定 F_e_max | 说明 |
|------|----------------|------|
| 摩擦系数 f | ✅ | f↑ → F_e_max ↑ |
| 小轮包角 α₁ | ✅ | α₁↑ → F_e_max ↑（以小轮为准，木桶效应） |
| 初始拉力 F₀ | ✅ | F₀↑ → F_e_max ↑（但过大缩短带寿命） |
| 带速 v | ❌ | 不直接决定 F_e_max，但影响离心力 |
| 带轮直径 | ❌ | 通过包角间接影响 |

#### 减速 vs 增速传动对比

相同条件下（中心距、材料、F₀、转速），减速传动与增速传动的最大有效拉力 F_e **相等**（取决于 f、α、F₀，与布置无关），但**功率** P = F_e·v 因带速不同而不同。

### 二、带传动的应力分析（07:27–18:25）

#### 三种应力的来源与分布

| 应力类型 | 符号 | 产生原因 | 分布特征 |
|---------|------|---------|---------|
| **拉应力** | σ₁ / σ₂ | 紧边/松边拉力除以截面积 | 紧边高(σ₁)，松边低(σ₂)；仅在直线段 |
| **离心应力** | σ_c | 带绕经带轮时的离心力 | **整个带上均匀分布** |
| **弯曲应力** | σ_b | 带弯曲绕经带轮 | 仅存在于带轮弧段；小轮 > 大轮 |

> "离心力虽然是在小轮这一块产生的，但离心力作用在带上会让整个带发生均匀的弹性变形——整个带一圈上都有离心应力，而且大小一样。"

#### 弯曲应力公式

```
σ_b ≈ E · h / d_d
```

- E：带材料的弹性模量
- h：带的高度（V 带为节面以上高度）
- d_d：带轮的基准直径

**小轮弯曲应力更大**（d 小 → σ_b 大）。

#### 最大应力位置

```
σ_max = σ₁ + σ_c + σ_b₁
```

出现在**小带轮紧边入口处**（即带刚开始绕上小带轮的位置）——此处拉应力最大（紧边）、弯曲应力最大（小轮）、离心应力全带相同。

#### 应力分布图绘制方法（考试重点）

三步法：

1. **画离心应力**：整圈一条水平线（均匀分布）
2. **叠加拉应力**：紧边直线段 σ₁ 高，松边直线段 σ₂ 低；带在轮上弧段时拉力从 σ₁ 逐渐过渡到 σ₂（或反之）
3. **叠加弯曲应力**：在小轮弧段叠加 σ_b₁（峰值），大轮弧段叠加 σ_b₂（较小）；直线段无弯曲应力

> "考试的时候会给你换一下转向，或者把小轮画到另一边，你要能判断紧边在哪，然后一步步画。"

### 三、轴压力与卸载带轮（18:25–20:10）

#### 轴压力计算

带对轴的作用力（径向力）近似为：

```
F_Q ≈ 2F₀ · sin(α₁/2)
```

此力会使轴产生弯曲变形，影响传动精度。

#### 卸载带轮

对于精密传动，可在带轮与轴之间增加**卸载装置**：通过**花键连接**将扭矩传给轴，而将径向力通过**套筒**直接传给箱体，轴只受扭矩不受径向力。

### 四、弹性滑动（23:24–31:30）（本节核心）

#### 产生机理

1. 带是弹性体，紧边拉力 F₁ > 松边拉力 F₂ → 紧边变形量 ε₁ > 松边变形量 ε₂
2. 带在**主动轮**上从紧边转到松边：变形量由大变小 → 带在轮面上**回弹收缩** → 带速 < 轮速
3. 带在**从动轮**上从松边转到紧边：变形量由小变大 → 带被**拉长** → 带速 > 轮速
4. 这种由弹性变形差异引起的微差滑动称为**弹性滑动**

> "带在主动轮上是回弹，所以带速比轮速慢；在从动轮上是拉长，所以带速比轮速快。"

#### 滑差率 ε

```
ε = (v₁ - v₂) / v₁
```

一般 ε ≈ 0.01 ~ 0.02（1%~2%）。

#### 实际传动比

```
i = n₁ / n₂ = d₂ / [d₁ · (1 - ε)]
```

由于 ε 的存在，传动比**不固定**（受载荷影响）。

### 五、弹性滑动 vs 打滑（31:30–35:12）

| 对比项 | 弹性滑动 | 打滑 |
|--------|---------|------|
| **成因** | 带的弹性变形 + 紧边/松边拉力差 | 过载，所需拉力 > 最大摩擦力 |
| **发生范围** | 局部（仅在带轮包角的一部分弧段） | 全面（整个包角范围） |
| **能否避免** | ❌ **不可避免**（带是弹性体） | ✅ **可以避免**（合理设计） |
| **影响** | 传动比略有变化，效率降低 | 传动失效，磨损加剧 |
| **设计处理** | 在传动比计算中引入 ε 修正 | 以不打滑为设计条件 |

> "弹性滑动就是带传动与生俱来的缺陷——因为带是弹性体，摩擦传动就必然有弹性滑动。打滑是过载了才会发生，可以避免。"

### 六、带轮结构与材料（35:12–41:02）

#### 带轮结构类型

| 类型 | 适用直径范围 | 特点 |
|------|-------------|------|
| **实心式** | 直径较小 | 结构简单，无需掏空 |
| **腹板式** | 中等直径 | 中间有腹板连接轮缘和轮毂 |
| **轮辐式** | 大直径（D > 350mm） | 用轮辐代替腹板，减重并防止离心应力引起裂纹 |

#### 材料

- 常用：**HT150、HT200**（灰铸铁）
- 小功率场合：铝合金

### 七、张紧方式（41:02–48:00）

带在长期使用后会因塑性变形或磨损而松弛，需张紧装置恢复初始拉力。

| 张紧方式 | 原理 | 特点 |
|---------|------|------|
| **调中心距** | 通过滑轨+调节螺栓改变中心距 | 结构简单直接，最常用 |
| **张紧轮** | 在松边增加一个辅助压轮 | 用于中心距不可调的场合 |

**张紧轮安装原则**：应安装在**松边**（松边更易松弛，且装在松边不会增大紧边弯曲应力）。

> "张紧轮应放在松边——既然松了，松边肯定松得更快，在松边张紧效率更高。"

### 八、带传动设计准则（48:00–50:23）

带传动的设计需同时满足两个条件：

1. **不打滑条件**：传递的有效圆周力 ≤ 最大摩擦力（由欧拉公式确定）
2. **足够的疲劳强度**：带的循环最大应力 σ_max ≤ [σ]（保证一定使用寿命）

实际设计中，通过查表选择单根 V 带的基本额定功率 P₀，再乘以修正系数（工况系数 K_A、长度修正系数 K_L、包角修正系数 K_α），得到许用功率 [P] ≥ 计算功率 P_ca。
