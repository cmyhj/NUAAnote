## 要点详述

### 一、上节回顾与课程引入（01:22–08:40）

教师快速回顾了机械设计的四大基本要求（**功能性、可靠性、经济性、社会性**）和零件失效的两大分类：
1. **整体失效**：强度失效（静载/疲劳/冲击）、刚度失效、失稳
2. **表面失效**：接触疲劳（点蚀）、磨损、腐蚀（非接触）、发热

进而引出设计准则中最基本的**强度准则**——使用应力法或安全系数法。

### 二、载荷与应力分类（08:40–17:50）

**载荷类型**：
- **名义载荷**：理想工况下的理论值，如电机额定扭矩
- **计算载荷** = 名义载荷 × 载荷系数 K（考虑震动、启停、周期性运动等附加载荷）

**应力类型**：
- **静应力**：不随时间变化（如桌面上的重物）
- **变应力**：随时间变化，又可细分为：
  - **稳定循环变应力**：幅值恒定（正弦波形）
  - **不稳定循环变应力**：幅值随机变化（研究生阶段用可靠性方法处理）

**稳定循环变应力的五个参数**（必考选择题/填空题）：

| 参数 | 含义 | 公式 |
|------|------|------|
| σ_max | 最大应力 | 曲线最高点 |
| σ_min | 最小应力 | 曲线最低点 |
| σ_m = (σ_max+σ_min)/2 | 平均应力 | 应力的直流分量 |
| σ_a = (σ_max-σ_min)/2 | 应力幅 | 应力的交流分量 |
| r = σ_min/σ_max | 应力比 | 表征不对称程度 |

重要关系：σ_max = σ_m + σ_a

### 三、三种典型循环应力（17:50–22:30）

| 类型 | 应力比 r | 特征 | 图示理解 |
|------|---------|------|---------|
| **对称循环** | r = -1 | σ_max = -σ_min，σ_m=0 | "前后跑1000米"——从+1000到-1000 |
| **脉动循环** | r = 0 | σ_min=0，σ_m=σ_a | "爬坡跑1000米"——从0到+1000 |
| **静应力** | r = 1 | σ_max = σ_min | "平路走"——恒定不变 |

其中**对称循环(r=-1)是材料疲劳极限的标准测试工况**，在后续疲劳计算中最为常用。

### 四、静强度计算（22:30–35:30）

**材料的分类**：
- **塑性材料**（如 45 钢）：以屈服极限 σ_s 为判据，失效表现为明显塑性变形
- **脆性材料**（如铸铁、玻璃）：以强度极限 σ_b 为判据，失效表现为突然断裂

**单向应力状态**（简单拉/压/扭）：σ ≤ [σ] 或 S ≥ [S]

**复合应力状态**（拉+扭组合，如直升机旋翼同时承受拉力和扭矩）：
- **塑性材料**用第三/第四强度理论合成当量应力
  - 第三强度（最大切应力）：σ_r3 = √(σ² + 4τ²)
  - 第四强度（形状改变比能）：σ_r4 = √(σ² + 3τ²)
- **脆性材料**用第一强度理论（最大拉应力）

**应力集中**：在截面突变处（键槽、轴肩、螺纹等），局部应力远大于名义应力。塑性材料有一定的应力缓和能力，脆性材料则需重点考虑。

### 五、静强度与疲劳强度的适用条件（35:30–40:10）

在零件设计寿命内，若循环次数 N < 10³~10⁴ 次，可按**静强度**计算；若 N > 10⁴ 次，则需按**疲劳强度**计算。

实例分析——飞机上不同零件的设计策略：
- **安全通道门**（使用次数极少，约10次）→ 静强度设计，可做减重
- **起落架**（每次飞行只收放一次）→ 接近静强度设计
- **发动机主轴**（高速旋转，循环次数极高）→ **必须按疲劳强度设计**

### 六、疲劳失效的物理过程（40:10–46:00）

疲劳失效的三个阶段：
1. **裂纹萌生**：在循环应力作用下，应力集中部位产生微观裂纹
2. **裂纹扩展**：持续循环加载下，裂纹逐渐扩展（可观察到明显的疲劳辉纹）
3. **最终断裂**：裂纹扩展到临界尺寸，剩余截面不足以承载，发生突然断裂

**S-N 曲线与疲劳实验**：
- 标准疲劳实验使用对称循环(r=-1)加载
- 采用升降法（Up-Down Method）测定材料的疲劳极限
- 通常需要 12~24 个试样，每个试样需循环至 10⁷ 次
- 这解释了为什么材料疲劳数据是极其宝贵的工程基础数据
