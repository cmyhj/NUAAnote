**求解要点**：
1. 合金钢取 ψ_σ=0.2
2. 由 ψ_σ = (2σ_{-1} - σ_0)/σ_0 反推 σ_0，得 σ_0=916MPa
3. 确定 A(0, σ_{-1})、D(σ_0/2, σ_0/2)、C(σ_s, 0)、G(45° 线与 AD 延长线交点)
4. 对于 r=-0.5 的工况，由 r 与 σ_a/σ_m 的关系计算斜率，在图上作射线交于 AD 段
5. 求交点 M' 的坐标 → 得到极限应力 σ_lim = σ_m' + σ_a'

### 二、Miner 疲劳损伤累积理论（07:15–40:50）

#### 2.1 基本思想

实际零件常常承受**变幅循环应力**（如不同工况下应力水平不断变化），而非单一恒幅应力。Miner 法则的核心假设：

1. **损伤独立**：每个应力循环造成的损伤独立存在，互不影响
2. **损伤线性累积**：总损伤为各应力水平损伤之和
3. **临界破坏条件**：总损伤达到 1 时，零件发生疲劳破坏

> "你今天踹了墙一脚，明天再踹一脚——天天踹，到第四年墙就倒了。损伤已经产生了，它是独立累积的。"

#### 2.2 数学表达

**基本公式**：
```
Σ(n_i / N_i) = 1
```
其中：
- n_i：在应力 σ_i 作用下的实际循环次数
- N_i：在应力 σ_i 作用下零件能承受的**最多**循环次数（由 S-N 曲线确定）

**结合 S-N 曲线**（高周疲劳区 CD 段）：
```
σ_i^m · N_i = σ_{-1}^m · N_0 = C
```
由此可反求任意应力水平下的 N_i。

#### 2.3 等效稳定变应力法

当零件受到多级应力时，可以**等效**为某个参考应力下的恒幅载荷：

**基本思路**（教师以"班级身高等效"类比）：
- 一个班级有不同身高的人（1.5m、1.6m、1.7m、1.8m）
- 为了比较，可以把所有人都"等效"到同一个基准身高（如 1.7m）
- 1.8m 的人等效为 (1.8/1.7)^? × 人数 个 1.7m 的人……

**数学公式**（等效到参考应力 σ_q）：
```
σ_q^m · N_q = Σ(σ_i^m · n_i)
```
其中 N_q 为等效循环次数，σ_q 为选定的参考应力（通常选作用时间最长的应力）。

**选择参考应力的原则**：取**数值较大且作用时间较长**的应力作为等效基准。如例 2 中取 80MPa（作用 10 秒/周期）作为参考。

#### 2.4 例题详解

**例 1**（简单情况）：
- 45钢调质，σ_{-1}=307MPa, m=9, N_0=5×10^6
- 在 σ_1=500MPa 下跑 10^4 次，σ_2=400MPa 下跑 10^5 次
- 求安全系数，以及若再加 σ_3=350MPa 还能循环多少次

**解答思路**：
1. 由 S-N 曲线求 N_1 和 N_2（各应力下的极限循环次数）
2. 由 Σ(n_i/n_i') 求等效计算应力 σ_ca
3. S = σ_{-1} / σ_ca ≈ 1.1
4. 由 Σ(n_i/N_i) + n_3/N_3 = 1 求 n_3

**例 2**（工程实际）：
- 轴转速 100rpm，总工作时间 200h
- σ_1=100MPa 占 3s/周期，σ_2=80MPa 占 10s/周期，σ_3=20MPa 占 7s/周期
- 材料 σ_{-1}=270MPa，K_σ=2.5，[S]=1.5
- 计算步骤：
  1. 由时间占比和总工时计算各应力实际循环次数 n_i
  2. 选择 σ_q=80MPa（作用时间最长）作为等效基准
  3. 按等效公式求 N_q
  4. 求寿命系数 K_N = ᵐ√(N_0/N_q)
  5. 求计算应力 σ_ca = K_N × σ_{-1} / K_σ
  6. 实际安全系数 S_q = σ_{-1} / (K_σ × σ_ca) = 1.62 > [S]=1.5，安全

> "逻辑其实很简单——把各应力的损伤加起来，看总损伤有没有到 1。"

### 三、接触强度与 Hertz 理论（40:50–52:00）

#### 3.1 接触形式分类

| 接触类型 | 理想形式 | 实际形式（弹性变形后） | 典型例子 |
|---------|---------|---------------------|---------|
| **点接触** | 一个点 | 小椭圆面 | 球轴承、凸轮从动件 |
| **线接触** | 一条线 | 窄矩形面 | 齿轮啮合、滚子轴承 |
| **面接触** | 一个面 | 不变 | 滑动轴承 |

#### 3.2 接触疲劳的失效过程

1. **初始裂纹**：在循环接触应力作用下，次表面最大切应力处萌生微观裂纹
2. **裂纹扩展**：润滑油被压入裂纹，在高压下产生"油楔效应"促进裂纹扩展
3. **点蚀（pitting）**：表面材料剥落形成凹坑
4. **三体磨损**：剥落颗粒进入摩擦界面成为"第三体"，加剧磨损

#### 3.3 Hertz 接触应力公式（了解）

两个弹性曲面接触时，接触区尺寸和应力分布由 Hertz 公式描述：

```
σ_H = √(F_n · E_eq / (π · ρ_eq · b))
```

关键参数：
- **等效曲率半径**：1/ρ_eq = 1/ρ₁ + 1/ρ₂
- **综合弹性模量**：1/E_eq = (1-ν₁²)/E₁ + (1-ν₂²)/E₂
- **接触宽度** b 由几何尺寸和载荷共同决定

> "这个公式非常复杂，考试不要求记，后续齿轮章节用到的时候会直接给出。"

**接触强度校核准则**：
```
σ_H ≤ [σ_H] = σ_Hlim / S_H
```
