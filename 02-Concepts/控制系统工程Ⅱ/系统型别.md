# 系统型别（Type）

## 定义

系统型别是指开环传递函数中积分环节（1/s）的个数 ν。系统型别决定了系统跟踪不同输入信号的能力：型别越高，系统能无静差跟踪的输入信号阶次越高。

## 直觉理解

好比一个人的学习能力：系统型别就像学习能力的"等级"。Type 0 系统只能无静差跟踪常数（阶跃输入）；Type Ⅰ 系统能无静差跟踪常数和斜坡（速度输入）；Type Ⅱ 系统能无静差跟踪常数、斜坡和抛物线（加速度输入）。

## 前置概念

- 开环传递函数：系统前向通路与反馈通路传递函数的乘积
- 积分环节：传递函数中的 1/s 项，具有记忆功能
- 稳态误差：系统稳定后，期望输出与实际输出的差值

## 推导到 / 关联到

- 稳态误差：系统型别决定了系统跟踪不同输入信号时的稳态误差
- 静态误差系数：衡量系统跟踪不同输入信号时的稳态精度
- 开环增益：开环传递函数中的比例系数，影响稳态误差大小

## 易混概念

- 开环增益：开环传递函数中的比例系数，影响稳态误差大小，但不决定系统型别
- 闭环极点：闭环传递函数的极点，决定系统稳定性

## 典型例子

- Type 0 系统：开环传递函数中没有积分环节，对阶跃输入有稳态误差
- Type Ⅰ 系统：开环传递函数中有1个积分环节，能无静差跟踪阶跃输入
- Type Ⅱ 系统：开环传递函数中有2个积分环节，能无静差跟踪阶跃和斜坡输入
