# 稳态误差

## 定义

稳态误差（e_ss）是指系统稳定后，期望输出与实际输出的差值。它是衡量控制系统精度的重要指标，反映了系统跟踪输入信号的能力。稳态误差越小，系统精度越高。

## 直觉理解

好比射箭：你瞄准靶心（期望输出），箭射出去后落在某个位置（实际输出）。稳态误差就是箭落点与靶心之间的距离。稳态误差越小，射箭越精准。

## 前置概念

- 传递函数：零初始条件下，输出拉式变换与输入拉式变换之比
- 终值定理：e_ss = lim_{s→0} s·E(s)，用于由 E(s) 求稳态误差
- 稳定性分析：计算稳态误差的前提是系统必须稳定

## 推导到 / 关联到

- 系统型别：开环传递函数中积分环节的个数，决定了系统跟踪不同输入信号的能力
- 静态误差系数：衡量系统跟踪不同输入信号时的稳态精度
- 动态误差：系统暂态过程中的误差，与稳态误差互补

## 易混概念

- 动态误差：系统暂态过程中的误差，随时间变化；稳态误差是暂态过程结束后的误差
- 稳态误差与稳定性：只有稳定的系统才有稳态误差，不稳定的系统没有稳态误差（因为输出发散）

## 典型例子

- Type 0 系统：对阶跃输入有稳态误差，误差为 1/(1+K_p)
- Type Ⅰ 系统：能无静差跟踪阶跃，对斜坡输入有常值误差 1/K_v
- Type Ⅱ 系统：能无静差跟踪阶跃和斜坡，对抛物线输入有常值误差 1/K_a
