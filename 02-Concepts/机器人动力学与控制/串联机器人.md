# 串联机器人

## 定义

串联机器人是各关节**串联连接**的开链结构，灵活性高、工作空间大，但刚度相对不足。工业上最常见的6轴机器人就是串联结构。

## 直觉理解

串联机器人就像**人的手臂**——肩膀→上臂→肘→前臂→腕→手，一节一节连起来。好处是灵活、能伸得很远；坏处是像悬臂梁，刚度不够高。

## 结构特点

- 开链式结构，像悬臂梁
- 每个关节串联连接
- 电机+减速器+传动装置构成关节
- 关节之间通过连杆连接

## 优缺点

| 优点 | 缺点 |
|------|------|
| 工作空间大 | 刚度较低 |
| 灵活性高 | 误差累积 |
| 结构简单 | 承载能力有限 |
| 成本相对低 | 动态性能受限 |

## 刚度问题

工业机器人刚度仅为机床的 **1/50~1/20**：
- 原因：开链式（串联）vs 闭链式（闭环）
- 机器人像悬臂梁，机床像封闭结构

**影响**：
- 精度低：轨迹偏差大
- 质量低：表面粗糙度不达标

## 解决方案

| 方案 | 特点 |
|------|------|
| 并联/混联机器人 | 提高刚度 |
| 柔顺控制 | 控制层面补偿 |
| 误差补偿 | 软件层面修正 |
