# 欧拉四元素 (Euler Parameters / Quaternions)

## 定义

欧拉四元素是由轴角法衍生的**4个参数**描述姿态的方法：

- 欧拉矢量：$\mathbf{e} = \lambda \sin(\theta/2)$
- 四个标量（欧拉参数）：
  - $\varepsilon_1, \varepsilon_2, \varepsilon_3$ = 欧拉矢量在坐标系三轴上的投影
  - $\varepsilon_4 = \cos(\theta/2)$

**约束方程**：$\varepsilon_1^2 + \varepsilon_2^2 + \varepsilon_3^2 + \varepsilon_4^2 = 1$

## 直觉理解

方向余弦矩阵有9个元素但只有3个独立，欧拉四元素用4个参数（有1个约束）来描述3个独立变量。它的好处是**没有奇异性**，在编程中很常用。

## 超球面的几何意义

- 2个独立变量约束为1 → 圆（一维球面）
- 3个独立变量约束为1 → 球（二维球面）
- 4个独立变量约束为1 → **超球面**（三维球面，无法直观想象）

这解释了为什么姿态比位置更难描述——姿态空间是高维的超球面。

## 各方法之间的转换

| 转换 | 方法 |
|------|------|
| 四元素 → 方向余弦矩阵 | 有固定公式，编程中常用 |
| 方向余弦矩阵 → 四元素 | 观察法 |
| 四元素 → 转轴转角 | $\theta = 2 \arccos(\varepsilon_4)$ |

## 优势

- **无奇异性**：不像方向余弦矩阵在某些姿态下接近奇异
- **计算效率高**：只需4个参数
- **插值方便**：球面线性插值（SLERP）
