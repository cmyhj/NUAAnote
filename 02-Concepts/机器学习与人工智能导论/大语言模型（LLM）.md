# 大语言模型（LLM）

## 定义

大语言模型（Large Language Model, LLM）是一类基于 **Transformer 架构**、在**海量文本数据**上预训练的深度学习模型，参数量通常在数十亿到数千亿级别。LLM 通过自监督学习（下一个词预测 / Masked Language Modeling）从数据中学习语言规律，具备文本生成、理解、翻译、推理、代码生成等能力，代表作包括 GPT 系列、LLaMA、ChatGLM 等。

## 直觉理解

好比一个读过全世界所有书的超级学霸——他没有"标准答案"数据库，而是通过阅读数万亿字的书籍网页，学会了"人类通常如何组织语言"的统计规律。你问问题，他就根据学到的语言模式"猜测最有可能的答案"——本质是高级版的"自动补全"（Auto-complete）。

## 前置概念

- Transformer 架构：所有 LLM 的基础架构，完全基于注意力机制
- 预训练（Pre-training）：在海量无标注数据上的大规模训练阶段
- 自监督学习（Self-supervised Learning）：用数据自身构造监督信号（如遮掩部分文本预测缺失的词）

## 推到到 / 关联到

- 涌现能力（Emergent Abilities）：当模型规模超过某个阈值时，突然表现出小模型不具有的能力（如思维链推理）
- 幻觉（Hallucination）：LLM 可能生成看似合理但不符合事实的内容——概率生成模式无内在逻辑一致性保证
- 微调（Fine-tuning）：在预训练基础上用特定任务数据调整模型参数
- RAG（检索增强生成）：在 LLM 问答时从外部知识库检索相关文档辅助回答，缓解幻觉问题

## 易混概念

- LLM vs 传统机器学习模型：传统模型针对特定任务训练（如分类器）；LLM 通过预训练获得通用语言理解能力，可适应多种任务
- LLM vs 大型语言模型概念的具体范围：严格来说 LLM 特指 Transformer-based 的大规模模型；早期的统计语言模型（n-gram）不叫 LLM
- 概率生成 vs 逻辑推理：LLM 本质上是一个概率模型——它生成"最可能的词序列"，而非进行形式逻辑推理。这是"幻觉"的根本原因（田畅老师强调的观点）

## 典型例子

- GPT-4：OpenAI 的多模态大语言模型，能理解文本和图像输入，生成人类水平的文本回复
- ChatGPT：基于 GPT 系列模型的对话式 AI，可用于编程助手、创意写作、问答等
- 课程报告选题：田畅老师鼓励学生选 AI 相关主题——大模型幻觉、AI 对某行业的影响等作为期末大作业方向
