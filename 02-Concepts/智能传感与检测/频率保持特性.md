# 频率保持特性

## 定义

频率保持特性是线性系统的重要特性之一：输入信号的**频率成分**通过线性系统后**保持不变**（仅幅值和相位改变）。

## 直觉理解

如果你给一个线性系统输入一个包含3Hz成分的信号，输出里**一定也有3Hz成分**——只是幅值可能变小了，相位可能延迟了。如果输入输出频率不同，说明系统是非线性的。

## 数学表达

若输入 $x(t)$ 包含频率 $\omega$ 的成分，则输出 $y(t)$ 也必包含频率 $\omega$ 的成分。

## 判断意义

- 若输入输出频率相同 → 系统是**线性**的
- 若输入输出频率不同 → 系统是**非线性**的

**例子**：余弦波通过二极管变成方波（频率成分改变），说明二极管是非线性元件。

## 与其他线性系统特性的关系

| 特性 | 描述 |
|------|------|
| 叠加性 | 系统对输入之和的输出等于各输入单独作用的输出之和 |
| 比例性 | 系统对k倍输入的输出等于k倍输出 |
| 时不变性 | 输入延迟τ，输出也延迟τ |
| 微分特性 | 对输入求导后通过系统，等于输出的导数 |
| 频率保持特性 | 输入频率成分通过系统后保持不变 |
