# Open Loop 与 Close Loop（开环与闭环）

## 定义

- **开环（Open Loop）**：系统输出不对输入产生影响的控制/测量方式。信号单向流动，无反馈通路。
- **闭环（Close Loop）**：系统输出通过反馈通道与输入比较，形成误差信号驱动调节。信号沿回路流动，有反馈通路。

## 直觉理解

老师说："**感知最重要的就是把 open loop 变成 close loop**。"

- **Open loop** = 蒙眼走路。你下达指令，但不知道实际发生了什么，走偏了也无法纠正。
- **Close loop** = 睁眼走路。眼睛（传感器）看路（反馈），大脑比较"想走的路"和"实际的路"的差距，调整脚步（控制）。

## 前置概念

- **传感器**：闭环中提供反馈量的关键
- **测试系统组成**：理解信号流动方向

## 推导到 / 关联到

- **反馈（Feedback）**：闭环的核心，分为正反馈和负反馈
- **传感器的作用**：传感器将物理世界的状态"告诉"控制器，使系统从开环变为闭环。"给系统装上眼睛"就是加入传感器实现闭环
- **测控一体化**：测量（测试系统）是开环，加入传感器反馈后形成闭环控制
- **智能传感**：智能传感器内部往往有闭环自校准/自补偿

## 易混概念

- **Open loop ≠ 无传感器**：测试系统有传感器但无反馈
- **Close loop ≠ 一定有传感器**：反馈量不一定来自传感器（可来自模型估计），但传感是闭环最可靠的方式

## 典型例子

| 场景 | Open Loop | Close Loop |
|------|-----------|------------|
| 空调 | 设定温度，一直吹 | 温度传感器检测室温，达到设定值停机 |
| 电机控制 | 施加固定电压 | 编码器测转速，PID调节电压 |
| 加热炉 | 通恒定电流加热 | 热电偶测温，调节加热功率 |
| 人拿杯子 | 大脑发出"伸手"指令（开环也行不通） | 眼睛看手的位置，触觉感知接触，实时调整 |

老师金句：**"给系统装上传感器，open loop 就变成了 close loop，这就是感知的意义。"**
