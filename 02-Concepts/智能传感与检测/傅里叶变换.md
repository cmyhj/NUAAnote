# 傅里叶变换

## 定义

傅里叶变换（Fourier Transform）是一种将信号从**时域**转换到**频域**的数学工具。核心思想：**任意信号都可以分解为不同频率的正弦波和余弦波的叠加**。

## 直觉理解

想象你在听一首交响乐。时域告诉你"此刻声音有多响"，频域告诉你"此刻有哪些乐器在演奏"。傅里叶变换就像一个"频率棱镜"，把混合的光（信号）分解成彩虹（频谱）。

## 傅里叶级数（周期信号）

### 三角函数形式

对于周期为 $T$ 的信号 $x(t)$：

$$x(t) = a_0 + \sum_{n=1}^{\infty} [a_n \cos(n\omega_0 t) + b_n \sin(n\omega_0 t)]$$

其中基频 $\omega_0 = \frac{2\pi}{T}$，系数计算：

$$a_0 = \frac{1}{T}\int_{-T/2}^{T/2} x(t)dt \quad \text{（直流分量）}$$

$$a_n = \frac{2}{T}\int_{-T/2}^{T/2} x(t)\cos(n\omega_0 t)dt \quad \text{（余弦系数）}$$

$$b_n = \frac{2}{T}\int_{-T/2}^{T/2} x(t)\sin(n\omega_0 t)dt \quad \text{（正弦系数）}$$

### 复指数形式

利用欧拉公式 $e^{j\omega t} = \cos(\omega t) + j\sin(\omega t)$：

$$x(t) = \sum_{n=-\infty}^{\infty} C_n e^{jn\omega_0 t}$$

$$C_n = \frac{1}{T}\int_{-T/2}^{T/2} x(t)e^{-jn\omega_0 t}dt$$

### 幅值与相位

$$A_n = \sqrt{a_n^2 + b_n^2} \quad \text{（第n次谐波幅值）}$$

$$\varphi_n = \arctan\left(\frac{b_n}{a_n}\right) \quad \text{（第n次谐波相位）}$$

## 傅里叶变换（非周期信号）

### 正变换（时域→频域）

$$X(\omega) = \int_{-\infty}^{\infty} x(t)e^{-j\omega t}dt$$

### 逆变换（频域→时域）

$$x(t) = \frac{1}{2\pi}\int_{-\infty}^{\infty} X(\omega)e^{j\omega t}d\omega$$

### 物理意义

- $X(\omega)$ 是复数，包含幅值和相位信息
- $|X(\omega)|$ 是幅值谱：各频率成分的强度
- $\angle X(\omega)$ 是相位谱：各频率成分的初始相位

## 时域-频域对应关系

| 时域特性 | 频域特性 | 示例 |
|----------|----------|------|
| 周期 | 离散 | 方波→离散谱线 |
| 非周期 | 连续 | 矩形窗→sinc函数 |
| 连续 | 非周期 | 指数衰减→连续谱 |
| 离散 | 周期 | 采样信号→周期频谱 |

**反义词对应**：
- 时域压缩 ↔ 频域扩展
- 时域扩展 ↔ 频域压缩
- 时域卷积 ↔ 频域乘积
- 时域乘积 ↔ 频域卷积

## 典型函数的频谱

| 时域函数 | 频域函数 | 数学表达式 |
|----------|---------|------------|
| 矩形窗 | sinc函数 | $X(\omega) = \tau \cdot \text{sinc}(\frac{\omega\tau}{2})$ |
| $δ$函数 | 直流分量 | $X(\omega) = 1$ |
| 直流信号 | $δ$函数 | $X(\omega) = 2\pi\delta(\omega)$ |
| 双边指数 | 洛伦兹型 | $X(\omega) = \frac{2a}{a^2+\omega^2}$ |
| 高斯函数 | 高斯函数 | $X(\omega) = \sqrt{\pi}e^{-\omega^2/4}$ |
| 符号函数 | $\frac{2}{j\omega}$ | $X(\omega) = \frac{2}{j\omega}$ |

## 傅里叶变换的性质

| 性质 | 时域 | 频域 |
|------|------|------|
| 线性 | $ax_1(t)+bx_2(t)$ | $aX_1(\omega)+bX_2(\omega)$ |
| 时移 | $x(t-t_0)$ | $X(\omega)e^{-j\omega t_0}$ |
| 频移 | $x(t)e^{j\omega_0 t}$ | $X(\omega-\omega_0)$ |
| 尺度变换 | $x(at)$ | $\frac{1}{|a|}X(\frac{\omega}{a})$ |
| 卷积 | $x_1(t)*x_2(t)$ | $X_1(\omega) \cdot X_2(\omega)$ |
| 乘积 | $x_1(t) \cdot x_2(t)$ | $\frac{1}{2\pi}X_1(\omega)*X_2(\omega)$ |
| 微分 | $\frac{dx}{dt}$ | $j\omega X(\omega)$ |
| 积分 | $\int x(t)dt$ | $\frac{X(\omega)}{j\omega}$ |

## 与拉普拉斯变换的关系

$$\text{拉普拉斯变换：} X(s) = \int_{0}^{\infty} x(t)e^{-st}dt, \quad s=\sigma+j\omega$$

当 $\sigma=0$ 时，拉普拉斯变换退化为傅里叶变换：

$$X(j\omega) = X(s)|_{s=j\omega}$$

拉普拉斯变换引入了衰减/增长因子 $\sigma$，工程应用更广泛（可分析系统稳定性）。

## 计算示例

### 方波的傅里叶展开

方波（幅值 $A$，周期 $T$）：

$$x(t) = \frac{4A}{\pi}\sum_{n=1,3,5,...}^{\infty} \frac{\sin(n\omega_0 t)}{n}$$

- 只在奇数倍基频上有值
- 幅值随谐波次数递减：$\frac{4A}{\pi}, \frac{4A}{3\pi}, \frac{4A}{5\pi}, ...$

### 三角波的傅里叶展开

$$x(t) = \frac{8A}{\pi^2}\sum_{n=1,3,5,...}^{\infty} \frac{(-1)^{(n-1)/2}\sin(n\omega_0 t)}{n^2}$$

- 幅值衰减更快（$1/n^2$ vs $1/n$）

## 频谱图绘制方法

### 什么是频谱图

频谱图（Spectrum）是将信号的频率成分可视化表示的图形：
- **横轴**：频率 $f$（Hz）或角频率 $\omega$（rad/s）
- **纵轴**：幅值 $|X(\omega)|$ 或功率 $|X(\omega)|^2$

### 绘制步骤

**第一步：判断奇偶性**
- 奇函数：$a_0=0$, $a_n=0$，只有 $b_n$（正弦项）
- 偶函数：$b_n=0$，只有 $a_0$ 和 $a_n$（余弦项）

**第二步：计算傅里叶系数**
- 代入公式积分求解 $a_0$, $a_n$, $b_n$
- 计算幅值：$A_n = \sqrt{a_n^2 + b_n^2}$

**第三步：确定频率轴**
- 基频：$\omega_0 = \frac{2\pi}{T}$
- 谐波频率：$n\omega_0$（$n=1,2,3,...$）

**第四步：画图**
- 在每个谐波频率处画竖线，高度为对应幅值
- 通常画到第9次谐波即可（奇函数画1,3,5,7,9；偶函数画2,4,6,8）

### 单边幅值谱 vs 双边幅值谱

#### 单边幅值谱（考试常用）

**定义**：只画正频率部分的频谱图，将负频率的能量"折叠"到正频率上。

**为什么用单边幅值谱**：
- 实信号的频谱是共轭对称的（负频率和正频率的幅值相等）
- 画双边谱会重复，单边谱更简洁
- 工程上只关心正频率（负频率没有物理意义）

**特点**：
- 只画正频率部分
- 幅值为 $A_n$（完整的幅值）
- 横轴：$0, \omega_0, 2\omega_0, 3\omega_0, ...$

**绘制方法**：
1. 计算傅里叶系数 $a_n$, $b_n$
2. 计算幅值 $A_n = \sqrt{a_n^2 + b_n^2}$
3. 在每个谐波频率 $n\omega_0$ 处画竖线，高度为 $A_n$

#### 双边幅值谱

**定义**：画正负频率的频谱图，用于理论分析。

**特点**：
- 正负频率都画
- 幅值为 $A_n/2$（能量平分到正负频率）
- 横轴：$...,-3\omega_0, -2\omega_0, -\omega_0, 0, \omega_0, 2\omega_0, 3\omega_0,...$

**与单边谱的关系**：
- 单边谱幅值 = 双边谱幅值 × 2
- 单边谱只画正频率，双边谱正负都画

#### 直流分量的处理

- **单边谱**：直流分量 $a_0$ 直接画在频率为0处
- **双边谱**：直流分量 $a_0$ 画在频率为0处（不除以2）

#### 示例：方波的单边幅值谱

方波（幅值 $A$，周期 $T$）：
- $b_n = \frac{4A}{n\pi}$，$n=1,3,5,...$
- $A_n = b_n$（因为 $a_n=0$）

单边幅值谱：
| 频率 | 幅值 |
|------|------|
| $\omega_0$ | $\frac{4A}{\pi}$ |
| $3\omega_0$ | $\frac{4A}{3\pi}$ |
| $5\omega_0$ | $\frac{4A}{5\pi}$ |
| $7\omega_0$ | $\frac{4A}{7\pi}$ |
| $9\omega_0$ | $\frac{4A}{9\pi}$ |

#### 示例：三角波的单边幅值谱

三角波（幅值 $A$，周期 $T$）：
- $a_n = \frac{8A}{n^2\pi^2}$，$n=1,3,5,...$
- $A_n = a_n$（因为 $b_n=0$）

单边幅值谱：
| 频率 | 幅值 |
|------|------|
| $\omega_0$ | $\frac{8A}{\pi^2}$ |
| $3\omega_0$ | $\frac{8A}{9\pi^2}$ |
| $5\omega_0$ | $\frac{8A}{25\pi^2}$ |
| $7\omega_0$ | $\frac{8A}{49\pi^2}$ |
| $9\omega_0$ | $\frac{8A}{81\pi^2}$ |

### 考试技巧

1. **必背公式**：
   - 方波：$b_n = \frac{4A}{n\pi}$，$n=1,3,5,...$
   - 三角波：$a_n = \frac{8A}{n^2\pi^2}$，$n=1,3,5,...$

2. **快速画图**：
   - 方波：幅值按 $1, 1/3, 1/5, 1/7, 1/9$ 递减
   - 三角波：幅值按 $1, 1/9, 1/25, 1/49, 1/81$ 递减

3. **标注要求**：
   - 在图上标出具体幅值（如 $\frac{4A}{\pi}$, $\frac{4A}{3\pi}$）
   - 标出频率轴（$\omega_0$, $3\omega_0$, $5\omega_0$）

### Matlab 绘制频谱图

```matlab
% 生成方波信号
fs = 1000;  % 采样频率
t = 0:1/fs:1;  % 时间轴
f0 = 5;  % 基频
x = square(2*pi*f0*t);  % 方波信号

% FFT变换
X = fft(x);
n = length(x);
f = (0:n-1)*(fs/n);  % 频率轴
magnitude = abs(X)/n;  % 幅值

% 绘制单边幅值谱
figure;
plot(f(1:n/2), 2*magnitude(1:n/2));
xlabel('频率 (Hz)');
ylabel('幅值');
title('方波的频谱图');
grid on;
```

## 应用

1. **频谱分析**：识别信号中的频率成分
2. **滤波器设计**：在频域设计滤波器，再转换到时域实现
3. **图像处理**：二维傅里叶变换用于图像频域分析
4. **通信系统**：OFDM调制基于傅里叶变换
5. **故障诊断**：通过振动频谱识别机械故障
