# 磁通门传感器

## 定义

磁通门传感器利用**软磁铁芯的磁饱和效应**测量静态磁场的传感器。核心结构包括高磁导率磁芯（坡莫合金）、激励线圈和感应线圈，采用差动结构消除偶次谐波。

## 工作原理

1. 激励线圈产生交变磁场
2. 软磁铁芯周期性达到磁饱和
3. 外磁场打破对称性，产生二次谐波
4. 感应线圈检测二次谐波幅值
5. 通过二次谐波幅值反推磁场强度

## 差动结构

两个铁芯绕向相反：
- 消除奇次谐波
- 只保留偶次谐波
- 提高测量精度

## 与霍尔传感器对比

| 特性 | 霍尔传感器 | 磁通门传感器 |
|------|-----------|-------------|
| 气隙 | 有 | 无 |
| 量程 | 宽 | 窄 |
| 适用场景 | 粗测 | 精测 |
| 成本 | 低 | 高 |
| 精度 | 一般 | 高 |

## 应用场景

- 卫星姿态控制（嫦娥号）
- 地磁监测
- 工业无损检测
- 航空航天

## 历史

战国司南 → 1600年吉尔伯特《磁论》 → 法拉第/麦克斯韦电磁理论 → 磁通门传感器
