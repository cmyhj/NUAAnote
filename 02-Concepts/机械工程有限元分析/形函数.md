# 形函数

## 定义

定义在单元内部的插值函数，用于将节点位移映射到单元内任意点的位移（或坐标）：

$$u(x) = \sum_{i=1}^{n} N_i(x) u_i$$

其中 $N_i(x)$ 是第 $i$ 个节点的形函数，$u_i$ 是该节点的位移值。形函数在节点 $i$ 处取值为 1，在其他节点处取值为 0。

## 直觉理解

形函数就像"影响力函数"。每个节点对单元内部不同位置的影响力大小不一样——离节点越近，这个节点的影响越大。形函数 $N_i$ 描述的就是节点 $i$ 的"影响力"如何随位置变化。在一维线性单元中，形函数是直线：左节点的影响从左到右从 1 降到 0，右节点的影响从 0 升到 1。

## 前置概念

- **单元与节点**：形函数定义在单元上，节点是采样点
- **拉格朗日插值**：形函数本质上就是拉格朗日插值多项式在有限元中的应用

## 推导到 / 关联到

- **刚度矩阵**：形函数的导数出现在应变-位移矩阵 $[B]$ 中，是刚度矩阵被积函数的核心部分
- **有限元法（FEM）**：形函数是 FEM 实现"分片近似"的工具
- **等参变换**：用相同形函数分别插值几何坐标和位移场，实现任意形状单元的标准化计算

## 易混概念

| 概念 | 区别 |
|------|------|
| **基函数**（伽辽金法中的试函数） | 形函数在伽辽金法中既做试函数又做权函数，但概念上试函数用于近似解，权函数用于加权残差 |
| **权函数** | 在加权残量法中，权函数与形函数可以不同（如配点法），但伽辽金法中二者相同 |
| **样条函数** | 样条函数强调整体光滑性，形函数强调单元内插值和节点连续性 |

## 典型例子

一维二节点杆单元：形函数为 $N_1(x) = 1 - \frac{x}{L}$，$N_2(x) = \frac{x}{L}$。在 $x=0$ 处 $N_1=1, N_2=0$；在 $x=L$ 处 $N_1=0, N_2=1$。单元内任一点的位移由 $u(x) = N_1 u_1 + N_2 u_2$ 线性插值得到。
