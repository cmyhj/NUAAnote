# 平面应力与平面应变

## 定义

对弹性力学三大方程进行 2D 简化的两种典型假设：

- **平面应力（Plane Stress）**：$\sigma_z = \tau_{xz} = \tau_{yz} = 0$，$\varepsilon_z \neq 0$
  - 适用于薄板（厚度远小于面内尺寸），载荷在面内、不沿厚度变化
- **平面应变（Plane Strain）**：$\varepsilon_z = \gamma_{xz} = \gamma_{yz} = 0$，$\sigma_z \neq 0$
  - 适用于长结构（如水坝、隧道），载荷沿长度方向不变

## 直觉理解

- **平面应力**：看一张薄纸被从两边拉伸。纸很薄，厚度方向可以自由收缩（$\sigma_z=0$），但如果拉长它会变薄（$\varepsilon_z \neq 0$）。纸的"侧面"不受力，是自由表面。
- **平面应变**：想象一堵很长的水坝，中间切出一片薄片来看。两侧厚厚的混凝土挡住，这个薄片在长度方向不能伸缩（$\varepsilon_z=0$），但内部会有厚度方向的应力（$\sigma_z \neq 0$）。

## 前置概念

- **弹性力学三大方程**：本假设是在三大方程基础上做的维度简化
- **应力与应变概念**：理解正应力/正应变、剪应力/剪应变

## 推导到 / 关联到

- **有限元法（FEM）**：平面问题是 FEM 教学和工程中最常见的 2D 简化，大幅降低计算成本
- **单元与节点**：平面问题中单元是 2D 的（三角形/四边形），每个节点 2 个自由度

## 易混概念

| 概念 | 区别 |
|------|------|
| **轴对称问题** | 轴对称也把 3D 简化为 2D，但用的是柱坐标，假设几何和载荷绕轴旋转对称；平面问题是直角坐标下的 2D 简化 |
| **三维问题** | 三维没有简化假设，计算量大；平面应力/应变是工程近似 |
| **平面应力 vs 平面应变** | 本质区别在于厚度方向是自由 ($\sigma_z=0$) 还是约束 ($\varepsilon_z=0$)，导致弹性矩阵 $[D]$ 不同 |

## 典型例子

- **平面应力**：含圆孔的薄板单轴拉伸。$[D]$ 矩阵中 $D_{33} = \frac{E}{2(1+\nu)}$ 且 $D_{11}=D_{22}=\frac{E}{1-\nu^2}$，$D_{12}=\frac{\nu E}{1-\nu^2}$
- **平面应变**：长隧道截面的围岩应力分析。$[D]$ 矩阵中 $D_{11}=D_{22}=\frac{E(1-\nu)}{(1+\nu)(1-2\nu)}$，$D_{12}=\frac{\nu E}{(1+\nu)(1-2\nu)}$
