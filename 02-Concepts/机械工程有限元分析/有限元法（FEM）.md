# 有限元法（Finite Element Method, FEM）

## 定义

将连续体离散为有限个单元，利用分片插值逼近整体解的一种数值方法。核心思想：**离散近似**——用有限个自由度（DOF）逼近无限自由度问题。

## 直觉理解

想象要测量一条曲线的长度。如果用手工测量，可以将曲线分成很多小段直线，每段用尺子量，加起来就是总长。分段越细，结果越准。有限元法做的是同样的事：把复杂的连续体切成许多"小片"（单元），在每个小片上用简单的函数近似，然后组装起来得到整体的近似解。

## 前置概念

- **弹性力学三大方程**：FEM 求解的是这些方程的近似形式
- **线性代数**：刚度矩阵的组装与求解依赖矩阵运算
- **微分方程数值解**：FEM 是 PDE 数值方法的一种

## 推导到 / 关联到

- **单元与节点**：FEM 的离散化载体
- **刚度矩阵**：FEM 的核心代数系统
- **形函数**：实现单元内插值的关键工具
- **虚功原理**：推导单元刚度矩阵的力学基础

## 易混概念

| 概念 | 区别 |
|------|------|
| **有限差分法（FDM）** | FDM 直接离散微分方程，FEM 离散积分形式（弱形式） |
| **解析法** | 解析法给出精确解但只适用于简单几何/边界；FEM 适用任意复杂问题但给出近似解 |
| **边界元法（BEM）** | BEM 只在边界离散，FEM 在整个域离散 |

## 典型例子

悬臂梁的变形分析：将连续梁离散为若干个梁单元，每个单元两端有节点。组装所有单元的刚度矩阵后，施加边界条件和载荷，求解线性方程组得到各节点位移，进而得到全梁的应力分布。
