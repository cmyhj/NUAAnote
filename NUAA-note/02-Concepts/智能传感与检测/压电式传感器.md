# 压电式传感器

## 定义

压电式传感器利用**压电效应**（Piezoelectric Effect）工作——某些晶体（石英、压电陶瓷等）在受到机械应力时，会在晶体表面产生与应力成正比的电荷。压电式传感器适用于测量动态力、压力、加速度、振动等快速变化的物理量。

## 直觉理解

想象你用力捏一块打火机里的压电陶瓷——它会瞬间产生高压电火花。压电传感器就是这个原理的精密版：受到挤压（压力/振动）→ 产生电荷（电信号）。问题是电荷会很快泄露，所以它只适合测量"变化"（动态），不适合测量"一直压着"（静态）。

## 前置概念

- 传感器：压电式传感器是能量转换型传感器（将机械能转换为电能）
- 正压电效应：机械变形 → 产生电荷（传感）
- 逆压电效应：施加电场 → 产生机械变形（驱动/执行器）

## 推导到 / 关联到

- 电荷放大器：压电传感器的输出阻抗极高，需电荷放大器将电荷转换为低阻抗电压信号
- 加速度计：最常见的压电传感器应用——质量块在振动中压迫压电晶片产生电荷
- 动态响应：压电传感器的固有频率很高（可达几十 kHz），适合高频动态测量

## 易混概念

- 压电式 vs 电阻式（应变片）：压电式 = 自发电型（无需外部电源），只测动态；电阻式 = 被动型（需激励电源），可测静态和动态
- 压电式 vs 电容式：压电式适宜高频振动测量；电容式适宜低频/静态测量
- 正压电效应 vs 逆压电效应：正效应 = 力→电（传感器用）；逆效应 = 电→力（超声换能器/压电马达用）

## 典型例子

- 压电加速度计：汽车碰撞测试中测量冲击加速度，内部质量块振动压迫压电晶片
- 声呐换能器：利用逆压电效应将电信号转换为水下声波（发射），正压电效应接收回波
- 发动机爆震传感器：检测发动机汽缸的异常振动频率，反馈给 ECU 调整点火时刻
