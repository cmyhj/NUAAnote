# 单元与节点

## 定义

- **单元（Element）**：将连续体离散化后得到的小子域，是 FEM 离散的基本单位
- **节点（Node）**：单元与单元之间的连接点，自由度（DOF）定义在节点上

单元通过节点连接组成网格，节点位移是 FEM 的基本求解变量。

## 直觉理解

把一张地图分成很多小方格，每个小格就是一个**单元**，方格的四个角就是**节点**。整张地图的完整地形信息（高度等）只需要记录每个角点的数值，小格内部的数值通过插值得到。

在有限元中同理：我们只直接求解节点上的位移，单元内部的位移由形函数插值得到。

## 前置概念

- **有限元法（FEM）**：离散化是 FEM 的第一步，"切分"成单元和节点

## 推导到 / 关联到

- **形函数**：定义在单元上，利用节点值进行内部插值
- **刚度矩阵**：每个单元有自己的刚度矩阵，通过共享节点组装成整体矩阵
- **自由度（DOF）**：节点上每个独立的位移分量称为一个自由度，是代数系统的最小未知量

## 易混概念

| 概念 | 区别 |
|------|------|
| **有限元网格** | 网格是所有单元和节点的总体；单元和节点是网格的组成部分 |
| **积分点（Gauss 点）** | 积分点是单元内部用于数值积分（如高斯积分）的采样点，不是节点，结果通常也在积分点处最精确 |
| **网格节点 vs 几何节点** | 有限元节点是离散计算点；几何节点（CAD 中的 control point）用于定义几何形状，不一定与有限元节点重合 |

## 典型例子

一个平面三角形单元：3 个节点（三角形顶点），每个节点在 2D 问题中有 2 个自由度（$u_x, u_y$），共 6 个自由度。三角形单元内部位移场由 3 个形函数插值得到。多个三角形单元共享边上的节点，形成连续网格。
