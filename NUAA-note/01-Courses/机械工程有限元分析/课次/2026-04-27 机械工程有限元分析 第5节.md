## 关键概念

- **[[有限元法（FEM）|有限单元法 (FEM / Finite Element Method)]]**: 将连续体离散为有限个单元，通过对每个单元求解再组装得到整体响应的数值近似方法。
- **[[单元与节点|节点 (Node)]]**: 单元之间的连接点，描述位移和力的基本对象。有的软件称 node，有的称 grid。
- **[[单元与节点|单元 (Element)]]**: 离散后的基本计算单位，如一维弹簧单元、二维三角形/矩形单元、三维体单元等。
- **[[刚度矩阵|刚度矩阵 (Stiffness Matrix)]]**: 描述节点力与节点位移之间线性关系的矩阵，{f} = [k]{δ} 是所有静力学有限元方程的基本形式。
- **离散化 (Discretization)**: 将连续体划分成有限个形状规则的单元的过程，单元越密，近似精度越高。
- **数字孪生 (Digital Twin)**: 基于物理模型（含力学特性）的虚拟仿真系统。教师强调"真正的数字孪生要带着力学特性，不只是空间布置的可视化"。
- **CAE (Computer Aided Engineering)**: 计算机辅助工程，FEM是其核心方法之一，与 CAD、CAM 共同构成现代工程设计体系。

### 有限元的核心思想——从"三角形近似圆"说起

FEM 本质上是一种 **数值近似算法**。教师用"不知道圆周率时如何计算圆面积"来解释：

1. 如果只会算三角形面积，就把圆分割成许多小三角形
2. 6个三角形 → 8个 → 16个 → 160个 → 精度越来越高
3. 现代 FEA 一个结构可划分 **40万～100万个单元** [22:15-22:22]
4. 每个单元单独计算力学特性，然后机械地组装（用计算机编程实现），最终逼近真实系统 [22:30-22:48]

### 两类力学问题 vs FEM 的优势

| 类型       | 描述          | 传统方法                 | FEM        |
| -------- | ----------- | -------------------- | ---------- |
| **离散结构** | 桁架、桥梁等由杆件组成 | 结构力学手工可算，但复杂时不可行     | 任意复杂结构均可求解 |
| **连续体**  | 板带孔、导弹外壳等   | 弹性力学偏微分方程，复杂边界几乎无解析解 | 离散后轻松求解    |

**精度对比**：早期将整架飞机简化为一根梁，误差约 **50%**；现代 FEA 动力学误差可到 **5-10%**，静力学可达 **千分级** [29:18-29:44]。

### FEM 发展简史

- **1960s** — Clough（美国，中国工程院外籍院士）首次在航空结构分析中提出 "finite element" 一词，用三角形和矩形单元建立节点力-位移关系 [30:11-31:11, 33:39-34:04]。
- **中国独立发展** — 恒康（音）在大型水坝计算中独立使用了类似方法，时间略晚于美国 [30:51-31:11]。
- **清华传承** — 杜庆华、王旭成（编有《有限单元法》）、钱伟长等推动国内 FEM 发展 [31:53-32:33]。
- **1970s-80s** — 计算机普及使 FEM 从理论走向工程；早期用打孔纸带编程，效率极低 [35:40-35:51]。
- **1990s-2000s** — 前/后处理可视化技术成熟，CAD/CAE 集成，出现通用和专业 FEA 软件 [36:06-36:55]。

### 弹簧单元——FEM 最简模型

以单个弹簧为例讲解 FEM 的最小计算单元：

- **节点**：弹簧两端为节点（node/grid），每个节点有位移 u 和力 f
- **单元平衡方程**：f = k · δ（δ = uⱼ − uᵢ）
- **矩阵形式**：
  ```
  {f₁}   [ k  -k ] {u₁}
  {f₂} = [-k   k ] {u₂}
  ```
- **边界条件**：无边界条件方程不可解。例如固定 u₁=0，则方程退化为 k·u₂ = f₂ [44:45-45:35]

**两弹簧串联组装演示** [46:32-50:49]：
- 节点 1-2-3，弹簧 k₁、k₂ 串联
- 先写出每个单元各自的刚度矩阵
- 根据**节点力平衡**（节点 2 处的力来自两个单元 + 外载荷）组装总体刚度矩阵
- 本质是线性代数方程组求解，只不过矩阵有明确的物理意义
