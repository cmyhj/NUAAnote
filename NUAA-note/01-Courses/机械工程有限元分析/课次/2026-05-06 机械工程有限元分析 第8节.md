## 要点详述

### 1. 自由度 (DOF) 的深刻理解 (03:14–06:56)

- **弹性变形自由度 ≠ 运动自由度**：理论力学中的自由度指刚体运动，有限元中的自由度指弹性变形的独立分量。
- **DOF 是有限元"规模"的核心指标**：若某结构有 N 个节点，每节点有 m 个 DOF，则总体刚度矩阵为 Nm × Nm，平衡方程数为 Nm。
> 例：1 万节点、实体单元 (3 DOF/节点) → 3 万个方程，矩阵 3 万×3 万。

### 2. 形函数 — 位移插值的灵魂 (10:42–17:13)

- 基本假设：位移在节点之间按**线性**分布（基于均匀连续假设）。
- 自然坐标引入目的：将积分区间从 [0, L] 归一化到 [0, 1]，极大简化后续计算。
- 推导链条：假设 u(x) → 用节点位移 u₁,u₂ 插值 → 形函数 N₁ = 1−ξ, N₂ = ξ → 矩阵形式 u = N·u⁽ᵉ⁾。
- **形函数的本质**：节点位移对场点位移的"加权贡献"，ξ=0 时 N₁=1 完全由节点1贡献；ξ=1 时 N₂=1 完全由节点2贡献。

### 3. 虚位移原理 — 通用推导框架 (22:29–27:31)

完整路径：

```
位移场假设 u(x) = N·u⁽ᵉ⁾
      ↓
应变 ε = du/dx = B·u⁽ᵉ⁾      (B = dN/dx = [−1/L  1/L])
      ↓
应力 σ = E·ε = E·B·u⁽ᵉ⁾
      ↓
虚位移原理:  ∫ᵥ δεᵀ·σ dV = δuᵀ·f     虚应变能 = 外力虚功
      ↓
约去虚位移 δuᵀ → K⁽ᵉ⁾ = ∫ᵥ Bᵀ·E·B dV
      ↓
代入杆单元:  K = (EA/L)·[1  −1;  −1  1]   (与弹簧等效结果一致)
```

该公式对**平面单元、三维单元**同样适用——只需将标量 E 替换为弹性矩阵 D（含 E, ν）。

### 4. 双杆串联例题完整流程 (30:04–43:35)

**问题**：杆1 (截面 2A, 长 L) + 杆2 (截面 A, 长 L)，两端固定，中点受 P。

| 步骤 | 操作 | 结果 |
|------|------|------|
| ① 单元 K | 杆1: K₁ = (2EA/L)·[1 −1; −1 1], 杆2: K₂ = (EA/L)·[1 −1; −1 1] | 两个 2×2 |
| ② 组集 | 按 u₁,u₂,u₃ 叠加 | 3×3 总体 K |
| ③ BC | u₁=0, u₃=0; f₂=P | — |
| ④ 求解 u₂ | 划去行列 → 单自由度方程 | u₂ = PL/(3EA)×? [ASR 不清晰] |
| ⑤ 支反力 | f₁ = K(1,:)·u; f₃ = K(3,:)·u | — |
| ⑥ 杆应力 | σ = E·B·u⁽ᵉ⁾ | σ₁ = σ₂ = P/3A |

**验证**：力的封闭性 — 外力 P 与两个支反力平衡；应力估计符合直觉（两杆并联等效截面 3A）。

### 5. 坐标变换引出 (43:55–48:05)

- 局部坐标系 (小写 x,y)：杆沿 x 方向，仅有轴向变形。
- 总体坐标系 (大写 X,Y)：斜杆在 X,Y 方向均有位移分量 → 每节点 2 DOF → 4×4 刚度矩阵。
- 坐标变换是有限元处理复杂结构几何的基石。
