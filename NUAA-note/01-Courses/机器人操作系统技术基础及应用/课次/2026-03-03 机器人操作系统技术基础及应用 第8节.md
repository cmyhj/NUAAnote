## 关键概念

| 概念 | 说明 |
|------|------|
| **[[ROS（机器人操作系统）|ROS (Robot Operating System)]]** | 开源机器人软件开发平台，提供硬件抽象、底层驱动、消息传递、程序管理等功能，并非真正的"操作系统" |
| **分布式 / 点对点架构** | ROS 中每个功能模块作为独立节点运行，通过 TCP/IP 网络通信；节点可分布在不同的主机上 |
| **话题 (Topic)** | ROS 中异步数据流通信方式，发布/订阅模型 |
| **服务 (Service)** | ROS 中同步数据通信方式，请求/响应模型 |
| **Master Node (ROS1)** | 主节点，是 ROS1 的单点故障环节；ROS2 已移除 |
| **LTS vs 非 LTS** | 长期支持版（5年维护）vs 短期版（2年维护） |
| **发行版 (Distribution)** | 基于 Linux 内核，打包不同工具软件形成的完整操作系统版本，如 Ubuntu、Red Hat |
| **虚拟机 (VM)** | 在宿主机中通过软件模拟完整计算机硬件，运行另一个操作系统，适合初学者搭建 ROS 环境 |

### 4. ROS 核心设计理念 [13:36-17:12]

- **核心目标**：提高机器人研发中软件的复用率，避免重复发明轮子
- **分布式松散耦合**：
  - 每个功能模块作为独立节点，可单独设计、编译
  - 非主节点的普通节点故障不影响其他节点
  - ROS1 有一个 **Master 主节点**（单点故障）；ROS2 彻底去中心化
- **开源生态**：遇到需求先搜索已有开源实现（如电机驱动），直接复用

### 5. ROS 五大特点 [17:12-24:30] ★ 考试重点

| # | 特点 | 要点 |
|---|------|------|
| 1 | **点对点设计** | 基于 TCP/IP 的分布式网络；节点间通信方式：**话题**（异步，发布/订阅）和**服务**（同步，请求/响应）；节点可跨主机分布 |
| 2 | **多语言支持** | 支持 C++、Python、Java 等；C++ 功能更强但语法繁琐，Python 简洁适合初学者；老师考虑明年 ROS2 改用 Python |
| 3 | **架构精简，集成度高** | 模块化框架，每个功能节点可独立编译；节点间通过消息接口实现移植和复用；开源社区已有大量现成代码（如视觉算法） |
| 4 | **组件化工具包丰富** | **RViz**（可视化工具，显示机器人模型/传感器数据）、**Gazebo**（仿真环境） |
| 5 | **开源免费** | 免费+开源是 ROS 成为主流平台的关键因素；缺点：遇到问题需自行解决 |

### 6. ROS 版本历史 [24:30-32:26]

- **2010**：第一版 ROS 1.0 "Box"（乌龟主题）
- **命名规律**：按英文字母顺序，每个版本名字均在首字母基础上保持两个单词首字母相同（如 Noetic Ninjemys）
- **本课程使用**：**Noetic Ninjemys**（2020 年 5 月发布，ROS1 最后一个 LTS，已于 2025 年结束官方支持，但仍可用）
- **教材使用**：Kinetic Kame（2016 LTS，已停止支持）
- **配套 Ubuntu**：**20.04 Focal Fossa**
- **版本类型**：
  - **LTS（长期支持版）**：5 年维护，推荐课程使用
  - **非 LTS**：2 年支持，追求新功能时使用
- **世界乌龟日**（5 月）：ROS 每年在该日期发布新版本；乌龟作为吉祥物与 Linux 企鹅类似，便于推广

### 7. Linux 基础 [32:28-36:17]

- **操作系统**：管理和控制计算机硬件与软件资源的程序，直接运行在裸机上
- **Linux**：自由开源类 UNIX 操作系统，1991 年由芬兰赫尔辛基大学学生 Linus Torvalds 开发
  - **内核 (Kernel)**：最底层基础模块
  - **发行版 (Distribution)**：内核 + 工具软件打包（Ubuntu、Red Hat、红旗等）
- **企鹅标志**：Linus 曾遭企鹅咬伤

### 8. 环境搭建：虚拟机安装 [37:57-51:25]

**虚拟机 vs 原生安装对比**：

| 方面 | 虚拟机 | 原生安装 |
|------|--------|----------|
| 难易度 | 容易 | 复杂 |
| 硬件兼容性 | 统一配置，兼容性好 | 需自行解决驱动 |
| 性能 | 较低（软件模拟） | 高（直接运行于硬件） |
| 备份/迁移 | 简单（直接复制文件） | 麻烦 |

**安装步骤**：
1. 下载 **Ubuntu 20.04 LTS** 镜像（官网 [ubuntu.com](http://ubuntu.com) → Downloads → Other downloads → Past releases → 选择 20.04 → 64-bit PC desktop image）
2. 安装 **VirtualBox**（老师推荐 16.1 版，约 200+ MB）
3. 创建虚拟机 → 配置内存/CPU → 加载镜像 → 开始安装
4. 建议：**课前带电脑**跟做，或课后自行复习；虚拟机坏了可找同学拷贝，无需重装
