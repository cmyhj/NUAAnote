## 学习路线建议

```
第1步：理解 ROS 是什么（第1章）
  ↓  安装 ROS Noetic，运行小乌龟例程
第2步：掌握 ROS 架构与通信机制（第2章）
  ↓  理解节点、话题、服务、Master 的概念和关系
第3步：动手编程（第3章）
  ↓  Publisher/Subscriber → Server/Client → 自定义消息
第4步：熟练使用工具链（第4章）
  ↓  launch → TF → rqt → rviz → Gazebo → rosbag
第5步：建模与仿真（第5章）
  ↓  URDF → XACRO → Gazebo 仿真 → ros_control
第6步：SLAM 与导航（第6章）
  ↓  gmapping → amcl → move_base → 完整导航栈
  
第7步：展望 ROS2（第7章）
  ↓  理解 ROS1 局限 → DDS → QoS → 迁移路径
```

# **快速记忆**

1.ROS的设计目标是提高机器人研发中的软件复用率
2.ROS主要有以下几个特点: 
(1）点对点的设计
(2）多语言支持 
(3）架构精简、集成度高 
(4）组件化工具包丰富 
(5）免费并且开源
3.ROS Noetic Ninjemys--Ubuntu20.04 Focal
