## 5.1 URDF —— 统一机器人描述格式

### 5.1.1 什么是 URDF

URDF（Unified Robot Description Format）是 ROS 中机器人模型的 XML 描述格式。通过 URDF，可以完整定义机器人的几何结构、运动学关系和物理属性。

一个 URDF 模型由两类核心元素构成：**link（连杆）**和**joint（关节）**。

### 5.1.2 `<link>` 标签

`<link>` 描述机器人刚体部分的外观和物理属性：

```xml
<link name="base_link">
    <visual>           <!-- 外观：网格模型、颜色、尺寸 -->
        <geometry>...</geometry>
        <material>...</material>
    </visual>
    <collision>        <!-- 碰撞检测区域 -->
        <geometry>...</geometry>
    </collision>
    <inertial>         <!-- 惯性参数：质量、质心、惯性矩阵 -->
        <mass value="1.0"/>
        <inertia .../>
    </inertial>
</link>
```

三个子标签的用途：

| 子标签 | 用途 | 备注 |
|--------|------|------|
| `<visual>` | 外观渲染（rviz 中显示） | 网格文件、颜色、尺寸 |
| `<collision>` | 碰撞检测范围 | 可比 visual 区域大（简化计算） |
| `<inertial>` | 质量与惯性矩阵 | Gazebo 动力学仿真必需 |

### 5.1.3 `<joint>` 标签

`<joint>` 描述两个连杆之间的连接关系：

```xml
<joint name="joint_name" type="revolute">
    <parent link="parent_link"/>
    <child link="child_link"/>
    <origin xyz="0 0 0.1" rpy="0 0 0"/>      <!-- 相对位姿 -->
    <axis xyz="0 0 1"/>                        <!-- 旋转/滑动轴 -->
    <limit lower="-1.57" upper="1.57" effort="10" velocity="1.0"/>
</joint>
```

**六种关节类型：**

| 类型 | 说明 |
|------|------|
| `revolute` | 旋转副——有角度限位 |
| `continuous` | 旋转副——无角度限位（连续旋转，如轮子） |
| `prismatic` | 滑动副——沿轴平移 |
| `fixed` | 固定连接——两连杆无相对运动 |
| `floating` | 浮动——六自由度 |
| `planar` | 平面运动——三自由度 |

## 5.2 XACRO —— URDF 的宏优化

### 5.2.1 为什么需要 XACRO

手动编写 URDF 的 XML 代码非常繁琐，尤其是多关节机器人，大量重复的 link/joint 代码使维护困难。XACRO（XML Macros）通过**宏定义、变量、文件引用**简化重复结构的编写。

### 5.2.2 XACRO 核心语法

```xml
<!-- 定义属性变量 -->
<xacro:property name="wheel_radius" value="0.05"/>
<xacro:property name="wheel_width" value="0.02"/>

<!-- 定义宏模板 -->
<xacro:macro name="wheel" params="prefix parent reflect">
    <joint name="${prefix}_wheel_joint" type="continuous">
        <origin xyz="${reflect*0.1} 0 ${-wheel_radius}" rpy="0 0 0"/>
        <parent link="${parent}"/>
        <child link="${prefix}_wheel"/>
        <axis xyz="0 1 0"/>
    </joint>
    <link name="${prefix}_wheel">
        ...
    </link>
</xacro:macro>

<!-- 调用宏 -->
<xacro:wheel prefix="left" parent="base_link" reflect="1"/>
<xacro:wheel prefix="right" parent="base_link" reflect="-1"/>

<!-- 引用外部文件 -->
<xacro:include filename="$(find pkg)/urdf/sensors.xacro"/>
```

XACRO 文件需经 `xacro` 命令编译为纯 URDF 后才能被 ROS 工具加载：
```bash
xacro model.xacro > model.urdf
```

## 5.3 Gazebo 仿真集成

### 5.3.1 `<gazebo>` 扩展标签

URDF 本身只定义几何与运动学，要使其在 Gazebo 中具备物理行为，需要通过 `<gazebo>` 标签补充：

- **material（材质）**：颜色与纹理
- **inertial（惯性）**：质量、质心、惯性矩阵
- **collision（碰撞）**：碰撞检测几何体
- **transmission（传动装置）**：电机与关节的扭矩传递
- **sensor（传感器）**：激光雷达、摄像头插件

### 5.3.2 差速驱动模型

差速驱动是移动机器人最常见的底盘模型，Gazebo 通过 `libgazebo_ros_diff_drive.so` 插件实现：

- 订阅 `/cmd_vel` 获取速度指令
- 根据两轮差速公式计算左右轮角速度
- 发布 `/odom` 里程计数据与 `/tf` 变换

## 5.4 ros_control 控制框架

### 5.4.1 框架概述

ros_control 是 ROS 中机器人控制的标准化框架，解耦了控制算法与硬件驱动。同一套控制器代码可在 Gazebo 仿真和真实硬件上运行。

### 5.4.2 三层架构

```
┌──────────────────────────────────────┐
│     Controller Manager                │
│  (加载、启动、切换控制器)              │
├──────────────────────────────────────┤
│     Controller                        │
│  (具体控制算法：位置/速度/力矩)         │
├──────────────────────────────────────┤
│     Hardware Interface                │
│  (抽象硬件：read() → 读状态            │
│            write() → 写指令)           │
└──────────────────────────────────────┘
```

- **Controller Manager**：从 YAML 配置文件读取控制器类型和参数，管理控制器的生命周期
- **Controller**：实现具体控制算法。按模式分为位置控制（position）、速度控制（velocity）、力矩控制（effort）
- **Hardware Interface**：定义 `read()` 和 `write()` 标准接口，不同平台各自实现 `RobotHW` 基类

### 5.4.3 `<transmission>` 标签

URDF 中的 `<transmission>` 标签是 ros_control 集成的关键，定义执行器（电机）到关节的映射关系和机械传动参数。

## 本章小结

1. **URDF**：用 XML 描述机器人结构，核心元素为 `<link>`（刚体）和 `<joint>`（关节）
2. **`<link>`** 三个子标签：`<visual>`（外观）、`<collision>`（碰撞）、`<inertial>`（惯性）
3. **`<joint>`** 六种类型：revolute、continuous、prismatic、fixed、floating、planar
4. **XACRO**：用宏定义和变量简化 URDF 编写，需编译为纯 URDF 后使用
5. **`<gazebo>`** 标签：为 URDF 模型添加物理仿真属性
6. **ros_control**：三层架构（Controller Manager → Controller → Hardware Interface），统一仿真与实机控制
